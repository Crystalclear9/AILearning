## 1. 来源分组

同一视频相邻帧、同一人不同照片或同一设备批次可能高度相关。划分应对应新场景：新身份按身份，新设备按设备，未来按时间。随机图片划分可能只测近重复记忆。

<a id="sec-1-1"></a>

### 基础算例：同来源随机划分与新来源测试不同

一段视频切成相邻帧后随机分配，训练与测试可能含几乎相同背景和对象；测试新摄像头则面对新的成像与来源。两种分数回答不同问题。若部署目标是新摄像头，应按来源留出并检查类别覆盖；还可在已有来源上研究时间变化。整体准确率之外附来源样本数和错误类型，避免大来源掩盖小来源失败。

<a id="deep-dive-1"></a>

### 深入讲解：视觉审计如何区分真实泛化与来源捷径

先列真实部署的新单位：新患者、设备、工件、地点或视频。把同源近重复整体划到同一侧，才能检验对应泛化；随机按文件拆开可能只测试记忆同一对象的外观。

按类别、大小、亮度和来源审查数量与标签一致性。某类只在一种背景出现时，模型可以用背景而非目标判断；加入更多同背景样本未必解决，需要对照和覆盖。

鲁棒测试分自然新来源与合成干预。压缩、噪声、裁剪强度应现实且保持标签可判断，裁掉目标后沿用原标签会改变任务。背景替换还可能引入伪影，应与自然样本共同解释。

交付契约记录输入、尺寸、类别和后处理，固定已知样本对齐训练与部署入口。时延和峰值内存需在代表负载测量，不由参数数目推断。

将失败列为可解释类别，提出相应验证实验。审计目的不是把数据清得只剩容易样本，而是明确模型使用的信息和结论实际覆盖范围。

<a id="sec-2"></a>

## 2. 分层检查

按光照、遮挡、分辨率、目标尺寸、来源和罕见类别检查。总体平均掩盖某组失败时，应报告组支持度与错误示例。人工查看前先固定抽样规则，避免只选符合解释的案例。

<a id="sec-2-1"></a>

### 机制展开：分层分析要保留统计分母

按类别、尺寸、来源、清晰度划分错误时，每组都给样本或实例数，指标聚合也说明按图、对象还是像素。某小组极差可能是真实弱点，也可能估计波动大，反复筛选最大差异还含探索选择。将发现形成假设，再用开发或新来源验证；数据质量、缺失与难度分别检查，不能只依据一张分组表判定唯一根因。

<a id="sec-3"></a>

## 3. 分布变化测试

加入合理噪声、压缩、亮度和裁剪检查稳健性，但强度要反映真实使用。模型对某干预敏感不必然证明使用了错误线索，因为干预可能破坏目标信息。应结合背景对照与新来源数据。

可建立“来源×干预强度×类别”表：在真实新来源数据上评价，再对原样本施加多档可解释扰动，比较相对退化和失败数。噪声、压缩及亮度参数要记录，并抽查标签是否仍可辨；裁剪若移除了目标，不能继续沿用原分类标签或原框而当成一般鲁棒性测试。

同时保留未经干预的对照，避免只见扰动后分数而不知道基线。若要检验背景捷径，可保持前景目标并改变背景，再辅以自然新背景样本；合成替换的边缘伪影本身也可能改变模型行为。

<a id="sec-4"></a>

## 4. 交付说明

记录通道顺序、数值范围、尺寸、类别映射、后处理阈值及评价协议。部署前用已知样例核对训练推理一致，测时延与峰值内存。更新模型时同时回归旧场景与新场景。

将预处理与后处理写成完整契约：输入颜色空间及通道顺序、缩放和裁剪、归一化、输出类别表、框坐标含义及阈值。对同一原始图像比较训练评价入口与部署入口，核对中间张量和最终预测；文件加载成功不能代替这个一致性检查。

提供固定的正常、边界和失败样例，说明测试过的分辨率、来源及设备条件。延迟测量写明批量和预热，峰值内存写明精度。版本更新同时检查旧场景与新增场景，记录退化和恢复方式，使交付结果能够被独立复核。

<a id="sec-5"></a>

## 5. 代表性测试比简单加扰动更重要

人工噪声测试提供局部稳健性线索，真实新设备和新环境则可能同时改变光学、背景和采样机制。两者互补，不能用几十种合成扰动替代实际部署数据。采集测试应先定义场景覆盖和独立单位。

错误审计可随机抽取正确与错误样本，并额外查看高置信度错误。只看错误会低估总体，也可能无法发现数据泄漏带来的虚假正确；只看高分例子则隐藏失败。抽样规则与统计表一起记录。

部署版本应关联预处理、权重和后处理阈值。改变检测阈值可能减少误报却降低召回，不能当作同一模型质量无变化。每次更新都按相同协议比较，并保留关键场景的回归样本。

<a id="sec-6"></a>

## 6. 进阶：域偏移与捷径的可证伪分析

背景替换、遮挡和设备外测试可以检验捷径假设，但人工干预可能产生分布外伪影，单一实验不能唯一证明依赖机制。应结合来源分组、自然反例与多种干预，区分相关证据和因果结论。

稳健性报告要预设扰动强度、样本覆盖与独立单位，防止按结果挑场景。校准、错误代价和最坏子组表现可能与平均准确率不同，部署判断应多维比较，并报告尚无证据的范围。

<a id="sec-6-1"></a>

### 用来源干预识别视觉捷径

若同一设备或同一患者的相似图像跨训练和测试，模型可能利用来源特征而非任务内容。应按真正部署面对的独立单位划分，例如对象、地点、拍摄会话或时间。随机图片划分回答的是另一种更接近同来源插值的问题。

可以遮挡背景、交换背景或改变无关水印，观察预测是否显著变化；这些干预用于检验捷径假设，但要确认未同时破坏目标信息。鲁棒性测试应包括代表性自然变化，不能只用几个方便生成的人工噪声就概括现实域偏移。

报告把整体性能与关键来源分组并列，附样本数和失败类型。某组差可能来自标签质量、可见信息缺失或分布差异，单看模型分数无法区分。先验证数据与任务机制，再决定补数据、改增强或调整架构。

<a id="sec-7"></a>

## 7. 练习与解析

**题目：** 实验室照片准确率 99%，户外只有 70%，如何组织排查？

**解析：** 先检查预处理与标签一致，再按光照、背景、尺度与设备分组；收集代表性户外验证样本，比较适配方案。不能直接用实验室总体分数支持户外可靠性。

<a id="sec-8-2"></a>

### 边界追问：人工噪声鲁棒是否等于自然域鲁棒

**问题：** 在高斯噪声测试稳定，能否声称新摄像头、夜间和新地点都可靠？

**推理解析：** 不能，扰动机制不同。应选代表性自然来源和时间变化，检查标签、成像与捷径。人工扰动可测试某类敏感性，但不覆盖全部外部泛化。按来源与样本量报告，并用对应独立数据确认，不从单一压力测试推全面结论。

<a id="sec-8"></a>

## 8. 进阶研究练习与解析

**问题：** 证明二值区域 Dice 与 IoU 的关系，并解释平均后为何不能直接换算。

**解析：** 令交集 I、并集 U，两个区域面积和为 U+I，因此 Dice=$2I/(U+I)=2IoU/(1+IoU)$。该变换非线性，逐图或逐类变换后平均通常不等于对平均 IoU 变换。评价中还需处理空区域和忽略标签规则。

**研究设计：** 构造大小目标与不同背景比例，比较像素准确率、各类 IoU 和 Dice，展示一个模型背景很准但小目标全漏。固定评价协议，避免用不同平均规则夸大改善。

<a id="sec-8-1"></a>

### 综合练习：识别小目标退化而总体指标稳定

**问题：** 总体 mIoU 变化很小，但小目标完全漏掉，怎样报告？

**逐步解析与验收：** 按类别、尺寸和来源拆分，给样本数、漏检与边界误差，并核对像素量程、缩放和标注。背景或大对象可掩盖小对象失败。验收把训练目标、指标聚合与真实任务代价对应，不能以总体均值稳定否认关键群体退化。
