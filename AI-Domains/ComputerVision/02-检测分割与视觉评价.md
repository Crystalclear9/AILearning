## 1. 不同任务有不同标签结构

目标检测输出类别、位置框和置信度，一张图可能有多个目标。语义分割为每个像素分配类别，实例分割还区分同类不同对象。检测框常有左上右下或中心宽高两种表示，数据变换后必须同步变换标注。

检测通常需要在分类与定位之间共同优化。非极大值抑制通过重叠关系去除重复框，但阈值设置可能影响拥挤场景中的相邻目标；现代检测器也有不同的去重设计，不能认为全部依赖同一种后处理。

<a id="sec-2"></a>

## 2. IoU 与 AP

IoU 为预测区域与真实区域的交集面积除以并集面积。检测中还需根据类别、置信度顺序和匹配规则判定 TP、FP，再计算精确率召回率曲线和 AP。AP@0.5 与对多个 IoU 阈值平均的 AP 不是同一指标，报告时应说明评估协议。

分割常报告各类 IoU、均值 IoU 或 Dice。像素准确率可能被大面积背景主导；小目标即使完全漏掉，总体像素准确率也可能很高。

<a id="sec-1-1"></a>

### 基础算例：一对检测框算出 IoU

真实框和预测框均为面积 100 的正方形，交集面积为 50，则并集为 100+100-50=150，IoU 为 1/3，不是 1/2。若评价阈值为 0.5，这个预测不能算满足定位条件；分类正确仍可能因定位失败成为错误。多个预测对应同一目标还需遵守匹配和去重规则。先用这些小框核对坐标与面积约定，再解释完整 AP 数值。

<a id="sec-2-1"></a>

### 机制展开：AP 汇总的是排序后的匹配过程

按置信度从高到低处理预测，在规定类别和 IoU 下与真实对象匹配，再累计精确率和召回。重复预测不能多次领取同一真实对象的真阳收益。AP 插值、IoU 阈值和类别平均方式依协议而异，AP50 与跨阈值平均不能混称。报告还要区分类别错、定位错和漏检，避免一个总体数掩盖机制不同的失败。

<a id="deep-dive-2"></a>

### 深入讲解：检测匹配与分割指标中的分母到底是什么

IoU=交集面积/并集面积，衡量区域重叠。检测还要求类别与一对一匹配：一个真目标通常最多匹配一个预测，重复框会算额外假阳性。仅看到每个物体上有框，不代表precision高。

AP依预测分数排序及匹配阈值建立precision-recall汇总，具体插值和多阈值协议需说明。不同IoU、类别平均和候选过滤不是同一指标，不能只写一个“AP”就跨实验比较。

语义分割按像素类别，实例分割还区分同类不同对象。Dice=2交集/(两区域面积和)，IoU与之相关却不同；按全像素、逐图或逐类平均会改变小对象权重。

忽略区域与未标注目标要按协议处理，不能一律当背景。数据不平衡时像素准确率可能很高却漏掉全部小目标，因此应看类别重叠、漏检与边界。

用两目标、三预测的小图手工匹配，逐个写TP/FP/FN，再比较不同阈值。这个算例能解释后处理和排序为何影响最终指标，而不是仅背公式。

<a id="sec-3"></a>

## 3. 数据划分与误差分析

同一视频的相邻帧、同一工件的多角度照片可能非常相似，应按来源分组划分。对检测应区分漏检、重复框、类别错和定位偏；对分割应区分边界误差与小区域遗漏，再针对原因改进。

先以真实部署中新出现的单位决定划分：新视频、新工件、新患者或新拍摄设备是不同泛化目标。将同源样本放在同一侧，再检查文件哈希、近重复及类别覆盖；若需要按时间外推，还要保留时间顺序。来源分组后分数下降，可能是原协议过于容易，并不表示分组方法错误。

误差分析使用固定样本与类别统计，并保存真值和预测叠加图。漏检集中在小目标时查分辨率和采样，框已覆盖但类别错误时查类别混淆，重复框偏多时查匹配与后处理。每次调整都在验证集确认，避免看测试错误后反复设计规则。

<a id="sec-4"></a>

## 4. 定位误差会影响检测的真阳性判断

一个框类别正确但位置偏移，IoU 未达到阈值时仍可能被算作未匹配预测，同时真实对象被漏检。提高定位精度与提高分类置信度是不同方向，因此应分开检查。置信度阈值改变保留框数量，IoU 匹配阈值改变正确框的定义，二者不能混淆。

分割的小目标评价还会受边界影响：同样偏移几个像素，大目标的 IoU 变化不大，小目标可能大幅下降。应按尺寸分组分析，并检查标注一致性。标注边界本身存在歧义时，单个指标不能完整代表实际视觉质量。

<a id="sec-5"></a>

## 5. 检测的匹配与重复预测

同一真实目标通常只允许一个预测匹配，其他重复框可能算假阳性。因此只看框是否覆盖物体不够，还要检查类别、分数排序与一对一匹配规则。

分割标注的边界和忽略区域也需进入评价；若把未标注区域当背景，可能惩罚合理预测。所有指标都应附数据协议，而不是只给 AP 或 IoU 名称。

<a id="sec-6"></a>

## 6. 进阶：AP与区域指标的评价约定

检测 AP 由置信度排序、类别和 IoU 阈值下的匹配共同决定，重复框通常形成额外假阳性。不同插值、平均阈值与最大检测数会改变数值，AP@0.5 不等于多阈值平均，必须报告协议。

分割 Dice 与 IoU 在单个二值区域满足 $Dice=2IoU/(1+IoU)$，但先逐类平均再换算通常不等价。背景比例、忽略区域与小目标影响也不同，总体像素准确率不能替代这些结构评价。

<a id="sec-6-1"></a>

### AP 的匹配规则怎样影响检测结论

IoU 为预测框与真实框交集面积除以并集面积。检测评价先按置信度排序，再在规定类别和 IoU 阈值下匹配真实对象；同一真实对象被重复预测时，额外预测通常不能重复计真阳。定位误差、分类错误与重复框会通过不同机制影响精确率—召回曲线。

AP 依赖阈值、插值和汇总协议，不是所有数据集都采用相同定义。COCO 类评价还跨多个 IoU 阈值和对象尺度汇总，因此单个 AP50 不能替代全部定位质量。实例数少时，少数框的匹配变化可能显著改变数值，应同时观察样本数量。

分割任务还要区分逐像素准确率、类别平均 IoU 和实例级指标。背景占比很大时，全像素准确率可能掩盖小目标完全失败。先确定任务单位是图、像素还是对象实例，再选择聚合方式与可解释的分组结果。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 真实区域和预测区域面积均为 100，交集面积为 60，IoU 与 Dice 各是多少？

**答案：** 并集为 140，IoU 为 $60/140\approx0.429$；Dice 为 $2\times60/(100+100)=0.6$。它们刻画重叠但数值标尺不同，不应混用阈值。

<a id="sec-7-1"></a>

### 边界追问：高 AP50 是否证明精确定位

**问题：** 模型在 IoU=0.5 表现好，在更高阈值明显下降，应怎样解释？

**推理解析：** 分类与粗定位可能有效，但框的精细位置仍差。报告跨阈值和对象尺寸结果，区分定位、漏检与重复。不同 AP 约定不能混称同一数值；改置信阈值也不自动修复坐标尺度或解码错误。先核对匹配与标注，再判断结构改进。
