## 1. 图像是具有空间结构的信号

彩色图像通常包含三个颜色通道，但读取库可能采用 RGB 或 BGR，张量也可能为 HWC 或 CHW。像素值范围可能是 0 到 255、0 到 1，或经过标准化。通道与范围错误不一定引发异常，却会显著改变模型输入分布。

分辨率与裁剪会改变可见内容；缩小图像可能抹掉微小目标，中心裁剪可能把关键对象裁掉。预处理必须服务任务，而不是机械套用某个尺寸。

<a id="sec-1-1"></a>

### 基础算例：同一图像张量的轴顺序不同

彩色图像在文件读取后常按 H×W×3 表达，模型可能要求 3×H×W。交换轴应使用转置语义，不能随意 reshape；后者可能重新解释元素排列而破坏颜色与空间对应。检查时选一个已知像素，追踪三个通道的值，再核对量程和颜色顺序。训练前可视化应使用完成预处理后的样本并正确逆变换，避免原图正常而模型实际输入已错。

<a id="deep-dive-1"></a>

### 深入讲解：图像表示预处理与标签不变性怎样决定学习对象

图像张量包含空间与通道语义，不同库可能使用RGB/BGR、HWC/CHW及不同数值范围。转成正确shape还不够，通道交换或重复归一会让同一像素变成另一输入。先用固定彩色小图逐步核对。

分类将整图映成类别，裁剪目标再分类与杂乱整图分类拥有不同信息。预训练输入约定、目标尺寸和类别表必须与任务一致，不能只更换最后一层便忽略数据来源。

增强假设标签在变换下保持。水平翻转对某些物体合理，对方向文字或左右语义可能改变目标；检测与分割还需同步变换框和掩码。视觉检查变换后成对标注，是必要的接口验证。

迁移学习冻结与解冻改变适应自由度，运行统计、学习率和验证策略也会影响。用合理基线和同预算比较，才能区分预训练信息、数据量与模型结构收益。

评价按来源分组，避免同视频相邻帧或同物体多角度跨集合。模型性能应对应实际要遇见的新对象和拍摄条件，而不只是随机文件划分下的重复识别。

<a id="sec-2"></a>

## 2. 图像分类输出什么

单标签分类为整张图给一个类别，多标签分类允许多个类别同时成立。两者的输出归一化和损失不同。CNN 利用局部结构与参数共享，视觉 Transformer 把图像划成 patch 并通过注意力建模关系；模型是否合适还取决于预训练、数据规模和计算预算。

迁移学习通常先用预训练骨干提取特征，再训练新分类头，随后按验证表现决定是否微调。输入归一化要匹配预训练要求，冻结参数后也需注意归一化层的训练与评估行为。

<a id="sec-2-1"></a>

### 机制展开：分类输出空间由标签关系决定

互斥 K 类通常输出 K 个 logits 经归一比较，多标签则为每类独立事件建模；同一图有猫和狗时，强制 Softmax 会制造不必要竞争。训练需对应整数索引或多热目标，评价再按任务计算类别或样本指标。类别不平衡、置信阈值和拒答属于不同环节。先明确标签能否同时成立，再选择输出与损失，而不是按模型默认头部反推任务定义。

<a id="sec-3"></a>

## 3. 增强必须保留标签含义

翻转、旋转、颜色扰动可能改善鲁棒性，但字符识别随意旋转、医学影像任意翻转或颜色敏感任务大幅变色，都可能改变标签语义。增强参数应只在训练阶段随机采样，验证与测试遵循固定协议。

实现增强时先确认作用对象：检测框、分割掩码与图像必须共享同一次几何变换；掩码缩放一般需要保持离散标签，不能用产生混合类别值的普通连续插值。先可视化变换前后的成对样本，再训练。验证阶段只保留固定的尺寸与数值处理；若使用测试时增强，应单独说明变换集合、预测合并和额外成本。

检查增强收益时固定数据划分和训练预算，分别查看整体表现与受影响类别。某增强改善多数类却损害方向敏感类别时，应调整适用范围或强度，而不是仅凭总准确率保留。

<a id="sec-4"></a>

## 4. 数据偏差可能比架构更关键

若所有猫照片来自室内、狗照片来自草地，模型可能依赖背景而非动物。可以交换或遮挡背景、收集跨场景数据、按来源分别评估，检查这种捷径。总体准确率很高，也不能排除某些场景完全失败。

采集设备、压缩格式与拍摄日期也可能泄漏类别。训练与测试中相同拍摄批次混合，容易让评估高估新设备泛化。数据说明应包括来源与分组规则，误差分析则按场景、目标大小和图像质量查看，而不只按类别汇总。

<a id="sec-5"></a>

## 5. 标签质量与观察范围

图像类别可能依赖拍摄者背景知识，而非像素本身。标注时要定义可见目标、模糊情况与排除规则，检查不同标注者一致性。数据难例与错误标签应分开，不能所有低分案例都归咎模型。

视觉任务还要说明输入场景：整图、裁剪对象或连续视频包含不同信息。用人工裁剪的理想输入训练，却部署到杂乱整图，评估并不匹配。

<a id="sec-6"></a>

## 6. 进阶：增强表达的对称性假设

数据增强把某类变换视为标签不变或标签等变。例如分类翻转可能不变，检测框必须同步变换，字符旋转则可能改变类别。增强并非无条件增加有效样本，而是向学习过程注入任务假设。

可比较无增强、合法增强和破坏标签增强，控制预算检查收益机制。预训练的影响也需区分源数据、结构和优化。只在同拍摄来源随机划分，不足以证明新设备或新场景鲁棒性。

<a id="sec-6-1"></a>

### 视觉数据的表示单位与增强假设

一张图可表示为 H×W×C 或 C×H×W，通道顺序、颜色空间和像素量程都属于输入协议。归一化把数值变换到模型预期范围，但不能恢复丢失细节。调整分辨率还改变小目标是否可见，因此比较模型时需记录 resize、裁剪和插值方式。

增强相当于提出标签应在某类变换下保持的假设。左右翻转常适合部分物体分类，却可能改变文字、交通标志或方向性标签；旋转数字也可能改变含义。应先人工检查变换后的样本，再衡量验证收益，不能只因增强增加多样性就默认合理。

迁移学习可先冻结编码器训练分类头，再按验证协议决定是否解冻。数据少或来源偏移大时，两者效果取决于已有表示与新任务的匹配。报告不仅包括准确率，还应给类别支持数、错误样例和来源划分，避免背景捷径被误认为物体理解。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 区分红灯与绿灯时，强烈随机改变颜色是否总是合理？为什么？

**答案：** 不合理，颜色本身就是标签依据。增强应模拟任务允许的变化，不能把决定类别的信息随机破坏后仍保留原标签。

<a id="sec-7-1"></a>

### 边界追问：单标签头能否直接处理多对象共存

**问题：** 同一图可同时有猫和狗，使用只允许一类的 softmax 输出会引入什么约束？

**推理解析：** 它强迫类别相互竞争，无法直接表达两个独立事件都高概率。先确定任务是互斥分类、多标签还是检测，再选目标和损失。修改阈值不能修复错误标签空间；数据、输出与评价单位必须一致，不能只依模型默认头部定义任务。
