## 1. 目标检测的组成

典型检测器含骨干特征、多尺度处理、类别预测与位置回归。两阶段方法先产生候选再分类回归，单阶段方法直接在特征上输出候选；基于集合预测的方案则采用不同匹配与去重机制。不同设计处理目标数量、尺度和重复的方式不同。

框回归可预测角点、中心宽高或相对偏移。训练标签编码、图像缩放与推理解码必须一致，否则预测可能形状合法却全部错位。随机翻转、裁剪后，框与 mask 都要同步更新。

<a id="sec-1-1"></a>

### 基础算例：图像缩放时框坐标同步变换

原图 100×200，连续坐标框为 (20,10,60,50)，图像宽高同时缩半后，新框为 (10,5,30,25)。若再裁掉左侧 5 个新像素，横坐标需再减 5，并处理超出裁剪范围的部分。标签不能只保持四个数不变，也不能独立归一而忘记后续解码。把增强后框重新画回图像，可以直接发现尺度、平移、通道或端点约定错误。

<a id="deep-dive-1"></a>

### 深入讲解：从候选定位到后处理的检测流水线如何协同

检测通常同时预测位置与类别，训练还需决定哪个候选对应哪个真目标。匹配或分配规则决定监督落到哪里，位置编码决定网络回归的量；候选框、中心点或集合预测有不同设计，不能混用更新公式。

位置损失与分类损失量级不同，组合权重影响梯度。背景远多于前景，采样、类别权重或专门损失改变训练偏好；只看总loss下降可能漏掉定位或稀有类别退化。

后处理阈值和重复抑制影响召回与重复框。过强抑制可能删去拥挤场景相邻对象，过弱则产生假阳性；应在验证确定，并报告实际参数。

分割像素目标还需处理类别、忽略标签和空前景。交叉熵强调局部概率，Dice类项强调区域重叠，按图还是按批归约也改变行为；两者结合应分别监控。

完整验收要看预处理坐标、预测解码、反缩放及匹配评价。框在缩放图上正确但映回原图错位，属于接口错误，而不是模型定位能力低。

<a id="sec-2"></a>

## 2. 语义与实例分割

语义分割输出每像素类别，编码器提取上下文，解码器恢复空间分辨率；跳连可结合浅层细节。实例分割进一步分开同类不同对象，不能只靠像素类别图自动得到所有实例。

<a id="sec-2-1"></a>

### 机制展开：像素语义与对象实例是不同标签结构

语义 mask 给每个像素类别，同类两个相连对象仍可拥有相同类别；实例任务还需区分对象身份。解码器上采样和跳连恢复可利用的空间信息，不自动生成实例划分。离散类别 mask 缩放应保持标签语义，不能无条件用产生中间类别值的插值。先画标签网格与对象集合，再设计批量接口、损失和匹配，避免输出尺寸正确但任务已改变。

<a id="sec-3"></a>

## 3. 损失与不平衡

背景通常占多数，简单像素准确率容易掩盖小目标。交叉熵、Dice 类损失或其他设计有不同侧重，类别权重改变错误代价。框损失与分类损失的相对尺度也要监控，不能只观察总损失。

以二值分割为例，预测概率 $p_i$、标签 $y_i\in\{0,1\}$，一种 soft Dice 损失为 $1-(2\sum_i p_i y_i+\epsilon)/(\sum_i p_i+\sum_i y_i+\epsilon)$。它直接关注区域重叠，与逐像素交叉熵的优化侧重点不同；分母采用平方和等其他变体时，公式与数值也改变。需说明按图像、批次还是类别归约，以及无前景图像怎样处理。

组合损失应分别记录各项未加权值、权重与梯度尺度，避免某项仅因数量级大而主导。训练集可用于确定类别权重，分割阈值在验证集选择；最终按类别报告 IoU/Dice、漏检和边界错误。对于稀有小目标，整体像素准确率很高仍可能代表完全没检出。

<a id="sec-4"></a>

## 4. 从标注到训练目标的对应

分类标签每图一个或多个，检测每图有不同数量的框，分割每图有像素网格。组批与损失归一化因此不同：检测不能假定每图目标数一样，分割不能让大面积背景不受控制地主导目标。先画输入与标签结构，才能正确设计数据集接口。

框坐标还分连续与离散端点、绝对像素与归一化比例。缩放图像时坐标必须同尺度变化，裁剪后框需要平移并处理被截目标。应在增强后把标注重新画回图像，直观核对，而不只检查数组数值范围。

分割上采样后的边界可能模糊，某些类别只有几个像素，对插值和标注噪声更敏感。总体 mIoU 之外按类别和尺寸审查，可以知道模型是在学主体还是遗漏细节。

<a id="sec-5"></a>

## 5. 进阶：集合预测与一对一匹配

检测的目标集合无天然顺序。若固定框编号回归，会把等价排列视为不同答案；集合预测通过匹配把预测与真值对应，再计算类别和位置代价。匹配规则是训练目标的一部分，不是纯后处理。

常见候选式检测与集合式检测对重复、负样本和数量有不同设计。损失下降不保证所有目标尺寸公平改善，应分别分析分类、定位和漏检。坐标约定及增强后的标签变换，仍需像素级可视核对。

<a id="sec-5-1"></a>

### 从标签结构推导模型输出与训练目标

目标检测需要同时预测类别和位置，语义分割为每个像素预测类别，实例分割还区分同类不同对象。三者输出粒度不同，数据标注不能直接互换。训练损失的分类、定位和掩码项也需分别确定匹配和归约单位。

候选式检测通常先产生较多候选再筛选，集合预测则可通过一对一匹配把无序预测与真实集合对应。匹配解决“哪个预测负责哪个对象”，不只是后处理细节；训练分配规则与评价匹配规则可以不同，但必须各自明确。

类别不平衡既可能来自对象频率，也可能来自大量背景位置。采样、损失权重和难例处理各改变不同部分，不能只用总体损失下降证明稀有对象改善。应按类别、尺寸、遮挡和定位阈值检查错误，并核对增强后标签几何是否同步更新。

<a id="sec-6"></a>

## 6. 练习与解析

**题目：** 图像水平翻转，原宽度 W、框横坐标为 $[x_1,x_2]$，连续坐标下新框是什么？

**解析：** 变为 $[W-x_2,W-x_1]$；离散像素端点约定可能涉及 W-1，应与标注格式一致。高度不变，不能只翻图不翻标签。

<a id="sec-6-1"></a>

### 边界追问：语义 mask 能否自动给每个实例身份

**问题：** 两个同类相连对象在语义图中连为一片，能否靠相同像素类别恢复唯一实例？

**推理解析：** 一般不能，类别标签没有提供全部实例边界，需额外表示、匹配或后处理假设。插值只改变网格，不创造丢失身份。比较语义与实例方案先统一标签结构及评价单位，避免把输出尺寸相同当成同一任务已解决。
