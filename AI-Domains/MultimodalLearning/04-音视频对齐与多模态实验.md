## 1. 时间粒度

音频帧、视频帧和文本 token 具有不同采样率，需明确对齐窗口、时间戳和缺失片段。简单按数组下标对齐可能错误。长视频还需选择帧采样与时间建模，避免只凭静态场景猜动作。

<a id="sec-1-1"></a>

### 基础算例：同一事件在不同时间粒度上的配对

视频每秒多帧、音频连续采样、字幕可能按句给时间段，把第 i 帧直接配第 i 段字幕没有自然依据。应按事件时间窗对齐，明确容忍偏移与任务粒度。可将音频偏移一段时间，检查任务是否按预期退化；若不退化，可能依赖静态捷径，也可能任务本不需同步。来源与相邻片段应按合适单位划分，防止近重复泄漏。

<a id="deep-dive-1"></a>

### 深入讲解：音视频采样如何决定模型实际看见的事件

视频抽帧间隔、音频采样率和文本时间戳定义观察粒度。短事件可能完全落在两帧之间，回答失败不一定是推理不足，而是输入没有包含证据；报告应说明实际采样覆盖。

先统一时间基准和偏移，核对同一事件在画面、声音与字幕的对应。压缩、剪辑和缺帧可能破坏同步，需要保留来源及变换记录，不能仅按文件长度粗配。

任务按动作、顺序、计数和短时事件分组。交换先后、遮去关键片段或移动音轨可检验利用方式，但要确保题目仍有定义，干预不应被误当自然样本。

图文检索明确候选库和多个正例，语音任务关注噪声口音和内容，生成还需证据支持。总体平均可能掩盖模型只使用某个容易模态。

交付记录采样、时间窗、编码与融合、缺失和可见范围，并保留可核查片段。模型无法识别未采到的信息，应如实作为观察边界而非无限能力承诺。

<a id="sec-2"></a>

## 2. 模态利用检查

设立单模态基线、全部模态、打乱配对与缺失模态对照。若打乱图像几乎不影响结果，可能模型只依赖文本，或数据任务不需要图像。干预也可能产生分布外输入，应结合真实子集验证。

<a id="sec-2-1"></a>

### 机制展开：模态利用检查应包含必要信息子集

整体打乱文本不降分可能因为视觉已经足够，不能直接证明训练完全没学文本。构建必须结合两种信息的子集，再与单模态及正常、打乱配对对照，可区分任务冗余与模型忽略。时间偏移、来源替换等干预也要尽量保留其他条件。报告对照的适用范围，而非把一次分数差当作全部模态贡献的因果量。

<a id="sec-3"></a>

## 3. 任务评价

图文检索明确候选库和多个正例；视频问答按动作、顺序、计数与证据位置分组；语音任务检查噪声、口音与时间同步。总体平均不足以解释跨模态能力。

跨模态检索需说明查询方向、候选库规模与正例集合：一张图对应多条正确描述时，任一正例命中可按既定规则计入 Recall@K，不能把其他正确描述当负例。候选库越小通常任务越容易，换库后的分数不应直接比较。

视频和音频任务按时间证据设计对照，例如交换两个动作先后、遮去关键片段或移动声音时间轴。需要同时保留原始有效样本，确认干预没有使问题本身无法回答。记录动作顺序、计数、小事件及同步偏差下的表现，才能区分模型读到了信号，还是仅靠语言常识猜中。

<a id="sec-4"></a>

## 4. 交付与限制

记录各模态前处理、采样率、时间窗口、编码器与融合、可见范围及缺失策略。评价生成内容是否被实际信号支持，防止语言先验产生流畅但没有画面依据的回答。

交付示例需覆盖同一内容的原始时间轴、各模态采样位置及融合输入，以便确认字幕、画面和音频没有错位。若使用片段抽样，说明未被抽到的短事件可能无法识别，不能将抽帧模型描述为完整观看全部视频。

对生成输出保留可核查的片段或时间引用，分别检查实体、动作、顺序和数字是否受到信号支持。记录真实缺失、噪声和冲突下的行为，以及这些场景是否参与训练；未测场景应写为能力边界，避免用总体平均分掩盖关键失败。

<a id="sec-5"></a>

## 5. 时间信息与语义配对

视频每秒几十帧，音频波形每秒上万点，文字可能只给整句时间段。对齐必须按时间与窗口，不是让三个数组同长度就算同步。延迟、缺帧和字幕偏移都可能导致模型学习错误关系。

对动作顺序任务，打乱帧后性能应受到合理影响；但如果数据标签靠背景就能预测，模型可能根本不用时间。应构造相同场景不同动作或相反顺序的对照，并检查模型是否真正利用动态。

多模态缺失时的回退行为应在训练和评估体现。比如只有音频、只有文本或图像损坏，系统要明确是否仍能回答及证据来源，而不是输出与完整输入同样自信的结论。

<a id="sec-6"></a>

## 6. 进阶：时序干预与静态捷径

视频第一帧即可达到完整模型成绩，不能证明时序理解；帧打乱无影响也可能说明任务靠背景。应构造同场景不同动作、逆序与自然反例，且注意人工干预自身可能制造分布外伪影。

多模态时间轴需按时间戳与窗口对齐，不是统一数组长度。音频、字幕与视觉的延迟和缺失应纳入验证，错误配对即使有大量数据也可能强化错误关联。交付要保留各模态预处理和缺失策略。

<a id="sec-6-1"></a>

### 时间对齐决定模型学习的是内容还是偶然同步

音频、视频帧和文本具有不同采样频率与时间粒度。应先定义任务需要事件级、片段级还是帧级对应，再统一时间戳与容忍误差。简单按文件顺序配对可能保留大概主题，却无法支持细粒度时序推断。

诊断可以保留内容但打乱时间顺序、移动音画偏移或交换同来源片段，观察任务变化。若时序被破坏后仍保持高分，模型可能利用静态背景、说话者或字幕捷径；也可能任务本来不需要时序，需结合标签定义解释。

划分按人物、视频来源或会话而非任意短片段，避免相邻片段泄漏。报告单模态与联合模态、缺失模态、不同同步误差下的结果，并附样本量和来源。对齐失败属于数据机制，不能仅通过增加网络规模修复。

<a id="sec-7"></a>

## 7. 练习与解析

**题目：** 视频分类仅靠第一帧就达到完整模型分数，能否证明学到了动作时序？

**解析：** 不能，可能背景已泄漏类别。应使用需要时序才能区分的样本、帧顺序干预和跨场景验证，分离静态与动态线索。

<a id="sec-8-2"></a>

### 边界追问：时间打乱不降分是否证明时序建模成功

**问题：** 音视频顺序被打乱后分数不变，应怎样区分解释？

**推理解析：** 可能任务本不需时序，也可能模型只用背景、人物或字幕捷径。构建必须利用顺序的子集并控制其他变化，再与单模态、偏移和配对对照。不要把一次干预差值当通用因果贡献；来源与相邻片段划分也应正确。

<a id="sec-8"></a>

## 8. 进阶研究练习与解析

**问题：** 如何证明联合模型确实利用图文对应，而不是文本捷径？

**解析：** 设置文本、图像、联合与打乱配对对照，控制数据与预算。若打乱几乎无影响，可能任务无需图像或模型未利用；这本身还不能确定唯一原因。再用只有视觉证据能区分的自然子集和反事实对照验证。

**边界：** 人工置换可能生成分布外样本，应结合真实缺失和冲突情形。检索评价要允许多个合法正例，固定候选库；不能把唯一原配对当全部语义真值。

<a id="sec-8-1"></a>

### 综合练习：联合分数高但可能存在单模态捷径

**问题：** 图文模型在打乱文本后仍保持分数，怎样继续验证？

**逐步解析与验收：** 比较纯图、纯文、正常配对及确需互补信息的子集，并检查干预是否破坏了无关条件。结果可能是任务无需文本，也可能是模型忽略它。验收给竞争解释和区分对照，不把一次打乱结果直接当作所有模态贡献的因果量化。
