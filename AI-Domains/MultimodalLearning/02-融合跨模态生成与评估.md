## 1. 三种融合位置

早期融合在较低层组合原始或浅层特征；中间融合通过联合网络、交叉注意力等交换信息；后期融合组合各模态独立模型的输出。选择取决于同步程度、数据量和缺失情况，不能只按结构复杂程度判断效果。

跨注意力允许一模态查询另一模态内容。对视频和语音，还需时间对齐；字幕错位或采样不同步会让模型学习到虚假对应关系。

<a id="deep-dive-1"></a>

### 深入讲解：融合位置缺失标记与冲突规则怎样改变系统行为

早期融合合并较低层特征，中间融合让模态交互，后期融合组合独立输出。它们需要的对齐程度、数据量和缺失策略不同；更早交互不自动更强，可能增加对同步与完整输入的依赖。

跨注意力由一模态查询另一模态，合法对应可按位置、时间或关系限制。音视频采样不同步时，网络会被迫学习错误配对，不能靠增加层数解决源时间轴问题。

缺失不能仅填零而不解释，静音是一个真实观测，音轨不存在是未知。训练应包含允许的缺失组合和标识，评价按可用模态分组；若任务缺关键证据，应允许相应不确定。

冲突也由任务定义。判断画面动作应依画面，转写旁白依音频，不能通用地“视觉优先”。标注与评价若未定义规则，模型选择和错误判定都会含糊。

比较完整、单模态、屏蔽与置换时保持任务可解性，说明干预可能带来的训练外分布。这样才能区分融合收益、捷径和真正鲁棒。

<a id="sec-2"></a>

## 2. 从编码器到生成模型

视觉语言模型可把视觉特征映射到语言模型可接收的表示，再训练描述、问答或指令任务。生成流畅文本并不保证内容被图像支持，模型可能依赖语言先验猜测。例如画面没有猫，却因为上下文习惯生成“猫在沙发上”。

评估应区分对象识别、计数、空间关系、文字读取和跨模态推理，而不只看整体问答准确率。改变图像而保持问题不变，是检查模型是否真正使用视觉信息的一种对照。

<a id="sec-2-1"></a>

### 机制展开：从共享表示到条件生成多了接口

双塔对齐给可比较向量，不会自动让语言解码器理解任意视觉编码。条件生成还需投影、交叉注意力或其他连接模块，将视觉特征接入合适 token 与维度，并按目标训练。冻结编码器、训练桥接与联合微调有不同成本和遗忘风险。需分别检查对齐、融合与生成，不能用检索成功直接证明细粒度回答正确。

<a id="sec-3"></a>

## 3. 缺失与冲突场景

训练时可模拟模态缺失，检查只有文本或只有音频时的行为；模态互相矛盾时需要定义信任规则。多模态模型还可能只利用最容易的一个模态，因此应做单模态基线和模态消融。

将测试集分为模态齐全、缺失某模态、信号损坏、模态冲突四类，并保持任务目标明确。例如判断视频实际动作时，冲突字幕不应压过画面证据；若任务是转写旁白，则应按音频判断。所谓冲突必须相对于任务规则定义，不能用统一的“视觉总是优先”替代。

先比较单模态模型和完整融合模型，再分别屏蔽或置换一个模态，观察结果变化。置换可能产生训练外组合，应与真实缺失数据共同解释。若屏蔽关键模态完全不影响需要该模态的问题，优先检查数据捷径、配对错误和评价标签，而不是直接宣称模型鲁棒。

<a id="sec-4"></a>

## 4. 单模态消融与反事实对照

分别只保留图像、只保留文本、使用全部模态，可以衡量互补收益；打乱图文配对则检查模型是否利用正确对应关系。若打乱后几乎不变，可能任务依赖单模态或存在标签捷径，而非真正跨模态理解。

冲突样例也很有价值，例如文字说红色、图像显示蓝色，要预先定义回答应依据哪种证据。否则评价标签本身可能含糊。多模态系统需要同时检查各模态的质量、同步和证据来源，流畅的综合回答不能替代这些检查。

<a id="sec-1-1"></a>

### 基础算例：联合模型是否真的利用第二模态

正常图文配对准确率为 0.9，打乱文本后仍为 0.9，说明当前证据未显示文本带来必要收益；可能图像已足够，也可能模型忽略文本。再比较纯图、纯文和需要两者互补的子集，才能区分解释。干预若把输入变得完全异常，也不能直接量化真实贡献。多模态评价应针对明确假设设计对照，而非只看联合分数。

<a id="sec-5"></a>

## 5. 模态缺失不是只填零

缺失输入若用零向量代替，模型需要知道这是缺失而非真实信号。可引入缺失指示、训练期模态随机丢弃或专门分支，评价覆盖单模态可用情况。

当模态相互矛盾，任务应定义证据优先级或允许不确定回答。没有清晰标准，模型输出与评价标签都可能含糊。

真实零信号与不存在信号含义不同，例如静音音轨可能是有信息的观测，而音轨缺失表示未知。输入中应有明确缺失标记或结构化分支，并在训练与评价采用同一约定，避免模型把填零当成普通模式。

模态丢弃需要保持任务仍可解或允许表达不确定；若问题只能根据画面回答，删除画面后不能仍要求同一确定答案。按可用模态组合分别报告表现，并检查融合模型是否比对应单模态基线提供增益。缺失鲁棒与模态冲突处理需要不同测试。

<a id="sec-6"></a>

## 6. 进阶：融合收益与信息可替代性

联合模型优于单模态可能来自互补信息、额外容量或训练数据，不能只归因跨模态推理。需单模态、联合、打乱配对和缺失模态对照，尽量控制预算，检查模型是否真正使用对应信号。

跨注意力允许一模态查询另一模态，但流畅输出仍可能主要依赖语言先验。对象、计数、空间关系和时间同步应分别评价；模态冲突时任务要定义证据优先级或允许不确定回答。

<a id="sec-6-1"></a>

### 融合收益需要证明模型确实利用两种信息

早期融合在较低层联合输入，中期融合交互表示，后期融合组合决策。更早交互可能增强互补信息建模，也增加对配对、同步与缺失的依赖；后期融合简单但可能难以表达细粒度关系，没有普遍最优位置。

可比较视觉单模态、文本单模态、正常配对和打乱配对。若打乱后几乎不降，联合模型可能主要依赖单一模态或来源捷径；但干预必须保留其他条件，不能把输入分布完全破坏后作过强机制解释。

缺失模态不只是填零问题。训练中从未见过缺失状态时，零向量可能是异常输入；应定义缺失指示、回退与训练覆盖。冲突模态也需明确可信来源和任务目标，不能默认联合输入总比单模态可靠。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 多模态分类比文本模型只高 0.1%，随机替换图片后结果几乎不变，可能说明什么？

**答案：** 模型可能主要依赖文本，图片信息未被有效利用，或任务本身无需图片。应检查配对质量、视觉编码和数据偏差，并使用更需要视觉证据的评估子集。

<a id="sec-7-1"></a>

### 边界追问：缺失模态填零是否自动合理

**问题：** 训练从未见过缺图场景，上线把缺图表示全置零，能否视作正常缺失处理？

**推理解析：** 不自动，零向量可能落在异常输入区域。需定义缺失指示、回退和训练覆盖，区分语义冲突与完全缺失。比较单模态和联合方案，检查模型是否真实利用互补信息；联合输入更多不保证在所有缺失条件下可靠。
