## 1. GAN 的对抗关系

生成器把噪声 $z$ 映射到样本 $G(z)$，判别器区分真实和生成样本。原始目标为 $\min_G\max_D E_x[\log D(x)]+E_z[\log(1-D(G(z)))]$。实际常使用生成器的非饱和损失等变体，以改善训练信号。

两个网络同时更新，学习目标不断变化。判别器太弱提供不了有效方向，过强也可能让某些目标下梯度不理想。损失数值不能像普通固定标签监督学习那样直接解读为生成质量。

<a id="sec-1-1"></a>

### 基础算例：判别器分数与生成器目标不能混称

对一张生成样本，判别器输出 D=0.1，非饱和生成器损失为 -log0.1，约 2.303；原始饱和形式涉及 log(1-D)，梯度行为不同。判别器则同时使用真实和生成样本优化自己的区分目标。训练中需说明当前更新哪一方、哪些参数固定和损失符号，不能把两种 loss 的大小直接当同一质量量表。

<a id="deep-dive-1"></a>

### 深入讲解：对抗目标为什么可能学到分布却仍训练不稳

原始GAN让判别器区分真实x与生成G(z)，生成器试图改变输出使其难以区分。判别器不是固定质量标准，而随训练变化；双方交替更新形成耦合动态，不能按普通单目标下降直觉解释所有曲线。

固定G且理想判别器有足够表达时，最优D(x)=pdata(x)/(pdata(x)+pg(x))。这一关系显示判别是在比较密度比，但实际网络和有限更新未必达到理想状态，理论最优不直接等于训练轨迹保证。

生成器可能集中少数容易欺骗判别器的模式，样本清晰却覆盖差。判别loss低或接近某值也不能单独判断成功，因为模型容量、优化与两分布重叠共同影响。

不同对抗损失、正则和约束改变梯度性质，不能只调一个学习率期待所有形式等价。比较应控制数据、网络与预算，并分别看质量、多样性、条件和记忆。

固定随机输入观察训练变化，再用预设随机样本和分组覆盖评价。精选图像能展示可能性，却不能描述整体分布，更不能替代训练稳定性证据。

<a id="sec-2"></a>

## 2. 模式坍塌

若生成器只输出少数几种看起来很真的样本，可能骗过当前判别器，却没有覆盖真实数据多样性。这叫模式坍塌。单独挑选好看的样本无法发现问题，需要检查多样性、重复率和条件覆盖。

训练稳定方法包括目标函数设计、归一化或约束、平衡更新频率等，但都应在具体设定中验证。Wasserstein 类方法有不同的判别目标和约束，不能只把原始损失名称改掉就得到同一算法。

<a id="sec-2-1"></a>

### 机制展开：模式遗漏可以与单张逼真同时存在

真实数据含等量两种模式，生成器只输出其中一种，即使每张都很逼真，覆盖仍缺一半。判别器平均准确率与视觉展示不足以量化这种遗漏，需要分布和条件覆盖检查。提高多样性又可能牺牲局部质量，因此评价分维度。训练中更新比例、正则与目标形式影响博弈动态，不宜用某一方 loss 持续下降直接推断生成分布改善。

<a id="sec-3"></a>

## 3. 生成模型怎样评价

FID 比较特征空间中分布的均值和协方差近似，依赖特征提取器、样本量和预处理；数值不能脱离协议跨场景随意比较。条件生成还要检查条件一致性，例如输入“两个红色方块”时数量和颜色是否正确。

还应检查训练样本记忆、近重复输出和罕见类别覆盖。好看的少量样本与高覆盖、可控性是不同维度。

<a id="sec-4"></a>

## 4. 对抗目标中的交替更新

更新判别器时，生成样本通常被视为固定输入，不应顺带更新生成器；更新生成器时，要通过判别器对输入的梯度传回生成器，但不一定更新判别器参数。两个阶段的梯度流向需要明确，否则代码可能优化了错误角色。

判别准确率接近 50% 可能意味着难以区分真实与生成，也可能只是判别器没有学会。必须结合样本、覆盖与独立指标解释，不能把单个平衡数字视为训练成功。对抗过程尤其需要保留检查点，观察模式是否随训练丢失。

<a id="sec-5"></a>

## 5. 质量与覆盖可能相互取舍

生成样本非常清晰却高度重复，可能覆盖不足；样本很多样但偏离真实分布，也不算成功。评价需要同时看逼真度、覆盖、条件遵循与记忆风险。

FID 等单指标依赖特征和样本量，不能对不同预处理或领域直接横向排名。应保留代表性随机样本，而不只展示手选成功结果。

生成样本集中在少数容易模式，可能使平均视觉质量较高却遗漏罕见群体；追求更广覆盖又可能纳入低质量样本。应使用能区分真实感与覆盖的评价、类别或条件分组，并查看全部预设随机抽样，而非精选展示。

同一指标受特征模型、样本数和预处理影响，固定协议后再比较。若提高引导、截断或拒绝采样改变保留分布，报告拒绝率与额外成本；“筛出来的好样本”与原模型直接采样的质量不是相同问题。

<a id="sec-6"></a>

## 6. 进阶：GAN最优判别器与散度解释

理想分析先固定生成器，求判别器的最优响应，再研究代回后的分布目标。实际训练却只做有限次交替更新，两个网络同时移动，未必达到每步最优响应。因而要区分目标层面的散度解释与优化过程的动态；下节给出最优响应公式，并结合梯度与模式覆盖说明其局限。

判别器准确率一半可能是分布匹配，也可能未学会。模式坍塌与梯度饱和需结合覆盖、样本和独立指标判断；非饱和或 Wasserstein 变体的目标与约束不同，不能只替换损失名称。

<a id="sec-6-1"></a>

### 最优判别器推导的条件与训练现实

对原始 GAN 目标，固定生成分布后可逐点最大化 $p_{data}\log D+p_g\log(1-D)$，得到 $D^*=p_{data}/(p_{data}+p_g)$。代入后与 Jensen–Shannon 散度相连。此结论假定理想分布和最优判别器，不是有限网络交替训练必然收敛的证明。

当判别器轻易区分真假，原始饱和形式可能给生成器较弱梯度，常见非饱和生成器目标改变更新信号。交替更新次数、容量与正则共同影响博弈动态，单看判别损失高低不能等同于样本质量。

模式坍塌表示只覆盖部分数据模式，即使单张样本逼真也可能严重。评价应同时检查质量、覆盖与训练近重复。提高判别准确率并非最终目标；需要观察生成分布是否改善，而不是让一方训练得越强越好。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 一个模型只生成同一张极其清晰的图，另一个生成很多稍模糊但不同的图，能只凭清晰度断定前者更好吗？

**答案：** 不能。前者多样性严重不足，可能只覆盖一个模式。应根据质量、覆盖、条件一致性与任务需求共同评价。

<a id="sec-7-1"></a>

### 边界追问：生成器 loss 下降是否代表模式覆盖增加

**问题：** GAN 样本越来越逼真却只剩一种模式，训练损失是否能单独判成功？

**推理解析：** 不能，对抗双方同时变化，loss 不等于统一质量量表。固定条件与样本选择，分别检查逼真度、覆盖、多样性与近重复；理想最优判别器的散度关系不保证有限训练动态。只展示成功图会进一步掩盖遗漏。
