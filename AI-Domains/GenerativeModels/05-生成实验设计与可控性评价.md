## 1. 明确生成任务

无条件生成关注总体分布，条件生成还要符合文本、类别或结构约束，重构则给定输入恢复。三个任务的输入与评价不同，应分别建立样本协议。输出质量高不表示条件被正确使用。

<a id="sec-1-1"></a>

### 基础算例：质量与覆盖可以朝相反方向变化

模型 A 总生成一种非常逼真样本，B 覆盖多种合理模式但偶尔有缺陷。只挑一张最好图会偏向 A，只看多样性又可能忽略 B 的质量问题。应固定条件与种子集合，保留全部输出，分别统计质量、覆盖、约束遵循和近重复。加速比较还要报告延迟与失败率；减少采样步骤后展示几张成功图，不能证明总体无损。

<a id="sec-2"></a>

## 2. 设计对照

固定模型比较采样器和步数，固定采样比较条件与无条件，固定预算比较方法。对文本条件，检查对象、数量、属性和关系，而不只看总体美观。多个随机种子和随机提示用于防止挑图。

<a id="sec-2-1"></a>

### 机制展开：对照应固定生成条件与样本选择

比较采样器时固定模型、提示集合、种子集合和预算，比较训练方法时再说明模型与数据差异。任何手动重抽直到成功都会改变选择协议，应计入成本或独立展示。质量、多样性、条件准确和记忆分开统计，不同特征器与样本量的分布指标不直接横比。最终报告包含失败，而非只从所有运行中拼出一组最佳图片。

<a id="deep-dive-2"></a>

### 深入讲解：生成实验怎样同时评价质量覆盖和条件满足

先固定生成目标：无条件分布、文本条件、编辑或重建有不同证据。重建输入来自真实样本，不等于从先验随机生成；二者不能放在同一精选图中称相同能力。

固定提示集、种子、样本量和采样协议，分别报告条件中的数量、属性、关系与来源支持。一个总体相似度可能漏掉关键逻辑错误，人工规则与自动指标需配合。

质量与覆盖可取舍。筛选、强引导、截断或拒绝采样改变保留分布，应报告拒绝率和额外成本。只展示筛后最好样本，会夸大普通采样可达到的稳定表现。

记忆检查先做完全重复，再用合适特征检索近邻并人工复核。常见语义相似不自动证明复制，未找到近邻也不证明没有记忆；阈值、方法与漏检范围都需说明。

比较速度时固定质量问题，报告网络评估次数、端到端时间和硬件。让评价流程可重复且样本选择透明，研究结论才不依赖展示者眼光。

<a id="sec-3"></a>

## 3. 记忆与近重复

对生成结果检索训练集近邻，检查是否复制敏感或重复内容。相似不自动证明记忆，需要考虑任务与数据常见模式，但高度一致样本应进一步审查。训练与评估集合也应去重。

可以先对训练集和生成集做完全重复哈希筛查，再用适合任务的特征检索近邻，最后人工核对高相似候选。图像要区分同一场景的公共结构与近乎逐像素复制，文本要区分常见短语与长段罕见内容复现。相似阈值必须说明，并用不同来源样本估计误报，避免把一般语义相似都记作记忆。

评价集也要做来源与近重复隔离；否则复现训练样本可能同时抬高质量分数。报告候选比例、人工确认标准和检索方法的漏检边界。未发现近邻，只能说明当前筛查没有检出，不能证明不存在训练数据记忆。

<a id="sec-4"></a>

## 4. 报告

记录数据、模型、目标、采样日程、步数、引导、精度、耗时和样本数量。指标与随机样本共同展示，说明未覆盖的失败模式。优化速度时同时评估质量与多样性变化。

固定提示集合、随机种子和样本数，保留全部生成结果或预先定义的抽样规则，避免只展示最好看的几个。若某指标依赖特征模型或参考分布，也记录其版本、样本量和前处理；不同评价器输出的数字不能直接放在同一排名中。

将质量、覆盖、条件遵循和资源分列，并展示典型失败。加速方案在同样输出规格下比较耗时，同时检验质量和多样性是否退化；把采样步数减少带来的速度收益与模型结构改变分开说明，才能判断方法取舍。

<a id="sec-5"></a>

## 5. 条件可控性的具体检查

将提示拆成对象、属性、数量、空间关系与否定条件，分别统计满足率。生成“两个蓝球在红箱左边”时，画面漂亮但数量错或关系反都属于条件失败。随机提示集合应覆盖简单与组合条件，不能只测熟悉模板。

为检查多样性，同一条件采多个种子，观察构图与细节是否变化；为检查覆盖，跨多个条件与类别采样。两种多样性不同，不能只看同一提示变化就声称覆盖全部数据分布。

评价加速时，固定数据、提示、种子集合与输出尺寸，比较步数或采样器改变的影响。记录失败率和重复率，保留随机网格而非手选样本，才有依据声称质量是否保持。

<a id="sec-6"></a>

## 6. 进阶：分布指标与样本选择偏差

FID 在特征空间用高斯近似比较均值协方差，受特征器、样本量和预处理影响，也不完整衡量条件遵循或训练样本记忆。不同协议的数值不直接可比，手选图更不能替代随机样本评价。

应把逼真度、覆盖、多样性、条件准确和近重复分开。加速对照固定提示与种子集合，报告失败及成本；若反复试采样参数后只展示最好结果，评价也包含选择偏差，需要保留开发与最终测试边界。

<a id="sec-6-1"></a>

### 生成评价应把分布匹配和任务可控性分开

FID 在固定特征器中用高斯均值和协方差近似比较分布，受样本量、预处理与特征域影响。两个数据集可在这些统计上接近，却在条件遵循、稀有模式或近重复上不同，因此不能用一个数代表全部生成能力。

条件生成可按对象数量、属性、关系、文字或时序约束分别设定评价。固定条件集合与随机种子集合，保留所有样本而非只挑成功图，再统计失败率和多样性。若需要人工评分，应明确规则、盲评和样本选择，避免知道模型名称后的偏好。

加速实验至少报告步数、延迟、显存、质量与覆盖，并区分每次采样成本和训练成本。若反复尝试多套采样参数，应保留开发集和最终评价条件。记忆检查可结合近邻与来源核对，但特征近不等于逐字复制，需要人工与数据证据解释。

<a id="sec-7"></a>

## 7. 练习与解析

**题目：** 减少采样步数速度翻倍，展示三张成功图，足够证明无损加速吗？

**解析：** 不够，应在固定代表性条件和足够样本上比较质量、覆盖与约束遵循，并报告波动和失败样本。

<a id="sec-8-2"></a>

### 边界追问：单个分布指标更好是否全面更优

**问题：** FID 降低但条件准确和少数模式覆盖变差，能否只按 FID 宣布生成全面提升？

**推理解析：** 不能，它只反映指定特征统计和协议的一部分。报告样本量、预处理、条件维度、覆盖与失败，保留固定开发和最终选择边界。若采样更慢或需要多次重抽，成本也需纳入，不能把手选结果当总体表现。

<a id="sec-8"></a>

## 8. 进阶研究练习与解析

**问题：** 从 KL 非负推导 VAE 下界，说明增加 KL 权重后的目标变化。

**解析：** 将 $\log p(x)$ 写成 q 下完整对数联合加熵，再加 q 与真实后验的 KL，即得到 ELBO 加非负间隙。原 ELBO 的两项系数由概率模型确定；额外加权会改变偏好，通常不能再直接称原模型对数证据的同一精确下界分解。

**实验：** 固定模型和预算改变 KL 权重，分别记录重构、KL、先验采样质量与覆盖。总损失不能跨权重直接比较，重构更好也不代表从先验随机采样更合理。

<a id="sec-8-1"></a>

### 综合练习：加速采样的质量结论如何成立

**问题：** 采样步数减半，展示三张成功图，是否证明无损？

**逐步解析与验收：** 没有。固定条件和种子集合，保留全部输出，比较质量、覆盖、条件遵循、近重复与延迟，报告失败。开发采样参数后另用最终集合检验。验收说明样本量和波动，不把手选展示或单个分布指标视为全部能力。
