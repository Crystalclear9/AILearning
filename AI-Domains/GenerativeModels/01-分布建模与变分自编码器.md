## 1. 生成不是复制单个训练样本

生成建模希望学习数据分布或可采样机制，使新样本具有训练数据中的结构。条件生成进一步建模 $p(x\mid c)$，条件可以是类别、文本或其他模态。重构训练样本、生成多样样本和完成下游任务是不同能力，应分别评价。

自回归模型将联合分布分解为条件概率乘积，可以直接优化相应对数似然，但通常逐步采样。隐变量模型引入 $z$，通过 $p(x)=\int p(x\mid z)p(z)dz$ 描述复杂分布；积分通常难以精确计算。

<a id="sec-2"></a>

## 2. VAE 的两部分

VAE 用编码器 $q_\phi(z\mid x)$ 近似后验，用解码器 $p_\theta(x\mid z)$ 重构数据。最大化证据下界

$$E_{q_\phi(z\mid x)}[\log p_\theta(x\mid z)]-D_{KL}(q_\phi(z\mid x)\|p(z)).$$

第一项鼓励保留重构信息，第二项让后验与先验保持联系，使从先验采样的隐变量也有机会生成合理样本。它不是简单把任意重构误差加一个任意约束，两项有概率建模含义。

<a id="sec-1-1"></a>

### 基础算例：高斯后验参数从 log variance 还原

后验均值 μ=1、log variance 为 log4，则方差为 4、标准差为 2，采样写 z=1+2ε。若直接把 exp(log4)=4 当标准差，实际方差变为 16。标准正态先验下 KL 为 $(1+4-1-\log4)/2$，约 1.307 nat。这个单维例子可同时核对参数含义、重参数化尺度与闭式损失，避免损失能下降却优化了另一种分布。

<a id="sec-2-1"></a>

### 机制展开：重构项与先验约束各控制什么

ELBO 的重构项是 q 后验下的期望 log pθ(x|z)，KL 项限制 qφ(z|x) 与先验的差异。重构分布若为固定方差高斯，负对数似然与平方误差相连；若方差可学，尺度项不能随意丢掉。单看重构好不保证先验采样好，过强解码器还可能减少对 z 的利用。应分别观察重构、KL、后验使用与先验生成，而不是只报总损失。

<a id="deep-dive-2"></a>

### 深入讲解：VAE如何用可计算下界替代困难边缘似然

生成模型先抽z~p(z)，再抽x~pθ(x|z)，边缘pθ(x)=∫pθ(x,z)dz难算。引入qφ(z|x)，分解logpθ(x)=ELBO+KL(qφ||真实后验)。最大化下界同时学习生成与近似推断，不是简单压缩后重建。

ELBO为Eq logpθ(x|z)−KL(qφ(z|x)||p(z))。第一项的损失形式由观测模型决定，高斯可对应带尺度平方误差，伯努利对应不同似然；重构项与KL权重不能随意改后仍称同一标准目标。

对角高斯用z=μ+σ⊙ε，ε独立标准正态，路径导数能传到μ、σ。网络输出log方差时，σ=exp(logvar/2)，漏掉1/2会改变采样及KL。标准正态先验的KL可逐维闭式核对。

KL过强可能让编码几乎不含输入信息，解码器强时还可能出现后验坍塌；重构好也可能只是记忆，生成覆盖与隐空间有用性需独立评价。

用一维高斯手算KL，再核对采样均值方差与梯度，最后检查后验重构和先验生成，两种样本回答不同问题。VAE的理解应从概率模型一直连到训练参数化。

<a id="sec-3"></a>

## 3. 重参数化

当后验为对角高斯，可写 $z=\mu(x)+\sigma(x)\odot\epsilon$，$\epsilon\sim\mathcal N(0,I)$。随机性移到不依赖参数的噪声，使采样后的目标可对均值和尺度求路径导数。网络常输出 log variance，需正确换算成标准差。

<a id="sec-4"></a>

## 4. 从先验采样与重构不同

重构时，隐变量来自输入相关的近似后验；生成时，隐变量通常来自先验。一个普通自动编码器即使重构很好，也不保证随机选取隐空间点能解码成合理数据。VAE 的概率约束正是为了让编码分布与可采样先验建立联系。

解码器的概率分布也决定损失形式：高斯观测模型可导出平方误差相关项，Bernoulli 观测模型则对应二元交叉熵。不能只因像素位于 0 到 1 就认为某个概率假设必然正确，应看数据表示与建模目的。

<a id="sec-5"></a>

## 5. ELBO为何是下界

对数证据可分解为 ELBO 加 $D_{KL}(q(z\mid x)\|p(z\mid x))$。KL 非负，因此 ELBO 不超过真实对数似然，近似后验越接近真实后验，差距越小。这解释了编码器不仅用于压缩，也承担推断职责。

优化下界仍可能受模型表达和近似族限制。训练损失下降不保证所有数据模式都被覆盖，仍需独立样本与生成评价。

<a id="sec-6"></a>

## 6. 专题推导：对角高斯KL与采样梯度

<a id="sec-6-1"></a>

### 下界从哪里来

在 q 的支持满足条件时，将 $p_\theta(x)=\int q_\phi(z\mid x)p_\theta(x,z)/q_\phi(z\mid x)\,dz$ 写成期望，对 log 使用 Jensen 不等式得到 ELBO。等价的 KL 分解还告诉我们，下界差距是 q 与真实后验的不匹配，而不是随机抽样误差本身。

<a id="sec-6-2"></a>

### 闭式KL怎么得到

令 q 为均值 μ、对角方差 $\sigma^2$ 的高斯，p 为标准高斯。展开两者对数密度差，再使用 $E_q[(z_j-\mu_j)^2]=\sigma_j^2$、$E_q[z_j^2]=\mu_j^2+\sigma_j^2$，得到

$$D_{KL}(q\|p)=\tfrac12\sum_j(\mu_j^2+\sigma_j^2-1-\log\sigma_j^2).$$

网络若输出 log variance v，则标准差是 exp(v/2)，不是 exp(v)。漏掉二分之一会改变噪声尺度，重构和梯度都可能表面合理却目标错误。

```python
import torch
from torch.distributions import Normal, Independent, kl_divergence
torch.manual_seed(42)
mu = torch.tensor([[0.2, -0.4]], dtype=torch.float64, requires_grad=True)
logvar = torch.tensor([[0.3, -0.2]], dtype=torch.float64, requires_grad=True)
std = torch.exp(0.5 * logvar)
closed = 0.5 * (mu.square() + logvar.exp() - 1 - logvar).sum(-1)
q = Independent(Normal(mu, std), 1)
p = Independent(Normal(torch.zeros_like(mu), torch.ones_like(std)), 1)
assert torch.allclose(closed, kl_divergence(q, p))
epsilon = torch.randn_like(mu)
z = mu + std * epsilon
loss = z.square().mean() + closed.mean()
loss.backward()
assert torch.isfinite(mu.grad).all() and torch.isfinite(logvar.grad).all()
print(closed.detach())
```

这里固定一次噪声形成路径导数估计，单次梯度含 Monte Carlo 波动。解析 KL 消除了该项采样误差，但重构期望仍可能采样。改变损失求和和平均轴会改变 KL 与重构相对权重，跨实现比较必须统一归约。

<a id="sec-7"></a>

## 7. 进阶：ELBO分解与重参数化的条件

$\log p_\theta(x)=\mathcal L(\theta,\phi;x)+D_{KL}(q_\phi(z\mid x)\|p_\theta(z\mid x))$，下界差距正是后验近似误差。对角高斯重参数化把采样写成可微映射与参数无关噪声，允许路径导数，而不是对随机节点直接随意求导。

重构项权重来自观测模型和尺度。改变 KL 系数形成不同目标，不再自动等于原始 ELBO。后验坍塌、近似族限制与解码器过强需分别分析，训练下界改善也不证明样本覆盖。

<a id="sec-7-1"></a>

### ELBO 的间隙说明推断与生成是两层近似

定义 $\mathcal L=E_q[\log p_\theta(x\mid z)]-D_{KL}(q_\phi(z\mid x)\|p(z))$，则 $\log p_\theta(x)-\mathcal L=D_{KL}(q_\phi(z\mid x)\|p_\theta(z\mid x))$。下界松紧取决于近似后验家族及其拟合，不只取决于解码器生成能力。

对角高斯后验写为 $z=\mu+\exp(\ell/2)\odot\epsilon$，其中 ℓ 为 log variance。将 ℓ 直接取指数当标准差，会使方差再平方。标准正态先验的 KL 为 $\frac12\sum_j(\mu_j^2+e^{\ell_j}-1-\ell_j)$，可用 μ=0、ℓ=0 得零作边界检查。

重构使用后验样本，随机生成使用先验样本，两种质量可能不同。增强 KL 权重改变目标偏好；当权重不小于 1 时，在相同定义下加权目标仍不高于原 ELBO，但不再是原分解中的同一紧下界。比较时应分别报告重构、KL 与先验生成，而非跨权重比较总损失大小。

<a id="sec-8"></a>

## 8. 练习与参考答案

**练习：** VAE 的 KL 项被过度强化，重构变差可能是什么原因？

**答案：** 编码器被迫接近先验，可能少用输入信息，甚至出现后验坍塌。应检查重构与 KL 的相对尺度、模型容量与训练过程，而非只看总损失。

<a id="sec-8-1"></a>

### 边界追问：后验重构好为何先验生成仍差

**问题：** VAE 对输入重构很好，但从先验随机采样差，是否只需更低重构 loss？

**推理解析：** 不一定，后验编码区域与先验采样区域可能匹配不足，近似推断和解码器也会影响。分别检查 KL、潜变量利用、后验与先验样本质量。提高某个加权项改变目标取舍，总 loss 不能跨权重直接比较；需要与生成任务对应的评价。
