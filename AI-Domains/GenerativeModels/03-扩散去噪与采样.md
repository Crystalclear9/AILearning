## 1. 前向过程逐步加噪

扩散模型定义一个固定加噪过程，让数据逐渐接近简单噪声分布。常见写法为 $x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon$，其中 $\epsilon\sim\mathcal N(0,I)$，$\bar\alpha_t$ 是由噪声日程累计得到的保留信号比例。

训练随机采样时间步，让网络根据 $x_t$ 和 $t$ 预测噪声，常用平方误差。不同参数化也可以预测干净样本或其他等价相关量，公式和采样更新必须对应。

<a id="sec-1-1"></a>

### 基础算例：加噪公式可以直接跳到指定时间步

若累计信号比例为 0.64，则 $x_t=0.8x_0+0.6\epsilon$。取 x0=2、ε=-1，得到 xt=1；已知 x0 和 xt 可还原该次 ε，但训练网络通常只看到 xt、时间和条件，目标是学习条件统计预测。构造指定 t 的样本不必逐步模拟此前全部噪声。时间采样、输出参数化和反向采样式仍需一致，不能把训练步数与生成步数混为一谈。

<a id="sec-2"></a>

## 2. 反向过程生成样本

推理从随机噪声开始，使用网络估计去噪方向，逐步得到数据样本。采样器与步数影响速度和误差；减少步数不意味着质量永远保持不变。潜空间扩散先在压缩表示中生成，再解码到像素，减少成本，但也受编码器重构质量影响。

<a id="sec-2-1"></a>

### 机制展开：离散 DDPM 均值更新依赖当前时间参数

令 αt=1-βt，在噪声预测参数化下，常用均值为 $\mu_\theta=\alpha_t^{-1/2}[x_t-\beta_t\epsilon_\theta(x_t,t)/\sqrt{1-\bar\alpha_t}]$，再按指定方差加入随机项得到前一步。βt 与累计的 ᾱt 不是同一量，跳步采样也不能不加修改套用相邻步公式。最后一步的噪声约定、输出参数化与采样日程需配套，才能解释减少步数带来的误差。

<a id="deep-dive-2"></a>

### 深入讲解：噪声预测与逐步反向更新怎样闭环

前向用累计系数将x0直接采成xt，不必逐步模拟此前噪声。条件高斯结构给训练目标ε，但同一个xt可能来自不同x0和ε，平方损失最优预测的是条件均值，不是保证恢复每次原始随机噪声。

反向均值由当前βt、αt及累计αbar共同决定，噪声预测器只是其中一个输入。β与累计量混用、相邻步公式直接跳步或最后一步随机项错误，都会改变采样。

预测x0、ε或v可由特定路径系数转换，但损失时间权重和端点数值敏感不同。必须先写参数化定义，不能把同一检查点输出换名字就接到另一采样器。

classifier-free guidance组合条件与无条件预测，其尺度零点约定各异。强引导改变向量场，可能提升条件遵循却损害覆盖，不能只按一个视觉样本选强度。

用解析高斯或已知单步样本先核对加噪、还原、时间编号，再扩大到完整采样。分离网络拟合误差、数值积分误差与引导造成的分布变化，才能理解速度质量取舍。

<a id="sec-3"></a>

## 3. 条件与引导

文本条件可通过交叉注意力进入网络。classifier-free guidance 常组合有条件和无条件预测，增强条件响应；较强引导可能牺牲多样性并产生伪影。引导尺度的具体数值约定依实现而定，不能跨工具机械比较。

一种明确约定为 $\epsilon_{guided}=\epsilon_{uncond}+w(\epsilon_{cond}-\epsilon_{uncond})$，此时 w=0 是无条件、w=1 是普通有条件预测。也有实现写为有条件加额外差分，参数零点因此不同，阅读代码时应先换成同一公式再比较。

训练通常随机丢弃条件，使模型学习两种输入情况。推理中强引导改变反向向量场，并不保证仍精确采自原条件分布。应在固定提示、种子、采样器和 NFE 下扫描引导强度，分别测条件满足、覆盖和伪影；单一质量分数不足以选择所有任务的强度。

<a id="sec-4"></a>

## 4. 噪声日程与信号强度

当 $\bar\alpha_t$ 接近 1，$x_t$ 保留较多原始信号，去噪任务偏向细节；接近 0 时，输入几乎是噪声，模型更依赖学习到的总体结构与条件。不同时间步的难度与损失尺度可能不同，采样时间步和加权方式会影响训练。

采样随机种子只确定某次噪声路径，在模型、采样器、精度与实现改变后，不保证完全相同输出。评价应使用多个样本与固定协议，既看视觉质量，也看多样性和条件遵循，避免只挑一张成功图片。

<a id="sec-5"></a>

## 5. 去噪目标与采样器对应

网络预测噪声、干净样本或速度等参数化，其训练目标和反向更新公式需配套。混用不同实现的输出含义，会产生数值合法但语义错误的采样。

采样步数、噪声日程、引导尺度与随机种子一起决定生成流程。固定模型时改变任一项，都应重新评价质量、速度与多样性。

记 $x_t=\alpha x_0+\sigma\epsilon$，其中 $\alpha^2+\sigma^2=1$；一种常用速度约定为 $v=\alpha\epsilon-\sigma x_0$。则 $x_0=\alpha x_t-\sigma v$、$\epsilon=\sigma x_t+\alpha v$。这些转换来自一个二维正交变换，必须与当前 t 的系数一致，不能只把网络输出换变量名。

端点系数接近零时，某些基于除法的转换更敏感。跨实现移植检查点时核对目标类型、时间编号、噪声日程和方差处理；单步还原的解析算例通过后，再测试整段采样。连续时间联系见[连续生成进阶篇](../../AdvancedStudies/ContinuousGenerativeModels/README.md)。

<a id="sec-6"></a>

## 6. 进阶：去噪回归的条件期望解释

固定噪声级，平方误差最优预测为 $E[\epsilon\mid x_t,t]$。在高斯加噪、$1-\bar\alpha_t>0$ 且可交换求导与积分的条件下，它与加噪数据边缘分布 $p_t(x_t)$ 的 score 有关系：$\nabla_{x_t}\log p_t(x_t)=-E[\epsilon\mid x_t,t]/\sqrt{1-\bar\alpha_t}$。这里的 $p_t$ 是 $x_t$ 的分布，不是独立标准高斯噪声 $\epsilon$ 自身的分布。

因此噪声预测学习的不只是逐像素“去掉这次噪声”，而是分布层面的条件方向。训练时步权重、噪声日程与采样器共同决定实际目标和误差；无条件与条件引导组合改变采样偏好，不保证任意大引导都改善质量。

<a id="sec-6-1"></a>

### 噪声预测与 score 的关系可以直接求导得到

前向条件为 $q(x_t\mid x_0)=\mathcal N(\sqrt{\bar\alpha_t}x_0,(1-\bar\alpha_t)I)$。对其对数密度关于 $x_t$ 求导得到 $-(x_t-\sqrt{\bar\alpha_t}x_0)/(1-\bar\alpha_t)$，代入加噪表达就是 $-\epsilon/\sqrt{1-\bar\alpha_t}$。再对给定 $x_t$ 的后验取期望，得到边缘 score 关系，需满足交换求导与积分等条件。

平方误差训练的最优预测是条件均值，而不是从含噪输入唯一还原本次噪声。多个干净样本可能生成相同附近的 $x_t$，因此网络学习的是条件分布的统计方向。时间步权重改变不同噪声级对目标的贡献。

采样时噪声参数化、日程与更新式必须配套。预测 ε 的网络不能不经转换就当作预测 $x_0$ 的网络使用。减少步数、改变引导或改用潜空间都需重新测质量、多样性与成本，不能从训练损失更低推断所有采样设置都会更好。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 扩散训练为什么通常不必为每个样本完整执行所有加噪步骤？训练次数与采样步数是不是一回事？

**答案：** 上式可以直接从 $x_0$ 构造任意采样时间步的 $x_t$，再训练该步预测。训练更新次数是参数优化预算，采样步数是生成一次样本的反向计算次数，二者不同。

<a id="sec-7-1"></a>

### 边界追问：改变采样时间步能否原样用相邻更新

**问题：** 噪声预测网络不变，从一千步跳到几十步，直接删除循环步骤就一定合法吗？

**推理解析：** 不一定，原相邻步公式依赖当前与累计日程，跳步需使用配套采样器或相应推导。噪声、干净样本与速度参数化也不能混用。固定模型比较质量、覆盖、条件与成本，再判断加速，不以能输出图像证明目标一致。
