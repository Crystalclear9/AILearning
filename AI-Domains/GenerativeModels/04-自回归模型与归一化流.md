## 1. 自回归分解

联合分布可写为条件概率乘积，按确定顺序逐项预测。训练时真实前缀已知，可并行计算适当掩码下多个位置；采样需逐项推进。顺序选择会影响建模难度与生成速度。

图像也可按像素或离散表示自回归生成，但长序列成本较高。语言模型只是这种概率分解在文本中的应用，不能把所有生成模型等同大语言模型。

<a id="sec-2"></a>

## 2. 可逆变换与密度

归一化流用可逆变换把简单变量 z 映射到数据 x，并通过雅可比行列式计算密度变化。可精确求似然需要变换既足够灵活，又能高效求逆和行列式，这形成结构约束。

一维 $x=az+b$、$a\ne0$ 时，$p_X(x)=p_Z((x-b)/a)/|a|$。扩大空间后密度相应降低，总概率保持为 1。漏掉雅可比会得到错误归一化。

<a id="sec-1-1"></a>

### 基础算例：一维密度缩放与二维面积缩放

标准正态 z 经 x=3z+1 变换，x 均值为 1、标准差为 3，密度为 $p_Z((x-1)/3)/3$。若漏掉除以 3，积分会变成 3，失去归一。二维每轴都放大三倍，行列式为 9，密度应除以 9。雅可比修正的是体积变化，必须与变换方向和维数对应；可采样不自动说明实现了正确可计算密度。

<a id="sec-2-1"></a>

### 机制展开：耦合变换用三角雅可比降低成本

可把 z 分成两块，令 x1=z1、x2=z2⊙exp(s(z1))+t(z1)。逆变换由 x1 直接恢复 z1，再逐元素还原 z2；雅可比为分块三角，log 行列式为 Σs(z1)。这种结构便于精确计算，却限制一次变换的信息混合，通常需堆叠并交换分块。表达能力、求逆与行列式成本共同决定流结构，而不是只要求函数可微。

<a id="deep-dive-2"></a>

### 深入讲解：自回归与可逆流怎样以不同方式计算密度

自回归将联合密度写条件乘积，顺序决定每一步看到什么。训练真实前缀可并行计算适当mask下的损失，采样仍逐项推进；串行成本来自依赖，不只是实现不够快。

归一化流令x=f(z)，基础z密度已知，可逆变换给 $p_X(x)=p_Z(f^{-1}(x))|\det J_{f^{-1}}(x)|$。雅可比补偿体积变化，若一维x=2z，密度必须除2，不能只代入基础密度。

流结构常为便于逆和行列式而设计，表达与计算有取舍；任意神经网络不保证可逆。连续流用散度积分计算密度，又引入积分与迹估计成本。

显式似然不自动等于样本真实感或任务可控性。VAE给下界、GAN通常无同样可计算密度、扩散多步反向，各有目标和代价。选方法需先明确密度、采样、条件还是表示需求。

比较固定输出规格、信息和资源，区分训练成本、单样本延迟及批量吞吐。参数少不保证所有生成路径更快，低负对数似然也不证明无记忆或高覆盖。

<a id="sec-3"></a>

## 3. 方法选择

自回归直接建模条件分布但串行采样；VAE 有显式隐变量推断与下界；GAN 依赖对抗匹配，通常无同样形式的可计算密度；扩散通过逐步反向过程采样。比较需看任务目标与预算，不只选最热门名称。

先把需求写成可比较条件。若需要给样本计算概率，应区分精确可计算似然、变分下界和需要额外估计的量；若重视条件控制与视觉质量，则需在同一提示、分辨率和采样预算下比较。模型是否具有显式密度，与是否生成高质量样本是两个维度。

速度也需拆成训练成本、首个样本延迟和批量吞吐。自回归串行、扩散多步、流模型可逆变换分别有不同计算路径，不能只按参数量判断快慢。比较时固定输出规格和硬件，同时报告质量、多样性、条件遵循与失败例，不以一组精选结果代替分布评价。

<a id="sec-4"></a>

## 4. 密度变换与采样方向

生成时从简单分布采 z 再向 x 变换，求数据密度时则需反向找到 z，并加入逆变换雅可比。能采样不代表能高效求密度，能求密度也不代表生成一定快，模型结构决定这些代价。

自回归模型每一步条件在已有变量上，改变生成顺序仍是合法分解，却改变网络可利用结构。例如图像扫描顺序与二维空间并不完全一致，模型需额外结构捕捉空间关系。训练与采样应使用同样顺序和编码。

比较生成方法要先确定目标：压缩与隐空间编辑、准确似然、快速采样或高保真条件图像需要不同能力。一个指标领先的模型不一定在其他目标也最合适，实验应给多维成本与质量。

<a id="sec-5"></a>

## 5. 进阶：Change-of-variables与精确似然

可逆变换 x=f(z) 满足 $\log p_X(x)=\log p_Z(f^{-1}(x))+\log|\det J_{f^{-1}}(x)|$。流模型的结构需同时支持表达、求逆和行列式，所谓精确似然依赖这些可计算约定，不表示已拟合真实分布。

自回归模型直接因子分解但常串行采样，VAE 优化下界，GAN 常无同样显式密度，扩散使用多步生成。比较时应说明概率目标、采样成本和任务质量，不能从一个指标推全方面优劣。

<a id="sec-5-1"></a>

### 变换方向与行列式符号的完整核对

若 x=f(z)，则 $p_X(x)=p_Z(f^{-1}(x))|\det J_{f^{-1}}(x)|$。等价地，在 z 处写成 $\log p_X(f(z))=\log p_Z(z)-\log|\det J_f(z)|$。正向和逆向公式中的符号相反，是很多流模型实现错误的来源。

一维 x=2z+b 时，密度除以 2；两维每轴放大两倍时，面积放大四倍，密度应除以 4。雅可比修正保持概率质量，而非保持密度数值。可用简单线性映射核对方向、绝对值与维数。

自回归模型通过条件概率分解获得似然，流模型通过可逆映射计算密度，二者的训练与采样成本结构不同。精确可计算似然不表示已拟合真实分布，也不保证视觉质量；连续密度、离散编码与去量化约定不同，跨方法数值比较需要统一测量对象。

<a id="sec-6"></a>

## 6. 练习与解析

**题目：** 标准正态 z 经 x=2z 变换，x 的标准差与密度峰值如何变化？

**解析：** 标准差变为 2，峰值减半。分布更宽但总面积仍为 1，体现概率质量与密度值的区别。

<a id="sec-6-1"></a>

### 边界追问：可采样是否意味着可精确算似然

**问题：** 黑箱映射可从简单噪声生成数据，能否自动按流模型公式求密度？

**推理解析：** 不能，流式密度计算还需合适可逆性、雅可比与求逆成本。非双射映射可能有多原像或维数变化，普通一对一公式不直接适用。准确可计算似然也不保证语义样本好，概率目标和任务质量分别比较。
