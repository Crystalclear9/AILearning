## 1. 三类典型任务

文本分类输出整段标签，序列标注为每个词或字符标记类别，生成任务输出新的 token 序列。命名实体识别常用 BIO 等方案表达实体边界；子词分词后，标签如何映射到子词需要明确定义，并在损失中忽略无效位置。

生成任务可以用 encoder-decoder 或 decoder-only 模型完成，训练通常基于真实目标前缀。推理时自己的输出进入下一步，可能累积错误，不能只用训练损失评价生成质量。

<a id="sec-1-1"></a>

### 基础算例：实体边界错误不能只看 token 正确率

真实实体为“北京大学”，若预测仅“北京”，大部分文本 token 仍可能正确，但实体跨度并未完整匹配。实体级精确率和召回因此不同于逐 token 准确率。子词分词后，还需把标签与原文跨度对齐并定义忽略位置。评价应与最终使用的实体单位一致；否则一个只擅长预测大量非实体标签的模型也可能拥有很高总体准确率。

<a id="sec-2"></a>

## 2. 指标应对齐任务

分类可用 macro-F1，实体识别应报告实体级别的精确率与召回率，而不是只看大量“非实体”位置的准确率。翻译、摘要可使用 BLEU、ROUGE 等自动指标，但词面重叠不能完整判断事实正确、逻辑连贯或信息遗漏。

困惑度是平均 token 负对数似然取指数，需在相同分词、语料和计算规则下比较；不同 tokenizer 的每 token 困惑度不可直接当成同一尺度。

<a id="sec-2-1"></a>

### 机制展开：评价单位决定什么算一次错误

分类按文本或标签，实体抽取按跨度与类型，生成按完整内容与约束。逐 token 准确率可能因大量非实体位置而很高，却遗漏全部关键实体。参考字符串也可能不覆盖合法同义答案。把真实使用时的输出单位写清，设置对应人工核验与自动指标，并按长度和来源报告；不能用同一平均正确率代表所有语言任务。

<a id="deep-dive-2"></a>

### 深入讲解：分类标注生成为何需要三套不同评价单位

文本分类以文档或句为单位，序列标注关注实体跨度与类型，生成关注完整输出。逐token正确率会被大量O标签或常见词主导，不能代替实体级F1或生成任务成功率。

实体严格匹配需边界和类型同时正确。“北京大学”真为一个机构，预测“北京”为地点，即使很多字符标签相近，也通常是一错一漏。部分匹配可另报，但不能混进同一主指标。

生成参考答案可能不唯一，词面重叠高不保证事实正确，低也不保证错误。实体、数字、否定、完整性和格式应分项核对，必要人工依据来源判断。

同用户、文档或事件的近重复需按来源隔离。模型在模板改写上高分，不足以说明面对新事件有效；评价还要按语言、长度和领域给支持数。

人工或模型评价器也需要清晰规则、盲化和抽查。先确定什么叫正确，再选择指标，而不是拿方便计算的数值替代任务定义。

<a id="sec-3"></a>

## 3. 数据检查决定结论可靠性

去重应注意近重复文本与模板泄漏，同一用户、文档或事件的内容可能需要分组划分。训练数据和测试数据语言、时间、长度不同，也可能引起显著分布变化。

对生成结果应抽样检查事实、实体、数字、否定关系和来源支持。自动指标可用于快速比较，但需要与人工定义的任务标准互补。

按任务独立单位划分后，检查完全重复、近重复、模板及同源改写。文本预处理如词表、TF-IDF 或特征选择只在训练部分拟合；从全体标签筛词再交叉验证会造成泄漏。用户、事件和时间都可能比随机文本行更适合作划分单位。

人工核对一批目标错误，特别是实体、数字、否定与时间关系，保留来源上下文。对不同语言、长度和领域报告样本数和分数，区分数据覆盖不足与模型机制问题。自动指标下降应回到具体任务标准解释，不将词面不一致全部视作事实错误。

<a id="sec-4"></a>

## 4. 生成评估中的事实与措辞

参考答案不是唯一正确表述，词面相似度低可能只是改写；相似度高也可能把关键数字或否定词写错。应为任务建立具体维度，例如实体是否一致、数字是否正确、结论是否被原文支持、是否遗漏核心条件。

人工评估要给出清楚标准，并尽量让评价者不知道模型身份，减少先入为主。自动评价模型也可能偏好更长、更流畅或与自身风格接近的文本，因此需要抽样人工复核与一致性检查，不能把一个自动分数当作完整事实判断。

<a id="sec-5"></a>

## 5. 自动指标与参考答案覆盖

同一问题可能有多种正确表述，参考答案有限时词面指标会漏判；关键实体或否定错一处，又可能仍有很高重叠分数。应根据任务拆分事实、完整性、格式与语言质量。

人工或模型评价也要给清晰规则，盲化模型身份并抽样核对，防止流畅度、长度或偏好掩盖实际错误。

建立小型人工核对集，故意加入同义改写、关键实体替换、数字错误、否定翻转及遗漏条件。比较自动指标对这些变化的敏感性，才能知道它主要衡量词面、语义还是任务约束；不能只因与另一指标相关就认为已测事实正确。

人工评分规则要给可操作例子，对有歧义的样本双人复核或记录分歧。模型评价器固定版本、提示及候选顺序，抽查长度和措辞偏好。报告各维度与总体结果，保留原始回答和证据，避免用一个综合分隐藏严重事实错误。

<a id="sec-6"></a>

## 6. 进阶：序列标注的结构目标与评价

BIO 转移规则表达实体边界约束，线性链 CRF 对整条标签路径归一化，区别于每位置独立 softmax。前向求和用于配分函数，Viterbi 最大化用于解码，不能混为同一步。

子词标签映射和特殊位置掩码会改变目标，实体级 F1 要还原完整边界与类型。生成任务的参考答案可能不唯一，词面指标既可漏判合理改写，也会忽略否定或数字错误，需任务结构检查。

<a id="sec-6-1"></a>

### 文本任务的输出结构决定错误单位

分类给每个文本一个或多个类别，序列标注给 token 或跨度赋标签，生成任务输出长度可变的文本。把所有任务统一成逐 token 准确率，会丢失实体边界、句级约束和完整回答质量。

实体识别若要求边界与类型完全匹配，预测少一个 token 可能整段计错；分词改变后还要把标签或跨度正确映射回原文。生成中的同义表达可能与参考字符串不同，自动重叠指标不能完整衡量事实和可执行约束。

评价集应覆盖常见、稀有、歧义和无法回答情形，并记录来源与标注规则。多个标注者分歧可能反映任务本身未定义清楚，不能一律归为模型错误。先统一输出与评价口径，才有比较模型的基础。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 实体识别数据中 95% token 都不是实体，全部预测为非实体能得到 95% token 准确率，这是否可用？

**答案：** 对识别实体的目标几乎没有帮助，实体召回率为零。应按实体边界与类别评价，并查看各类支持度和错误类型。

<a id="sec-7-1"></a>

### 边界追问：token 准确率高能否证明实体抽取好

**问题：** 绝大多数 token 为非实体，模型几乎全预测 O，怎样揭示问题？

**推理解析：** 按实体跨度和类型计算精确率、召回，附支持与错误案例。大量背景可让逐 token 准确率很高却漏掉全部实体。子词对齐、无效标签和边界规则需固定。评价应对应实际提取对象，而不是选择最有利的平均单位。
