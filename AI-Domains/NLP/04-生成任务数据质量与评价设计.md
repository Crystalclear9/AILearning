## 1. 训练样本定义

明确输入、目标输出和损失位置，区分翻译、摘要、问答与开放生成。起止符、截断和目标错位影响实际任务。生成结果应检查完整序列，不能只看教师强制下 token 损失。

训练样本应明确来源 ID、输入、目标和允许可见的信息。摘要只能依据给定原文，问答要定义是否允许外部知识；样本来源相同时生成的多个变体应按来源分组划分。对问答来源做标识，也有助于发现同一文档跨集合泄漏。

人工核对一个批次的 token 与标签：自回归预测通常由当前位置预测下一 token，框架可能内部移位，不能再手动移位一次；起止符和 padding 的损失位置需一致。截断若删除目标证据或回答结尾，应明确过滤或处理规则，避免教模型从不完整条件猜答案。

<a id="sec-2"></a>

## 2. 数据去重与污染

完全重复、模板近重复、同一事件多版本都可能跨划分。按来源、时间和文档家族隔离更接近未见内容测试。模型可能已在预训练见过基准，还要谨慎解释绝对成绩。

<a id="sec-2-1"></a>

### 机制展开：去重应覆盖内容与来源关联

逐字去重不能识别轻微改写、共享模板或同文档不同片段。应按任务判断近重复和来源分组，保留版本与切分规则；测试内容参与提示调优也算开发信息。去重阈值可能误删合法相似样本，需抽查。训练污染检查、标签质量和评价器偏好分别验收，不能把“没有完全重复行”当作所有泄漏已消除。

<a id="sec-3"></a>

## 3. 评价维度

翻译检查语义与实体，摘要检查事实支持与遗漏，问答检查答案、证据与拒答，代码生成检查实际行为。自动指标用于快速筛选，需与任务专用检查及人工样例结合。

<a id="sec-1-1"></a>

### 基础算例：文本生成指标先与失败类型对应

摘要可能与参考用词不同却事实正确，也可能词语高度重合却把数字或关系写反。单一 n-gram 重合无法完整区分。可把评价拆为事实支持、覆盖、冗余和格式约束，并用人工核验抽样检查自动评分。对不同来源与长度分别报告，避免只选择容易回答的样本。提示或解码参数若经测试回答调整，原测试已参与开发。

<a id="deep-dive-3"></a>

### 深入讲解：生成评价怎样沿证据到答案定位错误

先定义输入可见范围和目标：摘要只依据原文，问答是否允许外部知识，输出有哪些必要字段。若证据不足，合理不确定回答与胡乱补全应区分，不能只奖流畅长答案。

样本中起止符、移位、padding和截断决定实际训练目标。框架可能内部移位，不应重复操作；截断若删去关键证据，却仍保留确定目标，会教模型在缺信息时猜测。

去重按来源和近重复检查，数据污染不只完全相同字符串。同一文档生成的许多问答应整体划分，否则测的可能是记忆文档而非新来源泛化。

错误可分证据未召回、已见却误解、生成无支持、格式失败和题目歧义。对应修复不同：增加检索不能自动纠正已在上下文中的错误推理，改提示也不能创造缺失事实。

报告完整输出及来源，按长度语言领域汇总，固定解码和抽样。自动指标用于快速比较，关键事实与约束还需针对性核查，不能让一个总分掩盖严重内容错误。

<a id="sec-4"></a>

## 4. 诊断与报告

把错误分成检索不足、理解错误、生成不支持、格式错误与任务歧义。按长度、语言、领域分组报告，注明采样和解码设置。流畅不是事实正确，长回答也不必然更完整。

每类错误应有可复查的样本、输入证据和判定依据。检索不足意味着正确证据未进入候选，生成不支持则是证据已在输入但回答超出或违背它；这两者需要不同修复。任务存在多种合理答案时，应先校验标注规则，不能把所有分歧归于模型。

报告各类错误的数量或占比、分组样本数与抽样方式，并给出完整生成而非只截取正确片段。修改后使用固定回归样例和新的独立样本验证，防止规则只修复已经看过的题目。

<a id="sec-5"></a>

## 5. 将评价标准写成可执行规则

摘要可检查关键实体、数字、时间、否定和结论是否被原文支持；问答可检查是否直接回答问题、证据是否包含所需信息、引用是否对应。每个维度有明确正反例，评价者才更一致。

对开放生成，不宜要求措辞与参考完全一致，也不能让任何流畅文本都算正确。允许合理改写，同时对新增事实要求支持。自动评价器需抽样人工复核，检查是否偏好长度或形式。

数据污染调查也应谨慎：模型给出标准答案可能来自能力或已见内容，不能只凭表现判断。可用新编问题、时间隔离和来源去重提供额外证据，并明确尚不能确认的部分。

<a id="sec-6"></a>

## 6. 进阶：自动评价器的偏好与测量误差

人工或模型评价应有清晰规则、盲化与一致性检查。评价模型可能偏好长度、自身风格或位置顺序，成对比较可交换候选次序检验。流畅度高不能替代事实支持，单一综合分数也隐藏错误来源。

研究结论应区分模型能力、检索证据和评价器误差。保留原输出与逐项标签，抽样核对数字、实体、否定和遗漏。重复调整评价提示直到某模型获胜，会把评价器也变成被选择的开发工具。

<a id="sec-6-1"></a>

### 生成数据与评价器都可能引入选择偏差

监督生成样本应明确提示、上下文、目标回答和不应计算损失的部分。训练文本去重不仅防逐字记忆，也要考虑模板、近重复与同来源泄漏。测试题若进入训练或调参，最终高分无法独立说明泛化。

自动评价器也有偏好，例如可能更喜欢长回答、特定格式或与自身风格相似的输出。应与人工抽样核验，按事实、完整性、约束遵循和拒答分别评估，检查评价器在关键错误类型上的漏检。一个总分不应掩盖互相冲突的维度。

比较生成设置时固定提示集合、解码规则和预算，包含失败与无法回答样本。若看过测试回答后修改提示，再在同一批问题上报告提升，应标为开发结果。保留独立最终集，使“改得更像参考答案”和“真实任务更可靠”可以被区分。

<a id="sec-7"></a>

## 7. 练习与解析

**题目：** 摘要把“未显著提高”写成“显著提高”，其他词几乎一致，为何需要专门检查？

**解析：** 否定关系翻转核心结论，词面重叠可能仍高。评价需检查事实和逻辑关系，而非仅依赖文本相似度。

<a id="sec-8-2"></a>

### 边界追问：自动评价器给高分是否就事实正确

**问题：** 回答更长、格式漂亮，评分提高但引用不支持关键数字，怎样验收？

**推理解析：** 将事实、支持、覆盖和格式分项，加入高重合错误与同义正确对照，并人工抽样校验评价器。评价模型也有偏好与测量误差，不能用一个总分替代证据审查。固定提示、解码和最终集合，防止选择反馈循环。

<a id="sec-8"></a>

## 8. 进阶研究练习与解析

**问题：** 为什么文本流畅和词面重叠高，都不足以证明摘要事实正确？

**解析：** 把“未提高”改为“提高”，或把数字十改成百，其余措辞保持，词面分数仍可很高，核心命题却翻转。评价应核对实体、数字、时间、否定与来源支持，允许合理改写而拒绝无据新增。

**研究设计：** 建立可控错误对照，测试自动指标和评价模型的识别率，再盲化人工复核。若评价器偏好长度或候选顺序，交换位置和控制长度检验。报告的是测量工具有效性，不只被评价模型的一个综合分数。

<a id="sec-8-1"></a>

### 综合练习：评估生成事实而非只看措辞

**问题：** 回答与参考词汇高度重合，但关键数字错误，自动重合指标高，怎样改评价？

**逐步解析与验收：** 增加基于证据的事实核对、数字和关系检查，并人工抽样核验评价器。保留同义正确表达与高重合错误表达两类对照。验收分维度报告事实、覆盖和格式，固定提示与样本选择；不要只换一个总分继续隐藏错误类型。
