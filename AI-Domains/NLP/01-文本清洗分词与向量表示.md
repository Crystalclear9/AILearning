## 1. 文本处理不是越干净越好

文本中大小写、标点、数字、空格可能含有任务信息。情感分析中的感叹号和否定词，代码中的空格和大小写，都不能随意删除。应先明确任务，再决定规范化规则，并对训练与推理使用相同流程。

分词把文本变成 token 序列，token 可以是词、子词、字或字节片段，不等于自然语言中的一个汉字或单词。子词方法在词表规模与未知词表示之间折中；不同 tokenizer 可能使同一句话得到不同长度。

<a id="sec-2"></a>

## 2. 词袋与 TF-IDF 基线

词袋记录词频，忽略顺序。TF-IDF 结合文档内词频和全语料稀有程度，削弱到处都出现的词。它在文本分类和检索中常是有价值的基线，且成本较低。词表和 IDF 都需要在训练语料上拟合。

短语“不是很好”与“很好”可能具有相反含义，单纯词袋难以表示顺序，可加入 n-gram，或使用上下文模型。高维稀疏特征不应无必要地转为大型稠密矩阵。

<a id="sec-1-1"></a>

### 基础算例：词袋表示保留词频却丢失顺序

句子“甲喜欢乙”与“乙喜欢甲”在相同词表下可能有同样词频向量，却表达不同关系。词袋适合作为部分主题分类基线，但不直接保留角色顺序。加入词组特征或上下文编码会改变表示能力及成本。预处理也应保留任务需要的信息：否定、数字、标点和大小写未必是噪声。先用这种最小对照句检查特征是否能区分目标，再评价复杂模型。

<a id="sec-2-1"></a>

### 机制展开：TF-IDF 中 IDF 由文档频次决定

词频表达词在当前文档出现量，IDF 用训练文档中包含该词的频次降低常见词权重，平滑与归一化细节依实现。词表和 IDF 不应由测试语料重新拟合；未知词按既定规则处理。词袋无法直接保留任意长程顺序，但词组特征可补部分局部结构。强稀疏基线有助判断复杂模型收益来自表示还是额外预处理与输入覆盖。

<a id="deep-dive-2"></a>

### 深入讲解：文本表示怎样由计数走到任务相关语义

词袋将文档映成词频向量，忽略大部分顺序，却可提供强分类或检索基线。TF-IDF降低许多文档都常见词的相对权重，词表与IDF只在训练语料拟合，不能偷看评价分布后仍称独立。

分词和清洗会改变信息。大小写、标点、否定和数字可能是任务关键，删除“not”或把所有数字替换同一符号，可能破坏标签；“更干净”不是自动更好。

稀疏向量表达词面匹配，静态嵌入共享词表示，上下文嵌入依句子，句向量还需池化与训练目标。任意隐藏层平均不自动产生适合余弦检索的语义几何。

子词拆分能缓解未登录词，却改变序列长度和标签对齐。一个实体被拆成多片时，读取、标注和损失需有统一规则，不能只按原词位置截取。

用否定翻转、同义改写、实体与数字替换的小对照检验表示。与词袋基线比较，再看来源外任务，才能知道模型学的是词面、模板还是可迁移信息。

<a id="sec-3"></a>

## 3. 静态与上下文嵌入

静态词向量为同一词提供同一表示，上下文模型让表示依赖所在句子，从而区分多义词。句向量则把整段文本压缩成用于检索或比较的向量。训练目标和池化方式影响相似度含义，不能直接拿任何隐藏层平均后就声称具备可靠语义检索能力。

例如“苹果发布新品”与“苹果成熟了”中同一词需要不同语义，静态词向量不随句子改变，上下文模型则会受邻近词与位置影响。若 tokenizer 将词拆成多个子词，还需定义如何读取或合并对应位置，不能把任意一个子词当成完整词义。

句向量用于检索时应明确池化、归一化、相似度及训练配对目标。仅用语言模型隐藏层均值，未必能得到适合余弦检索的几何；用有标注或自监督配对的独立检索集检验，再比较词袋等简单基线，才能判断表示收益。

<a id="sec-4"></a>

## 4. 词表是模型的一部分

训练与推理必须使用对应的 tokenizer 和词表。同一个整数 token id 在不同词表中可能代表不同文本，模型权重能加载并不意味着输入编码兼容。特殊 token、截断方向和最大长度也会影响结果，需随模型配置一起保存。

文本长度超过上限时，直接截断可能删除决定标签的结尾。可按段处理、滑动窗口或设计聚合，但要避免同一文档不同段跨训练测试泄漏。长文本任务应单独检查不同长度区间的错误，不能只报告总体分数。

<a id="sec-5"></a>

## 5. 分词长度与标签对齐

一个词可拆成多个子词，实体标注要约定只标首子词、复制标签还是采用其他映射。特殊符号和 padding 通常应从相关损失中排除。词级指标也需把子词预测还原，不能拿子词准确率冒充实体质量。

分词器、词表和特殊 token 应随权重保存；相同数字 id 在另一词表中可能完全不同，模型可运行不表示输入正确。

<a id="sec-6"></a>

## 6. 进阶：分词改变概率单位与输入几何

同一文本在不同 tokenizer 下长度和预测事件不同，因此每 token 困惑度不是统一尺度。词表、特殊符号、规范化和截断策略共同构成模型接口，权重可加载并不保证编码兼容。

TF-IDF 的 IDF 与词表也是数据拟合，不可在全数据先估计再做归纳评价。子词减少未知词问题，却不自动解决语义组合；静态、上下文和句级嵌入的训练目标不同，不能任意池化后假定拥有相同检索性质。

<a id="sec-6-1"></a>

### 分词与词表定义了模型看到的随机变量

同一句话按字、词或子词切分会得到不同长度与词表，进而改变稀疏性、未知项和概率单位。清洗也会改变信息：删除标点可能损失情感或结构，统一大小写可能合并本来有意义的实体。预处理需要依据任务，而不是把所有文本变成最少字符。

TF-IDF 用词频与逆文档频率突出有区分度词项，词表和 IDF 只能从训练文档估计。重复文档跨划分、模板来源相同或同一作者片段泄漏，都可能让简单基线看起来异常好。先检查去重与划分，再解释模型能力。

静态词向量给词项相同表示，上下文模型则依据周围内容产生表示。后者能区分多义用法，但需要更多数据、计算和正确掩码。比较时保留强稀疏基线，才能判断收益来自上下文建模，而不是更好的预处理或更多训练信息。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 为什么训练前在全数据上拟合 TF-IDF 词表和 IDF 也可能构成泄漏？

**答案：** 测试语料的词汇和频率参与了表示选择，使评估不再模拟未见文本。应把向量器放入训练 Pipeline，在验证折内拟合。

<a id="sec-7-1"></a>

### 边界追问：更强清洗是否总改善文本表示

**问题：** 统一删除数字、标点和大小写后分类分数变化，如何判断清洗是否合理？

**推理解析：** 先看目标是否依赖数量、否定、边界或实体大小写。清洗会改变可用信息，不只是去噪。用保留与删除的控制样例比较，在训练内选择规则；测试文本反馈参与调优应明确。不能把最少字符或最整齐文本自动称为最好输入。
