# 大语言模型

把预训练、后训练、检索、微调和评估连接起来，理解语言模型的能力与边界。

**先修知识：** NLP、Transformer、概率与模型评估。

## 学习顺序与覆盖范围

本主题分为两条实践支线：微调按第 1 → 2 → 4 章阅读，检索问答按第 1 → 3 → 5 章阅读。微调不是开始 RAG 的必修步骤，两条支线最终都要接受固定数据与评价协议的检验。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

微调支线在第 4 章核对数据、监督区域与训练验收；RAG 支线在第 5 章完成[综合练习：将 RAG 错误定位到可验证阶段](05-RAG系统拆解与评估集构建.md#sec-8-1)。可按目标分别完成，不要求先走另一条支线。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
