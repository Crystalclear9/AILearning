## 1. 模型学习的基本目标

自回归语言模型预测下一个 token 的条件分布。它通过大量文本学习统计结构、语法、知识关联与部分推理模式，但训练目标并没有直接保证事实真实或行为可靠。能继续写出合理句子，与能给出可验证结论是不同要求。

token 不等于字或词，不同语言与 tokenizer 的长度比例不同。上下文窗口限制模型一次可处理的信息范围，生成预算也会消耗相应资源。窗口更长并不意味着任意位置的信息都能同样可靠使用。

<a id="sec-1-1"></a>

### 基础算例：序列似然不是完整任务正确率

参考回答有四个 token，各条件概率为 0.5，整段概率为 1/16，平均 token NLL 为 log2。模型若更偏好另一种同义表述，参考 NLL 可能不佳而任务回答仍正确；也可能常见措辞概率高但事实错误。预训练似然和任务评价因此需要并列理解。分词器改变后，token 单位和序列长度也变，困惑度不宜脱离编码协议直接排名。

<a id="deep-dive-1"></a>

### 深入讲解：下一token目标为何能训练语言能力却不等于事实保证

自回归目标最大化真实序列各token的条件概率，训练时真实前缀已知，推理时前缀包含自身生成。它学习数据中的条件统计，文本看似自然不自动保证主张真实或任务完成。

tokenizer决定离散单位、长度和特殊符号。相同文本在不同词表中有效token数不同，困惑度和预算需按相同定义比较；起止、padding与对话模板也进入实际函数。

预训练数据的来源、重复和采样权重影响学到的分布。更多记录不等于等量新增信息，同模板大量复制会改变权重而非提供全新覆盖。评价题转载和同源改写也可能造成污染。

模型权重、临时激活和KV缓存共同占资源。批量、上下文、生成长度与键值头数影响缓存，prefill和decode瓶颈不同，不能只用参数位宽估所有推理内存。

理解目标后再分析能力：概率损失、完整生成、事实与工具任务需要不同评价。模型可提高平均文本预测，同时仍在罕见实体和数字上失误，分项证据比单一分数更有解释力。

<a id="sec-2"></a>

## 2. 预训练的数据与成本

清洗、去重、质量筛选与数据混合会影响能力。重复内容可能提高记忆而非泛化；测试集混入训练造成基准污染。参数规模、训练 token 数、优化设置和计算预算共同影响表现，不能只比较参数数量。

困惑度需要在相同分词和数据协议下解释。预训练损失降低通常说明分布拟合改善，但某个实际问答或工具任务仍需独立评估。

<a id="sec-2-1"></a>

### 机制展开：训练成本由有效序列与更新预算共同决定

参数规模、序列长度、批量、训练 token、精度和优化状态决定不同资源项；仅比较数据文件字节无法推断算力。重复内容可能增加 token 却不同比增加覆盖，长样本截断又改变有效监督。记录数据混合、有效 token 与选择过程，再看预训练 loss 和任务指标，避免把更大总量自动解释成更高质量信息。

<a id="sec-3"></a>

## 3. 推理中的资源

参数权重、KV cache 和临时激活共同占用内存。批量、上下文长度、输出长度、精度与模型结构都影响成本。量化可降低部分内存与计算开销，但效果取决于硬件和实现，也需要检查质量变化。

对 L 层、批量 B、缓存长度 T、每层 $h_{kv}$ 个键值头及每头维度 d，若 K 和 V 采用相同精度，每元素占 b 字节，原始 KV 张量容量约为 $2LBTh_{kv}db$。这只是缓存本体估计，实际还有分页、对齐和临时内存；分组查询注意力的键值头数也不等于查询头数。

长提示的 prefill 与逐 token decode 计算形态不同，应分别测首 token 延迟、后续 token 吞吐和峰值内存。增加并发通常提高总吞吐，却可能增加单请求等待。量化后重新检查任务正确性及数值异常，且区分权重量化和 KV 量化，不能把权重位宽直接用于估算所有内存。

<a id="sec-4"></a>

## 4. 记忆知识与使用上下文

参数中的知识可能过时，也可能只保留模糊关联；上下文则提供当前输入的信息，但模型仍可能忽略、混淆或错误整合。让模型复述给定文档、回答事实问题和做多步推理，应使用不同测试检查，不能用一种能力替代另一种。

长上下文评估还要改变证据位置、干扰内容和问题形式。若答案总放在开头，测试可能高估任意位置读取能力。应检查多个长度和位置，尤其是相似实体与版本冲突场景，让成绩反映真正需要的使用方式。

<a id="sec-5"></a>

## 5. 数据规模与有效信息

更多 token 不一定等于更多独立知识，重复、低质量与错误数据可能强化记忆和偏差。语料混合比例、去重与污染检查都是训练设计，参数规模不能单独解释能力。

评估还需看任务和语言覆盖。一个基准高分不表示在新领域、长文档或更新知识下同样可靠，应报告具体范围。

数据条数、字符数和有效训练 token 是不同单位；近重复、模板及转载可能让大数据量包含较少新增信息。先检查来源比例、时间、语言和重复簇，再根据目标任务安排采样权重，避免高频来源淹没小语种或稀有类型。

评价数据要与预训练和开发来源尽量隔离，公开题目可能已经广泛转载。所谓“更多数据改善”需要固定或说明模型、清洗、训练计算及采样变化。有效信息无法只由一个总量准确衡量，应结合覆盖与新来源表现判断。

<a id="sec-6"></a>

## 6. 进阶：预训练似然与任务能力之间的间隔

NLL 衡量模型对特定语料与分词单位的概率拟合，不直接等于事实、推理或工具任务成功。参数、数据量、混合质量和计算预算共同影响表现；语料重复和基准污染可使高分包含记忆。

缩放规律是特定范围中的经验关系，外推需要说明训练配置与误差。长窗口也是接口能力，不等于任意位置可靠利用。研究评价应覆盖长度、证据位置、时间与新任务，而不由单一基准或参数规模推断全面能力。

<a id="sec-6-1"></a>

### 下一 token 目标与任务能力之间还有评价层

预训练通过条件似然学习序列分布，输入编码决定 token 单位与长度。更低 token NLL 表示该编码和评价文本下概率拟合更好，不直接证明事实、规划或工具使用都改善；这些能力需要对应任务与数据。

数据量之外还需检查重复、来源比例和质量。重复文本增加训练 token 数，却未必同等增加有效覆盖；来源混合改变模型看到的任务分布。训练与评价近重复也会让能力判断过度乐观。应把总 token、独特内容与评价污染分开记录。

推理成本由参数、上下文、输出长度、精度与缓存共同决定。固定提示下回答更长可能同时改善某些评价偏好并增加成本，因此比较应固定预算或明确长度策略。不能把模型规模当成实际系统效果与资源需求的唯一指标。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 为什么两个不同 tokenizer 的模型不能只比较每 token 困惑度就排名？

**答案：** token 切分单位和序列长度不同，同一文本被拆成不同预测任务。需采用一致协议或合适的归一化评价，并结合实际下游任务。

<a id="sec-7-1"></a>

### 边界追问：更多 token 是否总代表更多有效信息

**问题：** 重复同批文档很多次后训练量增加，能否直接当作同比增加数据覆盖？

**推理解析：** 不能，重复会改变权重与记忆风险，不等于新增来源和任务。还需检查去重、混合、质量与评价污染。预训练 loss 下降与外部能力改善各需证据，分词与有效监督单位也要固定；文件字节或总 token 只是规模描述的一部分。
