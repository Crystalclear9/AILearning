## 1. 预训练后还要学习什么

监督指令微调使用指令与目标回答，让模型学会按任务格式响应。训练样本中哪些 token 计算损失应明确，常见做法是重点优化助手回答，而不是把所有角色文本都等价当作目标。

偏好学习利用相同提示下的回答比较，塑造更符合需求的行为。RLHF 常训练奖励模型后优化策略，DPO 等方法直接构造偏好优化目标。偏好数据质量、覆盖与评价者偏差都会影响结果，不能把“人类偏好”视为绝对真值。

<a id="sec-2"></a>

## 2. LoRA 的低秩更新

冻结原矩阵 $W$，令更新 $\Delta W=BA$，其中秩 $r$ 远小于输入输出维度。若 $W$ 为 $d_{out}\times d_{in}$，新增参数约为 $r(d_{in}+d_{out})$，比全量微调少。

例如 $1024\times1024$ 矩阵用 $r=8$，新增 $8(1024+1024)=16384$ 个参数，而原矩阵有 1048576 个。它减少可训练参数和相应优化器状态，但不意味着原模型权重与前向计算消失。

<a id="sec-1-1"></a>

### 基础算例：低秩更新的参数量手算

原矩阵为 1024×1024，完整更新约一百万参数。rank=8 的两因子分别为 8×1024 和 1024×8，共 16384 参数，未计偏置与其他可训练部分。节省来自限制更新矩阵秩，不代表原模型无需保存或前向。选择目标层、缩放与初始化都会改变实际行为。比较全量与低秩微调时还需控制数据、预算与评价，不能只按可训练参数比例断言同倍速度收益。

<a id="sec-2-1"></a>

### 机制展开：低秩因子梯度可直接由矩阵微分得到

有效权重 W+sBA，若上游对权重梯度为 G，则 B 梯度为 sGAᵀ，A 梯度为 sBᵀG。A 随机、B=0 时初始函数不变，通常 B 可先更新、A 首步为零；双零会阻断这条双线性更新。因子还有缩放不唯一性，rank、目标层与缩放需一起记录。省可训练参数不等于基础前向、缓存和全部显存按相同比例减少。

<a id="sec-3"></a>

## 3. 微调前确定要改变什么

如果问题是模型不知道某份经常更新的文档，检索可能比微调更直接；若问题是稳定输出格式或领域任务行为，微调可能更合适。两者也可以结合。训练验证应按文档来源、任务或时间隔离，防止同一模板换几个词就分到两边。

先保留一组实际失败请求，判断失败来源：知识缺失、检索不准、格式不稳定、指令理解或工具执行。知识经常更新时，可优先修文档与检索；格式和任务行为需要稳定学习时，监督微调更直接；回答之间的偏好取舍则需要成对偏好及相应评价。

将目标写成可验收指标，再决定数据与方法。若同一改动同时更换底座、提示模板和微调数据，无法辨认收益来源。微调后用目标任务、旧能力回归和新来源样本共同检查，不能把训练损失或少数熟悉例子当成行为已经全面改变。

<a id="sec-4"></a>

## 4. 微调样本质量与分布

大量模板相似样本可能只教会固定措辞，而没有覆盖任务变化。应包含不同长度、边界、失败情况与合理的不确定回答。把同一原始文档生成的多个问答随机分到训练和验证，可能让验证只测试记忆来源内容，而非新文档泛化。

微调后还需检查原有能力、格式遵循和目标领域以外的行为是否变化。只看训练损失不能判断是否过拟合。选择检查点、秩、学习率和训练轮次时保持独立验证，最终使用未参与选择的任务集合评价。

<a id="sec-5"></a>

## 5. 监督与偏好目标不同

监督微调提高目标回答概率，偏好学习则比较候选回答或优化奖励。二者数据来源、损失与偏差不同。奖励高不必然代表事实正确，模型可能优化评价器偏好而非真实需求。

微调后应检查基础能力是否退化，并在未参与训练和选择的新任务上评估。不能只凭训练损失和几个手选提示宣称全面改进。

<a id="deep-dive-5"></a>

### 深入讲解：监督答案偏好比较与低秩更新是三个不同层次

监督微调用目标回答提高相应序列概率，通常只对有效助手token计损失；偏好学习比较同提示下多个回答相对好坏。两者监督信号不同，偏好标签也不是事实真值，可能包含长度和风格偏差。

DPO用相对参考策略的获选与被拒回答log概率差，进入logistic损失。参考策略冻结，同提示使归一化项可在相应推导中抵消；将序列概率按token平均会改变目标，不能当无关细节。

LoRA是参数化方式：W冻结、更新BA秩受限。r远小于输入输出维时减少可训练参数与优化状态，但基础前向和激活仍有成本；它可用于监督或偏好训练，不是另一种同层级任务目标。

A随机、B零保持初始函数不变，首步通常B得梯度、A为零；双零会阻断该双线性路径。缩放、目标层和秩共同影响表达与优化，不能只按参数比例推速度。

先确定知识缺失、格式行为还是偏好问题，再选数据和训练。验收目标能力、旧能力、长度成本及新来源，避免只看训练loss和熟悉提示就宣布全面改善。

<a id="sec-6"></a>

## 6. 专题推导：LoRA的梯度与初始化

设冻结底座 W，增量为 $sBA$，其中 $A\in\mathbb R^{r\times d_{in}}$、$B\in\mathbb R^{d_{out}\times r}$，s 是缩放。若损失对有效权重梯度为 G，则 $\nabla_B L=sGA^T$、$\nabla_A L=sB^TG$。这明确了低秩因子如何接收更新，不是给 W 少训练几个元素。

常见初始化 A 随机、B 为零，使初始函数等于底座；此时 A 首步梯度为零，B 通常非零，后续才共同学习。如果两因子都为零，两边梯度都为零，适配会停住。若不冻结底座，则已经变成另一种训练设定。

```python
import torch
torch.manual_seed(42)
W = torch.randn(3, 4, dtype=torch.float64)
A = torch.randn(2, 4, dtype=torch.float64, requires_grad=True)
B = torch.zeros(3, 2, dtype=torch.float64, requires_grad=True)
x = torch.randn(5, 4, dtype=torch.float64)
scale = 0.5
prediction = x @ (W + scale * B @ A).T
assert torch.allclose(prediction, x @ W.T)
prediction.square().mean().backward()
assert torch.allclose(A.grad, torch.zeros_like(A))
assert B.grad.norm() > 0
print("first-step gradient structure passed")
```

BA 的分解不唯一：对可逆 R，$BA=(BR)(R^{-1}A)$，函数相同但因子尺度与优化状态可不同。因此参数数目与秩描述表达约束，却不足以确定优化行为。秩、缩放、目标层和学习率应共同报告，合并到 W 后也要核对预测一致与精度误差。

<a id="sec-7"></a>

## 7. 进阶：KL约束偏好目标与低秩适配

KL 正则奖励优化的理想最优策略满足 $\pi^*(y\mid x)\propto\pi_{ref}(y\mid x)\exp(r(x,y)/\beta)$。DPO 利用该重参数化在相应偏好模型下构造直接目标，不等于无需假设就获得真实奖励。

LoRA 则约束更新 $\Delta W=BA$ 的秩，减少可训练自由度；能否覆盖所需改动取决于目标模块与秩。可训练参数少不自动意味着同倍数显存节省或无遗忘。偏好、格式与事实能力需分别验收。

<a id="sec-7-1"></a>

### 从 KL 约束目标到 DPO 损失与梯度

令 $\beta>0$ 为奖励目标中 KL 惩罚系数。在理想最优策略表达式中取对数，可得 $r(x,y)=\beta\log[\pi^*(y\mid x)/\pi_{ref}(y\mid x)]+\beta\log Z(x)$。采用 Bradley–Terry 偏好模型 $p(y_w\succ y_l\mid x)=\sigma(r(x,y_w)-r(x,y_l))$ 时，同一提示下的 $Z(x)$ 项相消。以可训练策略替换理想策略后，定义

$$
\Delta_\theta=
\log\frac{\pi_\theta(y_w\mid x)}{\pi_{ref}(y_w\mid x)}
-\log\frac{\pi_\theta(y_l\mid x)}{\pi_{ref}(y_l\mid x)},\qquad
L_{DPO}=-\mathbb E\log\sigma(\beta\Delta_\theta).
$$

$y_w$ 是偏好回答、$y_l$ 是被拒回答，参考策略冻结。单对损失可稳定计算为 `softplus(-beta * delta)`，其对 $\Delta$ 的导数是 $-\beta\sigma(-\beta\Delta)$；当 $\Delta=0$ 时为 $-\beta/2$。优化提升的是相对于参考策略的偏好差，不要求每个样本的获选回答绝对概率都单调增加。

语言模型的回答 log 概率是给定提示及此前回答 token 后，各有效回答 token 的 log 概率之和；padding 应屏蔽，提示作为条件，不直接计入回答损失。换成按长度平均会改变目标，不能当成无关实现细节。成对回答必须对应同一提示，且参考策略对比较回答需有支持。标签冲突、评价者偏好、长度效应和数据覆盖都影响学到的行为；偏好改善仍需独立检验事实准确性。

下面只核对双候选玩具模型的一次梯度方向，不包含真实语言模型的序列训练：

```python
import math
import torch
import torch.nn.functional as F

logits = torch.zeros(2, dtype=torch.float64, requires_grad=True)
reference_logp = torch.full((2,), -math.log(2), dtype=torch.float64)
beta = 0.5
logp = logits.log_softmax(dim=0)
relative = logp - reference_logp
delta = relative[0] - relative[1]  # candidate 0 is preferred
loss = F.softplus(-beta * delta)
loss.backward()
assert math.isclose(loss.item(), math.log(2), rel_tol=1e-12)
assert torch.allclose(logits.grad, torch.tensor([-0.25, 0.25], dtype=torch.float64))
updated = logits.detach() - 0.1 * logits.grad
assert updated.softmax(dim=0)[0] > 0.5
print("DPO pair loss and local gradient passed")
```

推导假设与目标见 [DPO 原论文](https://arxiv.org/abs/2305.18290)。上面的理想策略关系不表示有限模型、有限偏好样本和实际优化必定找到该最优策略。

<a id="sec-8"></a>

## 8. 练习与参考答案

**练习：** LoRA 只训练少量参数，是否意味着训练显存按相同比例下降？

**答案：** 不是。原模型权重、前向激活和部分反向中间量仍占内存，节省比例取决于实现、精度和优化器。应实际测量峰值，而非只按可训练参数比例估计。

<a id="sec-8-1"></a>

### 边界追问：LoRA 两因子都零初始化会怎样

**问题：** 有效更新 BA，A、B 均为零，首步能否通常自动启动同一双线性路径？

**推理解析：** 两边梯度分别含另一因子，双零可使首步都为零。常见随机 A、零 B 保持初始函数并允许 B 先更新，约定需配缩放与目标层。低秩限制更新空间，不保证每任务与全量等效；基础权重、前向和缓存成本仍需核算。
