## 1. 图网络并非越深越好

反复聚合可能让节点表示越来越相似，即过平滑。另一种困难是大量远处信息被压缩进有限维表示，常称过挤压。残差、归一化、结构调整或不同传播机制可以缓解某些问题，但应通过实际任务验证。

大图邻居数随跳数迅速增加，可用邻居采样控制计算。采样改变了聚合估计及信息覆盖，训练与推理流程应一致或明确处理差异。高连接度节点还可能主导内存与计算。

<a id="deep-dive-1"></a>

### 深入讲解：过平滑过挤压与采样误差不是同一个瓶颈

多轮相似聚合可能使节点表示趋同，难区分类别，这是过平滑的一种表现。远处大量信息经有限维向量和狭窄图路径压缩，则是过挤压的相关问题；二者都可能随深度出现，但机制不同。

增加层数也改变优化与采样规模，性能下降不能自动归因某个名称。可观察表示相似、远距离任务、梯度及结构对照，分别提出可区分解释的实验。

邻居采样减少子图规模，fanout多层展开可能迅速增长。单层均值在特定采样下可无偏，叠非线性与多层后不保证完整网络输出无偏；训练与评价采样协议需记录。

传导任务允许某些未标注节点特征和合法边可见，归纳任务面对新节点或新图。链接预测需移除目标边及反向副本，时间任务构图只能用过去；信息条件不同的分数不能直接比较。

报告实际节点边数、层数、采样与内存，并以无图或浅层基线判断复杂性是否值得。图学习的收益来自合法关系信息，而不只是使用更多邻居。

<a id="sec-2"></a>

## 2. Transductive 与 inductive

传导式设定允许训练时看到未标注测试节点的特征和图结构，但不使用其标签；归纳式设定评估未见节点或全新图。这两种协议回答不同问题，使用相同数据集也可能得到不可直接比较的结果。

允许看到某些结构信息并不等于允许使用未来边。交易风险等任务必须按预测时点构建图，不能让事后发生的关系反向进入训练特征。

<a id="sec-1-1"></a>

### 基础算例：图划分不仅是标签切分

训练节点和测试节点间存在边时，消息传递可能读取测试节点特征。Transductive 协议可允许这种无标签结构可见，inductive 新图协议则通常不允许预见新图。仅把标签数组分开不说明输入边界已经正确。链接预测还需从消息图排除不应预知的目标边。报告应明确节点、边、特征、时间和标签分别在何时可见，而不是只写一个训练测试比例。

<a id="sec-2-1"></a>

### 机制展开：传导与归纳评价使用不同信息

传导设置可允许测试节点的无标签特征和边参与表示，归纳新图则不能预先使用未来图。两者都可合法，但结论范围不同。标签分割不等于结构隔离，链接预测还需检查目标边、反向边和未来构图。比较时明确训练可见节点、边、特征与时间，不要把协议不同的分数直接当作算法优劣。

<a id="sec-3"></a>

## 3. 链接预测的特别检查

要从训练图中移除待预测边，并处理无向边的反向副本，避免模型直接看到答案。负样本不能从真实已存在但被划入测试的边中随意抽取。采样负例比例会影响 PR 指标和实际部署的难度。

划分应先于消息传递输入构建。无向边 (u,v) 与 (v,u) 属于同一关系，必须一起移除；用全部图计算的路径、度或嵌入也可能泄漏目标边，应按协议重新生成。时间链接预测只能使用截止时点已出现的边，负例应根据任务定义为该时点未连接或预测窗口内未形成连接，两种标签不能混用。

离线基准若知道全部正边，可按约定排除它们来抽负例；真实时间预测则不能用未来是否成边反过来构造当时可见特征。记录候选节点范围、负例数量与抽样分布，并固定评估候选集合。只在少量随机负例上取得高分，不等于能在全库高相似候选中检索成功。

<a id="sec-4"></a>

## 4. 图划分还涉及结构可见性

节点标签被遮住，不代表所有问题都已避免泄漏。如果某条边是根据标签或预测时点之后的行为构建，图结构本身已经编码答案。应说明节点特征、边及其时间是如何生成的，允许哪些信息在训练中可见。

对于新图归纳任务，训练测试应按整张图划分；若同一分子重复结构或近重复子图跨边界，可能高估泛化。不同协议下的图学习结果应分别解释，不能把传导式成绩直接当作面对全新结构的能力。

<a id="sec-5"></a>

## 5. 采样与小批评估

邻居采样减少计算，却可能漏掉关键边或高阶结构。不同层采样数影响覆盖与方差；训练和完整图推理的差异需说明。

大图分批推理还要避免节点重复计数与标签掩码错误。图可见范围、邻居采样与测试节点特征是否参与，应写进协议。

邻居采样改变一批中实际可见的子图，需记录每层 fanout、方向、是否放回、是否包含自身与边权。均值聚合在特定采样条件下可以估计完整邻域均值，但叠加非线性、多层相关采样与注意力归一后，不能直接宣称整个网络输出无偏。

评价可使用完整邻域或固定采样协议，两者成本与波动不同。若沿用训练随机采样，明确种子或重复次数，检查稀有邻居是否被遗漏。时间任务的采样也只能访问当时合法边，不能因构造小批子图就放松信息可见性。

<a id="sec-6"></a>

## 6. 进阶：过平滑与过挤压是不同机制

简化线性传播反复乘归一化邻接，在相应连通性条件下可能趋向低维主子空间，节点差异减弱；过挤压则是大量远处信息通过有限通道和瓶颈被压缩。两者都可能随深度恶化，但修复策略与证据不同。

残差、重连和归一化不能保证所有任务改善。评估还需说明传导式可见结构与归纳式新图边界，未来边、目标生成的边或反向测试副本都是结构泄漏，遮标签本身不足以保证独立。

<a id="sec-6-1"></a>

### 过平滑与过挤压需要不同诊断

重复邻域平均可能使节点表示越来越接近某个低维平稳子空间，这是过平滑的一种线性直觉；过挤压则指大量远处信息通过有限维瓶颈传播时难以保留。增加深度会同时改变可达范围、噪声和瓶颈，不能把所有深层失败都叫过平滑。

可以测量表示间距离或秩随层数变化，并用控制图结构与远距离任务检验信息瓶颈。残差、归一化、重新连边和采样处理的机制不同，比较时应说明目标是维持差异、扩大通路还是降低计算。

Transductive 协议可能允许看到测试节点的无标签结构，inductive 则通常面对新节点或新图。两者信息集合不同，分数不能脱离协议比较。链接预测还需防止把待预测边留在消息传递图中，以及负样本使用未来知识造成泄漏。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 无向图把边 `(u,v)` 放进测试，但训练图仍含 `(v,u)`，有什么问题？

**答案：** 对无向关系它们是同一条边，训练已看见答案。应对无向边统一规范化并成对移除，同时说明采样与评估规则。

<a id="sec-7-1"></a>

### 边界追问：传导高分能否直接声称新图泛化

**问题：** 训练可见全部测试节点特征和无标签边，能否把成绩当完全未见图能力？

**推理解析：** 不能，两种协议输入不同。明确节点、边、特征、标签与时间可见性，分别做传导或归纳测试。只拆标签不能证明结构隔离；也不能把合法传导协议笼统称泄漏。评价结论必须对应具体部署信息集合。
