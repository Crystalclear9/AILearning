## 1. 图比普通表多了关系

图 $G=(V,E)$ 包含节点和边，可带节点特征、边特征和方向。用户交易网络、分子结构和引用网络对应不同关系语义。边可能代表相似、接触或流向，不能默认相邻节点一定属于同一类别。

节点任务预测每个节点属性，边任务预测连接或关系，图任务预测整个分子的性质。输入输出粒度不同，训练与池化方式也不同。

<a id="sec-2"></a>

## 2. 消息传递的三个步骤

每层先根据邻居和边构造消息，再通过求和、均值或其他置换不变操作聚合，最后更新节点表示。邻居没有自然顺序，因此聚合不应依赖任意编号。堆叠 $k$ 层后，节点通常能够接收 $k$ 跳范围的信息。

经典 GCN 一层写为 $H^{(l+1)}=\sigma(\tilde D^{-1/2}\tilde A\tilde D^{-1/2}H^{(l)}W^{(l)})$，其中 $\tilde A=A+I$ 加入自环，$\tilde D$ 为对应度矩阵。归一化控制不同度数的聚合尺度；自环让节点保留自身信息。

<a id="sec-1-1"></a>

### 基础算例：三节点一轮消息传递

链图 A—B—C，节点标量特征为 1、2、5，采用含自身的邻居均值聚合。A 新值为 (1+2)/2=1.5，B 为 (1+2+5)/3=8/3，C 为 (2+5)/2=3.5。若不含自环，结果完全不同；若边有方向，可见邻居也改变。这个手算模型不是所有 GCN 的归一公式，但能核对邻居集合、共享规则和同步更新语义，再逐步替换成具体算子。

<a id="sec-2-1"></a>

### 机制展开：消息、聚合与更新可分别改变

消息函数处理发送者、接收者和边属性，聚合把可变邻居集合汇总，更新将结果与中心状态组合。聚合应对邻居排列不敏感，节点共享规则保证相应等变性；有向边与关系类型不能随意抹平。自环是否包含中心、是否度归一以及激活放在哪里，都改变实际算子。先在小图列邻居和权重，再将矩阵表达与逐节点计算对照。

<a id="gcn-normalization-example"></a>

### 对称归一化 GCN 与邻居均值的数值区别

仍取无向链图 A—B—C，加入自环后度数为 $(2,3,2)$，对称归一化传播矩阵为

$$
S=\tilde D^{-1/2}\tilde A\tilde D^{-1/2}
=\begin{pmatrix}
1/2&1/\sqrt6&0\\
1/\sqrt6&1/3&1/\sqrt6\\
0&1/\sqrt6&1/2
\end{pmatrix}.
$$

取 $h=(1,2,5)^T$、标量权重 $W=1$ 且暂不加激活，得到 $Sh\approx(1.3165,3.1162,3.3165)^T$。这与前面邻居均值的 $(1.5,8/3,3.5)^T$ 不同，因为对称归一化的边权是 $1/\sqrt{d_i d_j}$，随机游走式均值的边权则是 $1/d_i$。对称归一化矩阵的每行和也不一定为 1，不能用“是否保留常数向量”检验它是不是均值算子。

实现时确认邻接方向、度数来自加自环之后的矩阵、已有自环是否重复计入，以及层是否已经自行添加自环。逐节点手算和矩阵乘法应一致。公式及接口约定见 [GCNConv 文档](https://pytorch-geometric.readthedocs.io/en/latest/generated/torch_geometric.nn.conv.GCNConv.html)。

<a id="deep-dive-2"></a>

### 深入讲解：消息传递的邻居集合权重与置换性质

每层先从邻居构造消息，再无序聚合，最后结合中心状态更新。堆叠k层通常扩大到k跳，具体范围还受方向、采样和关系类型影响；把图无条件对称化会改变可见信息。

GCN加自环后用D⁻¹/²AD⁻¹/²归一，不等于简单行均值。邻居度数同时进入边权，因此不必每行和为1。先在三节点链列邻接、自环、度和权重，再矩阵乘，可理解算子真正来源。

共享函数和无序聚合使节点重编号时输出对应重排，即等变；图级池化再可不变。只换特征不换边是在改图，不是同图重新命名，不能据此检验等变性。

相邻标签相似是同质性假设，与存在多种节点类型的异质图概念不同。异配关系也可能有用，只是简单平均未必适合，需要方向、关系或高阶结构。

无图MLP与结构消融帮助判断关系收益。构图若使用目标标签或未来边，模型可通过结构泄漏答案；图预处理的信息边界同样属于训练协议。

<a id="sec-3"></a>

## 3. 同质性与异质性

引用网络中相连论文可能主题相似，邻居平均有帮助；交易网络中相邻账户的类别未必相同，盲目平滑可能损失区别。需要结合边类型、方向、时间和任务选择模型，不能把图卷积当作通用去噪器。

同质性描述相连节点在某类属性上相似，不等于“图中有多种节点类型”的异质图；单一节点类型也可能具有异配性，即相邻标签经常不同。是否有利于邻居平均，需要结合目标属性和关系语义判断，不能由网络名称推定。

可在训练可见的标签与边上检查同类连接比例，并与类别比例参照比较；再用特征 MLP、带自信息的邻居模型及关系消融验证。即使标签异配，关系仍可能通过更高阶结构或特定方向提供信息；简单平均失败不等于图信息完全无用。

<a id="sec-4"></a>

## 4. 有向关系不能无条件对称化

引用、转账和关注都可能有方向。把边简单变成无向，会改变信息含义：被引用与引用他人、收到钱与转出钱并不相同。可分别编码入边和出边，或使用关系类型专门建模；结构处理应由任务决定。

边权也需明确单位。交易金额、出现频次和相似度不是可互换权重。加入自环、做归一化后，其相对影响会变化。先用小图手工计算一层聚合，观察每个节点从哪些邻居收到什么，是理解图网络接口的有效办法。

<a id="sec-5"></a>

## 5. 节点特征与结构同样重要

图模型不一定优于只用节点特征的 MLP。若边噪声多或同质性弱，邻居聚合可能损害预测。应同时建立无图基线，判断关系提供了多少额外信息。

节点编号不应无意编码标签，边的生成规则也需透明。图结构若由预测目标反推构建，再用于预测相同目标，会形成结构性泄漏。

基线可用相同节点特征的 MLP，再逐步增加合法关系信息。若图网络改善，检查收益是否来自边、额外标签传播、构图使用了不同时间信息，或仅仅增加参数；控制划分与信息边界，才能归因。

节点 ID 的嵌入在固定传导图上可能有用，但对新节点需要额外定义，不能当作通用可迁移特征。图级读出也要检查节点规模是否成为捷径。分析特征、结构与两者交互时，各自的噪声和来源分布都应进入消融。

<a id="sec-6"></a>

## 6. 进阶：消息传递的置换等变性

对节点重排 P，邻接变为 $PAP^T$，特征变为 PX，基于共享变换和对邻居置换不变聚合的层应输出原结果左乘 P。图级读出再取置换不变聚合，才能不依赖任意编号。

此性质不保证结构区分能力。均值聚合会把不同多重集合映成相同均值，某些图在有限消息传递中不可区分。位置、类型和边特征改变可表达信息，也改变模型假设，应通过无图和结构消融检验收益。

<a id="sec-6-1"></a>

### 置换等变性来自共享与无序聚合

对节点置换矩阵 P，邻接与特征共同变为 $PAP^T$、PX。若消息函数共享，邻居聚合对排列不敏感，节点输出应对应变为 PH，而不是数值固定在原节点编号上。这是等变；对整图读出使用求和等无序操作后，才得到图级不变性。

标准化 GCN 常使用含自环的邻接与度矩阵，目的是控制不同度数的聚合尺度。漏掉自环、把有向图无条件对称化或使用错误度定义，都改变模型信息路径，不能仅因最终矩阵可相乘就认为等价。

节点特征和结构分别携带信息。应比较无结构特征模型、结构模型及合理消融，判断收益是否真的来自关系。若标签直接或间接参与构图，必须核对构图发生在训练边界内，避免关系本身泄漏答案。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 节点编号从 1、2、3 换成 8、5、9，但结构和特征对应关系不变，节点预测应发生什么？

**答案：** 预测应随节点重排相应重排，而非改变语义结果。节点级网络通常需满足置换等变性，图级池化则需相应的置换不变性。

<a id="sec-7-1"></a>

### 边界追问：节点重新编号应怎样改变输出

**问题：** 仅将节点编号置换，同时置换邻接与特征，节点输出应完全不变还是对应置换？

**推理解析：** 节点任务应对应置换，即等变；图级无序读出才可不变。只换特征而不换边是在改变图，不是同一输入重命名。用小图检验有助发现按编号捷径或聚合顺序错误，性质还依共享消息和排列无关聚合的结构。
