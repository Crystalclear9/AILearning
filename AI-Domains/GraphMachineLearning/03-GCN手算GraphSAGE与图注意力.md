## 1. 一个三节点例子

设链式图 1—2—3，加自环后度数为 2、3、2。GCN 中边 1—2 的归一化系数为 $1/\sqrt6$，节点 2 自环为 1/3。它不是简单对所有邻居等权平均，而采用对称度归一化。

```python
import numpy as np
A = np.array([[0., 1., 0.], [1., 0., 1.], [0., 1., 0.]])
At = A + np.eye(3)
d = At.sum(axis=1)
S = At / np.sqrt(d[:, None] * d[None, :])
X = np.array([[1.], [0.], [2.]])
H = np.maximum(S @ X, 0)
print(S, H, sep="\n")
assert np.isclose(S[0, 1], 1 / np.sqrt(6))
```

## 2. GraphSAGE

通过采样邻居并聚合特征构造节点表示，适合新节点归纳使用。聚合可采用均值或其他置换不变机制。采样控制规模，但需要足够覆盖与一致的特征接口。

<a id="sec-1-1"></a>

### 基础算例：同一中心节点的两种邻居统计

邻居特征 {1,3} 与 {2,2} 均值都为 2，均值聚合器无法单凭这个结果区分。若额外保留平方和，前者为 10，后者为 8，差异重新显现。是否能区分取决于先映射、再聚合、再更新的组合，不是给聚合换一个名称就自动更强。实际注意力还会随查询与键变化，应在小图中逐个列出分数与归一轴。

<a id="sec-2-1"></a>

### 机制展开：GraphSAGE 共享的是局部生成规则

通过采样邻居并用共享聚合和更新映射，模型可以对新节点计算表示，而不必为每个节点只存独立向量。采样降低计算与内存，却引入随机估计，稀有重要邻居可能被漏掉。每层采样量决定展开规模，多层组合不能只用单层邻居数估算成本。新节点泛化仍需合法特征和关系覆盖，不是方法名自带无条件保证。

<a id="deep-dive-2"></a>

### 深入讲解：均值聚合求和与注意力怎样区分邻域多重集合

GraphSAGE通常聚合采样邻居，再与中心特征组合更新。均值不能区分{1,3}与{2,2}，二者平均都2；求和又可能混淆不同大小集合，需结合表示和函数类分析，不能把某一种聚合称为通用完美方案。

简单非线性映射后求和可保留不同统计，例如同时聚合x与x²，上述两集合二阶和分别10与8。这个例子解释可学习消息为何可能比原始均值更强，但不证明能区分所有图。

GAT在合法邻居内计算分数并softmax，权重相加为1。分母必须排除不可见节点，自环与头拼接约定也影响结果；注意力不是把图结构边界自动变成全连接。

三节点手算应同时核对邻接方向、度归一和同步更新。若逐节点原地更新让后面读取已更新值，就从一层同步消息传递变成另一个算法。

比较聚合器时保持特征、采样和预算，检查任务所需的计数、角色或关系信息。输出形状一样并不代表表示保留了同样结构。

<a id="sec-3"></a>

## 3. 图注意力

图注意力在图给定的邻居集合内学习权重。以单头原始 GAT 为例，先用共享矩阵变换 $u_i=Wh_i$，对允许的边计算 $e_{ij}=\operatorname{LeakyReLU}(a^T[u_i\Vert u_j])$，再在接收节点 i 的邻居集合内归一：

$$
\alpha_{ij}=\frac{\exp(e_{ij})}{\sum_{k\in\mathcal N(i)}\exp(e_{ik})},\qquad
h'_i=\sigma\!\left(\sum_{j\in\mathcal N(i)}\alpha_{ij}Wh_j\right).
$$

这里 $\Vert$ 表示拼接；是否将 i 自身纳入邻居需要明确。假设某节点只有两个可见邻居，分数为 0 与 $\log3$，归一权重就是 1/4 与 3/4。不可见节点不能参加 softmax 的分母，否则实现已改变信息边界。为数值稳定，计算时可先减去本邻域最大分数。

多头注意力让不同头学习不同聚合，常见中间层拼接各头输出、最终层平均；具体维度需按结构核对。它比固定度归一化更灵活，却不自动获得边方向、时间或关系类型信息，也不保证区分所有图结构。注意力系数受邻域和特征共同影响，不能直接解释成因果重要性。实验应与同样特征及划分下的 GCN、GraphSAGE 和无图基线比较，并报告邻居采样与头数的计算成本。

原始结构可对照 [Graph Attention Networks](https://arxiv.org/abs/1710.10903)。

<a id="sec-4"></a>

## 4. 手算聚合后的节点值

节点二收到两侧值一和二的消息，各乘六的平方根倒数，自身值为零，因此输出约为一点二二五。端点节点保留自身的一半并读取中间零值，输出分别为零点五和一。邻接、度归一化与特征各承担不同作用。

若把所有节点特征都设为同一常数，对称归一化的结果不必仍完全相同，因为度结构不同；而简单邻居均值有不同性质。不能把所有图聚合都描述为完全等价平均。

GraphSAGE 和图注意力也需明确自信息、边方向与采样。学习到的邻居权重可能反映关联，但并不证明干预邻居会产生相同作用。解释仍要结合构图机制与外部证据。

<a id="sec-5"></a>

## 5. 综合算例与实现核对

把链式图中间节点的特征改成十，重新计算三个输出。端点除了保留自身，还会读取中间节点约四点零八的贡献；中间节点保留自身约三点三三，再加两侧贡献。这说明高值特征会沿边传播，但不同位置缩放不同。

独立尝试删除自环、改成行归一化、再把边对称性打破，分别解释输出变化。三个实验只改变一项，能区分自信息、度数与方向的影响。不要同时改变权重和图，否则无法解释差异。

验收时除了输出形状，还核对一个节点的手工和。若理论与程序不符，先查邻接矩阵行列方向、度是按哪一轴计算，以及是否重复加自环。图网络常见错误来自表示约定，自动求导无法发现这些语义问题。

<a id="sec-6"></a>

## 6. 专题反例：均值聚合能否识别邻居集合

```python
import numpy as np
sets = [np.array([1., 3.]), np.array([2., 2.])]
assert sets[0].mean() == sets[1].mean()
assert sets[0].sum() == sets[1].sum()
phi_sum = [np.array([x.sum(), (x*x).sum()]) for x in sets]
assert not np.array_equal(phi_sum[0], phi_sum[1])
print(phi_sum)
```

原始均值和求和都把两集合压成相同数值，但先作非线性映射 $\phi(x)=(x,x^2)$ 再求和即可在此例区分。不能由“求和更强”省略映射条件，也不能从这一个反例推导可区分所有多重集或所有非同构图。

图表达能力还受到迭代轮次、初始特征、关系与读出方式限制。一个模型没区分两图，可能是函数族限制，也可能只是训练未学到；应先给出理论不可区分条件或显式构造，再用实验判断优化。增加随机节点编号可能打破对称，也改变了问题假设，需说明是否允许和如何泛化。

<a id="sec-7"></a>

## 7. 进阶：聚合函数的可区分性反例

均值无法区分特征集合 {1,3} 与 {2,2}，最大无法区分 {1,3} 与 {3,3}；求和虽保留计数信息，也需足够表达的变换才有更强多重集区分能力。GIN 的分析将特定消息传递能力与 1-WL 测试联系，并非所有图都可区分。

手算 GCN 还要区分对称归一化与行均值，它们对度结构响应不同。图注意力赋权是学习机制，不自动提升所有表达限制，也不能单凭权重解释因果邻居贡献。

<a id="sec-7-1"></a>

### 聚合器碰撞与非线性映射的作用

邻居多重集 {0,2} 与 {1,1} 的均值都为 1，单独均值不能区分；求和也都为 2，所以不能笼统说求和总比均值强。若先映射 $\phi(x)=(x,x^2)$ 再求和，前者得到 (2,4)，后者为 (2,2)，此时可以区分。

可区分能力取决于消息映射、聚合与更新的组合。GraphSAGE 强调局部采样与共享映射，图注意力按内容给权重，但加权并不自动消除所有结构碰撞。某些对称图在消息传递框架下仍可能不可区分，节点编号也不应被当作合法语义捷径。

手算小图时逐步列出自环、归一化、邻居集合、聚合值和激活，再比较不同聚合器。采样会让同一节点的估计带随机性，度数大或重要邻居稀少时更需检验偏差与方差，而不只测一次前向形状。

<a id="sec-8"></a>

## 8. 练习与解析

**题目：** 为何 GCN 常加自环？如果不加会怎样？

**解析：** 自环让节点更新包含自身特征。无自环时某些结构或层可能只读邻居，孤立节点尤其缺少有效消息；是否需要还取决于额外残差等结构。

<a id="sec-8-1"></a>

### 边界追问：求和是否必然区分所有邻居集合

**问题：** 集合 {0,2} 与 {1,1}，均值和求和能否直接区分？

**推理解析：** 不能，两者均值一、和二。先作非线性映射如 (x,x²) 后求和可区分，但仍需讨论完整聚合更新的表达限制。注意力也不自动消除所有碰撞。不能从某个反例推断“求和总够强”，应明确函数族及图结构条件。
