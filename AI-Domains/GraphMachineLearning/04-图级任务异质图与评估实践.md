## 1. 图级读出

分子性质等任务需要把节点表示聚合为图表示，求和、均值、最大或注意力读出有不同偏好。求和保留部分规模信息，均值弱化节点数，选择应匹配任务。读出需对节点排列不变。

<a id="sec-1-1"></a>

### 基础算例：图级标签与节点级标签需要不同读出

节点分类为每个节点输出标签，图分类需把可变数量节点汇总成固定表示。求和读出随节点数变化，均值读出消除部分规模信息，二者保留的统计不同。若目标与图大小有关，均值可能丢信息；若大小只是来源捷径，求和又可能误利用。先明确任务与独立样本单位，再比较读出方式，并按来源或时间划分验证。

<a id="deep-dive-1"></a>

### 深入讲解：从节点到整图读出需要保留哪些结构信息

节点表示要变成图级输出，常用sum、mean或更复杂读出。sum随节点数量变化，mean可能抹去规模；分子性质若近似随原子数累积，与只需比例信息的任务需要不同偏好。

异质图含不同节点边类型，共享一套参数可能混合不相容语义。可按关系定义消息与组合，仍需明确方向、时间、边权单位及类型稀疏问题，参数更多也可能难估。

整图划分以图或来源为独立单位，分子近重复和相同骨架跨集合会影响新结构泛化。节点、边与图任务各有不同合法可见范围，不能只写随机80/20。

消融分离特征、结构和二者交互，并记录采样深度、子图规模及成本。删边同时改变度和连通性，解释时应说明保留了哪些性质。

最终读出、评价和新图输入契约一起验收。能处理固定图上的未标注节点，不自动代表面对全新图和关系类型也能相同表现。

<a id="sec-2"></a>

## 2. 异质图与边属性

不同节点类型、关系类型或有向边可能需要各自变换与聚合。交易金额、时间与方向不能只压成一条无向二值边而不说明信息损失。时序图必须以当时可见关系构建。

<a id="sec-2-1"></a>

### 机制展开：关系类型应进入消息语义

异质图中用户购买商品与用户关注用户是不同关系，可用类型特定变换再汇总。共享全部变换减少参数，却可能抹去方向和类型意义；每关系独立又增加稀有类型估计难度。边属性、时间与节点身份需按部署可见性处理。按关系或来源分析错误，才能判断问题来自样本稀疏、图结构还是聚合设计。

<a id="sec-3"></a>

## 3. 数据划分

节点、边和整图任务分别定义独立单位。链接预测移除目标边及反向副本，负采样不能包含真实正边；分子数据近重复结构跨划分也可能高估新结构泛化。报告实际协议而不是只写随机 80/20。

先写出部署要遇到的未知对象：已知图中的未标注节点、新节点、未来连接，或全新的图。传导式节点任务可能允许看到测试节点的无标签特征和合法边，归纳式新图任务则需要整图隔离；两者分数回答的问题不同。

分子任务可根据所需泛化目标考虑骨架或来源划分，并先处理同一分子的等价表示和近重复。时间图只用截至预测时点的信息构图，节点和边特征也遵守同一时间边界。把划分对象、构图时点和信息可见性一起记录，避免仅靠一个比例掩盖协议差异。

<a id="sec-4"></a>

## 4. 消融与成本

比较仅特征、仅结构与联合方法，检查关系收益；比较采样深度、层数与边处理。记录内存和邻居扩张成本。更多层可能过平滑或过挤压，不应默认有益。

消融时一次改变一种信息来源：保持相同节点特征、划分、调参预算与训练轮数，比较 MLP、去除或改变关系的模型，以及完整模型。随机打乱边需要说明保持了哪些性质，因为同时改变度分布、连通性和时间约束，会引入多个解释。

若每层采样 fanout 为 f、深度为 L，一个种子节点展开的邻居请求量可随层数近似按 f 的幂增长，实际受节点重叠与采样去重影响。因此同时报告采样设置、实际子图节点/边数、峰值内存及每批耗时。增加层数后的退化需结合表示相似、远距离依赖和优化情况分析，不能一律归因于过平滑。

<a id="sec-5"></a>

## 5. 图级泛化的来源单位

分子图可能因相似骨架高度相关，随机分子划分可能比新骨架划分容易。社交网络的新节点仍连在已有图中，与完全新网络也是不同任务。报告应说清未知的是标签、节点、边还是整图。

异质图中的关系类型通常不能直接合并。用户购买商品与用户关注用户在语义、方向和时间上不同，按类型定义消息或特征有助于保留信息。模型越复杂，越需要无图与简化结构基线证明必要性。

链接预测负例策略还影响难度。随机挑完全无关节点对通常比挑相似候选容易，指标因此可能很高。评价候选集合应接近实际推荐或风险任务，并防止测试正边被当负样本。

<a id="sec-6"></a>

## 6. 进阶：图任务的独立单位与负采样

节点测试可能允许看到无标签测试节点结构，而新图归纳不允许，两种协议回答不同问题。分子骨架划分与随机图划分的难度也不同，不能以同数据集名称视为可比。

链接预测需移除测试边及无向副本，负例还应排除已知真实正边。随机不相关节点对通常比实际候选容易；负采样比例改变 PR 与概率解释。研究报告要固定候选生成、时间和图可见性，再比较模型。

<a id="sec-6-1"></a>

### 图任务的独立单位影响划分与区间

节点分类的多条观察共享边，图级任务的样本可能又来自同一分子系列、用户或时间过程。逐节点或逐图随机划分未必产生独立总体，误差条也不能无条件按样本数平方根缩小。应依据真正部署来源选择独立单位。

异质图有不同节点与边类型，关系方向、类型特定变换和时间都属于输入语义。简单合并所有关系可作为基线，却可能丢失本来需要区分的机制。边属性更新和图级读出要明确是否保持所需置换性质。

负采样改变评价任务难度。随机负例可能很容易，与真实候选检索中的困难负例不同；未来会成边的对象也不能凭未来信息预先排除，除非协议明确允许。报告候选集合、负例比例和时间规则，才能解释链接预测指标。

<a id="sec-7"></a>

## 7. 练习与解析

**题目：** 图分类用节点均值读出，能否自动区分两张节点特征完全相同但节点数不同的空图？

**解析：** 不一定，均值可能完全相同。若规模重要，应加入节点数或使用相应读出，但仍需结合任务验证。

<a id="sec-8-2"></a>

### 边界追问：随机负边是否等同真实候选难度

**问题：** 链接预测使用很容易的随机负例，能否推断真实检索候选上的同等成绩？

**推理解析：** 不能，候选分布与负样本比例影响排序和判别难度，未来信息也可能被用于不合法筛负例。固定候选库、时间与可见边，再比较。报告负采样协议和不同难度，避免把一个方便构造任务的分数泛化到实际决策。

<a id="sec-8"></a>

## 8. 进阶研究练习与解析

**问题：** 用简单多重集反例比较均值、最大与求和聚合。

**解析：** 均值把 {1,3} 和 {2,2} 映成二，最大把 {1,3} 和 {3,3} 映成三，求和也会把某些不同集合相加成同值。适当可学习变换与求和可提高区分力，但仍受消息传递与 1-WL 类限制，不能宣称识别任意非同构图。

**实现验收：** 重排节点和邻居，检查等变或图级不变；构造相同节点特征但结构不同的图，测试是否可区分。区分数学表达限制、训练未学会和数据不足，不把所有失败都归为优化。

<a id="sec-8-1"></a>

### 综合练习：链接预测的候选边可见性

**问题：** 待预测边仍留在消息传递图，指标很高，如何修正？

**逐步解析与验收：** 按部署时点定义可见结构，移除不应预知目标边，并核对反向边、重复边及构图特征是否泄漏。固定负样本与候选集合后重新评价。验收画一张小图逐条追踪信息来源，不能只拆标签数组就认为完成了隔离。
