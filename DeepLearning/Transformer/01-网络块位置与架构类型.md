## 1. 一个块不只有注意力

Transformer 块通常包含多头注意力、逐位置前馈网络、残差连接和归一化。注意力让不同位置交换信息，前馈网络对每个位置的特征进行非线性变换，残差保留直接路径，归一化影响数值尺度和优化。

Pre-LN 把 LayerNorm 放在子层之前，Post-LN 放在残差合并后；这是结构上的区别，不能把不同模型的训练性质完全等同。前馈层常先扩大隐藏维度再映射回来，因此其参数量和计算量也可能很大。

<a id="sec-1-1"></a>

### 基础算例：一个块内形状如何回到残差维度

设输入形状为 (2,5,16)，批量 2、长度 5、模型维 16。注意力子层和前馈子层最终都需返回 (2,5,16)，才能与残差相加；前馈中间可扩到 64，再映回 16。扩大中间维不改变 token 数，注意力则负责 token 间交互。LayerNorm 常沿最后 16 维处理，不把五个位置混在一起。先画形状链，再理解各子层职责，能避免把前馈误当成时间维变换。

<a id="deep-dive-1"></a>

### 深入讲解：一个Transformer块怎样在交互与逐位置变换间分工

注意力让不同位置交换信息，前馈子层通常对每个位置独立应用共享非线性变换。只有注意力而没有FFN，或反之，都改变表达机制；残差与归一化则管理信息与梯度路径。

以Pre-LN形式为例，h'=h+Attn(LN(h))，输出为h'+FFN(LN(h'))。Post-LN将归一放在相加之后，参数和形状类似却不是同一函数，深层优化行为也可能不同。读实现应逐项画计算顺序。

无位置、无特殊固定mask的自注意力对同步重排等变，无法仅凭内容知道先后。加入位置或因果可见性后对称性改变；“不懂顺序”的说法必须限定结构。

Encoder双向读取输入，decoder因果生成，encoder-decoder再用交叉注意力读取源。任务与架构不是唯一绑定：分类也可读取decoder表示，关键是训练目标和信息边界。

先用短序列核对每个子层、残差及mask，再谈模型规模。块的局部公式与全系统标签、位置、缓存协议共同定义实际模型。

<a id="sec-2"></a>

## 2. 没有位置时会怎样

单纯自注意力不能自行知道词的先后顺序，需加入位置信息。绝对位置嵌入直接给各位置提供向量，正弦编码用不同频率构造信号；相对位置方法建模位置差，RoPE 通过旋转查询和键注入相对位置信息。

采用某种位置方法不代表可以无限外推到更长上下文。长度变化涉及训练分布、位置处理和注意力成本，需专门验证。

<a id="sec-2-1"></a>

### 机制展开：置换等变与位置破缺分别分析

不含位置、特殊固定 mask 等因素的自注意力，在输入 token 同步置换时输出也对应置换，这叫等变而非完全不变。它不提供词序信息。加入位置或因果可见性后，对称性改变，因此“Transformer 不懂顺序”不能脱离实际结构笼统使用。分析论文时先列位置、mask、池化和特殊 token，再判断哪些排列会保持或改变函数。

<a id="rope-relative-position"></a>

### RoPE 的相对位置从旋转内积中产生

在一个二维通道对内，令 $R(\varphi)$ 为平面旋转矩阵，位置 m 的查询和位置 n 的键变为 $R(m\theta)q$ 与 $R(n\theta)k$。由于旋转矩阵正交且角度可相加，有

$$
(R(m\theta)q)^T(R(n\theta)k)=q^TR((n-m)\theta)k.
$$

因此该内积显式依赖相对位移。实际模型把通道两两分组，各组使用不同频率；这改变的是注意力中查询与键的位置表达，不等于直接向每个值向量加入相同旋转。若模型采用部分旋转维度或其他变体，也应按配置实现。

带 KV cache 生成时，新 token 的位置必须衔接历史缓存；将每一步都错误设为位置零，形状仍可运行但相对位置已错。长上下文还会遇到训练中罕见的相位组合，采用 RoPE 不保证任意长度外推。可用短序列比较整段前向与逐 token 缓存前向，在关闭随机层后核对同位置输出。原理见 [RoFormer](https://arxiv.org/abs/2104.09864)。

<a id="sec-3"></a>

## 3. 三类常见架构

| 架构 | 信息可见性 | 常见用途 |
| --- | --- | --- |
| Encoder-only | 输入内通常双向可见 | 表示、分类、掩码预测 |
| Decoder-only | 因果自注意力 | 自回归文本生成 |
| Encoder-decoder | 编码输入，解码器因果生成并交叉读取 | 翻译、条件生成 |

架构与训练目标相关，但并非一一绑定所有用途。分类也可使用 decoder 表示，生成式模型也能通过提示完成分类。

<a id="sec-4"></a>

## 4. 残差维度约束结构

残差相加要求输入与子层输出形状相同，所以注意力和前馈子层通常最终回到模型维度 $d_{model}$。前馈中间维度可以更大，注意力头内部维度也可不同，但合并后必须满足接口。图中一个看似简单的加号，实际上对网络布局施加了明确约束。

LayerNorm 的归一化轴同样重要。对常见 $(B,T,D)$ 输入，通常沿最后的特征维处理，每个 token 单独归一化，而不是把不同时间位置混在一起。理解这些轴含义，才能在修改结构或迁移框架时避免无声错误。

<a id="sec-5"></a>

## 5. 原始结构与现代变体

不同 Transformer 使用不同归一化、激活、位置与注意力头设计。阅读论文应先画出实际块结构，再与熟悉版本比较；同名层不保证完全相同计算顺序。

参数主要分布在嵌入、注意力投影与前馈中，短序列与长序列的成本主导项也不同。不能把全部成本都归因于注意力矩阵。

<a id="sec-6"></a>

## 6. 进阶：残差路径与Pre-LN的梯度结构

Pre-LN 块写作 $x+F(LN(x))$，局部雅可比含直接单位路径；Post-LN 为 $LN(x+F(x))$，梯度还要经过归一化雅可比。二者对初始化与深度的敏感性不同，但不能脱离具体尺度给无条件收敛结论。

注意力负责位置间交换，前馈负责每位置非线性变换，前馈可能占显著参数与成本。研究架构需完整列出位置、激活、头数、归一化与残差，而不能仅以 Transformer 名称视为相同模型。

<a id="sec-6-1"></a>

### 残差块要同时描述归一化位置与信息边界

Pre-LN 常写为 $x+\operatorname{Attn}(\operatorname{LN}(x))$，Post-LN 则把归一化放在残差相加之后。它们的梯度路径和数值动态不同，不能因为都含相同子层就称为等价。前馈网络通常逐位置作用，注意力负责位置间交互，两者分工不同。

编码器一般允许输入位置双向读取；解码器自注意力使用因果边界；编码器—解码器结构还加入对源序列的交叉注意力。选择架构首先取决于任务可见信息，而不是把三类名称当大小不同的同一模型。

没有位置信息时，自注意力对相应输入置换呈等变性，无法单凭内容区分某些顺序变化。加入位置后，还要确保训练与缓存推理使用相同位置计数。残差维度、padding 和归一化轴都是架构的一部分，应在结构图或形状表明确标注。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 为什么下一词预测不能直接使用无遮挡的双向自注意力？

**答案：** 模型会读取需要预测的未来 token，形成目标泄漏，训练任务变得虚假容易，而实际生成时又无法获得这些信息。

<a id="sec-7-1"></a>

### 边界追问：无位置结论能否忽略因果掩码

**问题：** 说自注意力置换等变时，是否可对带固定因果 mask 的完整模型任意重排 token？

**推理解析：** 不能直接，等变分析需要同步处理所有结构或限定无位置、无固定特殊边界的条件。因果 mask 本身编码可见次序，位置与特殊 token 也改变对称性。判断架构性质要先列全结构，再说明具体置换和不变对象。
