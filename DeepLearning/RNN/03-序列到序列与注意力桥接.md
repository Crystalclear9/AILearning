## 1. 编码与解码

编码器处理输入序列，解码器逐步产生目标。早期 Seq2Seq 将输入压成最终状态，长输入时可能形成瓶颈。注意力让每个输出步动态读取各输入状态，缓解所有信息必须集中在一个向量中的限制。

对第 t 个解码步，可由解码状态 $s_t$ 与各编码状态 $h_i$ 计算分数 $e_{ti}=score(s_t,h_i)$，在有效输入位置归一得到 $\alpha_{ti}$，再取上下文 $c_t=\sum_i\alpha_{ti}h_i$ 参与输出预测。填充位置必须排除在分母之外，否则模型会把概率质量分给无效输入。

训练用真实前一输出作为下一步输入时，输入起始符与目标结束符的移位需一致；推理则将自身生成结果继续输入，直至结束符或最大长度。编码器是否双向取决于输入是否整体已知，解码器生成未来目标时不能读取尚未生成的真实 token。

<a id="sec-2"></a>

## 2. 对齐与掩码

编码器输出长度可与解码器不同，交叉注意力权重形状由输出查询数和输入键数决定。输入 padding 要被屏蔽，目标 padding 也不计入损失。起始符、结束符和目标错位都要明确。

<a id="sec-2-1"></a>

### 机制展开：源端 padding 与目标损失各有边界

交叉注意力应屏蔽无效源键，目标 padding 不进入有效 token 损失；目标自回归还需正确错位与可见范围。源长度和目标长度可不同，权重为目标查询数×源键数。若所有源键都被屏蔽，需明确空输入行为，不能任由 softmax 产生无定义结果。用一条短源、一条长源组批，核对有效输出不受补齐内容影响。

<a id="deep-dive-2"></a>

### 深入讲解：编码解码与对齐的每个概率条件是什么

编码器将输入转成一列状态，解码器按目标前缀逐步输出。固定单向量压缩会形成瓶颈，注意力让每个解码步根据当前状态读取不同输入位置，但读取范围仍受输入mask限定。

对第t步计算eti=score(st,hi)，对有效i做softmax，context为Σαtihi。padding不能参与分母；若所有位置无效，应有明确边界处理，而不是期望全负无穷归一正常。

训练用真实目标前一token，推理用模型自己的输出，起止符和错位要一致。框架若内部做移位，外部不能再移一次；否则模型预测目标错一位，数值仍可下降。

beam保留多个前缀及各自状态，累计log概率；结束候选不应继续像普通候选扩展。长度惩罚、温度和采样改变决策目标，最高概率序列也不一定最符合任务质量。

完整评价需看语义、事实、遗漏和结束行为。用固定短输入核对对齐、mask与状态，再逐步增加长度，能分清接口错误与真实模型能力不足。

<a id="sec-3"></a>

## 3. 解码策略

贪心逐步取最大概率，beam search 保留多个候选前缀，采样保留随机性。整句最高概率、最符合任务质量与最短长度可能不同；长度归一化等规则会改变候选偏好，需固定协议比较。

beam search 对每个候选前缀累计 token log 概率，再从扩展结果保留前 b 个；必须维护每个前缀自己的隐藏状态，并区分已生成结束符和仍需扩展的候选。提高 b 增加计算，却不保证任务指标提高，因为模型概率与任务质量可能不一致。

对数概率累加通常偏好较短序列，长度惩罚会改变候选排序，需明确定义分母与结束条件。采样则应说明温度、top-k 或 top-p 及随机种子，不能用单次幸运生成和确定性解码比较。评价同时记录完整输出、长度、重复和约束满足，而不是只看每一步最高概率。

<a id="sec-4"></a>

## 4. 误差与评价

训练中逐 token 正确不等于整句任务正确。翻译、摘要或指令任务还需评价完整输出的语义、事实和约束。检查重复、提前结束与长序列退化。

把完整输出中的错误分为内容遗漏、事实或实体错误、重复、提前结束及约束违反，分别抽样核对。逐 token 指标受真实历史条件帮助，完整生成则暴露自身错误传播；两种结果应并列解释，不能用前者替代后者。

比较解码策略时保持模型、输入和计算预算清楚，记录长度规则及结束条件。若只有部分例子出现长序列退化，按输入和输出长度分组，再检查注意力、截断和训练覆盖。词面指标可快速筛查，但关键数字与否定关系仍需针对性评价。

<a id="sec-5"></a>

## 5. 解码器每一步的输入输出

训练时第一步通常接起始符预测目标首 token，下一步接真实首 token 预测第二个，依此错开。推理则把自己刚生成的 token 接回，直到结束或预算。少一位或多一位会改变训练任务，应在三四个符号的小序列上人工核对。

注意力使目标步读取不同源位置，但输入 padding 必须排除。源序列与目标序列长度不同没有问题，匹配矩阵的两个轴各有明确角色。长句生成出现重复时，应检查解码、结束符与训练覆盖，而非只看注意力图。

beam search 保留多个前缀提高搜索范围，不保证任务质量单调提高。概率偏好、长度与参考评价可能不同，应固定解码设置并比较完整任务结果，而不是仅比较序列对数概率。

<a id="sec-1-1"></a>

### 基础算例：从三步目标列出训练输入与标签

目标为 A、B、EOS，教师强制输入为 BOS、A、B，输出标签为 A、B、EOS。解码第一步只能读起始符与合法源信息，不能直接读未来 B。推理时第二步接模型生成的首符号，而非真实 A。画出这三列对应关系，可同时检查标签错位、起止符、因果边界和训练推理差异；只检查输入与标签长度一致并不能排除复制答案。

<a id="sec-6"></a>

## 6. 综合算例与实现核对

手工设源句三个符号、目标四个符号，画出编码三步与解码四步。每个目标步都可对三个源状态分配注意，所需权重矩阵是四乘三。目标长度不必等源长度，结束符负责学习何时完成。

把教师强制训练输入与真实推理输入并列写出，会发现训练从不需要猜前缀，而推理每步依赖自身。评价长输出应真实生成，不能只报告在真实前缀帮助下的每步准确。

beam search 可扩大搜索，但若模型本身偏好短句或重复，搜索可能更忠实找到这种错误高概率输出。解码是使用已有分布，不能替代纠正数据、训练目标和模型的不足。

<a id="sec-7"></a>

## 7. 进阶：Teacher forcing与暴露条件差异

最大似然训练在真实前缀分布下优化条件概率，推理前缀由自身生成，错误可把状态带离训练条件。训练 token NLL 与整段任务质量因此不同，但这不意味着最大似然目标本身非法。

Scheduled sampling 等混合前缀方法改变训练分布与目标性质，应说明采样和梯度约定，不能简单称为无偏修复。Beam search 优化模型给出的概率，也可能更强化长度偏好，搜索扩大不保证外部指标单调改善。

<a id="sec-7-1"></a>

### 教师强制改变的是训练时的条件分布

自回归似然分解为 $\log p(y\mid x)=\sum_t\log p(y_t\mid y_{<t},x)$，训练使用真实前缀计算每一项是该目标的直接实现。生成时前缀来自模型自身，错误会把后续状态带到训练覆盖不足的位置；这解释条件差异，不意味着最大似然推导本身有误。

三符号目标 A、B、EOS 的训练输入可为 BOS、A、B，预测标签为 A、B、EOS。若输入与标签未错位，网络可能只学习复制当前符号。注意力使每个目标步读取源状态，但源 padding 和目标 padding 分别影响可见性与损失，不能只处理其中一个。

Beam search 寻找模型较高概率序列，不直接优化事实或任务指标。扩大 beam 可能更忠实暴露短句偏好；长度归一化又改变搜索目标。评价时应固定解码规则并实际生成完整序列，不能只报告真实前缀条件下的 token 准确率。

<a id="sec-8"></a>

## 8. 练习与解析

**题目：** 编码输入长 7、目标长 5，交叉注意力矩阵应是什么形状？

**解析：** 单头单样本为 $(5,7)$，每个目标查询对 7 个输入位置归一化，输出位置数由查询决定。

<a id="sec-8-1"></a>

### 边界追问：更大 beam 是否必然改善任务指标

**问题：** 模型偏好过短答案，扩大 beam 搜索是否保证摘要更完整？

**推理解析：** 不保证，搜索更忠实找到模型高概率输出，也可能强化长度偏好。长度归一化会改变搜索目标，仍不等于外部事实与覆盖。固定解码设置，实际生成完整输出评价，不能以真实前缀下 token loss 替代生成结果。
