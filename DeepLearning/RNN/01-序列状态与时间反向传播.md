## 1. 为什么需要状态

序列任务中，同一个输入可能因上下文不同而含义不同。简单 RNN 用隐藏状态概括过去：$h_t=\tanh(W_xx_t+W_hh_{t-1}+b)$。参数在所有时刻共享，因此序列变长并不会按时间步增加一套新权重。

输出可以是每步一个标签、整个序列一个标签，或者基于当前状态预测下一步。输入形状常为 $(B,T,D)$，但某些接口默认把时间轴放在第一维，必须检查 `batch_first` 等配置。

<a id="sec-1-1"></a>

### 基础算例：逐时刻状态为何不同于独立分类

取简化递推 $h_t=0.5h_{t-1}+x_t$，初始 h0=0，输入为 1、0、2，则状态依次为 1、0.5、2.25。最后状态同时包含当前输入和过去衰减信息，不能把每步当独立样本而任意重排。若另一条序列开始时不重置状态，就把前序列信息传入。实际 RNN 加入非线性与参数共享，仍需明确序列身份、初始状态和截断位置。

<a id="sec-2"></a>

## 2. 时间展开后的反向传播

将循环展开后，它是一张深度与序列长度相关的计算图。梯度通过多个时刻传播，重复乘状态雅可比，可能消失或爆炸。这不仅是“网络层数多”的问题，也与状态矩阵的谱性质、激活和数据有关。

截断时间反向传播把长序列分块，限制反向传播跨度以控制内存与成本；块间可以传递状态但切断计算图。它改变了梯度估计，不能声称仍精确捕捉任意长依赖。

<a id="sec-2-1"></a>

### 机制展开：时间反传共享的是参数而非独立层

展开 T 步后，每步使用同一组循环权重，因此总参数梯度是各时刻贡献之和；图上画成多层不代表有 T 套独立参数。早期状态的贡献经过多次雅可比乘积，可能衰减或放大。截断反传把跨边界梯度切断，隐藏值仍可继续传递。记录边界和实体对应，才能解释状态保留、梯度长度与计算成本的权衡。

<a id="deep-dive-2"></a>

### 深入讲解：时间展开如何让同一参数收到多个时刻的梯度

递归状态 ht=φ(Wh h(t−1)+Wx xt+b)把历史压成可更新表示。同一Wh在所有时刻复用，因此反向时各时刻对它的贡献相加，而状态梯度还需沿时间链向过去传递。展开图是理解共享与依赖的工具，并不是创建T份独立参数。

对早期状态的影响包含多个状态雅可比乘积。若相关方向长期收缩，远处信号弱；放大则可能爆炸。门控、初始化和裁剪各处理部分现象，裁剪仅限制当前梯度幅度，不让已经消失的信息重新出现。

截断BPTT将长序列分段，段间可传递隐藏状态却切断反向图，减少计算与内存；这意味着优化使用有限历史梯度，不等于精确全序列反传。新独立序列边界则应重置状态，避免串接无关对象。

padding损失掩码不一定阻止状态被填充值改变。分类读取应按真实长度或适当打包，双向更需注意反向先看到的填充。改变padding量但真实序列不变，是有用的接口检验。

训练与生成还存在真实前缀和自身预测前缀差异。完整滚动评价能发现重复、漂移和提前结束，一步教师强制分数不能代替实际序列行为。

<a id="sec-3"></a>

## 3. 变长序列与填充

批量需要对齐长度时可添加 padding，但损失和聚合必须忽略填充位置。若直接取“最后一个位置”的输出，短序列可能取到的是填充位置。可以使用真实长度索引、打包序列或掩码聚合。

损失掩码只解决输出计分，不一定阻止填充值改变隐藏状态。单向模型可按真实长度读取每条样本的最后有效输出；若继续跨批传递隐藏状态，应在新序列边界重置，并按截断反向传播计划切断计算图。双向模型还可能让反向分支先读取 padding，使用打包或正确的长度处理更关键。

例如两条长度为 3 和 1 的序列补齐到 3，第二条的分类表示应来自其唯一有效位置，不能直接取批张量最后一列。测试时把 padding 长度改变而保持真实序列不变，输出应在既定实现精度内一致；若不一致，先查状态读取与掩码作用位置。

<a id="sec-4"></a>

## 4. 隐藏状态的生命周期

独立样本之间一般不应无意传递隐藏状态，否则一个样本会读取另一个样本的信息。连续流分块训练时则可能有意保留状态，但需在块边界正确 detach，避免计算图无限延伸。批量打乱后，原状态也不再对应原来的序列。

序列级标签还涉及聚合选择：最后有效状态、平均池化和注意力池化保留信息的方式不同。取平均时排除填充，取最后时使用真实长度。多数序列问题中的形状错误不会立即报错，却可能让模型学到长度或填充模式，而非内容。

<a id="sec-5"></a>

## 5. Teacher forcing与预测误差累积

序列生成训练常用真实前一步输入，推理则使用自身生成结果。训练条件与推理条件不同，早期错误会影响后续状态。低训练损失不保证长序列生成稳定，需要完整滚动生成评估。

时间序列多步预测也有类似区别：一步误差与递归多步误差不能互相替代，应按实际预测跨度报告。

训练序列损失通常条件于真实前缀，实际生成则条件于模型前缀；一处错误可能把后续状态带到训练少见区域。不能只按 teacher-forced 准确率比较解码稳定性，应从起始符完整生成，记录结束、重复与长度退化。

多步时间预测要明确未来特征是否真的已知，不能把真实未来目标作为下一步输入后称部署预测。某些混合真值与预测输入的训练策略会改变学习分布，需要额外比较与理论说明，不能只因缓解暴露偏差的名称就断言保持原似然目标。

<a id="sec-6"></a>

## 6. 进阶：BPTT截断的偏差来源

隐藏状态跨步传播，完整梯度包含未来损失到过去参数的多路径和。截断时传递状态但切断计算图，前向仍记历史，梯度却忽略跨边界依赖，因此不等价于完整长序列目标的精确梯度。

截断长度控制内存、时间与估计偏差。独立序列间应重置状态，连续流则保持实体对应；打乱批后仍复用原位置状态会串联无关历史。论文比较须报告状态管理而不只是 RNN 类型。

<a id="sec-6-1"></a>

### 时间方向的梯度是雅可比乘积

对 $h_t=\phi(W_hh_{t-1}+W_xx_t)$，较早状态到后续状态的导数包含多次 $D_tW_h$ 相乘，$D_t$ 为激活导数对角矩阵。若这些算子的作用持续收缩，早期信号衰减；若持续放大，则可能爆炸。仅看 $W_h$ 的某一个元素无法判断完整动态。

梯度裁剪限制当前更新的范数，主要缓解爆炸，不直接恢复已经消失的长期信号。截断时间反向传播减少保留图长度，但也截断跨边界的参数信用分配。传递隐藏状态与传递完整计算图是两个不同决定。

批量训练中还要管理状态对应的序列身份。打乱用户顺序却继续复用旧隐藏状态，会把一个用户的历史传给另一个用户，形状仍完全合法。新序列开始、真实终止和批次截断需要明确状态重置或 detach 规则。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 一个批量真实长度为 `[5,2]`，统一填充到 5。直接取所有样本第 5 步输出作为摘要，有何风险？

**答案：** 第二条样本多经过了三次填充输入的状态更新，摘要可能被无效内容改变。应使用真实长度对应的最终状态或正确的打包机制。

<a id="sec-7-1"></a>

### 边界追问：detach 状态后是否丢失全部历史

**问题：** 连续流中把隐藏状态 detach 再传下一批，是否等于状态重置为零？

**推理解析：** 不是，数值仍携带历史，只切断跨边界的梯度路径。它改变信用分配跨度，不必消除前向记忆。新实体则需按规则重置或重新配对。把值生命周期与图生命周期分开，才能解释截断反传与流式推理。
