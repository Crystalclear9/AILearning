## 1. 从堆叠到残差

连续小卷积核可组合较大感受野，同时引入更多非线性。残差网络通过直连帮助深层优化，瓶颈块先压缩或变换通道、做空间处理再恢复。通道扩张、步长与直连投影必须共同对齐。

全局平均池化把空间位置汇总，适合整图分类；定位任务则需要保留空间结构。网络最后如何池化，取决于输出粒度，不是所有视觉任务都应压成一个向量。

<a id="sec-2"></a>

## 2. 多尺度特征

浅层分辨率高、细节多，深层覆盖范围大、语义更抽象。特征金字塔等结构结合不同尺度，帮助同时处理大小目标。融合前要对齐空间尺寸与通道，插值方式也影响边界。

<a id="sec-1-1"></a>

### 基础算例：不同尺度特征能恢复什么信息

浅层特征为 32×32，深层为 8×8。将深层插值为 32×32 只增加采样位置，不会凭空恢复被压缩的细节；与浅层跳连融合才能重新引入保留的局部信息。融合前还要对齐通道和坐标语义。对于小目标与边界，单纯尺寸匹配不保证内容匹配。可把每层位置映回原图覆盖范围，解释多尺度机制，而不是只检查两个张量能否相加。

<a id="sec-2-1"></a>

### 机制展开：特征融合不仅是尺寸插值

浅层与深层的采样中心、累计步长和感受野不同，插到同尺寸后仍需核对坐标对齐及通道映射。相加要求同维，拼接则增加通道并由后续映射混合。上采样不会自动恢复丢失细节；跳连提供已有高分辨信号。检测分割中边界偏移可能来自预处理、插值或对齐，而不一定是骨干表达不足。

<a id="deep-dive-2"></a>

### 深入讲解：多尺度与patch为何是在选择信息粒度

深层特征通常空间分辨率更低、语义更抽象，浅层保留更多位置细节。检测分割需要两者，跨层融合将不同尺度对齐后组合，但上采样方式、通道投影和坐标约定都影响结果。

残差帮助传播与复用特征，不能替代尺寸匹配。下采样块常用投影捷径，让两个分支在通道与空间上真正对应；意外广播即使可计算，也不是设计中的残差。

ViT将图像分patch并线性映射为token。224×224、patch16有196个，patch8有784个；全注意力分数规模约增16倍。更细粒度保留细节，代价是更长序列与更多中间状态。

卷积的局部共享与注意力的内容交互提供不同归纳偏置。数据规模、预训练、增强和计算共同影响结果，不能只对齐参数量就把差异全部归于结构。

先明确任务需要的目标大小、位置精度与全局关系，再选尺度。用小目标、边界和新来源分组评价，比仅比较总体分类分数更能判断表示是否适合。

<a id="sec-3"></a>

## 3. Patch与注意力

视觉 Transformer 把图像分块映射为 token，加位置后用自注意力交换信息。patch 大小决定 token 数与局部细节，减小 patch 会增加注意力成本。它与 CNN 的归纳偏置不同，预训练与数据规模常显著影响比较。

对 H×W 图像，若边长 p 的不重叠 patch 整除输入，token 数为 HW/p²；224×224、p=16 得 196 个，p=8 得 784 个，长度变四倍，普通全注意力分数规模约变十六倍。特殊 token 和实际分块规则还会增加少量或改变边界。

patch 嵌入可看成按块的线性投影，并不自动拥有所有平移等变性。较小 patch 保留细节却增加成本，较大 patch 可能损害小目标。比较 CNN 与 ViT 时控制数据、预训练和计算，避免把更多预训练资源误归于结构本身。

<a id="sec-4"></a>

## 4. 多尺度融合时的空间含义

浅层一个位置对应较小原图区域，深层对应更大区域。上采样让尺寸相同，却不自动创造缺失细节；跳连把保留的高分辨信息送回。分割边界改善通常来自组合，而非把小特征图插值大就恢复全部内容。

视觉 Transformer 的 patch 是把一块像素组合成一个初始表示。减小 patch 能保留更细空间粒度，但 token 数增多，注意力关系迅速增加。比较 CNN 时应说明输入分辨率、预训练和预算，否则架构结论混入条件差异。

普通分类头重视整体类别，检测和分割需空间定位。迁移分类骨干时可复用特征，但输出头、损失与标签结构必须重新设计，不能只把类别数改掉就覆盖所有视觉任务。

<a id="sec-5"></a>

## 5. 进阶：分解卷积的成本与表达约束

分解卷积时先问两个问题：是否减少理论运算，是否仍表示原来任意权重。前者可用参数与乘加计数回答，后者需要考察空间和通道耦合的限制。下节给出完整计数。实际延迟还受内核与带宽影响，因此理论节省、表达约束和设备实测速率应分别报告。

FLOPs 下降也不保证时延同比下降，内存访问和内核利用可能主导。视觉 Transformer 与 CNN 的比较还需控制分辨率、预训练和增强。多尺度融合保留不同空间信息，上采样本身不能恢复已丢失细节。

<a id="sec-5-1"></a>

### 卷积分解的节省来自连接方式的限制

标准 k×k 卷积参数数为 $k^2C_{in}C_{out}$。深度可分离卷积先逐通道空间卷积，再做 1×1 通道混合，参数数为 $k^2C_{in}+C_{in}C_{out}$。当 k=3、输入输出通道均为 64 时，标准卷积为 36864，分离形式为 4672，未计偏置。

减少参数和乘加的同时，也限制了一次层映射中空间与通道耦合的形式；加入更多层与非线性可重新增强表达，但不能直接称为原卷积的任意无损替换。实际速度还取决于内核实现、内存访问和设备，理论乘加下降不保证同倍提速。

视觉 Transformer 的 patch 投影换用 token 交互结构，比较时还需固定输入分辨率、预训练、增强与预算。卷积、多尺度和注意力可能组合使用，研究问题应具体到哪个结构假设在何种数据上带来收益。

<a id="sec-6"></a>

## 6. 练习与解析

**题目：** 把整图特征做全局平均后，能直接恢复每个像素类别吗？

**解析：** 一般不能，空间位置细节已被压缩。分割需要保留或重建空间特征，并通常结合高分辨率信息，不能只依赖分类摘要。

<a id="sec-6-1"></a>

### 边界追问：乘加减少是否保证设备速度同比提升

**问题：** 深度可分离卷积理论运算降很多，墙钟时间却变化很小，是否一定实现错？

**推理解析：** 不一定，设备内核、访存、调度与小张量开销可能主导。分解还限制表达，并非原卷积任意无损替代。分别验证函数目标、理论成本与真实测量，固定精度、批量和预热，再解释优化适用范围。
