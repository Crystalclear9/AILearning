# 卷积神经网络

理解局部连接、参数共享、输出尺寸和视觉特征层次。

**先修知识：** 神经网络基础；张量形状。

## 学习顺序与覆盖范围

第 1—2 章之后即可进入[手写数字项目](../Projects/README.md)。第 3 章的残差与多尺度可接着读；其中视觉 Transformer 先作概览，待完成[注意力](../Attention/README.md)与[Transformer 网络块](../Transformer/01-网络块位置与架构类型.md)后返回。第 4 章用于巩固卷积实验。

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：几何增强后验证标签仍成立](04-从尺寸推导到训练实验设计.md#sec-8-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
