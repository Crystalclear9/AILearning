## 1. 逐层写形状表

为输入、每个卷积、池化与分类头写出形状与参数量。核、步长、填充和膨胀共同决定尺寸；分组还改变通道连接。先用一个虚拟批次验证，再进入长训练。

```python
import torch
from torch import nn
layers = nn.ModuleList([
    nn.Conv2d(1, 8, 3, padding=1), nn.ReLU(),
    nn.MaxPool2d(2), nn.Conv2d(8, 16, 3, stride=2, padding=1)])
x = torch.randn(2, 1, 28, 28)
for layer in layers:
    x = layer(x)
    print(type(layer).__name__, tuple(x.shape))
assert x.shape == (2, 16, 7, 7)
```

## 2. 控制变量

比较结构时固定划分、数据增强、训练预算与选择指标。若新结构同时用了更高分辨率和更久训练，需单独对照才能解释结构收益。记录训练时间、参数与推理成本。

<a id="sec-1-1"></a>

### 基础算例：一个网络变宽会影响哪些量

固定输入与核大小，将卷积输出通道从 8 增为 16，当前层参数与输出激活约翻倍；若下一层输入通道也随之变大，后续参数和计算也改变。因此“只改宽度”不是只改一个最终数字。实验应记录逐层形状、参数和预算，说明是在比较同成本结构还是允许更大模型。训练曲线改善后还要检查验证、错误类型和推理成本，避免只按训练 loss 排名。

<a id="sec-2-1"></a>

### 机制展开：控制变量应对准要回答的比较问题

同参数量比较可减轻容量差异，但不必同算力；同训练时间比较反映实际预算，却允许更新数不同。若研究某个结构机制，可先做严格单因素，再做现实约束下的方案比较。输入分辨率、预训练、增强、搜索和重复次数都影响结论。把它们列为实验条件，避免“只改一个模块”的说明遗漏同时改变的成本与选择过程。

<a id="deep-dive-2"></a>

### 深入讲解：从形状表到控制实验形成可解释的视觉研究

逐层列输入输出、步幅、感受野与参数量，能够预先发现维度和分辨率瓶颈。若模型在小目标失败，可能是早期下采样已删除信息，后面加宽网络未必恢复。

控制实验一次改变分辨率、增强、深度或初始化中的一项，并保留相近选择预算。若算力和训练时长同时增加，应如实说明完整方案差异，而非只称某模块有效。

看每类、目标大小、背景和来源错误，标注支持数。背景替换或遮挡能提供捷径线索，但可能引入不自然输入，宜与自然新来源验证结合，不直接当因果证明。

训练前用极小集确认闭环，正式训练固定验证和测试角色。测试错误若用于设计新结构，已成为开发信息，后续需要新的独立评价范围。

最后将输入变换、模型和后处理整体加载，在固定图像核对预测及性能。尺寸正确、数值正确和任务有效各有独立证据，三者共同支撑结论。

<a id="sec-3"></a>

## 3. 错误分析

按类别、目标大小、背景与来源检查。遮挡或替换背景可帮助发现捷径，但干预也可能产生不自然图像，应结合多种证据。显著错误集中在某来源时，先调查数据和标签，而非只增加网络层数。

误差表需同时展示每组样本数和错误率，避免极小群体的波动被当成稳定规律。可从混淆矩阵找相近类别，再查看原图、增强后图像和预测置信度，区分标注歧义、目标过小与背景捷径。

提出改进时对应可验证假设：怀疑尺寸问题就控制其他因素比较输入尺度，怀疑来源偏差就保留新来源验证，怀疑标签噪声则先复核样本。误差分析可以推动验证实验，但不应一边查看最终测试错误一边持续优化，导致测试集失去独立性。

<a id="sec-4"></a>

## 4. 逐层结果的手算核对

输入二十八经过填充一的三乘三步长一卷积仍为二十八，池化核二步长二变十四，后续三乘三步长二填充一变七。通道从一到八再到十六，批量始终为二。先手算再运行，可以定位是尺寸公式还是代码参数误解。

参数量与特征图大小不同。更高分辨率不增加同一卷积核权重，却让每个核在更多位置执行，也保存更多反向激活。报告时同时给参数、实际计算和峰值内存，避免只用一个指标代表效率。

错误分析可以按目标大小、背景与来源分组。若所有错例来自同一拍摄批次，先检查颜色通道或曝光，而非直接加网络。一个有依据的数据修复可能比复杂结构更有效。

<a id="sec-5"></a>

## 5. 综合算例与实现核对

在形状实验后，可逐层统计参数：第一卷积有八组一乘三乘三权重及八个偏置，第二卷积有十六组八乘三乘三权重及偏置。池化和激活没有同样可训练核，但仍消耗计算与保存部分反向信息。

把第二层步长改成一，输出空间由七变十四，参数不变，激活规模约四倍。这个对照直接验证参数与资源的区别。若后面展平接全连接，尺寸变化还会增加头部参数，需一起核对。

训练实验先固定这些接口，再改变一个结构因素。报告准确率变化时同时说明参数和时间，否则“更深更好”可能只是额外计算换来收益，无法判断在同预算下是否仍成立。

<a id="sec-6"></a>

## 6. 进阶：尺寸实验与结构消融的证据

形状合法只证明接口兼容，错误通道顺序或 reshape 仍可产生相同尺寸。先手算一个输出位置所依赖输入，核对 padding、stride 和通道；再用虚拟批次检查层级形状，最后检验真实训练。

结构比较应同时报告参数、激活内存、计算和延迟。把输入尺寸加倍可能使特征图规模约四倍，而核参数不变。若后接展平全连接，头参数也会改变，不能只比较骨干卷积数量。

<a id="sec-6-1"></a>

### 形状表应包含参数和计算的累积

以单通道 8×8 图像，3×3、padding=1、输出通道 8 的卷积为例，输出为 8×8×8；2×2、步长 2 池化后为 8×4×4，展平长度 128。连接十类输出的线性层含 $128\times10+10=1290$ 个参数。逐层手算可在运行前发现通道或展平维度错误。

实验中只改变卷积核、宽度或深度时，还会改变参数量、激活内存与感受野。若研究的是结构本身，应说明是否控制总参数或训练预算；若研究的是实际最佳方案，则可允许不同规模，但同时报告成本，不能混用两种比较结论。

错误分析可按类别、图像质量、位置偏移和来源分组。增强是否合理取决于标签不变性，例如某些数字旋转会改变类别含义。先用小样本检查变换后的标签仍成立，再把增强当成正则手段。

<a id="sec-7"></a>

## 7. 练习与解析

**题目：** 输入从 28 增到 56，卷积参数不变，训练成本为何仍上升？

**解析：** 特征图空间位置增多，计算与激活存储通常显著增加。参数量只是成本的一部分，不能用它代替峰值内存和速度测量。

<a id="sec-8-2"></a>

### 边界追问：参数匹配是否就是所有成本匹配

**问题：** 两网络参数量相等，能否只比较准确率并称同预算？

**推理解析：** 不能，激活分辨率、运算、内存访问与训练轮次可不同。先声明预算是参数、样本、更新数还是墙钟；必要时同时给多个成本。单因素机制实验与现实最优方案比较可并存，但结论应对应各自控制条件。

<a id="sec-8"></a>

## 8. 进阶研究练习与解析

**问题：** 精确写出卷积平移等变性在哪些步骤失效。

**解析：** 在无限规则网格，共享核与平移可交换；有限填充的边界、非对齐步长采样和裁剪会改变可见集合。逐位置激活保留相应等变，空间聚合可能带来部分不变性，但不是对任意变换都成立。

**实验：** 同图平移一个像素，分别比较无下采样、步长二和不同 padding 的特征。只在共同有效区域评价，并控制插值。将理论性质、边界效应与真实鲁棒性分开，不能凭结构名称推断全部平移稳定。

<a id="sec-8-1"></a>

### 综合练习：几何增强后验证标签仍成立

**问题：** 分类图像左右翻转带来提升，能否直接推广到文本或方向标签？

**逐步解析与验收：** 不能，标签不变性由任务定义。构造含文字、方向或非对称关系的样例，人工确认变换后标签；检测与分割还需同步变换几何标注。验收先检查增强正确性，再在固定协议比较收益，不把增强多样性自动等同于合法新数据。
