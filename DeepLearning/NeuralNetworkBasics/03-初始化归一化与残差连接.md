## 1. 控制信号尺度

深层网络反复乘权重与激活，如果方差不断扩大或缩小，前向与梯度都会困难。Xavier 与 He 初始化根据扇入扇出和激活选择尺度，目标是让初始信号在层间较稳定，而不是保证训练自动成功。

不能把所有权重设为同一常数，因为神经元收到相同梯度后可能保持对称。偏置初始化则需看层类型与任务，不能机械要求所有参数都随机。

在输入分量近似独立、零均值且方差相近的初始化分析中，线性层 $z=Wx$ 有 $Var(z_j)\approx fan_{in}Var(W_{jk})Var(x_k)$。令权重方差约为 $1/fan_{in}$ 可控制线性前向尺度；考虑 ReLU 的半边截断时，常见 He 方差取 $2/fan_{in}$。Xavier 则以扇入扇出平衡前反向尺度，常见方差为 $2/(fan_{in}+fan_{out})$。

这些分析依赖激活分布、独立近似和结构，残差、门控或注意力可能需要不同尺度；不是训练全程方差恒定的证明。实际实现先检查层的维度约定和库初始化默认，再用固定小批查看激活与梯度，避免把卷积通道数直接当作完整 fan-in 而遗漏核面积。

<a id="sec-2"></a>

## 2. BatchNorm与LayerNorm

BatchNorm 利用批内统计，训练时还维护运行量；小批量、不同设备分片与分布变化可能影响表现。LayerNorm 通常对每样本相应特征轴归一化，避免依赖其他样本的同批组成。归一化轴和可学习缩放偏置应查实际接口。

对选定归一化集合 S，标准化写为 $\hat x=(x-\mu_S)/\sqrt{v_S+\epsilon}$，输出 $y=\gamma\hat x+\beta$。CNN 中 BatchNorm 常按每个通道在批与空间位置统计；Transformer 的 LayerNorm 常按每个 token 的末特征轴统计，二者即使张量形状相同也不是同一函数。

ε 控制近零方差的数值行为，可训练 γ、β 作用于约定特征维；运行均值方差是缓冲状态而非普通梯度参数。训练与推理使用的方差估计、动量定义和是否跟踪统计取决于实现；冻结 γ、β 不能阻止训练模式继续更新缓冲。比较时分别核对轴、统计来源及模式，而不是只对齐输出大小。

<a id="sec-1-1"></a>

### 基础算例：归一化统计量取决于选择的轴

两条样本分别为 (1,3)、(10,12)。按每条样本内部特征归一时，两者的中心化值都为 (-1,1)；跨批按同一特征归一时，第一列均值为 5.5、第二列为 7.5，得到另一种结果。归一化不只是“让均值为零”，还规定哪些观察共享统计量。LayerNorm、BatchNorm 等应按实际轴与模式理解，避免把数值形状相同误当成相同函数。

<a id="sec-2-1"></a>

### 机制展开：归一化的可训练部分与统计部分

归一化先用指定轴的均值方差标准化，再通过可训练缩放和平移恢复表达灵活性。BatchNorm 的运行统计不是普通梯度参数，训练与推理来源也不同；LayerNorm 按样本特征轴计算。冻结参数不等于冻结全部状态。比较前后行为时分别检查参数、缓冲区和模式，尤其小批量与分布变化可能改变批统计可靠性。

<a id="deep-dive-2"></a>

### 深入讲解：归一化与残差的状态轴和直接梯度路径

标准化先按指定集合求均值方差，再用可训练γ、β缩放平移。按批同通道与按每样本特征轴，得到完全不同函数；不能只说“均值为零方差为一”而不说明哪些元素共享统计。

BatchNorm训练统计和推理运行统计不同，冻结可训练参数不必然冻结缓冲更新。LayerNorm通常不依赖其他样本同批组成，仍有归一轴、ε和缩放约定。小批、分布变化和多设备统计会影响比较。

初始化分析通过fan-in与激活估计方差传播，He或Xavier是特定假设下的尺度选择。它们不是把任何深度网络变成恒定方差系统，残差与注意力结构还可能需要不同处理。

残差 y=x+F(x) 的输入雅可比为 I+JF，提供直接路径；若改为Px+F(x)，直接项变P，形状或秩也改变。相加前后激活、归一化位置都影响函数，不能靠同名“残差块”认定等价。

检验先让F为零，核对输出和输入梯度；再增加真实子层，观察激活及更新比。统计量是诊断线索，需连接具体结构预期，不能机械要求每层永远满足某个固定分布。

<a id="sec-3"></a>

## 3. 残差与维度

$y=x+F(x)$ 提供直接路径，使子层可学习在输入上增加的修正。形状不同时需要投影或下采样。残差不是保证不丢信息的魔法，它仍可能受归一化、激活与后续计算影响。

在可微处，残差块 Jacobian 为 $I+J_F(x)$，相比只有 $J_F$ 的链条提供一条直接梯度路径，但多层乘积仍受 F 的谱、尺度及归一化影响，不能由 I 一项推出梯度永不消失或爆炸。若使用投影捷径 $Px$，直接路径变为 P，也需检查秩与尺寸。

相加要求两个分支在每个轴语义上匹配，不应让意外广播掩盖通道或空间尺寸错误。对带激活的结构，还需区别相加前后是否经过激活。实现最小块时先测试 F 为零时的输出和输入梯度，再加入卷积、归一化和随机层；这能直接检查捷径是否按预期连通。

<a id="sec-4"></a>

## 4. 实践诊断

记录各层激活均值、方差、零值比例与梯度范数。某层持续极端值可提示初始化、学习率或数据尺度问题。不要因统计不同于零均值单位方差就认定错误，需结合具体结构预期。

先在固定小批次上记录同一组层的前向及反向统计：激活均值、标准差、有限值比例，参数梯度范数以及更新量相对参数量的比例。若损失异常，沿最早出现非有限值的层回溯，分别核对输入尺度、除法分母、指数和混合精度，而不是只在末端裁剪梯度。

训练与验证差异还要检查 `train()`/`eval()` 对 Dropout 和归一化的影响。统计量只是诊断线索，例如 ReLU 零值多可以正常，全部样本上长期恒零才更值得排查。每次只改一个可验证因素，并用固定输入复现变化，避免多个改动后无法判断原因。

<a id="sec-5"></a>

## 5. 方差传播的简化直觉

若一层把很多近似独立输入相加，输出方差与输入数和权重方差有关。输入通道翻倍却保持权重尺度不变，初始激活可能更大。初始化据扇入调整尺度，就是为减少这种逐层失控；激活截断一半信号又会改变合适系数。

BatchNorm 还包含可学习缩放和平移，不是永久强迫每层输出固定分布。运行统计来自训练过程，推理时分布变化会影响效果。小批量或不同预处理下，应检查统计是否稳定。

残差的直接路径能改善信息与梯度流，但若分支尺度很大，仍可能主导相加结果。初始化、归一化、学习率与结构需配合，不应把任一单个技巧当作深层网络训练保证。

<a id="sec-6"></a>

## 6. 进阶：初始化方差推导与归一化耦合

若输入独立零均值、权重独立方差为 s²，线性层输出方差近似为 fan-in 乘 s² 再乘输入方差。ReLU 在对称输入下保留约一半二阶矩，引出 He 尺度。依赖和分布不满足时，只是近似指导。

BatchNorm 还把同批样本通过统计量耦合，所以逐样本梯度和批量独立假设需谨慎。LayerNorm 的轴不同，并非直接替代。比较结构时同时记录批大小、训练评估模式和归一化配置。

<a id="sec-6-1"></a>

### 归一化与残差的作用需要按维度解释

BatchNorm 依赖批统计，训练与推理通常使用不同统计来源；LayerNorm 在单个样本的指定特征维归一，不依赖同批其他样本。对形状 (batch,time,hidden) 的序列，按 hidden 归一与把 time 也纳入归一是不同函数。

残差加法要求两条路径输出同形；通道或分辨率改变时需要对应投影。直连改善梯度路径，不意味着所有深度都可无条件稳定训练，残差支路的尺度、归一化位置和初始化仍影响动态。

研究结构时可以固定数据和预算，分别比较归一化类型、残差位置及缩放。若同时改深度、优化器和增强，无法把改善归于某一模块。还应检查小批量和分布变化下的行为：冻结参数不一定冻结 BatchNorm 的运行统计，模型模式属于实际函数的一部分。

<a id="sec-7"></a>

## 7. 练习与解析

**题目：** 输入维度 16，残差分支输出维度 32，能直接相加吗？

**解析：** 不能，需将直连或分支投影到一致维度，或调整结构。自动广播即使偶尔合法也可能不符合残差设计，必须检查语义。

<a id="sec-7-1"></a>

### 边界追问：冻结权重能否固定归一化函数

**问题：** BatchNorm 权重不更新，但训练模式继续使用批统计，输出会始终与原模型相同吗？

**推理解析：** 不一定，运行统计可变，同一输入也受同批组成影响。参数、缓冲区和模式各有职责。先定义是冻结可训练参数还是冻结整个特征函数，再核对前后状态与固定输入；只设置 requires_grad 无法表达所有意图。
