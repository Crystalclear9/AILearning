## 1. 损失定义就是优化偏好

MSE 强调大误差，MAE 更稳健但在零点不可微，Huber 在两者间分段折中。类别加权、标签平滑和掩码都会改变目标。多任务损失的系数决定各任务梯度相对影响，不能只把不同量纲的损失直接相加。

<a id="sec-1-1"></a>

### 基础算例：有效 token 分母改变损失权重

两条序列分别有 2 和 8 个有效 token，每条平均 loss 为 1 和 3。按 token 平均得到 (2×1+8×3)/10=2.6；按序列等权平均得到 2。两个目标都可定义，但长短序列贡献不同。padding 应从相应分母排除，类别权重也要说明归约方式。先写出完整加权目标，再实现 reduction，才能解释批量变化是否应改变梯度尺度。

<a id="deep-dive-1"></a>

### 深入讲解：损失权重归约和正则为何共同定义优化偏好

平方误差对大残差增长快，绝对误差对尾部较稳健，交叉熵关注目标概率；选择来自任务假设和代价，不是所有网络都应使用同一损失。组合多个任务时，尺度和归约决定各项梯度贡献。

若一项按像素总和、另一项按图像均值，图像尺寸变化会改变相对权重，即使λ不变。应分别记录未加权损失、权重、有效单位和必要梯度信息，避免总loss下降掩盖某项停滞。

Dropout、增强和显式正则改变训练条件，各有随机或函数约束；训练损失含这些项而验证不含时，数值不能直接当同一对象比较。过强正则也可能造成欠拟合。

排错从最小数据与简单设置开始：核对标签、输出及损失契约，确认梯度非零和参数更新，再加回增强、混合精度及完整数据。把所有因素同时打开，会让原因难以定位。

当训练好而验证差，检查泛化与分布；两者都差，检查表示和优化；验证奇怪则查模式及预处理。诊断需要区分竞争解释，而不是看到异常就加层或延长训练。

<a id="sec-2"></a>

## 2. 正则与数据

权重衰减限制参数，Dropout 引入训练随机性，早停使用验证控制拟合，数据增强表达任务不变性。每种方式的假设不同，过强可能损害训练与泛化。先建立无复杂干预的正确基线，再逐个加入。

<a id="sec-2-1"></a>

### 机制展开：增强与惩罚通过不同机制约束函数

参数惩罚对坐标下的权重收费，增强则要求训练目标覆盖变换后的输入，早停限制实际优化轨迹。它们不能视为同一系数的可互换实现。增强需保持任务标签成立，dropout 等随机机制也需在评价时采用规定模式。若同时修改多种正则，应设计对照区分收益；训练 loss 更高但验证更好并非自相矛盾。

<a id="sec-3"></a>

## 3. 排错闭环

检查数据范围与标签，再检查输出形状和损失；固定极小数据确认能拟合；查看梯度是否存在、参数是否变化；最后观察训练验证差距。训练失败时直接加深模型可能掩盖真正问题。

先在无增强、较弱正则的极小数据上训练，确认目标可以拟合；若失败，依次核对标签范围、logits 与损失契约、有效样本分母、梯度是否被 detach、优化器是否持有当前模型参数。打印参数更新前后差值比只看到非空梯度更直接。

极小集能拟合后，再逐步加回真实预处理、随机层和完整数据。训练正常而验证异常时检查评估模式、标签映射及前处理一致性；训练验证都差则查表示、目标与预算。每一步保留能复现问题的最小输入，避免重新训练整个项目才发现同一错误。

<a id="sec-4"></a>

## 4. 梯度检查工具

```python
import torch
x = torch.tensor([0.2, -0.3], dtype=torch.float64, requires_grad=True)
ok = torch.autograd.gradcheck(lambda z: torch.tanh(z).square().sum(), (x,))
print(ok)
assert ok
```

该检查比较自动梯度与数值近似，使用双精度并避开不可微点。它不能检测标签错误或验证泄漏，只验证被表达函数的局部导数。

<a id="sec-5"></a>

## 5. 把现象映射到可检验原因

训练损失完全不动，可先检查参数是否传给优化器、是否误用 detach、是否真的执行 step；损失震荡先看学习率和批数据；训练好验证差再看正则与分布。每项检查都用小实验验证，不同时改许多条件。

gradcheck 只比较指定函数在某输入的导数，因此通过后仍需确认函数就是目标任务。把标签反了的模型也能有完全正确梯度。测试正确性分为数学表达、求导、数据含义和评价四层。

训练中额外正则和增强使损失定义复杂时，分别记录数据项与惩罚项，避免总损失下降只是权重缩小而任务指标没有改善。通过分项日志才能知道优化实际发生了什么。

<a id="sec-6"></a>

## 6. 进阶：损失的条件风险与正则的目标变化

平方损失的总体最优函数是条件均值，绝对损失对应条件中位数；标签平滑、类别权重和难例损失改变条件目标。提升某损失不等于提升所有任务指标，尤其概率解释与阈值决策可能变化。

早停、衰减、Dropout 和增强各表达不同偏好。消融时固定预算并逐项比较，不能把多项同时改进全部归于一个模块。梯度检查仅验证微分实现，任务标签和评价泄漏仍需独立检查。

<a id="sec-6-1"></a>

### 损失归约与类别权重会改变有效任务

设每条样本损失为 $\ell_i$，加权均值可能定义为 $\sum_iw_i\ell_i/n$，也可能定义为 $\sum_iw_i\ell_i/\sum_iw_i$，两者梯度尺度不同。带掩码序列还要决定按样本、有效 token 还是序列平均；这些选择不能只凭 mean 一词判断。

类别权重增加少数类贡献，可能改善目标决策，却也改变概率拟合的偏好。训练后若要把输出当原始总体概率，需在目标分布上检验校准。重采样与权重也可能在某些条件下对应相近期望目标，但有限批量方差和训练轨迹不必相同。

正则项应明确系数与归约单位。若数据损失由 sum 改为 mean 而惩罚系数不变，两者相对强度随样本数改变。训练诊断中分别记录数据损失、正则贡献、验证指标和梯度范数，才能判断是在拟合、尺度还是数值环节出现问题。

<a id="sec-7"></a>

## 7. 练习与解析

**题目：** 网络对 16 条样本都无法拟合，首先增加数据吗？

**解析：** 通常先排查实现、损失、梯度与优化设置；更多数据未必修复小样本闭环失败。确认必要容量后再讨论泛化。

<a id="sec-8-2"></a>

### 边界追问：有效 token 平均与序列平均可互换吗

**问题：** 一条序列很短且难，另一条很长且易，按 token 与按序列平均会给同样梯度吗？

**推理解析：** 一般不会，前者给长序列更多总权重，后者给每条等权。掩码和类权重也会改变有效分母。先写统计目标，再实现归约；若改变目标，应重新解释学习率与正则相对尺度，而不是把固定比例差都归为随机波动。

<a id="sec-8"></a>

## 8. 进阶研究练习与解析

**问题：** 推导残差块的局部梯度并解释为什么它不保证永不梯度消失。

**解析：** 对 $y=x+F(x)$，雅可比是 $I+J_F$，提供不经过 F 的直接项。但多个块乘积、归一化与分支尺度仍会影响奇异值，甚至某方向 $J_F\approx-I$ 会相消。因此残差是改善优化结构而非无条件保证。

**实验：** 比较同深度普通与残差网络在控制初始化、归一化和预算下的层梯度、训练与验证。不要同时改宽度和训练时长后将全部收益归于直连；区分优化更容易与泛化更好的证据。

<a id="sec-8-1"></a>

### 综合练习：定位训练不能拟合小样本

**问题：** 十条样本训练 loss 不下降，怎样依次排查？

**逐步解析与验收：** 先检查输入标签对应与目标范围，再核对输出损失接口、梯度是否存在、更新是否发生与学习率尺度；暂时关闭复杂增强和强正则。固定一个批次比较更新前后 loss 与参数。验收区分前向目标、反向与优化三个层次，避免首先增加模型容量或训练轮数。
