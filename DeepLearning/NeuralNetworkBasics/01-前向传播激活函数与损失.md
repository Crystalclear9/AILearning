## 1. 多层网络为什么需要非线性

全连接层先计算 $z=Wx+b$，再通过激活函数得到 $h=\phi(z)$。如果每层都没有非线性，多层线性与偏置变换仍可合并成一次仿射变换，层数增加并没有带来新的函数形式。

ReLU 定义为 $\max(0,z)$，正区间梯度为 1，负区间为 0；零点采用实现约定。sigmoid 把实数映射到 $(0,1)$，常用于二分类概率，但输入绝对值大时梯度接近零。tanh 输出以零为中心，也有饱和区间。

<a id="sec-1-1"></a>

### 基础算例：两个线性层为何仍是一个线性关系

令第一层 h=2x+1、第二层 y=3h-4，合成后 y=6x-1，仍是一条直线。若中间加入 ReLU，则 y=3max(0,2x+1)-4，折点出现在 x=-0.5，可表达分段关系。增加层数与增加非线性作用不同。再加入多维输入时，权重负责混合特征，激活改变函数形状；输出层是否激活则由分类概率、回归范围等任务要求决定，不能所有层统一套同一操作。

<a id="sec-2"></a>

## 2. 从维度理解前向过程

若一个批量 $X$ 为 $(B,10)$，第一层权重为 $(10,16)$，激活后得到 $(B,16)$，第二层映射到三个类别，输出为 $(B,3)$。参数量为 $10\times16+16+16\times3+3=227$，与批大小 $B$ 无关。

隐藏层表示是由任务损失共同塑造的特征，不一定能给每个神经元分配明确语义。某些神经元响应图像边缘或类别属性，但这些解释需要实验验证。

<a id="sec-2-1"></a>

### 机制展开：批量前向中的每一维对应什么

X 为 B×D，第一层 W 为 D×H，则 XW+b 得 B×H，激活逐元素保留此形状，再乘 H×K 权重得到 B×K。B 只组织样本，不应进入特征权重大小；偏置在每条样本复用，反向跨 B 求和。检查前向时选一条样本逐层手算，并比较批量对应行，能发现转置或不必要的 batch 混合，不能只看最后类别数正确。

<a id="deep-dive-2"></a>

### 深入讲解：网络前向为什么既是函数复合也是特征变换

一层可写 h=φ(XW+b)，其中线性映射组合特征，非线性改变可表达函数。若所有层都无激活，多层仿射仍可合并成一个仿射映射，增加深度并没有获得一般非线性边界；深度价值来自复合与结构，而不是矩阵数量。

取标量 x，经两个ReLU单元得到 max(x,0)、max(−x,0)，相加可表示 |x|。这个小网络展示隐藏单元如何构造分段函数，也解释不同激活为何改变几何和导数。

输出必须匹配任务。回归可直接实数，单标签多分类通常给类别logits，多标签可给各事件独立logits。softmax归一让类别竞争，sigmoid并不要求概率总和1；交换它们会改变概率模型。

损失把输出连接到监督信号，反向只会优化写下的目标。输入归一、类别顺序和有效标签同样属于函数定义，不能因为网络结构看起来正常就忽略。

手算一个两输入两隐藏单元的前向，逐层列形状与激活，再修改一个输入预测变化。先理解信息如何通过，后续梯度与训练问题才有明确落点。

<a id="sec-3"></a>

## 3. 输出层与任务必须匹配

回归通常输出连续值并用 MSE、MAE 等损失；单标签多类分类输出 logits 并用交叉熵；多标签分类每个类别独立给出 logit，常用带 logits 的二元交叉熵。类别数、标签编码和损失的形状约定必须一致。

softmax 把 logits 归一化成和为 1 的概率，但模型的高置信度不等于预测可靠。尤其在训练分布之外，可能仍给出很高概率。

<a id="sec-4"></a>

## 4. 训练能力与泛化能力

一个大网络能拟合随机标签，说明它具有较强表达与优化能力，却不说明学到了可迁移结构。训练集准确率接近 100% 后，仍需看新数据、不同来源和分布变化下的表现。参数量只是容量的一种粗略描述，结构与训练方式也很重要。

激活尺度也影响后续计算。如果某层输出数值过大，sigmoid 可能饱和；若 ReLU 长期处于负区间，部分单元可能很少获得梯度。可以记录激活均值、方差与零值比例，但这些统计只是诊断信号，需要结合任务效果判断。

<a id="sec-5"></a>

## 5. 网络输出需要对应标签结构

单标签分类各类别互斥，softmax 把概率总和限制为 1；多标签分类可以同时为真，逐类别 sigmoid 不要求总和为 1。把多标签问题误用单标签交叉熵，会强迫正确标签互相竞争。

回归输出也有范围约束：非负值或比例可以使用适当变换，但激活可能影响梯度与误差尺度。结构选择应来自目标含义，不是每个输出都加同一种激活。

<a id="sec-6"></a>

## 6. 进阶：表达能力不等于可学习性

通用逼近结论通常讨论某函数族在给定紧集上能逼近连续函数，不保证有限数据能找到该参数、所需宽度足够小或分布外可靠。研究中应分开近似误差、估计误差与优化误差，不能因存在性定理就认为训练困难已解决。

ReLU 网络在每个固定激活区域内是仿射函数，但区域组合可形成复杂非线性。增加深度与宽度改变可表达结构及优化几何，不应只把参数总数当作全部容量。实际泛化还受目标、初始化与隐式偏好影响。

<a id="sec-6-1"></a>

### 非线性、表示能力与目标函数的对应

若每层都只有仿射映射，两层合成仍为 $W_2(W_1x+b_1)+b_2=(W_2W_1)x+(W_2b_1+b_2)$，堆叠层数没有扩大为非线性函数家族。激活函数改变这一限制，但更强表示能力不保证训练算法能找到合适解，也不保证有限样本泛化。

输出与损失要表达同一概率对象。互斥 K 类分类输出 K 个 logits，交叉熵内部完成归一化；多标签任务则通常对每个标签建独立二元目标。将多标签强行放入一个 Softmax，会迫使本可同时发生的标签相互竞争。

参数量可帮助理解规模，却不是完整容量度量。输入归一化、深度、共享结构和正则都会改变实际学习行为。先用一个批次验证输出形状、标签范围和可拟合性，再讨论大网络的优势，能避免把目标配置错误解释为网络表达不足。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 一个输入 4 维、隐藏 8 维、输出 2 维的两层 MLP，含偏置时有多少参数？删除激活后表达能力发生什么变化？

**答案：** $4\times8+8+8\times2+2=58$。删除非线性后，两层可合并成一个从 4 维到 2 维的仿射变换，不能表达一般非线性边界。

<a id="sec-7-1"></a>

### 边界追问：增加纯线性层会增加非线性能力吗

**问题：** 将一个线性层拆成两个仿射层，中间不加激活，是否已扩大成非线性模型？

**推理解析：** 没有，复合后仍为仿射函数；可能改变参数化、秩约束和优化轨迹，但不是凭层数创造非线性。引入激活后还需判断宽度与目标。比较结构收益时将表达家族与优化差异分开，避免把训练改善全部归为表示能力增加。
