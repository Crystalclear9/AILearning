## 1. 反向传播是一套梯度计算顺序

前向时保存必要中间量，反向从损失开始按相反拓扑顺序应用链式法则。共享参数从多处收到梯度时需要累加。反向传播负责算梯度，SGD、Adam 等优化器负责根据梯度更新，两者职责不同。

如果很多层的导数绝对值都小于 1，连乘可能产生梯度消失；若经常大于 1，可能爆炸。初始化、激活、归一化与残差连接都能影响传播，但没有一个设置能自动修复所有训练问题。

<a id="sec-1-1"></a>

### 基础算例：共享路径的梯度必须相加

设 y=x²+x，在 x=2 时，平方路径贡献 4，直连路径贡献 1，总导数为 5。若只沿其中一条路径反传，会得到错误但看似合理的导数。残差与共享参数网络都包含这种汇合。训练排错可先用这个极小图核对自动求导和手算，再检查真实网络中哪些参数被多处调用。计算图正确仍需建立在前向函数、标签和损失定义正确的基础上。

<a id="deep-dive-1"></a>

### 深入讲解：反向传播如何复用共享子图而不是枚举所有路径

链式法则沿路径相乘，分支汇合时相加。计算图若某中间量影响多个后继，其总导数是各后继贡献之和；反向按拓扑逆序处理，让每个局部导数只需计算并复用适当次数。

设 u=wx，L=u²+3u，则 dL/du=2u+3，dL/dw=(2u+3)x。若只反传平方分支，会漏掉3x；若把同一共享参数误当两份独立参数，则前向相似但更新不同。

多层梯度包含雅可比乘积，某些方向反复收缩或放大会造成消失爆炸。初始化控制初始尺度，归一化、残差和门控改变传播路径，仍不能保证所有训练配置稳定。

反向得到梯度后，优化器才决定更新；梯度正确不等于学习率合适。极小数据拟合可检验训练闭环，若失败先查数据标签、损失、图是否切断和参数是否真的变化。

验证需关闭随机训练行为并不执行更新，早停按固定验证标准选择。把求导、优化和评价分成清晰职责，有助于解释训练成功或失败来自哪一层。

<a id="sec-2"></a>

## 2. 初始化与正则化

相同层内若所有神经元权重完全相同，训练可能保持对称，无法学出不同特征。随机初始化用于打破这种对称；Xavier、He 等方法根据输入输出维度和激活特性控制初始尺度。

Dropout 在训练时随机屏蔽部分激活并做相应缩放，推理时关闭随机屏蔽。BatchNorm 使用批统计量训练并维护运行统计；LayerNorm 在单个样本的相应特征维上归一化，常用于序列模型。归一化层行为与网络结构有关，不可随意互换。

<a id="sec-2-1"></a>

### 机制展开：初始化尺度随扇入和激活改变

若输入坐标与权重近似独立、均值零，线性输出方差约为 fan_in×Var(w)×Var(x)。因此权重方差常随 fan_in 反比缩放；ReLU 丢弃部分信号后又需相应修正。这个计算依赖近似假设，不能保证任意训练阶段精确成立。初始化负责起点信号尺度，正则负责限制拟合，两者不同；零初始化隐藏层还可能维持对称，无法学出不同单元。

<a id="sec-3"></a>

## 3. 一个有效的排查顺序

先验证少量样本能否被明显拟合，再检查数据标签和损失，随后观察学习率、梯度范数和训练验证差距。小样本过拟合测试失败时，优先考虑实现或优化问题；测试成功也不保证总体泛化良好。

早停使用验证集选择参数状态；保存最佳验证模型，而非机械地保留最后一轮。评估要切换 `eval()` 并禁用不需要的梯度计算。

<a id="sec-4"></a>

## 4. 检查一批数据的完整闭环

先固定一批输入和标签，关闭不必要随机增强，反复训练，确认损失能明显下降。然后分别检查训练与评估模式，确认输出形状、损失计算、梯度和参数更新都发生了。某层若梯度一直为 None，可能根本没有参与计算图；梯度为零则是另一个问题。

查看参数更新前后差异也有帮助：有梯度却无变化，可能学习率过小、参数未交给优化器或更新未执行。把这些检查放在小数据上，比直接长时间训练后猜测“模型太小”更容易定位根因。

<a id="sec-5"></a>

## 5. 训练模式与推理模式

Dropout 和部分归一化层在训练推理行为不同；评估时必须切换模式。关闭梯度主要减少图构建与内存，不会自动替代模式切换。反之 eval 也不禁用梯度，二者分别控制行为和求导。

如果训练使用随机增强，训练损失高于验证损失可能合理。先对齐输入与损失定义，再判断欠拟合或泄漏，避免仅凭两条曲线高低下结论。

<a id="sec-6"></a>

## 6. 进阶：反向传播的路径乘积

深层梯度含多个局部雅可比乘积，其范数上界可由各层算子范数之积控制。反复小于一可能衰减，大于一可能放大；但不同方向与相关性使简单标量乘积只是局部直觉，不是所有训练轨迹的精确描述。

残差块雅可比为 $I+J_F$，提供直接路径，却不保证所有奇异值接近一。初始化、归一化和层尺度仍重要。诊断需看真实激活与梯度分布，而不是只根据层数判断必然消失。

<a id="sec-6-1"></a>

### 反向传播的两个核心操作是复合与求和

沿单条计算路径，梯度按链式法则相乘；同一变量被多条路径使用，梯度贡献相加。残差结构 $y=x+f(x)$ 的雅可比为 $I+J_f$，既有直连也有变换路径；漏掉直连梯度会改变实际优化函数。

初始化应避免所有隐藏单元拥有完全相同权重和梯度。若单元始终对称，它们只能一起变化，增加宽度也难以形成不同特征。按输入尺度选择随机初始化有助于控制信号方差，但推导依赖激活与独立近似，不是所有网络的精确方差保证。

排错先尝试小样本过拟合，关闭复杂增强和强正则，检查损失是否能下降。若连几条样本都学不会，优先检查标签、梯度、学习率和模式；若小样本可拟合而验证差，再研究泛化。不要在机制尚未跑通时增加网络与训练预算。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 训练损失持续下降，验证损失先降后升，应优先做什么？增加训练轮次一定有帮助吗？

**答案：** 检查是否过拟合并保留验证表现最好的状态，可调整正则、数据或容量。继续训练可能加剧过拟合；也需排查训练验证分布和损失定义是否一致。

<a id="sec-7-1"></a>

### 边界追问：所有隐藏单元零初始化为何有风险

**问题：** 同层所有单元参数与输入完全对称，训练会自动产生不同特征吗？

**推理解析：** 通常不会凭空打破确定性对称，单元可能收到相同梯度并持续相同。随机初始化帮助形成不同起点，尺度还与激活和扇入相关。输出层或适配器某一因子零初始化的结论不能直接推广为所有隐藏层都可全零。
