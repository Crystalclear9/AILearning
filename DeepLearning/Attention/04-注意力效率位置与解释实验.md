## 1. 长序列的两类成本

普通全注意力计算所有查询键关系，算术量随长度平方增长。优化内核通过分块与融合减少中间存储和内存访问；稀疏或局部注意力则改变可交互位置，可能改变模型能力。两类优化的性质不同。

KV cache 面向自回归推理，复用已算历史键值，仍需读取相应历史内容。分组查询或多查询注意力减少键值头数，降低缓存规模，但其结构不应与普通多头完全混为一谈。

<a id="sec-1-1"></a>

### 基础算例：长序列成本随哪一个维度增长

标准单头关系矩阵含 T² 个分数，T 从 1000 增至 2000，分数数量从一百万增至四百万，而不是两倍。投影与前馈常随 T 线性增长，所以总成本主导项取决于长度、模型维度与实现。分块和融合可能减少中间存储，稀疏注意力则改变交互结构；评价需区分运算等价优化与模型近似，并测真实延迟、内存和任务效果。

<a id="deep-dive-1"></a>

### 深入讲解：精确高效实现与改变注意力结构不能混为一谈

朴素全注意力显式分数随T²增长，既有算术量也有存储流量。融合分块内核可避免完整矩阵常驻并减少访存，仍计算相应精确全注意力；局部、稀疏或近似方法则改变可见关系或算子。

比较效率需给批量、长度、精度、训练推理模式及实际函数评估。短序列内核启动成本可能主导，长序列又可能受中间存储限制，不应从一个长度推广所有负载。

位置方法改变QK中位置信息，长输入能装下不意味着能有效使用。测试将相同证据放开头、中间、末尾并加入干扰，可区分容量、检索与位置利用问题。

解释实验先固定关注输出，再对高权重、低权重和随机位置做有控制干预。遮挡可能制造训练外输入，多头和残差也提供替代路径，因此热力图本身不证明因果依赖。

报告质量与速度一起看，保持相同信息范围及预算。若提速来自只看局部上下文，应明确这种模型变化，而非称所有全注意力功能无代价保留。

<a id="sec-2"></a>

## 2. 位置与相对关系

没有位置或其他顺序信号，自注意力对输入重排具有相应等变性质。绝对、相对或旋转位置机制让模型区分顺序。训练长度以外是否可靠，需专门检查，不由编码公式单独保证。

<a id="sec-2-1"></a>

### 机制展开：相对位置需要与缓存索引一致

绝对嵌入依赖位置编号，相对偏置依赖位置差，旋转式编码通过成对坐标旋转影响查询键关系。增量解码时，新 token 位置必须延续前缀，而不是每步重置为零；否则缓存内容与新查询的位置意义不一致。长度扩展也要核对训练范围和缩放约定，能够构造位置向量不等于模型已可靠学习超长距离关系。

<a id="sec-3"></a>

## 3. 解释实验

可查看权重分布、头间相似与输入干预后输出变化。注意力图只是计算中间量，不能单独证明某位置因果重要。遮挡也会改变分布，因此结合多种对照。

先固定待解释的输出，例如一个类别 logit 或指定 token 概率，再确定分析层和头。比较原输入、遮去高权重位置、遮去低权重但内容相似的位置，以及随机位置对照，记录输出差异。仅展示一张颜色强烈的热力图无法区分位置相关、冗余信息与实际决策依赖。

注意力后还存在值投影、残差和多层计算，同样权重可对应不同值内容。头间相似也不等于可直接删除，应做结构化消融并检查多任务和不同长度。干预若引入特殊符号或不自然句子，还要说明分布变化可能影响结论，避免将所有变化归于被遮挡内容。

<a id="sec-4"></a>

## 4. 无损实现优化与模型改变的区分

在精度允许范围内，融合内核应尽量保持原数学运算，仅改变分块与存储；局部、稀疏或压缩记忆改变模型可读信息，因此是新近似。前者主要核对数值一致与性能，后者还要重新检验能力。

KV 缓存降低重复计算，却会随上下文增长占内存。分组键值头降低缓存，不等于所有查询头共享同一读取结果，查询仍可以不同。解释结构时先写 Q、K、V 的头数与形状，比只用缩写更明确。

长序列评价可构造证据位于前、中、后的问题，并加入相似干扰。支持长输入只说明可接收，能否正确利用还取决于训练和模型。注意力热图的可视化不能替代实际答案与干预结果。

<a id="sec-5"></a>

## 5. 进阶：Flash式实现与稀疏近似的区别

分块在线 softmax 可用局部最大值和归一化和逐块合并，避免显式保存全部分数，同时保持同一全注意力数学目标；稀疏窗口则直接改变可交互集合。前者主要改变内存访问，后者改变函数族。

因此“线性显存”不自动代表线性算术量。长序列需分别报告预填充、解码、KV 缓存和质量。位置外推还受训练分布与干扰影响，不能从位置编码公式独自证明可靠长上下文。

<a id="sec-5-1"></a>

### 精确加速、近似稀疏化与位置外推的区别

标准自注意力关系矩阵随序列长度平方增长。分块计算、融合内核和重计算可以改变数据搬运与中间存储，同时保持目标运算在数值容差内相同；局部或稀疏注意力则改变哪些位置交互，属于模型结构变化。两者都可能提速，但证明义务不同。

位置编码引入顺序信息，不自动保证超过训练长度的可靠外推。绝对位置、相对位置和旋转式表示对距离的编码方式不同，仍需在目标长度与任务上检验。更长上下文可被接口接受，不等于有效信息利用随长度同比提高。

解释实验可改变候选证据、打乱局部输入或替换注意力路径，观察任务输出是否随之变化。注意力图展示内部权重，不能独立证明因果重要性。研究中应将机制可视化与可证伪的干预测试组合，而非只选择最符合预期的一张热图。

<a id="sec-6"></a>

## 6. 练习与解析

**题目：** 把全注意力换成窗口大小 32 的局部注意力，是否只是无损加速？

**解析：** 不是，可直接读取的范围已改变，远距交互需多层或额外路径。应在速度、内存与任务质量上重新验证。

<a id="sec-7-2"></a>

### 边界追问：位置方法支持长索引是否保证外推

**问题：** 位置编码可以计算一万个位置，训练只见一千，能否称模型可靠支持一万上下文？

**推理解析：** 不能，表示可构造、计算可执行与有效信息利用不同。应固定任务把证据放在不同距离，测准确率、长度与干扰效应，并报告资源。位置缩放、缓存索引与训练分布共同影响结果，不能只根据接口长度作能力声明。

<a id="sec-7"></a>

## 7. 进阶研究练习与解析

**问题：** 证明无位置自注意力的置换等变性，并构造因果 mask 下不成立的例子。

**解析：** Q、K、V 随 P 左乘，分数随 P 行列置换，softmax 和值加权对应变化，输出为原输出左乘 P。固定三角 mask 不随任意置换对应变换，因此可见边发生变化，原结论不再适用。

**实现验收：** 固定投影与关闭 dropout，对输入置换比较恢复顺序后的输出；再加因果 mask 展示差异。另检查未来 token 干预不改变较早输出。形状一致不足以替代这些结构性质检查。

<a id="sec-7-1"></a>

### 综合练习：掩码正确性的干预验收

**问题：** 检查因果注意力时，仅看 mask 为下三角是否足够？

**逐步解析与验收：** 不够。固定合法前缀，修改未来 token，过去有效输出在关闭随机性的条件下应不变；再改变被屏蔽 padding，检查有效位置。还需核对 API 布尔语义与全屏蔽行。验收测试真实信息路径，而非只验证一个数组外形。
