## 1. 注意力在解决什么

将整个长序列压缩成一个固定向量，可能让重要细节难以保留。注意力让每个查询根据当前需求，从多个位置读取不同权重的信息。例如翻译一个词时，可以更关注输入中对应的词，而不是只依赖一个总摘要。

查询 $Q$ 表示“要找什么”，键 $K$ 表示“每个位置可按什么特征被匹配”，值 $V$ 表示“实际读取的内容”。它们通常由输入通过不同线性投影得到，这些名称不是人工写入的关键词表。

<a id="sec-2"></a>

## 2. 缩放点积注意力

$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}+M\right)V.$$

若 $Q$ 为 $(T_q,d_k)$、$K$ 为 $(T_k,d_k)$、$V$ 为 $(T_k,d_v)$，匹配分数为 $(T_q,T_k)$，输出为 $(T_q,d_v)$。softmax 对每个查询对应的键维归一化。缩放减轻维度较大时点积数值过大带来的 softmax 饱和。

<a id="sec-1-1"></a>

### 基础算例：一个查询的读取结果逐项计算

两键得分为 0 与 log2，经 softmax 后权重为 1/3、2/3。对应值为 1 与 4，输出为 1/3+8/3=3。权重沿键轴之和为 1，输出位置数由查询数决定；值的维数决定输出特征维。若增加第二个查询，就得到第二组权重，而不是把已有输出再平均。这个例子把 QK 得分、概率归一和对 V 加权三个步骤分开，避免把注意力权重本身当作最终表示。

<a id="sec-2-1"></a>

### 机制展开：缩放控制点积的典型波动

若 q、k 坐标近似独立、零均值单位方差，点积含 dk 项，方差约 dk；除以 √dk 使典型尺度较稳定。softmax 分数差很大时概率接近 0 或 1，梯度可能变弱。缩放不是保证所有训练状态方差精确为一，也不能修复任意异常值。计算时还要核对 Q、K 最后维相同，以及 softmax 沿键轴归一。

<a id="deep-dive-2"></a>

### 深入讲解：QK匹配V读取与缩放系数为何各有作用

注意力先计算QKᵀ匹配，除√dk，再沿键位置softmax得到权重，最后乘V。Q和K决定读哪里，V决定读到什么；相同权重配不同值，输出完全可能不同。

若独立零均值、单位方差分量作点积，dk项相加方差约dk，除√dk把初始分数尺度控制在相近量级。这个解释依赖分布近似，不是所有训练时刻的精确方差定律；温度也会改变权重尖锐程度。

单查询分数(0,ln3)，权重(1/4,3/4)，值(2,10)，输出8。将所有分数同加100不改变权重，稳定实现可减最大值；若第二位置被mask，剩余权重归一后输出2，不是仍保留原来的1/4。

softmax输出是加权组合，不是必须硬选某个位置。值可为向量，各维共用当前头的权重；多个查询各有自己一行分布，归一轴错了就改变问题。

反向会同时通过权重和V传播，注意力图只是中间量。要解释最终预测，需要考虑投影、残差及后续层，不能把最大权重直接叫作因果解释。

<a id="sec-3"></a>

## 3. 一个手算例子

单个查询对两个键的分数为 $(0,\ln3)$，softmax 后权重为 $(1/4,3/4)$。若两个值为 2 和 10，输出为 $0.25\times2+0.75\times10=8$。输出是内容的加权组合，并没有自动选择唯一位置。

若两个键得分同时加同一常数，softmax 权重不变，这是数值稳定化减去最大分数的依据。若一个位置被合法掩码排除，剩余位置重新归一，输出可能从混合变成单个值；全部位置被排除则需明确处理，不能对全负无穷直接期待正常结果。

还要区分分数与值：相同权重下改变值会改变输出，高权重不一定代表对最终预测有最大的因果影响。用两个位置分别改变键、值和 mask，先手算预期，再核对实现，可定位错轴归一或将注意力误当硬选择的问题。

<a id="sec-4"></a>

## 4. 权重与内容共同决定输出

即使某键得到很高权重，若对应值向量接近零，对输出的实际贡献仍可能很小。反过来，较低权重乘一个较大值向量，也可能产生明显影响。因此注意力权重不是完整的重要性度量，值投影和后续网络同样参与计算。

softmax 还有一个平移不变性：对同一查询的全部分数加同一个常数，权重不变。这为数值稳定实现提供依据，可以先减去最大分数。分数比例变化则会改变分布尖锐度，说明缩放、温度与表示尺度都可能影响读取方式。

<a id="sec-5"></a>

## 5. 缩放因子的统计直觉

若查询与键分量近似独立、均值零且方差为 1，点积方差随维度 $d_k$ 增长。除以平方根可控制初始分数尺度，减少 softmax 过于尖锐。这是常见推导直觉，实际训练表示不一定满足所有独立假设。

分数、掩码、softmax 与值加权顺序应固定，不能在归一化后再把部分权重清零却不重新归一化，除非算法明确采用不同规则。

<a id="sec-6"></a>

## 6. 进阶：无位置自注意力的置换等变证明

对置换矩阵 P，输入变为 PX 时 Q、K、V 同样左乘 P，分数变为 $P(QK^T)P^T$。逐行 softmax 随行列置换对应变化，最终输出是原输出左乘 P。因此机制不会自行识别绝对顺序，需要位置或结构信号。

该结论假设无不一致的位置、mask 或随机影响。因果 mask 引入顺序边界后不能任意置换。等变也不等于输出不变；图级或序列级池化后才可能形成相应不变摘要。

<a id="sec-6-1"></a>

### 缩放项与加权读取的概率解释

单头注意力为 $\operatorname{softmax}(QK^T/\sqrt{d_k})V$，Softmax 沿键位置归一。若 q、k 的各坐标近似独立、均值零、方差一，点积方差随 $d_k$ 增大，除以平方根可控制典型尺度，减少过早饱和；这是初始化尺度分析，不是所有训练状态下的精确分布定理。

取一个查询，对两个键的分数为 (0,\log3)，权重为 (1/4,3/4)。若值分别为 2 与 6，读取结果为 5。分数表达访问偏好，值表达被读取内容；只看权重不能推断输出大小，更不能直接解释最终决策的因果来源。

查询数决定输出位置数，键数决定可读取位置数。Q、K 的特征维必须可做点积，V 的最后维可以不同；单样本权重形状是查询长度×键长度。把这三个角色与维度先写清，再理解自注意力或交叉注意力会更直接。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 若有 4 个查询、6 个键、值维度为 8，注意力权重和输出的形状分别是什么？

**答案：** 分别为 $(4,6)$ 和 $(4,8)$。输出位置数量由查询决定，读取来源数量由键和值决定。

<a id="sec-7-1"></a>

### 边界追问：高注意力权重是否代表因果重要

**问题：** 某词注意力最大，能否直接说它决定了最终答案？

**推理解析：** 不能，输出还依赖值向量、其他头、残差与后续层，权重只展示当前读取系数。可构造受控替换或遮挡并检查任务变化，但干预也需避免同时破坏其他条件。可视化用于提出机制假设，不单独证明因果贡献。
