# 注意力机制

理解查询、键和值如何形成动态加权，以及掩码与多头机制的作用。

**先修知识：** 矩阵乘法、softmax、神经网络。

## 学习顺序与覆盖范围

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

| 章节 | 主要内容 | 深入讲解入口 |
| --- | --- | --- |
| [查询键值与加权读取](01-查询键值与加权读取.md) | 注意力在解决什么；缩放点积注意力；进阶：无位置自注意力的置换等变证明 | [进入讲解](01-查询键值与加权读取.md#deep-dive-2) |
| [自注意力多头与掩码](02-自注意力多头与掩码.md) | 自注意力与交叉注意力；掩码是信息边界；进阶：多头分工与掩码的数学边界 | [进入讲解](02-自注意力多头与掩码.md#deep-dive-2) |
| [手写多头注意力与形状检查](03-手写多头注意力与形状检查.md) | 从线性投影到头维；代码中每一步的意义；专题实现：前向与反向同时对照参考模块 | [进入讲解](03-手写多头注意力与形状检查.md#deep-dive-1) |

## 如何完成本主题

完成各章后，先独立作答[综合练习：掩码正确性的干预验收](04-注意力效率位置与解释实验.md#sec-7-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
