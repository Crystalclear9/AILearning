## 1. 明确比较问题

如果研究卷积作用，比较相同预算下的 MLP 与 CNN；研究数据增强，保持网络与优化不变；研究优化器，报告每步和总时间。多个因素同时改变会使结论不可归因。

<a id="sec-1-1"></a>

### 基础算例：同预算与同质量比较可能给出不同结论

方法 A 一小时达到 0.90，B 半小时达到 0.88、两小时达到 0.92。固定一小时比较、达到 0.90 所需成本比较、充分训练后的最好效果比较，是不同问题。报告应先声明目标并给相应曲线或成本，再讨论方法优势。若只挑每种方法最有利的一个点，会混合预算与选择规则，使读者无法判断在自己的约束下该选哪种方案。

<a id="deep-dive-1"></a>

### 深入讲解：质量效率与研究结论应怎样形成一张可比较结果表

先确定比较是同预算谁好、同质量谁快，还是最坏群体谁稳。固定步数忽略每步成本，固定时间又需要公平硬件与实现；两类结果应分别报告，不能合成含糊“更高效”。

结果表列数据与划分、方法、主要指标、波动、训练预算和推理成本。消融说明单一改变与伴随参数量，超参数搜索消耗也影响完整方案成本。

误差条来自哪一层必须清楚：测试抽样、训练种子或跨环境。不同层级不能用同一个标准差代替，平均曲线也不能由各运行最好片段拼成。

报告先给实测问题和核心结果，再用消融与错误证据解释，最后列具体边界。没有运行的新方向写成研究问题，不把可能收益表述为已证实能力。

交付检查数据、配置、产物和表格是否追溯同一运行。研究价值不仅在分数提升，也在能明确说明为什么、何时有效、在哪些条件下仍未得到答案。

<a id="sec-2"></a>

## 2. 随机性与成本

预先选择若干种子，报告均值与波动；总训练时间、推理速度和参数量同时记录。多模型集成可能提高指标，但需明确额外训练与推理成本，不能与单模型成本混用。

<a id="sec-2-1"></a>

### 机制展开：成本报告包括选择过程而不只单次训练

方案每次训练较快但需试很多候选，研发总成本可能更高；达到某质量阈值所需样本与充分调优后的最好分数又是不同问题。先声明比较目标，记录候选预算、失败、训练和推理资源，再给质量结论。图表与权重由同一确定版本产生，使结果可追溯，而不是在不同运行中拼接最优片段。

<a id="sec-3"></a>

## 3. 报告结构

首先交代数据与任务，再说明协议和基线，接着给核心结果与消融，最后分析错误及限制。每张图应回答一个问题，报告表格与日志可追溯到同一实验。

核心结果表至少包含方法、数据划分标识、主要指标、运行波动、训练预算和推理成本。消融表应说明只删除或更改了哪个模块，并保留相近的选择预算；若参数量或训练步数同时变化，需要作为额外解释。图中的每条曲线注明种子或汇总方式，不能把不同运行最好的片段拼成一条。

错误分析应连接到证据，例如列出特定类别混淆数、代表性错误及其来源，再说明下一步是补标签、改预处理还是调整模型。报告中分清已经测得的结论与尚待验证的改进设想，限制应具体到数据和场景，便于后续继续工作。

<a id="sec-4"></a>

## 4. 扩展方向

可引入更高分辨率数据、迁移学习或分布变化测试，但每次扩展都重新检查标签、预处理和划分。小图像实验的高分不能直接转化为真实产品的可靠性。

扩展前先写出新问题与额外假设。例如提高分辨率同时增加计算和可见细节，迁移学习同时改变初始化和预训练信息；应设置对照，避免把多项变化归因于单一技术。若新增数据来自其他设备，先检查类别定义、通道、尺寸和标注标准能否对齐。

沿用已建立的训练、验证和错误分析闭环，再增加必要测量。保留原项目的固定回归集合，报告新增场景的收益及旧场景退化。研究设想可以作为下一步，但应与已运行的实验和已经获得的证据明确区分。

<a id="sec-5"></a>

## 5. 一张有解释力的消融表

列出基线、单项改动、验证均值与波动、参数量、训练时间和推理成本，每一行指向配置。若多个因素同时改变，先回退到单因素对照，再讨论交互；否则无法知道收益来自哪里。

对于小数据，零点几百分点可能只对应一个样本。报告原始错误数量，并按预设多个种子汇总。不要在看见测试结果后增加种子直到出现高分，选择过程本身会造成偏差。

最后将发现分成已验证结果与待验证解释。例如“某增强降低分数”是观察，“因为破坏笔画”还需查看样例或设计对照。保持证据层次，比为所有现象给确定原因更适合学习和后续研究。

<a id="sec-6"></a>

## 6. 综合算例与实现核对

假设三种子下 A 准确率为九十四、九十六、九十五，B 为九十五、九十五、九十五，均值相同但波动不同。不能选 A 的九十六与 B 平均比较，应按预设汇总并讨论稳定性与成本。

若新模型训练两倍时间后更好，另设基线也训练两倍的对照，才能区分结构与预算。若基线追上，结论应改为更久训练有效，而不是新结构必然优越。

报告可将任务、协议、结果、分析和限制各用一节，表格保留所有预设候选与关键失败。把可复现证据组织清楚，远比添加许多未经对照的模块更能展示学习成果。

<a id="sec-7"></a>

## 7. 进阶：消融的统计单位与成本公平

独立训练种子反映优化波动，测试样本反映评价抽样，不能混作一组独立观测。相同 epoch、更新、时间和总计算是不同公平标准，报告应与研究问题匹配，并列实际资源。

多模块同时新增需要拆解或组合对照，否则无从归因。挑最好种子或整条曲线最高峰会高估常规表现。保留完整预设运行、失败和配置，才能让项目从演示升级为可审查实验。

<a id="sec-7-1"></a>

### 用成本约束决定比较问题

同预算比较、达到相同质量的成本比较、每种方法充分调优后的最好效果比较，是三类实验。第一类固定资源，第二类记录达到阈值的训练或样本量，第三类必须同时披露调参预算。它们可能给出不同排名，不能在报告中切换目标而不说明。

端到端成本应包括数据处理、训练、选择和推理，至少保留对当前问题有影响的部分。一个模型训练较快但需更多候选搜索，实际研发成本可能更高；推理吞吐高但首请求慢，也可能不适合交互应用。

最终报告把主要结论与证据表对应，列明数据划分、候选、重复、选择规则、误差和资源。每个结论给出适用范围，区分已验证机制与待验证推测。交付产物、配置和图表应来自同一确定版本，保证别人能追溯数值。

<a id="sec-8"></a>

## 8. 练习与解析

**题目：** 新模型准确率提升 0.2%，推理慢三倍，如何判断是否采用？

**解析：** 先判断提升是否稳定，再按实际成本和延迟约束决策。报告准确率与资源取舍，不应仅凭最高分认定全面更好。

<a id="sec-9-2"></a>

### 边界追问：最优分数更高是否一定适合预算任务

**问题：** B 最后达到更高分但训练与调参成本远超 A，能否直接称 B 全面更好？

**推理解析：** 不能，固定预算、达到质量阈值成本和充分调优效果是不同问题。给质量成本曲线及选择过程，明确用户约束，再判断取舍。推理与维护成本也可能改变选择，单个最好分数不足以代表完整方案。

<a id="sec-9"></a>

## 9. 进阶研究练习与解析

**问题：** 一个实验同时新增注意力、增大宽度和延长训练，如何证明收益来自注意力？

**解析：** 至少设置同预算基线、仅注意力、仅宽度、仅训练时长，必要时加组合检验交互。统一数据、选择指标和随机协议，报告质量及成本。仅比较最终强模型与旧弱模型不能完成归因。

**报告验收：** 所有预设运行有配置和日志，图表可重算，最佳模型保存与验证选择一致。错误机制解释需额外对照，不把几个手选案例当证明。项目价值在于结论可被反驳和复现，而非模块数量。

<a id="sec-9-1"></a>

### 综合练习：一次可交付的比较应包含哪些对照

**问题：** 加入模块后测试好一点，怎样形成可审查结论？

**逐步解析与验收：** 固定划分与选择规则，做同预算基线、单模块消融和配对重复，报告每次差值、成本与失败类型。若测试反馈参与修改，下一轮独立评价另行安排。验收同时包括产物加载与指标复算，局部代码运行成功不能替代方法有效性。
