## 1. 完整 CPU 示例

下面代码建立训练、验证和测试集，并按照验证损失保存内存中的最佳权重。需要 NumPy、PyTorch 与 scikit-learn，无需下载数据。

```python
import copy
import numpy as np
import torch
from torch import nn
from torch.utils.data import DataLoader, TensorDataset
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split

torch.manual_seed(42)
torch.set_num_threads(2)
data = load_digits()
X = (data.images[:, None] / 16).astype(np.float32)
y = data.target.astype(np.int64)
Xdev, Xte, ydev, yte = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42
)
Xtr, Xva, ytr, yva = train_test_split(
    Xdev, ydev, test_size=0.2, stratify=ydev, random_state=43
)
loader = DataLoader(TensorDataset(torch.from_numpy(Xtr), torch.from_numpy(ytr)),
                    batch_size=64, shuffle=True)
model = nn.Sequential(
    nn.Conv2d(1, 8, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
    nn.Flatten(), nn.Linear(8 * 4 * 4, 10)
)
optimizer = torch.optim.Adam(model.parameters(), lr=0.003)
criterion = nn.CrossEntropyLoss()
best_loss, best_state = float("inf"), None
for epoch in range(20):
    model.train()
    total = 0.
    for xb, yb in loader:
        optimizer.zero_grad()
        loss = criterion(model(xb), yb)
        loss.backward()
        optimizer.step()
        total += loss.item() * len(xb)
    model.eval()
    with torch.no_grad():
        logits = model(torch.from_numpy(Xva))
        val_loss = criterion(logits, torch.from_numpy(yva)).item()
        val_acc = (logits.argmax(1) == torch.from_numpy(yva)).float().mean().item()
    if val_loss < best_loss:
        best_loss, best_state = val_loss, copy.deepcopy(model.state_dict())
    if epoch % 5 == 0:
        print(epoch, total / len(Xtr), val_loss, val_acc)
model.load_state_dict(best_state)
model.eval()
with torch.no_grad():
    prediction = model(torch.from_numpy(Xte)).argmax(1).numpy()
print("test accuracy:", (prediction == yte).mean())
```

## 2. 为什么需要深拷贝

`state_dict()` 中的张量与模型状态有关，简单保存引用可能随训练继续变化。这里用 `deepcopy` 固定最佳时刻。大型训练通常把检查点写入文件，并保存优化器、epoch 和配置。

<a id="sec-1-1"></a>

### 基础算例：最佳验证权重为什么要复制

训练第 3 轮验证最好，保存 `state_dict()` 的简单引用后继续更新参数，保存对象可能继续反映后续状态，而不是固定第 3 轮。深拷贝或写文件后重新加载，才能进行固定状态比较。最佳依据还要预先确定是验证 loss 还是准确率；二者不一定同轮最好。最终报告测试前先加载选定权重并切换评估模式，避免拿最后一轮误称最佳模型。

<a id="sec-2-1"></a>

### 机制展开：保存引用与保存快照不同

参数字典的张量可能与模型共享底层存储，继续训练后其值也会改变。要固定最佳时刻，应深拷贝或写入检查点，并记录对应验证值与轮次。大型模型还需考虑序列化成本及发布完整性。加载后固定输入核对预测只能验证函数快照，若要续训还需恢复优化器等状态，不能把两个目标混用。

<a id="sec-3"></a>

## 3. 平均损失的正确加权

假设一个 epoch 有大小分别为 64 和 10 的两批，其平均损失为 0.2 与 0.8。简单平均得到 0.5，而按样本加权为 $(64\times0.2+10\times0.8)/74\approx0.281$。最后小批不应与大批拥有相同总权重，因此代码累计 `loss.item() * len(xb)`。

最佳验证损失对应的权重未必具有最高验证准确率，因为概率置信度也影响交叉熵。必须预先明确主要选择指标，不能训练完后从多个指标挑最有利的结果。示例使用验证损失作选择，最终测试准确率作任务层面的报告。

<a id="deep-dive-3"></a>

### 深入讲解：训练代码中的均值保存和选择如何影响结果

epoch loss应累计批均值乘批样本数，再除总数。批大小4和1、损失1和5时整体为1.8，不是3；准确率同样累计正确数和总数，不平均不同大小批次的百分比。

验证用eval与无梯度，不执行更新，前处理固定。训练loss可能含增强或正则，验证不含时不可直接把数值间隙全部归为过拟合。

保存最佳模型时需深拷贝状态或持久化，否则仅存可变引用可能继续随训练变化。最佳权重与当时配置、步数和选择指标应关联，不能将最后优化器状态误配到较早权重后称精确恢复。

先核对单批，再小数据，再完整预算。运行示例中的数据范围和规模只支撑对应教学任务，不自动代表新设备或真实图像系统可靠。

加载后在固定输入复算预测和指标，确认类别顺序、模式与归一一致。能训练、能选择、能恢复三件事都成立，才是完整可运行例子的验收。

<a id="sec-4"></a>

## 4. 评估过程不应改变模型

验证中关闭梯度并切换模式，不能执行 optimizer.step。计算指标时按样本累计，保持标签和输出对应。若需选最佳模型，使用预先确定的验证指标，不在多个指标中事后挑最有利状态。

保留最佳权重需深拷贝或写检查点，保存引用可能随后续训练变化。最终加载后再次确认模式和输入归一化一致。

<a id="sec-5"></a>

## 5. 综合算例与实现核对

逐步核对训练循环：每批先清空旧梯度，前向得到十类 logits，用整数标签计算交叉熵，反向后更新。每轮结束切换 eval，验证不计算梯度也不更新参数，再按预设验证损失保存深拷贝。

若把清梯度移动到训练循环外，一般会无意累加所有批次；若在 loss 形成前调用 item，会切断计算图；若忘记恢复 train，后续含随机层的网络行为会不对。当前小网络没有这些层，也应养成完整模式切换习惯。

项目验收可以加入三项检查：第一批 logits 形状为批量乘十，短训练损失下降，加载最佳权重后预测与保存时一致。最后一项与测试泛化不同，分别验证程序交付与模型效果。

<a id="sec-6"></a>

## 6. 进阶：最佳状态选择与检查点正确性

验证损失选择的模型不一定拥有最高验证准确率，必须预先固定选择目标。保存 state_dict 的引用可能随后续更新变化，深拷贝或完整写入才能固定状态；日志轮次应与实际参数同步。

训练损失按样本加权，验证不更新参数，最终测试只评估确定方案。若查看测试错误后修改模型，原测试已成为开发信息。代码成功执行与协议正确是两层验收，项目需同时证明。

<a id="sec-6-1"></a>

### 最佳模型选择与指标汇总的完整核对

每个训练批先清梯度、计算 logits 与 loss、反传、更新；每轮验证切换 eval 并停止梯度记录，但验证不能执行更新。下一轮开始必须恢复 train。当前网络没有随机层时遗漏模式切换可能暂不暴露，扩展后却会改变行为。

批均值 loss 应按批样本数加权后汇总。若大小为 64 和 10 的两批 loss 为 0.2 和 0.8，epoch 均值约 0.281，而非 0.5。相同原则也适用于分布式或掩码 token 计数，只是有效单位需要重新定义。

最佳权重需深拷贝或写入检查点，不能只保存随模型继续更新的引用。加载后再次在固定输入上核对输出与模式，并记录选择轮次和验证值。这个检查证明产物保存正确，独立测试则评价泛化，不能用其中一项替代另一项。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 训练循环内用测试损失替换验证损失选择最佳模型，会发生什么？

**答案：** 测试集参与选择，最终测试准确率失去独立评估意义。应保留验证选择和测试报告的分工。

<a id="sec-7-1"></a>

### 边界追问：最佳 loss 权重能否称最佳 accuracy

**问题：** 验证 loss 最低在第十轮，accuracy 最高在第十二轮，报告能否将两轮优点合成一个模型？

**推理解析：** 不能，必须按事前规则选定一个状态，最终指标来自同一权重。概率置信度与分类正确有不同贡献。保存选择指标、轮次和产物，并固定输入核对加载结果，不把多个运行或轮次最优片段拼成虚构交付。
