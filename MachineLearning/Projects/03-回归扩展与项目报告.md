## 1. 换任务时重新定义指标

可使用 `load_diabetes` 的内置回归数据练习。以训练均值为基线，比较 `StandardScaler + Ridge` 与随机森林回归，主要报告 MAE 和 RMSE。这里数据仅用于统计建模教学，不能从练习模型推导实际应用建议。

分类的分层划分不能不加改变地套到连续标签；回归通常用普通 K 折，若有分组或时间则按实际结构改。模型名称和评分字符串也要改变，例如 scikit-learn 的负 MAE 评分越大越好，展示时应还原为正的误差。

<a id="sec-1-1"></a>

### 基础算例：两类误差对大尾部的不同响应

两模型误差分别为 A=(0,0,6)、B=(2,2,2)。两者 MAE 都为 2，但 A 的 RMSE 为 $\sqrt{12}\approx3.464$，B 为 2。A 在多数样本无误差，却有一个大错；B 把误差平均分散。哪个更好取决于实际代价，不能仅因一个指标相同就认为行为等价。残差分析和分组统计用于揭示这种结构，再在开发数据形成下一轮改进假设。

<a id="sec-2"></a>

## 2. 残差分析比一个分数更具体

残差定义为 $e=y-\hat y$。画预测值与残差、关键特征与残差的散点图；按目标区间或业务分组统计误差。若大目标总被低估，可能是损失、样本分布或模型表达的限制；若某一批数据异常，可能是输入生成机制变化。

分析测试错误后若据此修改方案，应把原测试集视为已用于开发。后续严谨评估需要新的未参与决策的数据，而不是继续宣称原测试分数完全独立。

<a id="sec-2-1"></a>

### 机制展开：残差方向与统计分组需要统一

若定义 e=y-ŷ，某组平均残差为正表示整体偏低估，负表示偏高估；换定义后符号相反。总体均值近零仍可掩盖两组相反偏差。按目标、预测或来源分组各回答不同问题，真实标签分组只能用于事后诊断，不能直接成为上线决策输入。报告样本数及探索性质，避免小组偶然差异被解释为确定机制。

<a id="deep-dive-2"></a>

### 深入讲解：回归误差分析怎样从一个平均数走向机制判断

MAE给平均绝对误差，RMSE对大残差更敏感，二者单位与目标一致。若RMSE远高于MAE，检查长尾和来源，而不是自动删除最差样本；真实困难对象可能正是任务关心的部分。

残差对预测值可看偏向和异方差，对时间可看漂移，对关键输入可看非线性遗漏。平均残差为零不代表误差小，因为正负抵消；相关结构也提示独立性假设需要审查。

如果目标先取log，训练优化与原单位评价不同。反变换预测不总等于原尺度条件均值，偏差需结合目标定义处理；不能把log空间RMSE直接写成原单位误差。

常数均值或中位数基线分别匹配不同损失，季节或分组基线也可能很强。复杂模型应在同一协议下超过恰当参照，再讨论更多参数的价值。

报告把主要结果、分组误差、尾部案例、预算和限制连起来。每个改进假设先由验证检验，独立测试保留评价角色，避免残差分析成为反复利用最终测试的入口。

<a id="sec-3"></a>

## 3. 最终报告的写法

用一段话交代任务与数据，然后说明划分和指标，给出基线与最终模型的同表比较，展示主要错误类型，最后说明限制。不要只写“模型效果很好”，应写“在固定的随机测试划分上，某指标为多少，相比基线改善多少，样本量与分布有哪些限制”。

结果表把基线、候选和最终方案放在同一划分与目标单位下，注明前处理、超参数搜索、选择指标、运行时间及样本数。若评估包含重复训练或重采样，解释区间来源，不能把不同层级波动混为一个误差条。

回归错误分析至少检查残差与预测值、时间和主要来源，报告大误差尾部及目标区间差异。结论对应实测结果，例如在哪些样本上改善、成本有何变化；尚未运行的改进写为下一步。独立测试不能继续用于反复选择特征或阈值。

<a id="sec-4"></a>

## 4. 把误差分析变成下一轮假设

发现某组误差较大后，先提出可检验假设，例如该组样本少、输入缺失较多或目标分布偏移。再在开发数据中做对照：补充缺失指示列、改变损失或增加有代表性的训练样本，观察该组及总体表现是否改善。

不要根据一个错误案例立即加入专门规则；规则可能只适配该样本。有效的误差分析应从多个案例形成共性，再用独立数据验证。最终报告应区分已经验证的原因、仅有相关证据的猜测和下一步计划，使读者知道结论有多强。

<a id="sec-5"></a>

## 5. 报告应包含数据和代码约束

注明数据为内置教学数据、样本量有限、划分规则与随机性。不能从一次小数据比较推导出某模型普遍最好。保留完整配置与指标生成代码，使表格可重新计算。

如果候选模型差异很小，可选择较简单、成本低和结果稳定者；不要只为了“最终模型”称号选择小数点后偶然最高的方案。

说明数据获取及使用前提、依赖版本、输入路径配置和结果复现入口，避免依赖作者个人机器的隐式文件。数据无法直接提供时，给出来源、提取定义或校验标识，并明确读者能够重现到哪一层。

结果对应的模型、前处理、配置及数据版本必须能关联，同一图表不可混入不同划分的最好点。若耗时测量与正式训练环境不同，应写清硬件、批量及测量窗口，不能将不等价的数字放在同一性能表里。

<a id="sec-6"></a>

## 6. 进阶：残差分组分析与多重探索

按目标区间、来源或缺失划组可揭示系统错误，但反复尝试很多分组后挑最大差异，也会产生选择偏差。应把这类分析标为探索，形成机制假设后在开发或新数据验证。

MAE 改善而 RMSE 变差，可能普通样本变好而少数大误差变坏。选择损失和模型取决于实际代价，不能只宣布一个指标全面更优。线性系数的预测解释也不等于因果作用。

<a id="sec-6-1"></a>

### 回归报告应连接误差单位与改进假设

MAE=20 表示平均绝对误差为目标的 20 个单位，不是 20%。RMSE 若明显更大，说明平方加权更突出尾部误差，但单凭二者差距还不能定位成因，应查看残差、样本范围和异常记录。

把残差按预测值、真实目标区间和可用分组分析，可以区分整体偏移、非线性结构和少数来源问题。真实目标分组用于事后诊断可以有价值，但上线时不能用未知真实标签选择不同处理规则。诊断所用信息与实际可部署输入应明确分开。

报告中的每项改进应对应一条可证伪假设，例如“缺失较多的来源误差高，加入合法缺失指示可能改善”。在开发数据验证后才更新方案。若发现只是标签或单位错误，应优先修数据，而不是把异常解释为需要更复杂模型。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 回归模型 MAE 更低但 RMSE 更高，可能意味着什么？

**答案：** 它可能改善了多数普通样本，却在少数样本上犯了更大的错误，因为 RMSE 更重视大误差。应查看误差分布和异常案例，再结合任务代价选择。

<a id="sec-7-1"></a>

### 边界追问：残差均值为零能否代表误差小

**问题：** 模型一半误差为十、一半为负十，平均残差为零，是否接近完美？

**推理解析：** 不是，MAE 和 RMSE 均为十，正负抵消不代表准确。再看来源与目标区间可能发现方向相反的系统偏差。先统一残差符号，再报告幅度、尾部和分组，不用一个接近零均值替代完整诊断。
