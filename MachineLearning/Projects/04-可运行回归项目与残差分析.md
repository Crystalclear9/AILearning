## 1. 定义任务与协议

使用 scikit-learn 内置糖尿病回归数据作为统计建模练习。目标是比较均值基线与岭回归，主要报告 MAE、RMSE。这个练习仅研究数据上的预测，不构成真实医疗应用或因果解释。

保留独立测试，训练内交叉验证选择 alpha，标准化放在 Pipeline。负误差评分越大越好，是库的统一评分约定，最终报告需恢复为正误差。

<a id="sec-1-1"></a>

### 基础算例：均值与中位数基线各自最优在哪

训练目标为 [0,0,9]，均值为 3，中位数为 0。均值常数预测的训练 MSE 为 18，预测 0 的 MSE 为 27；但预测 0 的 MAE 为 3，预测 3 的 MAE 为 4。平方与绝对损失的最优常数不同，因此主要目标是 MAE 时应考虑中位数对照。所有基线参数仍只能来自训练标签，不能借测试均值建立虚假更强基线。

<a id="sec-2"></a>

## 2. 完整代码

```python
from sklearn.datasets import load_diabetes
from sklearn.model_selection import train_test_split, GridSearchCV, KFold
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Ridge
from sklearn.dummy import DummyRegressor
from sklearn.metrics import mean_absolute_error, mean_squared_error
X, y = load_diabetes(return_X_y=True)
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.25, random_state=42)
search = GridSearchCV(make_pipeline(StandardScaler(), Ridge()),
    {"ridge__alpha": [0.1, 1., 10., 100.]}, scoring="neg_mean_absolute_error",
    cv=KFold(5, shuffle=True, random_state=42))
search.fit(Xtr, ytr)
baseline = DummyRegressor().fit(Xtr, ytr)
for name, model in [("mean", baseline), ("ridge", search)]:
    pred = model.predict(Xte)
    print(name, mean_absolute_error(yte, pred), mean_squared_error(yte, pred)**0.5)
residual = yte - search.predict(Xte)
print("mean residual:", residual.mean())
```

<a id="sec-2-1"></a>

### 机制展开：搜索评分与报告单位要对齐

GridSearchCV 使用负 MAE 是为了统一越大越好，输出报告应还原正误差。最优 alpha 的 refit 使用全部开发训练数据，不是把测试再合入。代码里的均值基线与主目标 MAE 并非天然最强常数对照，可另加训练中位数。残差表、图和指标从同一预测结果生成，才能保证报告对应同一个确定版本。

<a id="deep-dive-2"></a>

### 深入讲解：可运行回归例子怎样检查从列到残差的完整含义

固定输入列及目标单位，先划分再拟合前处理。训练均值填补、缩放和模型应作为一个对象保存，新样本复用相同变换；列名相同但顺序变化也可能破坏只按位置输入的接口。

用手工小批核对预测、残差、MAE和RMSE。若残差为(1,−1,4)，MAE=2、RMSE=√6≈2.449，平均残差4/3。不同指标强调不同方面，不能互相代算。

交叉验证选模型后重训开发数据，最终测试只用冻结方案。训练误差低、测试差时检查容量、数据差异和泄漏边界；两者都差则还需排查目标、表示及优化。

残差图应标单位、范围和样本，分组统计要给支持数。异常先查原始记录与标签，再判断是否为合理难点；删去高误差样本会改变评价总体。

加载已保存流程，在固定样例重新预测并复算指标，确保报告数字对应同一产物。可执行训练、可信评价和可恢复推理共同构成项目闭环。

<a id="sec-3"></a>

## 3. 解释而非只排名

查看高低目标区间误差，画残差与预测值。整体平均残差接近零不代表误差小，正负可抵消。若 RMSE 明显高于 MAE，检查是否存在大误差尾部与特定异常样本。

残差图横轴可分别取预测值、时间与关键输入，检查误差是否随量级扩张、具有周期或集中在某来源。若采用目标变换，评价时需明确是在变换尺度还是原单位上；回到原单位后指标可能明显不同，尤其在尾部。

异常样本先核对标签、单位和特征可用时间，再判断是否为真实困难案例。删除错误记录与删除高损失样本是两种决策，均应有训练边界内的规则。若残差随预测值有系统偏向，可尝试合适的特征、模型或损失，但所有改进仍由验证集选择，最终测试保留一次独立评价。

<a id="sec-4"></a>

## 4. 从输出数值到解释

均值基线只输出训练目标平均，主要检验特征是否带来预测收益。岭回归加入线性关系并通过 alpha 控制系数大小。选择依据是交叉验证 MAE，因此不应测试后再挑 RMSE 更好的一组参数而仍称原协议。

残差平均可能正负抵消，MAE 描述典型绝对偏差，RMSE 更受大误差影响。可按目标区间统计两者，检查高值是否持续低估。小数据的分组误差还要报告样本数，避免几个案例决定过强结论。

对内置数据的特征，也不能随意给系数赋予医疗因果解释。这个项目练习统计预测流程，真实使用需要不同证据、数据验证和具体任务设计。交付说明应保留这一范围，而不是让示例指标越过它。

<a id="sec-5"></a>

## 5. 综合算例与实现核对

可增加一个目标区间误差表，按真实目标的预设区间统计样本数、MAE 与平均残差。若高目标组平均残差为正，说明倾向低估；若总体均值残差近零，这种系统偏差仍可能被其他组抵消。

不要根据测试组表现反复调整分箱或超参数再报告最好结果。误差分析若用于改模型，下一轮需要独立验证安排。项目报告应标记这部分是探索发现。

对预测区间的进一步练习，需要另外方法和适用假设。点预测 MAE 低不表示已给出可靠个体不确定性；在没有区间方法时，应明确只输出点估计，不凭误差平均数随意构造置信度。

<a id="sec-6"></a>

## 6. 进阶：岭回归的有效复杂度与目标选择

标准化后的岭回归在各奇异方向连续收缩，小方向更受抑制；alpha 增大并非简单同倍缩小所有原始系数。若搜索以 MAE 选择，报告也需保留该依据，不能事后换成测试 RMSE 最好者。

均值基线对平方损失有最优常数性质，中位数则对绝对损失最优。比较回归基线时应说明其训练策略与主要指标，不应把不匹配基线作为夸大收益的工具。真实任务还需检查范围外与新来源表现。

<a id="sec-6-1"></a>

### 回归基线的训练策略应与主要损失对应

训练均值是平方误差下最优常数，中位数是绝对误差下最优常数。因此在 MAE 为主要目标的实验中，除均值基线外还可加入中位数基线，避免只用不匹配的弱对照。它们都必须仅从训练标签计算。

岭回归在不同奇异方向采用不同收缩比例；标准化改变惩罚对原始系数的相对含义。交叉验证选择 alpha 后 refit 作用于完整开发训练集，最终测试不再选择参数。负 MAE 评分是库统一“越大越好”的接口约定，报告时应还原误差的自然正值。

进一步可比较每条样本与基线的绝对误差差值，查看改善是否只来自少数尾部点。若需要区间预测，应另选带明确覆盖目标的方法，不能把总体 RMSE 直接当作每个样本相同的可信范围。点预测与不确定性估计有不同验收标准。

<a id="sec-7"></a>

## 7. 练习与解析

**题目：** alpha 选择后是否还要用全部训练集重新拟合？

**解析：** 需要。GridSearchCV 默认 refit 已完成这一步；最终测试不能用于再次选择 alpha。验证估计和最终测试须分别报告。

<a id="sec-7-1"></a>

### 边界追问：回归 R² 为负是否表示指标算错

**问题：** 测试真实值为 (0,2)，模型预测 (3,3)，按测试均值作 R² 基线，结果是多少？

**推理解析：** 测试均值一，基线平方误差和为二，模型误差和为九加一等于十，所以 R²=1-10/2=-4。它表示比该测试均值常数更差，不是概率越界。部署基线若只能由训练均值拟合，应另列相应误差，不能把两种基线混称；目标恒定时还需单独处理。
