# 概率模型

从联合生成假设推导分类、隐变量优化、参数后验与序列推断，分别检查模型、数值计算和预测决策。

**先修知识：** 概率与统计；基础矩阵运算。

## 学习顺序与覆盖范围

第 1 章用已知类别推导生成式分类和朴素贝叶斯；第 2 章移除来源标签，完整推导混合模型、责任度与 EM；第 3 章把参数估计推广为后验与联合预测；第 4 章为隐状态加入时间依赖，推导前后向、路径、软计数和序列学习。先掌握条件概率、矩阵运算与对数似然，再进入近似推断和研究练习。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

## 如何完成本主题

完成各章后，先独立作答[综合练习：两条独立序列能否首尾相连训练](04-隐马尔可夫模型与序列推断.md#sec-7-1)，再对照逐步解析与验收要求。

完成后，应能写出生成过程和完整联合式，推导未知量的后验及必要归一化；在小模型中用枚举或数值积分独立核对算法；说明 EM、MAP 和后验预测的目标区别；对序列分别计算似然、过滤、平滑、最佳路径与软计数。最后对模型失配、先验敏感性和预测对象变化给出具体反例。
