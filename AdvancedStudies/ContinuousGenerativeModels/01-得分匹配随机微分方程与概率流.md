## 1. 得分不是生成质量分数

对时间 t 的密度 $p_t(x)$，得分为 $s_t(x)=\nabla_x\log p_t(x)$，是与输入同维的向量场。它不等于 $\log p_t(x)$，也不是评价器输出的“好看程度”。密度的未知归一化常数对 x 求导后消失，这是得分建模方便的原因之一。

若知道任意位置附近的得分，仍需指定动力学与数值方法才能采样。有限网络在低密度区的误差、数据支撑与尾部都会影响生成；不能把训练均方误差下降直接解释为所有位置的得分都准确。

<a id="sec-2"></a>

## 2. 去噪目标为何能学习边缘得分

令 $x_t=\alpha(t)x_0+\sigma(t)\epsilon$，$\epsilon\sim N(0,I)$。给定 x0 的条件得分为 $\nabla_{x_t}\log p(x_t\mid x_0)=-\epsilon/\sigma(t)$。在适当正则与交换微分条件下，边缘得分为条件得分对 $x_0\mid x_t$ 的期望。

平方损失的最优预测是条件均值，因此训练噪声预测器估计 $\mathbb E[\epsilon\mid x_t,t]$，再用 $s_\theta=-\epsilon_\theta/\sigma(t)$ 可联系边缘得分。目标不是让网络还原每个输入中无法唯一确定的那次噪声，而是学习条件统计量。

得分误差平方与噪声误差平方相差 $1/\sigma(t)^2$，时间权重也会随参数化改变。若 σ 在端点为零，不能直接除零；实际训练时间区间、权重和采样端点应明确。

<a id="deep-dive-2"></a>

### 深入讲解：混合高斯得分说明局部方向不等于样本质量

考虑等权均值−2与2、方差1的混合。每个分量得分为μ−x，边缘得分不是固定平均，而是按当前位置的后验责任度加权；责任度可由两分量密度归一得到。

在x=1处，正分量比负分量密度大e⁴，责任度约(.018,.982)，得分约−3×.018+1×.982=.928。若误用固定各半平均，得到−1，连方向都错。

在x=0对称处得分为零，却位于两峰之间的低密度区域。这说明得分不是“质量分数”，零得分也可能是局部低谷或其他驻点；生成需要完整时间场与动力学，而非沿某个静态梯度走就必到好样本。

去噪条件得分对隐藏干净样本取后验期望，正与责任度思想一致。反向SDE和概率流的系数、时间方向必须配套，数值积分误差与学习误差分开测试。

用解析混合先核对方向、模式比例和方差，再替换学习网络，可以明确是哪一环出了偏差。只匹配一个均值，无法证明完整多峰分布已生成正确。

<a id="sec-3"></a>

## 3. 正向 SDE、反向 SDE 与时间方向

考虑标量扩散系数、与状态无关的正向过程 $dX_t=f(X_t,t)dt+g(t)dW_t$，t 从数据端 0 增至噪声端 T。在所需光滑及密度条件下，反向采样采用

$$
dX_t=[f(X_t,t)-g(t)^2s_t(X_t)]dt+g(t)d\bar W_t,
\qquad t:T\to0.
$$

这里 dt 是向过去走的负增量，反向布朗增量方差对应 $|dt|$。若代码用正步长 Δ 并令 t 减少，Euler 漂移项应写成减去 $[f-g^2s]\Delta$，不能忽略时间方向后又多加一个负号。

以上只写了常见状态无关的各向同性扩散形式，状态相关扩散需要额外分析，不能直接沿用。实际开始分布通常只是接近简单噪声，初始近似与有限步离散都是额外误差来源。

<a id="sec-3-1"></a>

### 进一步推导：将离散扩散连接到一个具体 SDE

常见方差保持过程取 $f(x,t)=-\beta(t)x/2$、$g(t)=\sqrt{\beta(t)}$，β(t)≥0。解的条件分布可写成 $X_t=\alpha(t)X_0+\sigma(t)\epsilon$，其中 $\alpha(t)=\exp[-\tfrac12\int_0^t\beta(u)du]$，$\sigma(t)^2=1-\alpha(t)^2$。这是离散乘积保留系数的连续对应，不应把瞬时 β 与累计噪声方差混为一谈。

代入反向漂移得 $-\beta x/2-\beta s_t(x)$；反向走时间时仍乘负 dt。概率流则把得分系数减半。若符号混淆，可先对零均值单位高斯作检验：该分布在方差保持 SDE 下不变，得分为 −x，概率流漂移应为零。这个简单不变量能迅速发现半系数错误。

对高斯混合，加噪后每个分量仍是高斯，边缘得分为各分量得分按后验责任度加权。责任度依赖当前位置，不能只平均分量均值或固定混合权重。使用 log-sum-exp 稳定计算，可构造多峰解析得分测试而无需训练网络。

一般过程的初始与终端分布、系数光滑及密度条件需要单独核对。这里给出一个常用特例帮助读懂扩散连接，不据此断言所有数据相关噪声、跳跃过程或任意参数化都服从相同反向式。

<a id="sec-4"></a>

## 4. 概率流 ODE 与基础算例

同一得分可定义概率流 ODE：$dX_t/dt=f(X_t,t)-\tfrac12g(t)^2s_t(X_t)$。在精确得分及相应条件下，它与正向 SDE 共享各时刻的边缘密度，但轨迹和路径联合分布不同；随机项消失不意味着可以删去半系数差异。

例如 $X_0\sim N(m,v_0)$，加性噪声方差为 $\sigma(t)^2$，则 $X_t\sim N(m,v_0+\sigma(t)^2)$，得分为 $-(x-m)/(v_0+\sigma^2)$。f=0，$g^2=d\sigma^2/dt$ 时，ODE 漂移系数为 $g^2/[2(v_0+\sigma^2)]$，使前向方差导数恰为 g²；倒时间积分则收缩回数据方差。

这个高斯例子可直接核对符号、半系数与时间端点。它并未说明真实非高斯数据的轨迹也只是简单缩放。

<a id="sec-5"></a>

## 5. 采样、引导与模型误差

反向 SDE、概率流 ODE及离散扩散采样器使用不同数值路径。比较步数需报告网络函数评估次数 NFE，因为高阶方法每步可能调用多次网络。较大步长会增加离散误差，而低质量得分也无法仅靠更小步长修复。

条件引导改变向量场，强引导可能提高条件遵循，同时降低覆盖或产生伪影。它通常不是对原始无条件分布的等价加速，不能只比较视觉效果而忽略分布变化。潜空间模型还要区分生成误差与编码解码重构损失。

<a id="sec-6"></a>

## 6. 可复核的数值实验

先用解析高斯得分，固定初始样本，比较反向 Euler 与 ODE 随步长缩小的均值方差误差。SDE 还需多次噪声重复或足够样本，不能对每条随机轨迹要求单调接近目标。ODE 使用相同初始样本，便于隔离离散变化。

再把得分乘以一个人为偏差因子，比较增加 NFE 是否仍不能恢复真实分布，从而区分近似向量场误差和积分误差。真实模型评估同时看质量、覆盖、条件与耗时，不能只看训练去噪损失。

<a id="sec-7"></a>

## 7. 练习与解析

**练习一：** 反向过程为何不能只把正向漂移取负？

**解析：** 反向条件转移还依赖密度梯度，得分项描述观察到当前位置后对过去状态的条件偏向。

**练习二：** ODE 与 SDE 边缘相同，是否表示同一噪声起点得到同一样本？

**解析：** 不表示，路径耦合不同，随机 SDE 还加入新的噪声。

**研究练习：** 在一维双峰混合分布上推导加噪边缘得分，固定起始分布比较随机和确定采样。报告模式比例、均值方差、NFE 与积分误差，避免只选一项矩统计就宣布完整分布一致。
