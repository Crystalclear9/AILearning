## 1. 从噪声到数据的方向约定

本章与上一章正向加噪记法不同：令 t=0 为基础噪声 z，t=1 为数据 x1，ODE 为 $dx_t/dt=v_\theta(x_t,t)$。生成从 0 积分到 1。写程序前先标明哪端是数据，不能只靠变量名“forward”判断符号。

速度场描述同一位置处概率质量的瞬时运动。若足够光滑并具有合适增长条件，ODE 定义流；边缘密度满足连续性方程 $\partial_t p_t+\nabla\cdot(p_tv_t)=0$。这是守恒关系，不是要求每个初始噪声预先对应某一训练样本。

<a id="sec-2"></a>

## 2. 条件路径产生可监督目标

一种简单路径为 $x_t=(1-t)z+tx_1$，通常先从基础分布和数据分布采样端点，再选配对。给定端点，路径导数为 $u_t=x_1-z$。训练

$$
\mathbb E_{t,z,x_1}\|v_\theta(x_t,t)-(x_1-z)\|^2.
$$

平方损失最优解为 $v^*(x,t)=\mathbb E[x_1-z\mid x_t=x,t]$。对路径上的测试函数 φ 求导，$d\mathbb E\phi(x_t)/dt=\mathbb E[\nabla\phi(x_t)^T(x_1-z)]$，再取条件期望，就得到由该边缘速度驱动的弱连续性关系。

因此监督目标来自可采样的条件路径，不需每次训练先完整求解生成 ODE。推理时仍需数值积分，训练不求解不等于生成一步完成。

<a id="sec-3"></a>

## 3. 直线条件路径不保证边缘轨迹直

不同端点对在中间位置可能相遇，该位置的最优速度是多种条件速度的平均。沿这个边缘速度积分的单条轨迹，不必等于任何一条训练端点连线。把“训练用了线性插值”直接说成“所有生成轨迹都是直线”会混淆条件路径与边缘流。

端点耦合影响中间分布和速度复杂度。独立配对易采样，基于近似最优传输的配对可能减少某些路径交叉，却增加匹配成本并改变训练条件。重整流等方法进一步改变配对和训练过程，不能仅凭名称断言所有设置更快。

<a id="deep-dive-3"></a>

### 深入讲解：条件配对路径与实际边缘流为何不能按样本逐条等同

训练可先抽噪声z与数据x1，给定端点走线性插值，监督速度x1−z。固定端点时路径直且速度恒定，但网络只见当前xt与t，不知道是哪一对端点，所以平方损失最优输出为条件平均速度。

若多条路径经过同一区域，它们要求的方向可能不同，平均后实际流的轨迹会弯曲。改变端点耦合会改变中间分布和速度复杂度，即使两端边缘相同；独立配对与近似传输配对不是同一训练问题。

极端离散端点的路径可在某时刻汇成一点再分开，这提示光滑可逆ODE的正则条件不能省略。这样的原子路径可帮助理解几何，却不能直接套所有连续密度与流存在唯一性结论。

高斯例中真实边缘解x(t)=tm+√Vt z，只保留一个基础噪声标识，并不等于训练时配对的独立数据点。导数恰匹配条件平均速度，展示分布正确与逐配对复现是不同要求。

积分器NFE、时间采样和路径权重共同影响误差。训练不求完整ODE只是一种目标构造优势，推理仍需数值验证，低回归误差不自动给有限步精确样本。

<a id="sec-4"></a>

## 4. 基础算例：两个高斯之间的边缘速度

设 z~N(0,1)、x1~N(m,s²) 且独立，则 $x_t\sim N(tm,V_t)$，其中 $V_t=(1-t)^2+t^2s^2$。由联合高斯条件期望得

$$
v^*(x,t)=m+\frac{ts^2-(1-t)}{V_t}(x-tm).
$$

只要 s>0，整个区间 Vt 为正。这一 ODE 的解为 $x(t)=tm+\sqrt{V_t}z$：对 t 求导可核对上式。t=1 得 m+sz，分布正确，但这条确定轨迹并不使用训练时独立配对的那个 x1。

```python
import numpy as np
m, scale = 2., 0.7
z = np.array([-1., 0., 1.])
for t in [0., 0.2, 0.6, 1.]:
    var = (1-t)**2 + t*t*scale**2
    covariance = t*scale**2 - (1-t)
    x = t*m + np.sqrt(var)*z
    velocity = m + covariance / var * (x-t*m)
    analytic_derivative = m + covariance / np.sqrt(var)*z
    assert np.allclose(velocity, analytic_derivative)
assert np.allclose(m + scale*z, np.array([1.3, 2., 2.7]))
print("Gaussian marginal velocity and analytic flow passed")
```

## 5. 与扩散和似然计算的联系

扩散概率流也以 ODE 搬运密度；流匹配直接回归路径速度，两者的路径、参数化与训练权重可建立联系，但不是随意互换目标仍相同。预测噪声、干净样本与速度之间的转换需要对应路径系数与端点处理。

若 ODE 可逆且满足所需正则，沿轨迹 log 密度满足 $d\log p_t(x_t)/dt=-\nabla\cdot v_t(x_t)$，因此可通过散度积分联系似然。高维散度可能用随机迹估计，额外引入计算和方差；“流匹配模型”不自动意味着已经廉价精确算出似然。

<a id="sec-5-1"></a>

### 进一步推导：散度积分怎样恢复密度

沿 $\dot x=v_t(x)$ 的流，连续性方程展开为 $\partial_t p+v\cdot\nabla p+p\nabla\cdot v=0$。沿轨迹求导并除以正密度，得到 $d\log p_t(x_t)/dt=-\nabla\cdot v_t(x_t)$，因此

$$
\log p_1(x_1)=\log p_0(x_0)-\int_0^1\nabla\cdot v_t(x_t)dt.
$$

给定数据端 x1，要同时反向积分位置到基础端 x0，并一致处理散度积分的上下限。常见错误是反向积分时既交换限又多取一次负号。对本章高斯速度，散度为 $[ts^2-(1-t)]/V_t$，积分为 log s，恰好得到高斯变换的 1/s 密度尺度，可作为解析核对。

高维散度是 Jacobian 的迹。若 ξ 满足 $E[\xi\xi^T]=I$，可用 $E[\xi^TJ_v\xi]=tr(J_v)$，配合 Jacobian 向量运算估计，而不显式构造整个矩阵。估计噪声、ODE 容忍和向量场误差都会影响似然，不能仅因模型定义了可逆流就称数值估计绝对精确。

流匹配的速度平方损失并不等于直接最大化精确似然。选择路径、时间权重或端点耦合可以改变易学习性；评价时应分清训练目标、理论边缘及数值似然三个层次。

<a id="sec-6"></a>

## 6. 研究比较要固定什么

比较路径时固定基础分布、端点数据、网络和时间采样，记录配对成本、训练函数评估及推理 NFE。固定步数与固定误差容忍是不同协议，自适应 ODE 求解器的实际调用次数应实测。

先用高斯解析例检查方向、端点和积分阶，再用多峰分布观察路径复杂度。质量提升可能来自更易学习的速度，也可能来自更强条件、数据或预算；通过控制变量区别。减少 NFE 后同时检查覆盖和条件遵循，而不是只看少量代表样本。

<a id="sec-7"></a>

## 7. 练习与解析

**练习一：** 条件路径导数恒定，为什么网络仍要输入 t？

**解析：** 给定当前位置对应的端点不确定性随时间改变，边缘条件期望速度一般随 t 变化。

**练习二：** MSE 训练目标很低，能否省略积分器检验？

**解析：** 不能，有限步误差、时间分布和训练外位置都可能影响生成。

**综合练习：** 对一维双峰目标比较独立端点配对和排序配对，手算或估计中间分布，训练相同速度网络。分别报告拟合误差、积分误差、NFE 和模式覆盖，说明训练路径与实际轨迹的区别。
