## 1. 决策规则与两个必须同时报告的量

固定分类器 f 和可靠性分数 s，阈值 t 定义接受 $A_t(x)=\mathbf1[s(x)\ge t]$，否则拒绝自动预测。接受覆盖率为 $C(t)=P(A_t=1)$，选择性风险为 $R(t)=E[\mathbf1(f(X)\ne Y)\mid A_t=1]$，仅在 C(t)>0 时定义。

全部拒答可以减少错误决策数量，却不说明已接受预测很可靠；若 C=0，条件风险不是自动等于零。总体服务损失还可能包括人工审核、等待和拒答代价，需要另行建模。

s 可来自最大概率、间隔、集成等，但名称不保证排序正确。即使阈值提高，错误率也不一定单调下降；模型可能对某类错误特别自信。要看风险—覆盖曲线及分组，而不只看一个阈值。

<a id="deep-dive-1"></a>

### 深入讲解：更高置信阈值为何可能保留更多错误而非更可靠

构造100条样本，其中最高置信20条错10条，其余80条全对。全回答风险10%，只接受最高20条风险50%。阈值提高降低覆盖，却不保证风险下降；分数是否真正排序错误，需要独立数据检验。

理想成本阈值依赖真实正确概率q，模型最大softmax仅是候选分数。概率校准、错误排序和固定接受集条件风险不同，不能因一种检查通过就自动继承另外两种性质。

有限预设阈值可用联合上界认证，即使从中选择也保留相应风险控制。若看到认证标签后不断创造新分数和阈值，简单K修正不覆盖实际搜索；需要新的独立数据或更强选择理论。

零观察错误也可能样本太少，上界仍宽。全拒答时条件风险并非自动零，覆盖、人工成本和被拒群体应一同报告，不能把难例移出分母后只展示高准确率。

保形覆盖指集合包含真值，选择性覆盖指回答比例，二者不能同名混用。真正的服务评价还应记录拒答后的结果与新分布行为，明确每项保证对应哪种随机实验。

<a id="sec-2"></a>

## 2. 从代价推导一个理想接受规则

假设错误代价为 ce>0、正确代价零、拒答固定代价 cr，且模型真正知道当前预测正确概率 q(x)。回答期望代价为 $c_e(1-q)$，拒答代价为 cr，因此当 $q\ge1-c_r/c_e$ 时回答更合算，边界处按约定处理。

这要求 q 有相应条件概率含义。未校准最大 softmax 分数不能直接代入后声称成本最优；审核结果不完美、容量有限或样本代价不同时，规则也会改变。拒答不是删除难例后重新报告更漂亮准确率，而是一套包含未回答者后果的决策方案。

成本最优阈值与固定风险上限的目标也不同：后者希望已回答错误率不超过 ε，并尽可能多回答。下面给出独立认证数据上一个易复算的保守方法。

<a id="sec-3"></a>

## 3. 固定阈值网格的有限样本认证

在查看认证标签之前冻结 f、s 和 K 个候选阈值。用 n 个独立同分布认证样本，对阈值 j 统计接受数量 mj 和错误数量 kj。mj>0 时，经验选择风险为 $\hat R_j=k_j/m_j$，一种同时上界为

$$
U_j=\min\left\{1,\hat R_j+\sqrt{\frac{\log(K/\delta)}{2m_j}}\right\}.
$$

mj=0 时令 Uj=1，不提供低风险认证。对固定接受集合，条件于 mj>0，已接受样本来自相应条件总体，一侧 Hoeffding 的失败概率可控制为 δ/K；对各 mj 平均，再对 K 个阈值用联合界。因此同一事件上所有具有正覆盖的候选都满足 Rj≤Uj。

在此事件上，即使根据认证数据选一个满足 Uj≤ε 的阈值，仍可保留风险结论。若阈值网格、分数或模型也由同一认证标签反复创建，简单 K 修正不自动适用；应独立划分或使用对应选择理论。

这个界通常保守，精确二项方法等可能更紧。本章给出自己的集中界例子，不把论文的其他检验公式当成同一实现。它也依赖当前抽样条件，不保证任意分布变化后的接受样本仍相同。

<a id="sec-4"></a>

## 4. 基础算例：零错误未必证据最强

设认证集有 1000 条，三个预设阈值接受数分别为 900、400、40，错误数为 90、12、0。经验风险为 10%、3%、0%。取 δ=0.05、K=3，上界约为 14.77%、10.15%、22.62%。若目标 ε=12%，只有中间阈值通过上述保守认证。

最高阈值虽然没有观察到错误，但样本太少；这不等于已经证明真风险为零。若没有候选通过，应报告未获得认证，而不是悄悄把风险目标放宽后仍称原目标达标。

```python
import numpy as np
accepted = np.array([900, 400, 40])
errors = np.array([90, 12, 0])
thresholds = np.array([0.5, 0.8, 0.95])
K, delta, target_risk = len(thresholds), 0.05, 0.12
empirical = errors / accepted
upper = np.minimum(1., empirical + np.sqrt(np.log(K/delta)/(2*accepted)))
qualified = upper <= target_risk
assert np.array_equal(qualified, [False, True, False])
chosen = np.flatnonzero(qualified)[np.argmax(accepted[qualified])]
assert thresholds[chosen] == 0.8
assert upper[-1] > upper[1]  # Fewer accepted examples despite zero observed errors.
print("empirical risks:", empirical, "simultaneous upper bounds:", upper)
```

认证集上覆盖估计也有波动，依据同集最大经验覆盖选择可能乐观。风险同时界与覆盖精度是两件事；最终服务表现仍宜用独立数据评价。

<a id="sec-5"></a>

## 5. 与校准、保形及 OOD 检测的边界

概率校准描述概率与频率关系，不直接保证按某分数截取后每个子群体的条件风险；保形集合覆盖真值也不等于只输出单标签或拒答后的相同风险。将多标签集合缩成一个猜测，会改变决策及保证。

OOD 检测希望识别某类新分布输入，选择性预测则可以对原分布困难样本拒答。高置信错误和未知变化仍可能被接受，不能因有拒答机制就宣称能识别所有未知。分布变化后需要重新检查覆盖、错误及接受组成。

某些系统用检索证据完整性或工具执行状态作为可靠性分数，这些线索仍需要固定规则和独立评价；一句“无法回答”是否合适，也依赖任务是否本来可解及拒答代价。

<a id="sec-6"></a>

## 6. 实验设计与分组评价

分别保留训练、方案选择、认证和最终评价角色，说明哪些数据用于学习 f、s、阈值网格和风险上限。小数据时可采用有相应论证的复用方法，但不能把所有角色混成一个验证分数。

报告完整风险—覆盖曲线、指定工作点、接受和拒绝数、分组风险与覆盖，以及审核成本和最终任务成功。总体低风险可能靠几乎不回答某个群体实现；应把这一分布显式列出。若要同时认证 G 个组与 K 个阈值，需要相应多重控制及组内样本，不沿用原单总体常数。

<a id="sec-7"></a>

## 7. 练习与解析

**练习一：** 某模型拒答一半后准确率上升，能否证明总体服务更好？

**解析：** 不足。还需拒答代价、覆盖、被拒群体及后续处理结果，不能只看接受集准确率。

**练习二：** 认证集接受 5 条全部正确，能否宣布风险低于 1%？

**解析：** 不能凭零错误直接得出，需要足够样本及指定置信方法；小样本上界通常很宽。

**综合练习：** 设计一个高置信错误子群，比较最大概率与另一分数的风险—覆盖曲线。冻结有限阈值后做同时认证，再在独立新来源测试，区分排序能力、有限样本保证与分布外泛化。
