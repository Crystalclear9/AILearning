## 1. 三种输出回答不同问题

点预测给一个最可能类别或数值，概率预测描述模型的分布判断，预测集合或区间则覆盖未来观测。回归均值的置信区间与单个未来 Y 的预测区间不同，后者还包含观测噪声。

概率校准检验某种概率陈述与频率是否一致。高准确率不保证校准，校准良好也可能分辨力弱：始终输出总体正类比例，在相应总体上可以满足某种边缘校准，却无法区分个体。ECE 受分箱与样本量影响，应同时看可靠性图、样本数和适当评分规则。

保形预测使用模型分数和独立校准样本构建集合，其核心保证依赖可交换性；它不是把模型的每个概率都修正为真实条件概率。

<a id="sec-2"></a>

## 2. Split conformal 的构造

先在训练数据拟合预测器并冻结，再保留 n 条校准样本。回归可取分数 $r_i=|Y_i-\hat f(X_i)|$，越大表示越不符合。给定错误率 α，定义 $k=\lceil(n+1)(1-\alpha)\rceil$，阈值 q 为校准分数第 k 小值；若 k>n，取无穷以保持该规则的保证。

预测集合为 $C(x)=[\hat f(x)-q,\hat f(x)+q]$。分类可以选择其他合法非符合度分数，再保留所有分数不超过阈值的标签；分数选择影响集合效率，不可在同一校准标签上无限调优后仍沿用原保证。

校准样本没有用于拟合或选择当前分数规则。选择模型、校准概率和构造保形阈值若共用数据，需要单独论证或再划分，不能都叫“验证集”而忽略复用。

<a id="sec-3"></a>

## 3. 排名为什么给出覆盖

在模型及规则冻结后，假设 n 条校准样本和一条未来样本可交换，其分数也可交换。无并列时，未来分数在 n+1 个分数中的秩均匀。若 k≤n，未来分数不超过校准第 k 小值，等价于它在全部 n+1 个分数中的秩不超过 k；若 k=n+1，阈值无穷而事件必然成立。所选 k 使其落在校准阈值内的概率至少 $k/(n+1)\ge1-\alpha$；有并列时采用不严格阈值可得到保守覆盖，随机化可处理细化排名。

所以 $P\{Y_{new}\in C(X_{new})\}\ge1-\alpha$ 是对随机校准集与未来样本的边缘保证。它不说每个固定 x、每个群体、每一份固定校准集都具有相同条件覆盖，也不保证区间很窄。

时间漂移、重复用户相关性或自适应选择可能破坏条件。有限样本公式中的 n+1 修正不可随意换成普通经验的 1−α 分位数，尤其小样本时会影响覆盖。

<a id="deep-dive-3"></a>

### 深入讲解：总体覆盖达到目标也可能集中遗漏某个群体

设90%群体所有预测集合都覆盖真值，另10%完全不覆盖，总体覆盖仍为90%。这个简单加权例说明边缘保证不能直接升级成每群体或每输入条件保证，必须写清概率平均了哪些随机对象。

split conformal利用校准与未来分数可交换的排名，给边缘覆盖；模型、分数和后处理若使用同一校准标签自适应选择，原来的排名论证不自动保留。n+1次序修正也是有限样本规则的一部分。

分类器若总报均匀概率，1−p标签分数全一样，集合可能包含所有类别，覆盖很高却无区分力。覆盖与集合大小必须共同报告，不能只追单一目标。

按预定义群体分别校准可在相应条件下保护组内，但样本更少、阈值更粗。尺度归一可改善异方差宽度，也不自动得到任意x条件覆盖。

评价需区分固定校准集表现与重复校准实验保证，新增来源还要核对交换条件。所谓分布无关不是不受任何未来变化影响，而是在指定抽样条件下无需假设某个参数分布族。

<a id="sec-4"></a>

## 4. 基础算例：手算阈值和一个区间

n=9、α=0.2，k=8。排序分数为 0.1、0.2、0.2、0.3、0.4、0.5、0.7、0.9、1.2，q=0.9。若新样本点预测为 3，区间为 [2.1,3.9]。样本少时阈值粒度很粗，极低错误率可能要求无穷集合，这不是程序异常。

```python
import math
import numpy as np

def conformal_threshold(scores, alpha):
    scores = np.asarray(scores, dtype=float)
    if scores.ndim != 1 or len(scores) == 0 or not np.isfinite(scores).all():
        raise ValueError("finite nonempty one-dimensional scores required")
    if not 0 < alpha < 1:
        raise ValueError("alpha must lie in (0, 1)")
    k = math.ceil((len(scores) + 1) * (1 - alpha))
    return float("inf") if k > len(scores) else np.sort(scores)[k-1]

scores = [0.1, 0.2, 0.2, 0.3, 0.4, 0.5, 0.7, 0.9, 1.2]
q = conformal_threshold(scores, .2)
assert np.isclose(q, .9)
assert np.allclose([3-q, 3+q], [2.1, 3.9])
assert math.isinf(conformal_threshold(scores, .01))
print("finite-sample order statistic and small-alpha boundary passed")
```

## 5. 提高效率但不偷换保证

异方差任务可用预先拟合的尺度 $s(x)>0$，分数改为 $|y-f(x)|/s(x)$，区间半宽为 $qs(x)$。尺度预测器也应在允许的开发数据拟合；它可使宽度适应输入，但仅凭这样缩放不会自动获得逐 x 条件覆盖。

分组保形可在事先定义的组内分别校准，获得相应组内交换条件下的覆盖，但小组样本更少，阈值更粗。分位数回归构造的区间也可再校准。需要明确是在改善宽度、边缘覆盖还是组内覆盖，这些是不同目标。

<a id="sec-5-1"></a>

### 进一步推导：分类集合与校准数据复用的区别

一种分类非符合度是 $r(x,y)=1-\hat p_y(x)$。用正确标签对应分数校准 q 后，集合为 $C(x)=\{y:1-\hat p_y(x)\le q\}$。即使概率尚未良好校准，只要分数规则冻结且交换条件满足，秩论证仍可工作；但集合可能很大，效率差。保形覆盖并不自动修正每个类别概率。

集合可为空、单标签或多标签，取决于模型与阈值。若产品要求永不为空，增加最高分标签通常只会扩大集合，但覆盖与大小报告必须说明此后处理；其他删减规则则可能破坏原保证。不能先展示较宽集合的覆盖，再用较窄单标签输出继承同一结论。

温度校准优化概率评分，保形校准选择非符合度阈值，是两个不同步骤。若在同一批标签上先反复选温度和分数，再按普通 split 公式给保证，交换推导所需的冻结条件未必成立。最简单方案是使用独立开发与校准数据，或采用有专门保证的复用方法。

可交换不必严格等同任意情况下的独立同分布，但常规时序与重复用户数据通常不能直接假设。评价应记录每个区间或集合对应的独立单位及时间，若改用分组或时间方法，应重新学习其具体条件而不是仅替换抽样名称。

<a id="sec-6"></a>

## 6. 评价覆盖与有用性

在未用于阈值的评价样本上报告经验覆盖、平均及分位区间宽度、集合大小和分组表现。若要实证检查有限样本保证，可重复整个“生成校准集—构造集合—抽未来样本”的实验；仅对同一校准集无限抽测试点，评价的是该固定集合的条件表现。

同时检验错误是否集中于少数群体或尾部，并记录校准数据版本。新分布下重新评价，而不是把分布无关理解成允许任意分布变化；它表示在满足所需抽样条件时不需要指定某个参数分布族。

<a id="sec-7"></a>

## 7. 练习与解析

**练习一：** 90% 覆盖是否意味着每个预测区间都含真值的概率为 90%？

**解析：** 不能作这种逐区间或逐 x 解释；本章给的是联合随机实验下的边缘覆盖。

**练习二：** 一个模型给所有人无穷区间，是否覆盖充分但实用性差？

**解析：** 是，因此需同时报告覆盖与宽度，不能只比单一指标。

**研究练习：** 构造两组异方差回归数据，比固定残差阈值和尺度归一分数的总体、分组覆盖及宽度。改变新数据两组比例，解释边缘保证与条件覆盖差别，并指出哪些变化仍符合原抽样条件。
