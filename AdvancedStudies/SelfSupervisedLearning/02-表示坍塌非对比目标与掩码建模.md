## 1. 仅对齐为何有平凡解

若目标只有两个视图表示的平方距离 $\mathbb E\|z-z'\|^2$，编码器把所有输入映成同一个常数就能达到零。此时视图间一致，却没有保留区分对象的信息。全部维度恒定是完全坍塌，表示只占少数维度则是维度坍塌，两者诊断不同。

避免常数解需要额外结构或约束：负例分离、方差与协方差正则、预测器与目标网络机制，或通过重建任务要求保留可预测信息。不同设计不能只用“拉近正例”概括。

<a id="sec-2"></a>

## 2. 方差、对齐与冗余控制

以一个常见 VICReg 形式为例，批量表示矩阵 Z 为 n×d，损失包含两视图均方差、每维标准差低于门槛的惩罚，以及协方差非对角元素平方和：

$$
s(Z,Z')=n^{-1}\sum_i\|z_i-z'_i\|^2,
\quad v(Z)=d^{-1}\sum_j\max(0,\gamma-\sqrt{\operatorname{Var}(Z_j)+\epsilon}),
$$

$$
c(Z)=d^{-1}\sum_{j\ne k}C_{jk}^2,\qquad
L=\lambda s+\mu[v(Z)+v(Z')]+\nu[c(Z)+c(Z')].
$$

C 是按样本中心化、采用既定分母的协方差。对齐保持视图共同信息，方差项惩罚每维变常数，协方差项减少维度冗余。权重、方差分母和特征尺度都是目标的一部分。

方差项惩罚常数表示，不等于证明任何初始化和优化轨迹都能避开退化驻点。批量过小导致统计噪声，特征维度大于可用样本秩时也不能期待样本协方差精确成为满秩单位阵。

<a id="sec-2-1"></a>

### 进一步推导：样本协方差的秩限制与尺度选择

中心化批矩阵 $Z_c\in R^{n\times d}$ 的秩至多 n−1，样本协方差 $C=Z_c^TZ_c/(n-1)$ 也至多这个秩。当 d>n−1 时，C 不可能同时拥有所有维度正方差、所有非对角恰为零，即不可能成为满秩正对角矩阵。有限批次损失各项存在结构取舍，不应把无法同时降为零自动当成训练错误。

标准差门槛作用在表示实际尺度上。若先对每条表示做单位长度归一，所有维度总能量受限制，不能不修改目标就期待每维标准差都达到任意大 γ。不同方法对归一化、投影维度及正则系数有不同约定，复现时需把它们作为完整目标一起记录。

有效秩可以从协方差或奇异值谱定义多个版本，应明确采用熵型、阈值型还是稳定秩；不同数值不可直接比较。高秩白噪声可能既有漂亮谱又没有任务信息，所以诊断不应停在“没有坍塌”，还要测试可读取性、迁移和来源外行为。

对于掩码建模，增加解码器容量也会降低重建误差，而冻结编码器的表示质量可能不变。对比消融宜固定编码器，分别控制目标、可见比例、解码器与训练预算；这样才能说明是保持信息的任务更合适，还是仅多花了计算。

<a id="deep-dive-2"></a>

### 深入讲解：方差惩罚为何不等于每个退化点都有逃离梯度

纯视图对齐在所有输入输出常数时为零，因此缺少区分信息。方差项对低标准差施加代价，协方差项抑制维度冗余；三者目标不同，应分别检查，而不只看合成loss。

对某维中心化值zi−均值，样本方差的导数与该中心化值成比例。若全部值恰相等，sqrt(var+ε)虽有限，方差梯度仍可能为零；因此常数表示可有正惩罚却是特殊退化驻点，不能从“损失惩罚坍塌”推出任意初始化必然逃离。

反过来z=(u,u,u)每维有方差却只占一维，说明只看标准差漏掉维度坍塌；白噪声高秩也不代表任务信息。需要谱、下游读取和跨来源一起评价。

中心化n条样本的协方差秩至多n−1，维度更大时不能同时获得任意满秩理想统计。小批统计、归一约定和目标权重因此影响能达到的数值，不应机械要求每项为零。

掩码重建又有不同目标，解码器更强可能改善重建而非编码表示。控制目标、可见比例和预算，才能比较不同防坍塌与信息保持机制。

<a id="sec-3"></a>

## 3. 停止梯度与目标网络不是一句魔法

某些自蒸馏方法让在线分支预测另一视图的目标表示，目标分支停止梯度并以动量方式更新。预测器、归一化、结构不对称及数据增强共同影响动力学。单独写一个 `detach()` 不能保证任意网络不坍塌。

分析时画出参数共享与梯度流向，明确目标分支何时更新、统计缓冲是否共享。可做有控制的组件消融，但去掉某组件后失败，也不能自动证明它是所有相关方法的唯一机制。

<a id="sec-4"></a>

## 4. 基础算例：满方差仍可能冗余

取一个中心化标量 u，让表示 z=(u,u,u)。每个维度都有方差，故仅检查逐维标准差不会发现表示其实只有一维；协方差非对角项大，特征矩阵只有一个非零奇异值。

反过来，所有表示都为常数时协方差矩阵为零，非对角惩罚也为零，所以只有去相关并不防止完全坍塌。需要同时看方差、有效秩及下游信息，不应把某一个统计量好看当作学习成功。

可以在小矩阵上分别构造常数、重复维度、独立维度表示，手算三个损失项；先验证概念，再实现跨设备聚合。若每个设备只用局部统计，目标可能与全局批量版本不同。

<a id="sec-5"></a>

## 5. 掩码预测保留什么信息

掩码建模隐藏部分输入，依据可见内容预测像素、token 或教师特征。平方误差的理想输出是目标在可见输入下的条件均值，多解问题可能导致像素平均；离散 token 交叉熵则学习条件分布，目标 tokenizer 又引入另一层假设。

掩码比例太低，任务可能依赖局部复制；过高可能几乎没有足够证据。输入重建好不保证语义表示好，背景纹理也可能占大部分误差。比较时说明可见 token 数、重建目标、解码器容量及总预算，避免把更强解码器的重建能力归给编码表示。

<a id="sec-6"></a>

## 6. 非对比与对比的实验比较

统一数据、训练可见量、编码器和选择预算，再比较冻结线性探针、全量微调与跨域检索。记录逐维方差、协方差谱及邻居结构，区分完全坍塌、低秩与任务信息不足；高秩随机噪声同样可以没有有用语义。

再检查视图增强是否丢失任务所需信息。对比方法不只是负例数，非对比方法也不只是少一个采样步骤。计算成本要涵盖目标分支、队列、重建解码器及跨设备统计通信。

<a id="sec-7"></a>

## 7. 练习与解析

**练习一：** 协方差对角为正，是否证明没有表示坍塌？

**解析：** 只排除逐维恒定，不排除维度完全重复；还要看谱和任务表现。

**练习二：** 重建误差最低的模型是否一定最好分类？

**解析：** 不一定，重建权重、背景与解码器可能主导，语义需要独立评价。

**综合练习：** 在相同小数据上比较纯对齐、加入方差项、再加入协方差项，以及掩码预测。报告训练目标、谱、线性探针和来源外测试，解释每项证据证明了什么，不能只凭一张散点图判定成功。
