# 自监督表示学习

研究配对、对比目标、非对比约束和掩码任务如何塑造表示。

**先修知识：** 神经网络、交叉熵、协方差；互信息解释可配合信息论返回阅读。

## 章节与学习目标

| 章节 | 核心内容 | 深入讲解入口 |
| --- | --- | --- |
| [第 1 章 对比目标、InfoNCE 与负样本机制](01-对比目标InfoNCE与负样本机制.md) | 正负样本定义了所学相似性；将对比学习写为候选分类；密度比与互信息边界 | [进入讲解](01-对比目标InfoNCE与负样本机制.md#deep-dive-3) |
| [第 2 章 表示坍塌、非对比目标与掩码建模](02-表示坍塌非对比目标与掩码建模.md) | 仅对齐为何有平凡解；方差、对齐与冗余控制；停止梯度与目标网络不是一句魔法 | [进入讲解](02-表示坍塌非对比目标与掩码建模.md#deep-dive-2) |

## 阅读顺序与验收

先完成第 1 章的定义与基本推导，再读第 2 章的方法扩展。遇到公式先复算低维例子，再进入实验设计；不要把局部数值检查当成算法整体效果证明。

**完成要求：** 手算 InfoNCE 梯度；构造恒定和低秩表示；用线性探针、跨来源与控制消融评价语义收益。

作答后再阅读各章解析。能够独立说明一个失效条件，并设计一个可区分竞争解释的对照实验，才算完成本主题的进阶学习。
