## 1. 正负样本定义了所学相似性

以同一原始对象的两个视图作为正对，编码器 f 与投影头 g 生成表示，常在投影空间归一后计算相似度。负对通常来自其他对象，但“不同样本”不等于“语义必不同”。配对机制、增强和采样共同定义要保持及忽略的信息。

若颜色对任务关键，却把强颜色扰动后的视图强制拉近，可能删除需要的信息。若裁剪经常只留下无关背景，正对可能不再共享目标。先检查视图语义和来源泄漏，再谈增加模型或负例数量。

<a id="sec-2"></a>

## 2. 将对比学习写为候选分类

给定锚点 x、正例 $y_1\sim p(y\mid x)$ 及 K−1 个候选负例，分数 $s_j=sim(z_x,z_{y_j})/\tau$，损失为

$$
L=-\log\frac{e^{s_1}}{\sum_{j=1}^K e^{s_j}}.
$$

它就是“哪一个候选与锚点配对”的交叉熵。对 s 的梯度为 softmax 概率减 one-hot；对未除温度的相似度再乘 $1/\tau$。低温度使困难候选更主导梯度，也可能放大噪声和假负例，并非越低越好。

归一化特征限制通过无限放大范数降低损失的路径，但不等于自动学得任务语义。需要区分投影空间的训练目标与编码器表示的下游用途。

<a id="sec-3"></a>

## 3. 密度比与互信息边界

在一个正例由条件分布生成、其余负例独立来自边缘分布等标准设置下，最优判别分数与 $\log[p(y\mid x)/p(y)]$ 相差只依赖 x 的项，因此对比目标可联系密度比估计。

相应 InfoNCE 构造给出 $I(X;Y)\ge\log K-\mathbb E L$ 的下界。该解释依赖配对及负采样条件；同一序列高度相关负例、条件化挖掘或改变候选分布后，不能不加分析仍套用原界。由于 $\log K$ 上限，有限候选也限制数值下界的表达。

即使下界提高，也不意味着所有下游任务更好。共享背景、设备或文本模板也能提供互信息，任务可能不需要这些线索。研究时要解释学习信号与目标语义之间的联系。

<a id="deep-dive-3"></a>

### 深入讲解：最优候选判别器如何恢复密度比

设一个候选由p(y|x)生成，其余独立来自p(y)，正例索引先验均匀。给定整组候选后，第j个为正的后验正比于p(yj|x)/p(yj)，因为其余边缘项在各候选假设间相消。

因此最优softmax分数可与log密度比相差一个只依x的常数。若两个候选比值为3和1，最优归一概率为3/4和1/4；这给对比分类目标一个可计算解释，而非简单“把相似拉近”。

负例不独立、来自条件挖掘或含重复时，原始生成假设改变。仍可训练一个有效目标，但不能无修改引用同一互信息下界和最优密度比形式。

温度、归一和投影头改变可实现分数及优化。低温放大难例梯度，也可能放大假负例；更多候选增加比较信息，却可提高语义碰撞概率和计算。

用已知小联合表核对候选后验，再比较真实任务表示。互信息可能来自背景或来源，训练对比成功不能单独证明模型保留了下游所需语义。

<a id="sec-4"></a>

## 4. 基础算例：均匀分数与一项梯度

K=4 且分数都相同时，损失为 log4，正例分数梯度为 −3/4，其余各为 1/4。若正例与三个负例的未缩放相似度均为零、温度 0.5，则相似度梯度再翻倍。

```python
import math
import torch
raw = torch.zeros(4, dtype=torch.float64, requires_grad=True)
temperature = 0.5
loss = torch.nn.functional.cross_entropy(
    (raw / temperature)[None, :], torch.tensor([0]))
loss.backward()
assert math.isclose(loss.item(), math.log(4), rel_tol=1e-12)
assert torch.allclose(raw.grad, torch.tensor([-1.5, .5, .5, .5], dtype=torch.float64))
print("InfoNCE candidate loss and temperature gradient passed")
```

这个局部核对不验证数据增强、跨设备负例或真实下游收益。若正例本身不合法，梯度方向正确也会优化错误的相似性。

<a id="sec-5"></a>

## 5. 大批量、队列与困难负例

大批量提供更多候选，但改变计算、批统计及优化条件；队列复用历史表示，降低当前批量要求，却可能存在编码器更新造成的表示陈旧。动量编码器等机制用于平衡一致性与更新速度，仍需记录队列和更新协议。

困难负例可能更有训练价值，也更容易是未标注的同义或同类对象。应检查来源与语义，必要时采用多正例或适合任务的采样。比较方法时保持实际候选数、有效批量和训练 token 或图像数量可比，不能只对齐 epoch。

<a id="sec-5-1"></a>

### 进一步推导：假负例与信息可见性的定量检查

若锚点所属语义类在候选总体占比为 pc，K 个独立随机候选中至少出现一个同类者的概率为 $1-(1-p_c)^K$。例如 pc=0.01、K=100 时约 0.634。它只说明潜在语义碰撞的频率，不代表每个同类候选对当前实例区分任务都是错误负例；必须先定义训练目标是实例识别还是语义聚类。

多正例目标可以把多个合法候选纳入分子或分别平均正例损失，不同写法的梯度与权重并不相同。若用标签或额外教师识别正例，方法获得的信息也改变，不能继续与纯无标注方案称相同监督条件。

跨设备候选还要明确梯度是否跨收集操作传播，哪些特征来自当前编码器或历史队列。只拼接了更多张量，不保证得到参考实现相同的目标；归一化统计、重复样本与候选掩码都可能改变有效学习信号。

可在已知语义标签但不用于训练的诊断集上统计候选碰撞，再改变批量、队列长度或采样分布，看下游近邻结构是否变化。控制总数据可见量与计算，才能区分更多候选、更多训练和不同信息来源的收益。

<a id="sec-6"></a>

## 6. 表示评价与消融

先冻结编码器训练线性探针，检查信息是否易被线性读取；再做全量微调评价可适应性，两者不能混称同一种表现。检索、跨域和少样本任务还检验不同能力。微调带来的收益不完全代表原表示直接可用。

消融配对、增强、投影头、温度与负例分布，控制预算。用新来源评估是否只学到设备或模板；检查同类近邻、困难样本及稀有群体。降维散点图和训练对比损失都不足以单独证明表示质量。

<a id="sec-7"></a>

## 7. 练习与解析

**练习一：** 更多负例是否一定改善语义表示？

**解析：** 不一定，假负例、表示陈旧和资源预算变化都可抵消收益。

**练习二：** InfoNCE 下降是否必然使目标任务错误率下降？

**解析：** 不必然，训练识别的是配对关系，未必等于下游类别。

**研究练习：** 构造同时包含目标形状与来源背景的图像，两视图共享不同程度背景。比较检索、线性探针和背景替换测试，说明对比目标可能利用哪些信号，并设计能区分竞争解释的消融。
