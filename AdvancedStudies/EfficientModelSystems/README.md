# 高效训练与推理系统

从状态与 I/O 预算理解分片、重计算、量化和实际推理瓶颈。

**先修知识：** PyTorch、设备计算、梯度累积与语言模型缓存；不要求具备多卡硬件才能完成算例。

## 章节与学习目标

| 章节 | 核心内容 | 深入讲解入口 |
| --- | --- | --- |
| [第 1 章 训练显存分解、分片与重计算](01-训练显存分解分片与重计算.md) | 峰值显存由哪些状态组成；数据并行为什么复制状态；状态分片的机制与边界 | [进入讲解](01-训练显存分解分片与重计算.md#deep-dive-2) |
| [第 2 章 量化误差、校准与推理瓶颈](02-量化误差校准与推理瓶颈.md) | 从实数到量化格点；权重误差不等于输出误差；权重、激活与缓存分别决定成本 | [进入讲解](02-量化误差校准与推理瓶颈.md#deep-dive-2) |

## 阅读顺序与验收

先完成第 1 章的定义与基本推导，再读第 2 章的方法扩展。遇到公式先复算低维例子，再进入实验设计；不要把局部数值检查当成算法整体效果证明。

**完成要求：** 列出训练内存预算；解释分片与峰值差距；复算量化输出误差；设计同时看质量、内存和延迟的测试。

作答后再阅读各章解析。能够独立说明一个失效条件，并设计一个可区分竞争解释的对照实验，才算完成本主题的进阶学习。
