## 1. 目标策略与日志策略

设行为策略 μ 收集独立轨迹 $\tau=(s_0,a_0,r_0,\ldots,s_H)$，目标策略为 π，有限时域回报 $G=\sum_{t=0}^{H-1}\gamma^t r_t$。我们希望估计 $V^\pi=E_\pi G$，却只有 μ 的日志；在日志上把动作换成 π 的选择，并不会自动得到对应奖励和下一状态。

本章假设起始分布与环境机制相同，状态或已记录历史包含所需信息，动作随机化条件概率已知或可按合法条件估计。若行为分配依赖未记录且影响结果的因素，直接用不充分状态估计 μ，不能凭高拟合质量恢复序贯可交换性。

覆盖要求更强：目标策略可到达并选择的轨迹前缀，行为策略需要给正概率。每个单独动作都曾出现，不代表目标的长序列组合已经充分覆盖。不能把回放缓冲存在当成可评价任意新策略的证明。

<a id="sec-2"></a>

## 2. 从轨迹密度比推到两种 IS

同一环境下，初态与转移条件密度在比值中相消，剩下动作概率比。令 $\rho_t=\pi(a_t\mid s_t)/\mu(a_t\mid s_t)$、$W_t=\prod_{k=0}^t\rho_k$，则普通轨迹 IS 估计为

$$
\hat V_{IS}=\frac1N\sum_{i=1}^N W_{H-1}^{(i)}G^{(i)}.
$$

第 t 个奖励只依赖当前前缀，利用条件期望可去掉后续无关比率，得到逐决策 PDIS：

$$
\hat V_{PDIS}=\frac1N\sum_i\sum_{t=0}^{H-1}\gamma^tW_t^{(i)}r_t^{(i)}.
$$

概率比正确、支持与可积条件满足时，两者期望均为目标价值。PDIS 减少早期奖励上不必要的后续权重，但不保证所有环境中方差统一更小。权重随时域相乘，方差可能很大；使用对数计算可防溢出，却不能消除统计不稳定。

自归一化、裁剪和截断权重是不同估计器，通常改变有限样本偏差。有效样本量是集中程度诊断，不是覆盖、无偏或置信区间有效的自动证书。

<a id="deep-dive-2"></a>

### 深入讲解：稀有动作怎样让无偏估计在多数数据集上看起来错得很稳

单步行为以0.01概率选动作1，目标总选1，动作1回报1、动作0回报0。普通IS样本贡献为100或0，期望1，方差99。抽100条完全没见动作1的概率为0.99^100≈0.366，此时估计恰为零，却不能据此认定目标无收益。

这个例子表明无偏是对重复数据集的期望性质，不保证每批都靠近真值。更长轨迹相乘权重会进一步稀疏，log域计算只解决数值范围，无法让没见过的信息出现。

PDIS只给每时刻奖励相应前缀比率，去掉不必要后续权重；DR再加入目标价值模型与加权残差。若模型准确可降方差，但数据稀少区域的准确性本身不易验证，不能拿模型自信替代支持。

自归一和裁剪可能改善某些有限样本表现，但引入不同偏差。比较需同时看偏差、方差、覆盖和目标策略距离，不只挑一次最接近真值的运行。

若目标策略由同一日志挑选，还增加选择问题。按独立轨迹开发与评价，或使用有相应同时保证的方法，才能把局部估计公式连接到可信策略决策。

<a id="sec-3"></a>

## 3. 序贯双重稳健递推

为每个时刻定义辅助 $\hat Q_t(s,a)$，并令 $\hat V_t(s)=\sum_a\pi(a\mid s)\hat Q_t(s,a)$，终点 $\hat V_H=0$。对一条轨迹从后向前递推

$$
D_H=0,\qquad
D_t=\hat V_t(s_t)+\rho_t\{r_t+\gamma D_{t+1}-\hat Q_t(s_t,a_t)\}.
$$

对独立轨迹平均 D0。若比率正确且辅助函数对当前评分数据视为固定，动作条件期望将辅助 Q 项与 V 项抵消，再归纳恢复目标 Bellman 期望。若每个时刻的 Q 都等于真实目标 Q，则残差在给定状态动作下均值为零，也给出另一种正确路线，但这不是无数据支持时可以验证的免费假设。

辅助模型使用相同轨迹过拟合时，前述固定函数论证不直接成立；可按独立轨迹拆分或交叉拟合。不能把一条轨迹中的不同时间步随机分到训练与评价，让未来信息泄漏给过去的模型。

H=1 时，上式退化为 bandit 的加权残差修正，与前章 AIPW 的思路相连；长时域还包含未来递推误差和前缀覆盖，不能只把单步倾向得分复制到每行就称已完成序贯分析。

## 4. 基础算例：枚举两步策略的真值

只有一个状态、两个动作，每步独立选动作；行为概率为 (0.8,0.2)，目标为 (0.3,0.7)，第一步奖励 a0、第二步奖励 2a1，γ=0.9。真值为 0.7+0.9×1.4=1.96。四条动作路径可以全部枚举，按行为概率加权，独立核对 IS、PDIS 与 DR 的期望。

```python
import itertools
import numpy as np
mu = np.array([0.8, 0.2])
pi = np.array([0.3, 0.7])
gamma = 0.9
true_value = 0.7 + gamma * 1.4
means = np.zeros(3)

def dr(a0, a1, use_exact_q):
    ratios = pi[[a0, a1]] / mu[[a0, a1]]
    d = 0.
    for t, action in reversed(list(enumerate([a0, a1]))):
        q = np.array([0., 2.]) if t == 1 else np.array([gamma*1.4, 1+gamma*1.4])
        if not use_exact_q:
            q = np.zeros(2)
        reward = action if t == 0 else 2*action
        d = pi @ q + ratios[t] * (reward + gamma*d - q[action])
    return d

for a0, a1 in itertools.product(range(2), repeat=2):
    probability = mu[a0] * mu[a1]
    rho0, rho1 = pi[[a0, a1]] / mu[[a0, a1]]
    trajectory_is = rho0*rho1*(a0 + gamma*2*a1)
    per_decision_is = rho0*a0 + gamma*rho0*rho1*2*a1
    means += probability * np.array([trajectory_is, per_decision_is, dr(a0, a1, True)])
    assert np.isclose(dr(a0, a1, False), per_decision_is)
    assert np.isclose(dr(a0, a1, True), true_value)
assert np.allclose(means, true_value)
print("exact target value and enumerated OPE means:", true_value, means)
```

精确 Q 在这个确定奖励、单状态例中消除了路径间波动，不代表真实复杂环境的 DR 估计都零方差。代码核验完整有限总体期望，不模拟“只抽四条轨迹就总能正确”。

<a id="sec-5"></a>

## 5. 从评价到策略选择还差什么

在同一日志上评价很多候选并选最高者，会产生选择偏差；最终价值区间不能只当作事先固定策略的区间。可以在开发轨迹上选择，独立轨迹上评价；或对有限候选建立同时有效的结论。

若新策略与 μ 差异太大，策略约束、保守方法或新交互可以改变可识别范围。Fitted Q Evaluation 通过 Bellman 回归估计目标价值，依赖函数、覆盖及估计条件，也不应以训练 TD 损失很低作为外部收益证明。

用下置信界决定是否替换行为策略，还需正确评价行为基线、配对结构与统计假设。本章不将一个点估计更高自动解释为“安全改进”。

<a id="sec-6"></a>

## 6. 诊断与实验设计

先在已知小 MDP 枚举真实策略价值，再比较辅助模型错设、行为概率错设、覆盖减弱和时域增加。报告偏差、方差、均方误差、权重尾部及可计算区间的覆盖，而不是只展示均值接近的一次运行。

实际日志记录策略版本、动作概率、合法动作集合、奖励和边界，核对概率是否对应真正执行动作。独立单位为轨迹或合适群组，bootstrap 也应保留该结构。长尾权重和少量轨迹下，普通区间可能不可靠；截断要明确偏差，不用重采样掩盖支持缺失。

<a id="sec-7"></a>

## 7. 练习与解析

**练习一：** μ 从不选择某动作，π 经常选它，IS 可否直接把缺失权重设为零？

**解析：** 不可，这删去目标策略部分回报，已破坏目标识别。需要新增信息、限制策略或明确外推假设。

**练习二：** 用正确行为概率时，DR 的 Q 是否必须精确？

**解析：** 在所述固定辅助模型和可积支持条件下，不必精确仍有无偏路线；但 Q 质量影响方差，有限样本可靠性另需分析。

**综合练习：** 让上述行为正动作概率从 0.2 降到 0.01，再增加时域。解析或重复模拟比较 IS、PDIS、DR 和裁剪版本，区分数值误差、方差爆炸及截断偏差，并保留独立策略评价。
