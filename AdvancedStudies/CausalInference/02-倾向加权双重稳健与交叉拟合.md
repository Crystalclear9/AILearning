## 1. 两类辅助函数

定义倾向得分 $e(x)=P(A=1\mid X=x)$，结果回归 $m_a(x)=\mathbb E[Y\mid A=a,X=x]$。前者解释处理分配，后者解释组内结果，两者都不是目标效应本身。

结果回归插值估计 $n^{-1}\sum_i[\hat m_1(X_i)-\hat m_0(X_i)]$；逆概率加权则把观察组重新加权回目标总体。两种方法依赖不同辅助模型，均仍需要前章一致性、可交换性和正性。

倾向模型的分类准确率不是主要验收目标。若几乎完美区分处理组，可能意味着重叠差；关注估计后加权协变量平衡和极端权重，而非追求最高 AUC。

<a id="sec-2"></a>

## 2. 从条件期望推导逆概率加权

对给定 X，有 $\mathbb E[AY/e(X)\mid X]=m_1(X)$，因为 $\mathbb E[AY\mid X]=e(X)m_1(X)$。同理，$\mathbb E[(1-A)Y/(1-e(X))\mid X]=m_0(X)$，因此

$$
\tau=\mathbb E\left[\frac{AY}{e(X)}-\frac{(1-A)Y}{1-e(X)}\right].
$$

当 e 接近 0 或 1，少数观察具有巨大权重，方差可能非常高。权重截断、重叠权重和删除区域可以改善有限样本行为，但可能引入偏差或改变目标总体，应事先定义。分别归一两组权重也是不同估计器，不能当成相同公式的小修饰。

<a id="sec-3"></a>

## 3. 双重稳健得分及其两次核验

定义未减去 τ 的 AIPW 得分

$$
\psi=m_1(X)-m_0(X)
+\frac{A(Y-m_1(X))}{e(X)}
-\frac{(1-A)(Y-m_0(X))}{1-e(X)}.
$$

若结果回归正确，即使使用不正确但保持合法范围的倾向函数，每个残差在相应处理组内条件均值为零，因此 $\mathbb E\psi=\tau$。若倾向正确，即使结果回归为其他函数，条件期望中的两个残差修正分别补回真实 m 与拟合 m 的差，仍得到真实 $m_1-m_0$。

这叫双重稳健，含义是两组辅助模型中至少一组在相应条件下正确或一致；不是两组都严重错误仍有保证，也不抵抗未测混杂。标准误与渐近正态通常还需重叠、矩条件及辅助误差收敛率。

<a id="deep-dive-3"></a>

### 深入讲解：双重稳健的误差抵消与两者都错时的具体偏差

设真实倾向e0=.3、真实组均值m10=4、m00=1，目标差3。故意用e=.6、m1=2、m0=3，条件期望偏差为 $(e-e0)[(m1-m10)/e+(m0-m00)/(1-e)]$，代入得0.5，所以期望得分3.5而非3。

若仅把e改回.3，偏差为零；若仅把两组m改回真值，偏差也为零。这个计算精确说明“双重稳健”指哪两条正确路线，不是两模型都有偏时仍无条件正确。

误差乘积在合适重叠下可用L2范数控制，形成正交性的二阶余项。e接近0或1时分母放大误差，速率和有限样本方差都可能恶化，交叉拟合不会取消支持条件。

交叉拟合按独立用户或单位切分，辅助函数未见评分单位，便于分析过拟合偏差；把同用户记录随机拆折不能达到同样目的。评分方差也需与相关结构匹配。

报告应包括重叠、平衡、权重尾部、模型敏感性和识别假设。辅助预测好只是必要线索，不能证明无未测混杂，更不能仅挑最大的效应作为最终发现。

<a id="sec-4"></a>

## 4. 交叉拟合为什么有用

将样本分 K 折，每次在其余折拟合 e 与 m，在留出折计算得分。汇总每条样本仅由未见过它的辅助模型产生的得分，再求均值。它降低灵活模型同样本拟合带来的偏差与经验过程困难，但不会修复识别失败。

在合适条件下，正交得分的剩余偏差与倾向误差、结果回归误差的乘积有关；常见充分路线要求该乘积为 $o_p(n^{-1/2})$。两者各自达到优于 $n^{-1/4}$ 的 L2 速率是一个方便例子，不是所有方法都必须恰好达到的单独门槛。

标准误可由折外得分的样本标准差除以 $\sqrt n$ 估计，前提是相应渐近条件成立。分组数据需按独立单位切折及估计方差，不可让同一用户同时进入辅助训练和评分。

<a id="sec-4-1"></a>

### 进一步推导：正交性的误差乘积从哪里来

令真实辅助函数为 $e_0,m_{10},m_{00}$，所用函数为 e、m1、m0。把拟合函数视为固定后，对 X 条件取期望，可直接展开 AIPW 的偏差为

$$
E[\psi\mid X]-(m_{10}-m_{00})
=(e-e_0)\left[\frac{m_1-m_{10}}{e}+\frac{m_0-m_{00}}{1-e}\right].
$$

推导时使用 $E[AY\mid X]=e_0m_{10}$ 与 $E[(1-A)Y\mid X]=(1-e_0)m_{00}$，先把每个残差项展开，再合并回归误差。任一组辅助误差为零，乘积就消失；两组误差都小时，剩余项是二阶乘积，而非一阶相加，这正是其正交结构的直观来源。

若 e 被界定在 [c,1−c] 且 c>0，用 Cauchy–Schwarz 可将总体偏差绝对值控制为倾向 L2 误差乘两组结果 L2 误差之和，再乘与 1/c 有关的常数。重叠变弱时常数变大，所以“正交”不等于不怕极端权重。

交叉拟合使当前评分样本没有参与拟合其辅助函数，便于对这些条件化误差进行分析。它不取消样本量、矩条件和收敛率要求；也不修复未测混杂。计算区间时可以用折外得分的样本方差，但只有当相应余项足够小且独立单位条件成立，普通正态近似才有依据。

<a id="sec-5"></a>

## 5. 基础算例：补偿项怎样抵消错误回归

只有一个协变量层，真实 e=0.5、真实处理均值 4、对照均值 1，ATE 为 3。故意设拟合均值为 0 和 0。结果回归差为零，但期望处理补偿为 4、对照补偿为 1，得分期望恢复为 3。

```python
import numpy as np
# Four equally weighted population atoms; this is an expectation check, not fitting.
a = np.array([1., 1., 0., 0.])
y = np.array([3., 5., 0., 2.])
e = np.full(4, 0.5)
for m1, m0, propensity in [(0., 0., e), (4., 1., np.full(4, 0.8))]:
    score = m1 - m0 + a * (y - m1) / propensity
    score -= (1 - a) * (y - m0) / (1 - propensity)
    assert np.isclose(score.mean(), 3.)
print("both robustness cases passed on the constructed population")
```

这组对称原子刻意令残差均值抵消，验证公式而不是说明有限样本估计总能精确得到 3。真实数据的抽样误差、辅助估计和不重叠仍需独立评价。

<a id="sec-6"></a>

## 6. 方法比较与分析流程

先报告目标总体与识别假设，再检查倾向分布、权重尾部、有效样本量及处理前协变量平衡。比较结果回归、IPW、AIPW 对建模选择的敏感性，差异大时调查重叠和模型错设，不能只挑效果最理想者。

在已知机制模拟中，可以分别错设 e、错设 m、两者都错，再加入未测混杂，区分统计稳健与识别失败。真实研究中预定主要估计器、折数、截断和敏感性分析，报告所有实质改变，避免把数据驱动选出的最大效应当成独立发现。

<a id="sec-7"></a>

## 7. 练习与解析

**练习一：** 两个辅助模型都用深网，是否自动双重稳健？

**解析：** 模型名称不保证一致性、速率与重叠；性质来自得分结构和估计条件。

**练习二：** 交叉拟合后是否不再需要独立单位划分？

**解析：** 仍需要。相关记录跨折会保留泄漏，方差也需反映相关结构。

**综合练习：** 构造混杂的二元处理模拟，固定真实 ATE，比较三估计器在正性良好与接近违反时的误差、区间覆盖和权重分布。新增未观测共同原因后，解释为何更复杂回归不能自动恢复识别。
