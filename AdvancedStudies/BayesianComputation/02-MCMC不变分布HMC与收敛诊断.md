## 1. 样本相关与不变分布

MCMC 构造转移核 K，使目标后验 π 为不变分布，即 $\pi K=\pi$。若再具有适当不可约性、非周期性与遍历条件，链才可能从初始状态渐近靠近目标。存在不变分布不保证有限时间已经混合，也不保证不同模式都被访问。

相邻采样相关，因此保留一万步不等于一万个独立样本。需要对实际关心的统计量 f 估计蒙特卡洛误差，而不是只报告链长度。预热样本一般不用于最终估计，调参阶段改变核也需与正式采样区分。

<a id="sec-2"></a>

## 2. Metropolis–Hastings 的接受机制

从当前 z 用提议分布 $q(z'\mid z)$ 产生候选，按

$$
a(z,z')=\min\left(1,\frac{\pi(z')q(z\mid z')}{\pi(z)q(z'\mid z)}\right)
$$

接受，否则留在原处。目标未归一化密度中的共同常数抵消。若提议对称，比值简化为目标密度比；非对称提议不能省掉 q。

证明可核对两方向通量均为 $\min\{\pi(z)q(z'\mid z),\pi(z')q(z\mid z')\}$，从而满足细致平衡并导出不变性。不可达区域、边界与零密度仍需检查，不能只验证接受率公式就宣称链能遍历全空间。

<a id="deep-dive-2"></a>

### 深入讲解：非对称提议为何不能省略MH中的反向概率

目标π=(.5,.5)，提议从0到1概率.9、从1到0概率.1，其余留原处。若只比较目标密度比，两方向都接受，实际链会更多停在1，平稳分布为(.1,.9)，与目标完全不同。

正确接受率从0到1为min(1,.1/.9)=1/9，反向为1；实际跨状态概率两边都是.1，通量平衡，目标各半得以保持。提议比正是在补偿“更常提议某方向”的偏差，不是可省略常数。

细致平衡给不变性，仍需链能到达相关区域并有合适遍历性质。把原地等待概率变很大可保持同一不变分布，却显著降低混合，说明正确目标与计算效率不同。

HMC用对称、体积保持等数值结构构造高效提议，仍以能量误差接受；任意换积分器后沿用相同接受式不一定合法。受限变量变换的Jacobian也属于目标。

诊断看多链、ESS、关键统计量蒙特卡洛误差与几何警告。样本很多、接受率高或R-hat近1各只提供部分证据，不能替代模型检验和遗漏模式调查。

<a id="sec-3"></a>

## 3. HMC 如何利用几何

对连续参数，引入动量 p 与质量矩阵 M，定义哈密顿量 $H(z,p)=U(z)+\tfrac12p^TM^{-1}p$，$U(z)=-\log\pi(z)$。哈密顿动力学满足 $\dot z=M^{-1}p$、$\dot p=-\nabla U(z)$，沿等能量面移动，避免纯随机游走的小步扩散。

数值上常用 leapfrog 半步动量、整步位置、半步动量。离散误差通过接受步骤纠正；步长过大产生能量误差，过小则每次有效移动成本高。NUTS 等自适应路径长度方法减少手调，但仍受后验几何影响。

受限参数通常先变换到无约束空间，并在目标中加入变换雅可比。漏掉雅可比会改变目标分布。漏斗形层级后验可考虑重参数化，单纯增加采样步数未必解决几何困难。

<a id="sec-3-1"></a>

### 进一步推导：leapfrog 步骤与有效样本量的尺度

令当前状态为 (z,p)、步长 ε，一次 leapfrog 为 $p_{1/2}=p-\epsilon\nabla U(z)/2$，$z'=z+\epsilon M^{-1}p_{1/2}$，$p'=p_{1/2}-\epsilon\nabla U(z')/2$。这个对称结构有助建立可逆且体积保持的数值提议，再用能量差计算接受概率。任意替换成普通非对称积分器，却保留同一简单接受比，可能不再满足所需性质。

质量矩阵决定不同方向的移动尺度，不是模型先验。高相关后验若用不合适的坐标和质量，稳定步长受最困难方向限制；预热估计尺度、重参数化和建模本身的改进可以比只延长链更有效。HMC 还需要梯度足够可靠，随机小批梯度不能无修改当作标准精确 HMC。

以相关系数 $\rho_k=\phi^k$ 的平稳过程作直观例子，$\tau_{int}=(1+\phi)/(1-\phi)$。φ=0.9 时约为 19，一万步对该均值的 ESS 约 526；φ 为负时情况又不同，ESS 公式不能只按链长打固定折扣。

蒙特卡洛标准误描述有限采样对后验统计的估计误差，与后验本身的不确定性不同。后验标准差大不等于采样器差；标准误小也不证明模型正确或没有遗漏模式。报告应把观测信息、模型后验与计算误差三层分别解释。

<a id="sec-4"></a>

## 4. 基础算例：不变性不等于快速混合

以下三状态目标为 (0.2,0.3,0.5)，对称提议尝试另两个状态。代码核对行概率、细致平衡及不变性，再把 99% 的步骤改为原地等待；新核仍有同一不变分布，却移动慢得多。

```python
import numpy as np
pi = np.array([0.2, 0.3, 0.5])
P = np.zeros((3, 3))
for i in range(3):
    for j in range(3):
        if i != j:
            P[i, j] = 0.5 * min(1., pi[j] / pi[i])
    P[i, i] = 1 - P[i].sum()
flow = pi[:, None] * P
assert np.allclose(P.sum(axis=1), 1)
assert np.allclose(flow, flow.T)
assert np.allclose(pi @ P, pi)
lazy = 0.99 * np.eye(3) + 0.01 * P
assert np.allclose(pi @ lazy, pi)
assert lazy[0, 0] > P[0, 0]
print("invariance holds for both kernels; their mixing speeds differ")
```

这是离散 MH 的性质核对，不是 HMC 实现，也没有通过有限代码验证任意连续后验的收敛。

<a id="sec-5"></a>

## 5. 有效样本量与诊断各管什么

在适当平稳与求和条件下，均值估计方差近似为 $\operatorname{Var}_\pi(f)\tau_{int}/N$，其中 $\tau_{int}=1+2\sum_{k\ge1}\rho_k$，相应 ESS 约为 $N/\tau_{int}$。不同 f 的相关性不同，均值、尾部事件和分位数需要分别诊断，ESS 也不是总体唯一固定数字。

多链 rank-normalized R-hat 主要比较链间与链内行为，bulk/tail ESS 描述不同位置的效率；发散、最大树深与能量诊断则提示 HMC 几何或调参困难。R-hat 接近 1 不是没有遗漏模式的数学证明，多个链可能一起困在相同区域。

<a id="sec-6"></a>

## 6. 一份可靠采样报告

从分散而合法的初值运行多链，区分预热与保留阶段，检查轨迹、关键投影、R-hat、ESS 与蒙特卡洛标准误，并注明参数变换和先验。若关心尾部概率，直接对该统计量诊断，不只看参数均值。

存在异常时先调查模型几何、尺度、参数化和约束，再调整步长或计算预算。常规抽稀会丢弃信息，不应作为提高每单位计算效率的默认手段；存储受限是另一个问题。最后做后验预测检查，区分采样器达到目标与目标模型适合数据。

<a id="sec-7"></a>

## 7. 练习与解析

**练习一：** MH 接受率高是否总更好？

**解析：** 极小提议步也能很高接受，却移动缓慢；效率需结合自相关、ESS 与耗时。

**练习二：** 四条链 R-hat 接近 1，可否宣布所有模式已覆盖？

**解析：** 不可。多链共同困住仍可能发生，需检查初值、几何与独立证据。

**综合练习：** 对具有解析后验的高相关高斯，比较随机游走与考虑尺度的提议。核对后验均值方差、每秒 ESS 和关键方向误差；再增加多峰结构，解释相同诊断为何可能出现局限。
