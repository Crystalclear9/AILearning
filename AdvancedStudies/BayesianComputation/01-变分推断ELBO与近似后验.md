## 1. 后验与计算目标

给定观测 x、隐变量或参数 z，后验为 $p(z\mid x)=p(x,z)/p(x)$。难点往往在证据 $p(x)=\int p(x,z)dz$，而不是不会写贝叶斯公式。最终可能关心后验均值、区间、预测积分或某个事件概率，不同目标对近似误差的敏感度不同。

变分推断选择可计算分布族 $q_\phi(z)$，把积分问题转为优化。需要分别考虑分布族限制、优化未完成及蒙特卡洛梯度噪声。训练目标收敛，只说明在当前近似与优化下的结果，不能保证后验所有尾部和模式都正确。

<a id="sec-2"></a>

## 2. ELBO 分解逐步推导

在相应密度与可积条件下，

$$
\log p(x)=\underbrace{\mathbb E_q[\log p(x,z)-\log q(z)]}_{\mathcal L(q)}
+\underbrace{\mathbb E_q\log\frac{q(z)}{p(z\mid x)}}_{D_{KL}(q\|p(\cdot\mid x))}.
$$

证明只需把 $\log p(z\mid x)=\log p(x,z)-\log p(x)$ 代入 KL；$\log p(x)$ 不随 z 变化，可移出期望。KL 非负，因此 $\mathcal L$ 是证据下界；固定模型时最大化它等价于最小化反向 KL。

若 q 把质量放在目标后验为零的区域，KL 可能无穷。反向 KL 对这种位置惩罚强，受限近似常偏向某个可覆盖模式；这不是“反向 KL 永远只保留一个模式”的无条件定理。分布族可以覆盖多个模式时，行为也不同。

<a id="deep-dive-2"></a>

### 深入讲解：在两状态潜变量上精确计算证据下界与KL差额

令潜变量z两种状态先验各半，对当前观测的似然为(.9,.1)。证据p(x)=.5，log证据约−.6931；真实后验为(.9,.1)。先取近似q仍为(.5,.5)，可逐项核对全部定义。

ELBO=Eq[logp(x,z)−logq(z)]，因q等先验，化为半log.9加半log.1=log.3≈−1.2040。二者差约.5108，恰等于KL((.5,.5)||(.9,.1))。下界不是随便一个正则技巧，而是明确后验失配对应的差额。

若q改成真实后验，KL为零、下界等于log证据。受限分布族或未优化到位时，无法消掉差额；固定生成模型时改善ELBO才可解释为减少该方向KL。

若同时改变模型参数，证据本身也变，不能仅凭不同模型ELBO数值断言某后验近似更准确。还应区分族限制、摊销误差和优化噪声。

先在这个有限表算完整，再看高斯均值场和重参数化，就能把抽象积分还原为加权平均。后验预测还需要对所关心量积分，点估计正确不保证联合不确定性也正确。

<a id="sec-3"></a>

## 3. 均值场更新与梯度估计

均值场设 $q(z)=\prod_jq_j(z_j)$，固定其余因子后，坐标最优满足 $\log q_j^*(z_j)=\mathbb E_{q_{-j}}\log p(x,z)+const$。可把 ELBO 中与该因子相关的项写成负 KL 得到；期望与归一化需可计算。独立近似牺牲变量间相关结构，不能只看每维均值就宣称近似准确。

连续可重参数化变量可写 $z=g_\phi(\epsilon)$，对固定噪声求路径导数。另一种 score 估计利用 $\nabla_\phi\mathbb E_q f=\mathbb E_q[f\nabla_\phi\log q]$，需要相应可交换微分条件，常需控制方差。离散变量一般不能直接套用普通连续路径导数。

<a id="sec-3-1"></a>

### 进一步推导：坐标更新的 KL 形式与共轭对照

固定其他因子，令 $h_j(z_j)=E_{q_{-j}}\log p(x,z)$，若归一化常数 $Z_j=\int e^{h_j(z_j)}dz_j$ 有限，则 $\tilde p_j=e^{h_j}/Z_j$。ELBO 中所有依赖 qj 的项为 $E_{q_j}h_j-E_{q_j}\log q_j$，恰为 $-KL(q_j\|\tilde p_j)+\log Z_j$。最大值因此在 qj=\tilde pj 取得，说明坐标公式来自优化，不是直接把其他变量替换为均值。

若联合项含平方、指数或乘积，期望通常需要相应高阶矩，例如 $E[z^2]\ne(Ez)^2$。只把隐变量换成后验均值可能改变目标，尤其在混合与层级模型中。若 Zj 不存在或不能解析计算，也不能继续把公式写成已得到可执行闭式解。

一个可解析对照是已知观测方差 σ² 的正态均值模型：n 个观测，先验均值 μ0、方差 τ0²，后验精度为 $n/\sigma^2+1/\tau_0^2$，后验均值为该精度倒数乘 $n\bar x/\sigma^2+\mu_0/\tau_0^2$。用它可检查变分实现的尺度、先验项和数据归约。

验证时既看均值也看方差与后验预测。若一维共轭例都不一致，先查似然和熵项，不应增加更灵活的近似族来掩盖局部错误；若共轭例一致而相关高斯不准，则可能正是均值场表达限制。

<a id="sec-4"></a>

## 4. 基础算例：均值对了，方差仍可错

目标后验为二维高斯，均值零、协方差 $\Sigma=\begin{pmatrix}1&\rho\\\rho&1\end{pmatrix}$。在完全因子化高斯族内最小化 $KL(q\|p)$，均值仍为零，最优每维方差是精度矩阵对角的倒数，即 $1-\rho^2$。

取 ρ=0.9，每维真实边缘方差为 1，均值场方差仅 0.19。对预测量 $z_1+z_2$，真实方差为 3.8，近似为 0.38。近似均值完全正确，也可能严重低估某个联合方向的不确定性。

```python
import numpy as np
rho = 0.9
cov = np.array([[1., rho], [rho, 1.]])
precision = np.linalg.inv(cov)
mean_field_cov = np.diag(1 / np.diag(precision))
v = np.ones(2)
assert np.allclose(np.diag(mean_field_cov), 0.19)
assert np.isclose(v @ cov @ v, 3.8)
assert np.isclose(v @ mean_field_cov @ v, 0.38)
print("target / mean-field predictive variance:", v @ cov @ v,
      v @ mean_field_cov @ v)
```

## 5. 表达能力与计算的取舍

全协方差高斯能表示相关，但存储及分解更贵；低秩加对角在成本与相关性之间折中；归一化流通过可逆变换增加表达能力，却也增加雅可比和优化成本。层级模型的参数化会显著影响后验几何，即使概率模型语义相同，推断难度也可能不同。

摊销推断使用共享网络将每个 x 映到近似参数，省去逐样本独立优化，却可能增加摊销误差。判断是否值得，要比较实际关心的预测量和总成本，不能仅按 ELBO 数值排序；不同模型的证据本身也会不同。

<a id="sec-6"></a>

## 6. 诊断与验证设计

在可解析共轭模型上先核对均值、协方差及预测积分；再在小规模任务与独立采样方法比较。记录多初始化 ELBO、梯度波动与关键后验统计，并检查某些模式是否被忽略。

后验预测检查从近似后验抽参数，再生成模拟观测，比较与实际数据有关的统计量。检查通过只说明被检验方面可解释数据，不等于先验、似然和后验都是真实机制。需要区分模型失配与推断近似：更灵活 q 也不能修复错误的观测模型。

<a id="sec-7"></a>

## 7. 练习与解析

**练习一：** ELBO 上升是否意味着每个后验预测区间更准确？

**解析：** 不一定。它优化全局近似目标，区间还受族限制、模型失配与关心方向影响。

**练习二：** 只有一个观测时可不可以做变分推断？

**解析：** 可以，推断对象是该模型后验；计算可行性和统计信息量是不同问题。

**研究练习：** 将算例 ρ 从 0 扫到接近 1，对比均值场与全协方差近似的 KL 和两个线性预测方向方差。解释为何反向 KL 目标下出现方差收缩，避免把某个高斯特例当成所有变分方法的必然行为。
