## 1. 连续控制

在[第 2 章](02-连续控制奖励设计与实验.md#ddpg-td3-updates)的确定性 Actor-Critic 基础上，SAC 使用随机策略，并把策略熵加入优化目标。现代常见的双 Q 形式从回放取样，令 $a'\sim\pi_\theta(\cdot\mid s')$，Critic 的停止梯度目标为

$$
y=r+\gamma b\left[\min_{i=1,2}Q_{\bar\phi_i}(s',a')-\alpha\log\pi_\theta(a'\mid s')\right].
$$

$b$ 仍表示是否允许自举，$\alpha>0$ 是熵温度，不是优化器学习率。两个 Critic 分别拟合同一目标。这里下一动作从当前随机策略采样，目标 Q 使用缓慢更新的参数；不要直接照搬 DDPG 的确定性目标 Actor。某些早期 SAC 形式包含额外状态价值网络，应按论文或实现版本区分。

Actor 用重参数化动作 $a_\theta=f_\theta(s,\epsilon)$，最小化 $\mathbb E[\alpha\log\pi_\theta(a_\theta\mid s)-\min_i Q_{\phi_i}(s,a_\theta)]$。更新 Actor 时固定 Q 的参数，仍保留 Q 对动作的导数。熵项鼓励分散，价值项鼓励有利动作；可以固定温度，也可以按明确的目标熵协议学习温度，二者实验条件不同。

例如 $r=1,\gamma=0.9,b=1,\min Q=3,\alpha=0.2,\log\pi=-1$，则目标为 $1+0.9(3+0.2)=3.88$；若真正终止使 $b=0$，目标仅为 1。连续分布使用概率密度，log 密度可能为正，不能套用离散概率不超过 1 的判断。

若高斯变量 u 经 `tanh` 和动作范围缩放变为 a，log 密度必须减去相应变换的 log Jacobian。简单将采样动作裁剪后继续使用原高斯密度，会让熵项和 Actor 目标失配。测试时应分别核对合法动作、有限 log 密度、终止目标和梯度路径，再比较回报。公式与现代变体见 [SAC 教学文档](https://spinningup.openai.com/en/latest/algorithms/sac.html)。

## 2. 离线限制

固定数据未覆盖的动作可能被 Critic 高估，Actor 再选择这些动作，会进一步偏离数据。离线算法使用相应保守性或行为约束等思路，但需要独立协议评价，不能从在线经验回放直接推导安全可用。

<a id="sec-1-1"></a>

### 基础算例：离线覆盖缺失不能靠更高 Q 值证明改善

离线数据在某状态只执行动作 A，动作 B 的真实后果没有被观察。函数近似可能给 B 很高 Q，Actor 随之选择 B，但训练数据没有提供足够证据证明它更好。应说明行为覆盖、约束及离线评价假设，不能用预测 Q 上升当部署收益。若可以交互验证，还需固定环境预算和安全任务协议；若不可交互，结论范围就必须对应可识别信息。

<a id="sec-2-1"></a>

### 机制展开：离线约束针对数据支持之外的推断

历史行为很少执行的动作，其后果无法由数据充分识别，Actor 最大化 Q 可能选择这些乐观外推。行为约束或保守估计限制此风险，也可能限制策略改进空间。离线评价需说明覆盖、模型或权重假设，不能用训练 Q 自评证明收益。若没有独立交互证据，就应把结论限定于可识别与已验证范围。

<a id="deep-dive-2"></a>

### 深入讲解：离线策略为什么更容易利用Critic的外推错误

在线策略可尝试动作并获得反馈，离线仅有固定行为日志。数据罕见动作的Q主要由函数近似外推，Actor最大化时可能专门挑这些乐观区域，没有新交互及时纠正。

行为约束限制偏离已支持动作，保守价值目标压低某些未支持高估，都会带来表达与改进空间取舍。不能只看训练Q更高就宣布超过行为策略，需要合法离策略评价或独立交互。

连续SAC目标的随机下一动作、双Q、熵密度与温度都需与前章一致。时间截断、动作缩放和概率修正是局部正确性的前提，不可被最终平均回报掩盖。

复现包含环境版本、原始步与控制步、奖励处理、回放、更新比例和全部种子。最好回合与平均独立回报不同，平滑图也应保留原始波动。

验收先局部目标，再小环境真值，再固定预算任务结果。没有覆盖的信息应明确留在不可识别范围，而不是用更复杂网络的自评分填补证据。

<a id="sec-3"></a>

## 3. 复现清单

记录环境与版本、观察与奖励处理、动作重复、时间上限、网络、回放、更新比例、预算、种子和评估方式。多个种子报告分布，平滑曲线注明窗口，保留原始数据。

复现记录还应包含训练与评价策略的区别、检查点选择规则、终止与时间截断语义，以及一次交互对应多少梯度更新。回放预热、采样分布、目标网络更新频率和奖励尺度常显著影响结果，不能只记录网络宽度和学习率。

种子至少区分环境随机性、参数初始化和采样过程。保留每次完整运行的原始点，再按预定方式汇总；不把全部回合当成彼此独立的训练重复。恢复检查点时若没有回放、优化器或环境相关状态，应说明只是部分恢复，不能宣称轨迹逐步相同。

<a id="sec-4"></a>

## 4. 综合验收

先验证小环境训练闭环，再与简单或随机策略比较，检查成功率与失败模式，最后讨论样本效率与速度。训练回报、最高回合与平均评估回报应分开。

先验收局部更新：终止状态不错误自举，目标停止梯度，Actor 梯度路径有效，动作与 log 概率一致。再在已知小环境检查策略是否超过简单基线，最后用预设种子和预算评价训练稳定性与任务效果；前一层通过不意味着后一层已经成立。

连续在线实验报告独立交互结果，离线实验则说明数据支持与评价假设，不能仅用同一 Critic 的高估值证明成功。运行产物需能加载并执行约定评价，资源、失败运行和检查点选择规则一并记录，才能形成可比较的结论。

<a id="sec-5"></a>

## 5. 在线与离线评价的差别

重要性采样、逐决策加权与序贯双重稳健的完整推导及枚举算例见[离策略评价进阶章](../../AdvancedStudies/CausalInference/03-序贯决策重要性采样与离策略评价.md)。学习时先确定评价目标与日志支持，再选择估计器，避免将训练 Critic 的自评分作为真实收益。

在线策略可以通过新交互纠正估计，离线策略只能依赖已有行为覆盖。未覆盖动作被误高估后，没有新环境反馈及时修正，风险更突出。算法选择首先取决于这个任务条件，而不是是否已经有回放缓冲。

复现时环境步数、动作重复和并行环境都会改变样本定义。一个控制步可能对应多个原始模拟步，图像预处理和奖励裁剪也改变难度。报告这些细节才能让结果可比较。

模型性能还包括稳定性与失败行为。多种子平均、成功率、回合长度和成本共同呈现，不应只选最好回合或平滑曲线峰值。若用于新环境或真实系统，需额外验证模拟差异与任务约束，教学基准成绩不能直接代表迁移能力。

<a id="sec-6"></a>

## 6. 进阶：复现层级与统计有效性

多环境并行、动作重复与时间上限改变样本单位，墙钟快不代表样本效率高。应报告原始交互、有效更新、资源、环境版本及奖励处理；比较同回报所需样本与同时间表现是不同问题。

种子波动、评估回合噪声和跨环境泛化也不同。保留原始运行，预设汇总，避免最好种子和最高峰。模拟成功迁移真实环境还需动力学、观测和约束验证，不能用单一基准平均回报覆盖。

<a id="sec-6-1"></a>

### 离线数据限制的是可识别的动作后果

离线强化学习不能通过新交互纠正未覆盖动作的价值误差。行为数据几乎从不选择某动作时，其后果无法仅靠函数近似可靠识别；Actor 若偏向这些动作，可能利用 Critic 的外推错误。保守估计或行为约束针对这一风险，但也可能限制超越行为策略。

离线评价依赖覆盖、模型或重要性权重等假设，长时域权重乘积可能方差很大。不能只用训练数据上的 Q 值更高证明策略更好；应说明评价信息来源、支持条件和已知失败范围。

复现分为代码可运行、局部更新一致、固定配置结果接近和跨种子统计结论稳定。每层需要不同证据。报告数据版本、环境、奖励、终止处理、预算、种子及选择规则，保留失败运行；最优种子不代表算法期望表现，离线指标也不自动等于真实部署收益。

<a id="sec-7"></a>

## 7. 练习与解析

**题目：** 方法 A 使用十倍并行环境，在相同时间回报更高，是否证明样本效率更好？

**解析：** 不证明，可能消耗更多环境交互。应同时比较达到表现所需样本与实际时间，明确并行资源和更新预算。

<a id="sec-8-2"></a>

### 边界追问：离线高 Q 能否代替外部评价

**问题：** 新策略偏向数据少见动作，预测 Q 高于行为策略，是否足以宣布改进？

**推理解析：** 不足，可能利用外推错误。说明覆盖、约束与离线评价假设，若有交互则按固定预算独立验证。没有相应信息时保留结论范围，不能把模型自评分当真实后果。多种子、选择规则与失败也应纳入复现报告。

<a id="sec-8"></a>

## 8. 进阶研究练习与解析

**问题：** 历史数据在某状态只执行动作 A，能否只靠这批数据确认动作 B 比 A 更好？

**解析：** 构造两个环境，它们对所有已观察状态—动作给出相同回报与转移，却分别令未覆盖的 B 获得很高和很低的回报。两者产生相同历史数据，但 B 的真实价值相反。因此不增加覆盖、结构假设或交互信息，单靠该数据不能识别 B 的收益；模型给出的高 Q 只是外推结果。

**实验与验收：** 在小型已知 MDP 中控制行为策略对 B 的选择概率，比较普通 Q 最大化、行为约束及保守估计。训练数据和环境交互预算固定，使用独立评价回合测真实回报，再按数据覆盖分组比较价值误差。覆盖趋零时不能因为误差条很窄就断言可靠；误差条也可能只反映同一错误模型的重采样波动。若真实交互不可获得，报告离线评价依赖的支持与建模假设，并保留不可识别区域。

<a id="sec-8-1"></a>

### 综合练习：离线策略收益的证据范围

**问题：** Actor 选出数据中很少出现的动作并得到高预测 Q，能否证明超越行为策略？

**逐步解析与验收：** 不能，可能在利用外推误差。检查覆盖与评价假设，比较行为约束或保守目标，并说明无法识别区域。若能交互，按固定预算独立验证；若不能，报告离线估计的条件与不确定性。验收区分模型自评分与真实策略效果。
