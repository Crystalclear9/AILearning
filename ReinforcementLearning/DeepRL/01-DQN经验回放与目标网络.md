## 1. 从表格到神经网络

状态很多时无法存储完整 Q 表，可用 $Q_\theta(s,a)$ 近似。对于有限离散动作，网络输入状态，一次输出各动作价值。训练目标是让当前估计接近 TD 目标，而目标本身又包含估计，因此不再是固定标签的普通监督学习。

函数近似、bootstrap 和 off-policy 学习的组合可能导致不稳定。即使损失下降，也可能只是更好地拟合了错误目标；回报才是行为层面的评估依据。

<a id="sec-1-1"></a>

### 基础算例：回放转移与网络动作维逐项对应

离散动作数为 3，网络对每条状态输出三个 Q 值。回放动作若为索引 1，训练只读取该行第二个值与目标比较，不把三个值平均当作当前动作价值。下一状态的 max 用于目标选择，终止掩码决定是否加入自举。一个小批里放不同动作和终止类型，逐项手算后再批量 gather，能发现样本索引或广播成批×批矩阵的错误。

<a id="sec-2"></a>

## 2. DQN 的两个关键机制

经验回放保存 $(s,a,r,s',terminated)$，随机抽样以减弱相邻轨迹相关性并重复利用数据。目标网络用较慢更新的参数 $\theta^-$ 构造

$$y=r+\gamma(1-terminated)\max_{a'}Q_{\theta^-}(s',a').$$

优化 $Q_\theta(s,a)$ 与 $y$ 的误差时，目标分支不参与反向传播。目标网络可周期性复制，或缓慢软更新。回放大小和更新频率影响数据新鲜度与稳定性。

<a id="sec-2-1"></a>

### 机制展开：回放与目标网络各减少一种耦合

回放随机取历史转移，减弱连续观察相关并复用数据；目标网络让自举目标不随在线每步立即同速变化。两者不消除分布偏移或错误外推，回放过旧、更新过密也可能不稳。目标通常停止梯度，参数通过硬复制或软更新变化。报告更新频率、环境步和缓冲规则，避免把不同数据预算误当算法纯收益。

<a id="deep-dive-2"></a>

### 深入讲解：回放与目标网络怎样降低相互追逐的估计难度

Q网络用参数共享泛化状态，目标y=r+γb maxQtarget(s',a)。若同一网络一边预测一边立即改变目标，更新高度耦合；目标网络缓慢或周期同步，使短期回归对象相对稳定，但不保证全局收敛。

回放打散相邻转移并复用样本，改变数据相关与利用效率；它不创造新环境信息，也可能保留旧分布。优先回放等机制又改变采样概率，需考虑对应权重和目标。

DQN使用目标网络同时选最大动作与评价，Double用在线选、目标评，减少某些共享噪声选择偏差。两网络相关、覆盖和函数失配仍存在，不能因此宣称完全无偏。

实现先核对目标停止梯度、动作gather、终止与外部截断。一个批里所有动作价值若都参与当前监督，可能已改变原公式。

用已知MDP观察Q偏差、TD损失与真实回报，再逐项加入回放和目标同步。训练loss下降不自动说明未见动作正确，更不能代替部署策略效果。

<a id="sec-3"></a>

## 3. Double DQN 的区别

选择与评价共用带噪数值时，最大值操作会倾向挑中较乐观的误差。诊断时不只看平均 Q 值，还应核对不同动作的误差相关性和实际回报。下一小节用零均值误差说明偏差来源，再写出 Double DQN 的分工，避免把缓解某类误差误称为消除了全部估计问题。

标准 DQN 目标常为 $r+\gamma b\max_aQ_{\bar\theta}(s',a)$；Double DQN 先用在线网络选择 $a^*=argmax_aQ_\theta(s',a)$，再由目标网络评价 $r+\gamma bQ_{\bar\theta}(s',a^*)$。两者目标均停止梯度，b 表示允许自举。

假设在线值为 (5,4)、目标值为 (1,3)，Double 选择第一个动作再取 1，而标准目标取 3。这个差别直接检验动作选择与评价是否真的分开。相关网络和数据偏差仍存在，不能从结构分离推出估计完全无偏或所有任务必胜。

<a id="sec-4"></a>

## 4. 回放缓冲区并非永远越大越好

较大缓冲区提供更多历史经验，降低相邻样本相关性，但也保留较旧策略的数据。环境或目标变化时，陈旧数据可能与当前学习重点不一致；太小又可能快速遗忘重要罕见事件。缓冲区容量、采样方式和每步更新比例需要共同考虑。

目标网络更新太快接近追逐自身变化，太慢则可能让目标滞后。DQN 的稳定机制是在这些动态之间折中，并不构成无条件收敛保证。应同时记录 TD 损失、Q 值尺度与实际回报，防止只看某一条曲线产生误判。

<a id="sec-5"></a>

## 5. 网络输出与目标动作

DQN 一次输出离散动作 Q 值，训练只取实际动作对应的值与目标比较，不能对全部动作都回归同一个奖励。动作索引 gather 的维度和 dtype 错误很常见，应在小批中打印核对。

回放中的终止与截断要分别保存，否则后续无法正确决定 bootstrap。环境 reset 后的新观察不能被误当作终止转移的下一状态。

<a id="sec-6"></a>

## 6. 进阶：最大值过估计与Double方法

若各动作估计含零均值噪声，max 的凸性使 $E[\max_a\hat Q_a]\ge\max_aE[\hat Q_a]$，选择与评价共享噪声会产生过估计倾向。Double DQN 用在线选动作、目标评价，缓解相关选择偏差，但并非保证无偏。

经验回放降低相邻样本相关、目标网络减慢目标变化，二者不构成深度 Q 学习的一般收敛证明。应同时看 Q 尺度、TD 损失与行为回报，防止稳定拟合错误目标。

<a id="sec-6-1"></a>

### 最大值过估计不需要每个动作都高估

设两个真实动作值均为零，估计误差为零均值随机变量，通常有 $E[\max(\epsilon_1,\epsilon_2)]\geq\max(E\epsilon_1,E\epsilon_2)=0$。取最大值会选择更乐观的噪声，因此单个估计无偏也不保证 max 目标无偏。

Double DQN 用在线网络选择 $a^*=\arg\max_aQ_\theta(s',a)$，再用目标网络评价 $Q_{\theta^-}(s',a^*)$，减弱选择与评价误差耦合。它不保证在所有函数近似和相关误差条件下完全无偏，也不能修复错误终止或数据覆盖。

经验回放降低连续样本相关并复用数据，目标网络放慢目标变化；两者缓解问题但不是通用收敛证明。回放分布过旧、稀有事件不足或训练更新过多，都可能影响稳定。报告环境步、梯度步和缓冲设置，避免只展示一条最好的回报曲线。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 计算 DQN 目标时为何要切断梯度？若真正终止仍加下一状态价值，会怎样？

**答案：** 标准半梯度更新把当前目标当作固定估计，避免同时沿目标分支改变。对终止状态加入未来价值会污染目标，使结束任务的价值被错误高估或低估。

<a id="sec-7-1"></a>

### 边界追问：Double DQN 是否保证完全无偏

**问题：** 选择评价分离后，是否可以不再检查价值误差和回报？

**推理解析：** 不能，它缓解特定最大值选择偏差，不消除函数近似、相关误差、覆盖或终止错误。回放与目标网络也不提供通用收敛证明。先核对人工批更新，再观察独立行为与预算，避免以某一个机制的理论动机概括完整算法保证。
