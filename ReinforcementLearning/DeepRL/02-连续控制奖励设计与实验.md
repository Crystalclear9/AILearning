## 1. 连续动作的方法选择

DDPG 使用确定性 Actor 和 Q Critic，通过 Critic 对动作的梯度更新 Actor；TD3 加入双 Critic、延迟策略更新等机制，缓解特定过估计与不稳定问题。SAC 使用带熵项的随机策略目标，兼顾回报与探索。它们都需要按自身假设设置回放、目标更新与动作尺度。

PPO 通常按当前策略收集新批次，DQN、DDPG、TD3、SAC 常重复利用回放数据。样本效率、并行采样效率和墙钟时间是不同指标，不能只比较更新次数。

<a id="sec-1-1"></a>

### 基础算例：连续动作的合法范围是分布协议的一部分

高斯策略先生成无界 u，再经 tanh 映入 (-1,1)，若环境范围为 (-2,2)，还需相应缩放。环境直接裁剪与可逆变换的概率模型不同，计算 log 概率要对应实际动作生成路径。奖励缩放、探索噪声与更新频率也影响训练。先验证动作与概率的一致性，再讨论连续控制算法优势，避免数值可以运行却优化另一个目标。

<a id="ddpg-td3-updates"></a>

### DDPG 与 TD3 分别怎样更新 Critic 和 Actor

从回放取 $(s,a,r,s',b)$，其中 $b=0$ 表示真正终止、$b=1$ 表示允许自举。DDPG 的目标为 $y=r+\gamma bQ_{\bar\phi}(s',\mu_{\bar\theta}(s'))$，Critic 最小化 $\mathbb E(Q_\phi(s,a)-y)^2$；计算该损失时对 y 停止梯度，目标网络用缓慢更新的参数。Actor 则最小化 $-\mathbb E Q_\phi(s,\mu_\theta(s))$，梯度沿 $\nabla_aQ_\phi\,\nabla_\theta\mu_\theta$ 传回。Actor 步固定 Critic 参数，但不能切断 Critic 对动作的梯度。

确定性策略通常在采样时加入探索噪声，评价时按事先约定使用无探索噪声的策略。噪声尺度与动作单位必须一致，不能只因 Actor 输出在 [-1,1] 就省略环境动作范围映射。

TD3 使用两个 Critic，目标动作先加裁剪噪声并限制在合法范围，目标值采用两目标 Critic 的较小值；Actor 更新和目标网络更新通常比 Critic 更少。三个机制分别处理目标动作附近的尖锐估计、乐观选择和更新耦合，并非使用两个网络就自动获得无偏估计。比较时需记录每次环境交互对应的梯度步数。

时间上限截断是否自举由任务的继续价值定义决定；不要把框架的任意 episode 结束标记都当成真正终止。SAC 的随机策略与熵目标详见[第 4 章](04-连续控制离线学习与复现协议.md#sec-1)。推导可对照 [DDPG](https://spinningup.openai.com/en/latest/algorithms/ddpg.html) 与 [TD3](https://spinningup.openai.com/en/latest/algorithms/td3.html) 教学文档。

<a id="deep-dive-1"></a>

### 深入讲解：确定性随机性与动作变换共同决定连续控制更新

DDPG让Actor输出确定动作，Critic学习Q，Actor通过Q对动作的导数更新。更新Actor时固定Critic参数，但保留动作到Q的梯度；将整段Q放no_grad会切断需要的信号。

TD3加入双Critic较小目标、目标动作平滑与延迟策略更新，各缓解不同耦合或乐观问题。SAC则优化随机策略和熵，目标含−αlogπ；它们不是只改网络个数的同一算法。

高斯u经tanh及范围缩放变实际动作，log密度需要相应Jacobian修正。直接裁剪动作后仍用原高斯log_prob，会让优化目标与实际生成分布不一致。

探索噪声、评价随机性、奖励尺度与终止定义都影响表现。训练回报提高还可能利用奖励漏洞，应同时测真实成功条件及失败行为。

比较记录每次环境交互对应更新数、预热、回放和目标规则。样本效率、并行采样速度与墙钟时间不同，不能只依据算法名称或训练step排名。

<a id="sec-2"></a>

## 2. 奖励设计会改变行为

如果奖励只与速度有关，智能体可能找到与真实任务不一致的高速行为；若给每次停留正奖励，可能学会拒绝结束。应明确最终成功条件，并检查策略是否利用奖励漏洞。训练回报提高不代表原始目标改善。

奖励裁剪、归一化与折扣都会改变学习尺度，有时还改变目标偏好。报告时应注明预处理，避免把不同定义的回报直接比较。

<a id="sec-2-1"></a>

### 机制展开：奖励改变的是所优化的行为排序

每步奖励“接近目标”可能让来回移动重复获利，存活奖励过大可能鼓励拖延。先列完成、循环、失败等候选轨迹手算总回报，检查是否符合真实目标。势函数形式在适当条件下有策略保持解释，任意加分没有同样保证。评价同时给成功率、约束和路径，不能只看被重新定义后的训练奖励升高。

<a id="sec-3"></a>

## 3. 强化学习评估要多重随机性

区分训练种子、环境种子和评估回合。训练中探索策略与部署策略不同，评估应使用预先规定的探索设置。报告多次独立训练及多回合均值、波动、成功率，并固定环境版本、时间限制和总交互预算。

回报曲线平滑可以辅助观察，但应保留原始数据，并说明平滑窗口；不能只展示最好种子或最好一次回合。环境接口返回 `terminated` 与 `truncated` 时，应按任务语义处理 bootstrap。

<a id="sec-4"></a>

## 4. 真实样本效率与模拟器条件

两个算法即使报告相同环境步数，也可能使用不同的并行环境数量、动作重复次数或观测预处理。比较前应确认一步的定义、终止规则、奖励缩放和评估政策一致。不同模拟器版本中的小变化，也可能使回报范围改变。

离线强化学习只使用既有数据时，还面临分布外动作价值被高估的问题，不能把普通 off-policy 在线算法直接当成可靠离线方案。是否能继续与环境交互、数据覆盖哪些动作，是选择算法前必须明确的任务条件。

<a id="sec-5"></a>

## 5. 实验预算与算法名字

相同算法可能因网络、奖励处理、更新比例和环境版本产生很大差异。比较应固定这些关键协议，报告环境步数和墙钟时间。只引用算法论文名不足以描述实验。

离线数据还受动作覆盖约束，在线 off-policy 算法不自动适用于完全离线任务。必须先明确是否允许继续采样。

环境步数、模拟器原始帧、梯度更新数与实际时间分开统计。动作重复四次时，一个控制步可能对应四个模拟步；多环境并行改变总采样速度；回放重复学习则增加更新而不增加新交互，三者不能互换。

比较算法时固定或明确这些预算，保留网络、奖励处理、预热和评价策略。若一个方法使用更大调参范围，最好结果还包含额外搜索成本。结论应说明是同交互更高回报、同时间更快进展，还是同资源下更稳定，不用一个算法名代替实验条件。

<a id="sec-6"></a>

## 6. 进阶：连续Actor-Critic的分布外动作问题

确定性 Actor 沿 Critic 对动作的梯度改善策略，但 Critic 在未覆盖动作上可能误高估，Actor 会利用这个误差。TD3 的双估计与延迟等机制针对特定问题，SAC 又加入熵正则，目标和采样不同。

完全离线数据不能通过新交互纠错，因此普通在线 off-policy 方法不自动可靠。需明确行为覆盖、保守或约束思路与评价协议，不能把缓冲区已有数据等同适合离线学习。

<a id="sec-6-1"></a>

### 连续 Actor-Critic 的动作选择也会放大价值误差

确定性 Actor 可通过最大化 Critic 给出的 Q 来选择动作，但若 Critic 在训练覆盖之外错误乐观，Actor 可能主动寻找这些误差区域。这个问题与离散 max 过估计有相似选择机制，却还包含连续优化和分布外动作。

DDPG 类方法使用确定策略与回放，SAC 类方法加入熵相关目标并学习随机策略，探索与目标形式不同。比较时需说明动作尺度、奖励缩放、更新频率、目标网络和温度等设置，而不是只按算法名归类。

奖励设计应检查副作用：提高每步存活奖励可能鼓励拖延，惩罚动作大小可能阻止完成任务。先在候选行为上手算总回报，再观察终止原因与成功率。样本效率还应计入并行环境数量和真实交互成本，模拟器墙钟快不等于现实样本便宜。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 算法 A 更新次数更少，但每次需十倍环境交互，能否称样本效率更高？

**答案：** 不能。样本效率关注达到表现所需的环境样本，应同时报告交互量、计算量与时间。训练回放中重复使用旧样本不等于产生新的环境交互。

<a id="sec-7-1"></a>

### 边界追问：连续动作裁剪能否沿用原高斯密度

**问题：** 策略采样无界 u 后直接裁剪到环境范围，继续用原密度更新，是否等价 tanh 策略？

**推理解析：** 不等价，裁剪非一对一，实际执行分布与原高斯不同；tanh 变换也需雅可比和缩放约定。动作、保存值、log 概率必须对应同一路径。先检查分布与接口，再比较算法名称或回报，不能以运行无报错判断估计正确。
