## 1. 两类估计目标

蒙特卡洛在回合结束后用真实采样回报 $G_t$ 更新价值，不依赖下一状态估计，但可能方差大且需要等待。TD(0) 用 $r+\gamma V(s')$ 作为目标，提前更新，并从已有估计 bootstrap。

状态价值更新为 $V(s)\leftarrow V(s)+\alpha[r+\gamma V(s')-V(s)]$，括号内是 TD 误差。它并不等于真实价值误差，因为下一状态估计也可能不准确。

<a id="sec-1-1"></a>

### 基础算例：MC 与 TD 对同一轨迹给出不同目标

两步奖励为 1、2，γ=0.9，下一状态估计值为 5。第一步 MC 回报为 2.8，TD 一步目标为 1+0.9×5=5.5。差别来自 TD 使用尚不准确的未来估计，不意味着其中一个公式写错。MC 等到完整结果，TD 可以更早更新，二者偏差方差与数据条件不同。真正终止时尾部价值为零，外部截断则不能不加区分地清零。

<a id="deep-dive-1"></a>

### 深入讲解：蒙特卡洛与TD的偏差方差和信息使用差别

MC等待完整后续回报Gt，再向样本均值更新，不需当前尾部价值；TD用rt+γV(s')自举，可在线更新但目标依赖估计。两者在不同随机性、时域与近似条件下有不同取舍，不能只说MC无偏就断言总更好。

一步TD误差δ=r+γV(s')−V(s)，更新V(s)←V(s)+αδ。终止时去掉尾部价值，截断则按任务保留；采样目标含噪，单步误差大不意味着长期学习错误。

SARSA使用实际下一行为动作Q(s',a')，Q-learning用maxaQ(s',a)构造贪心目标。行为与目标策略的关系不同，探索中的轨迹回报也可能不同；不能仅将公式一个max替换后忽略评价协议。

表格收敛结论需要访问和步长等条件，有限运行、函数近似和离策略组合不能直接继承。一个状态没访问过，其值即使数值很大也不构成有效知识。

先在已知小MDP求真实V/Q，再对照更新与策略行为。这样能分清采样波动、覆盖不足和实现错误，而非凭训练曲线猜算法性质。

<a id="sec-2"></a>

## 2. SARSA 与 Q-learning

SARSA 使用实际选出的下一动作：$Q(s,a)\leftarrow Q(s,a)+\alpha[r+\gamma Q(s',a')-Q(s,a)]$。它评估并改进当前行为策略，属于典型 on-policy 方法。

Q-learning 目标用 $\max_{a'}Q(s',a')$，学习贪心目标策略的价值，而采样时可以按另一种探索策略行动，因此是典型 off-policy 方法。这里“不同策略”不是说数据完全不需要覆盖有效状态动作。

<a id="sec-2-1"></a>

### 机制展开：SARSA 与 Q-learning 的目标策略不同

SARSA 使用行为实际采到的下一动作，Q-learning 用下一状态最大估计。若行为仍探索，SARSA 将探索后果计入对应策略价值，而 Q-learning 学习贪心目标并需覆盖。二者都依赖奖励与终止正确，函数近似下也不自动拥有表格收敛保证。比较时固定探索和评价协议，不能把训练行为回报与最终目标策略回报混用。

<a id="sec-3"></a>

## 3. 探索不能只靠运气

$\epsilon$-greedy 以概率 $\epsilon$ 随机选择动作，其余时间选择当前最优。探索太少可能永远无法发现有益路径；太多则降低当前回报。表格 Q-learning 的收敛结论需要有限问题、足够访问和合适步长等条件，不能直接套到任意神经网络训练。

<a id="sec-4"></a>

## 4. 行为策略与目标策略

行为策略决定实际收集什么数据，目标策略决定想学习哪个策略的价值。Q-learning 可以用带探索的行为收集数据，同时学习贪心目标；但从未访问的状态动作仍没有可靠依据。off-policy 不是允许无条件从任何数据推断所有动作效果。

SARSA 会把下一步可能继续探索的风险纳入目标，因此在有危险边界的任务中，可能学到对当前探索方式更稳妥的路线。比较两者时应看最终评估政策与训练策略，而不是只看算法公式里是否有 max。

<a id="sec-5"></a>

## 5. n步回报连接MC与TD

n 步目标累计前 n 步奖励后再 bootstrap，n=1 对应一步 TD，覆盖完整回合时接近蒙特卡洛。步数增加通常减少某些 bootstrap 偏差，却可能增加采样方差与延迟。

终止发生在 n 步之前时，目标应截到真正终止且不再加未来价值；若只是批次边界，则仍需按任务处理。回报长度与训练批长度不是同一个概念。

<a id="sec-6"></a>

## 6. 进阶：TD的bootstrap与半梯度

TD 目标含当前价值估计，标准半梯度更新把目标视为固定，不等于对均方 Bellman 残差做完整梯度下降。采样平方目标与期望算子的平方也不同，直接求残差梯度还涉及双采样问题。

表格 Q-learning 的收敛依赖有限问题、足够访问和合适递减步长等条件。函数近似、off-policy 与 bootstrap 组合可能不稳定，不能从表格证明推出任意深度网络收敛。

<a id="sec-6-1"></a>

### TD 目标为什么是自举而非监督真值

一步 TD 目标为 $r+\gamma V(s')$，未来部分由当前估计给出，既减少等待完整回合的需要，也把估计误差引入目标。MC 使用完整采样回报，在适当采样条件下不含同样的自举偏差，但可能波动更大。两者不存在对所有任务的固定优劣。

SARSA 的目标使用实际行为下一动作 Q 值，Q-learning 使用下一状态的最大 Q 值，分别体现对行为策略与贪心目标的不同学习关系。若探索仍持续，二者可能学习到不同的风险取舍，不能只因公式差一个 max 就混称相同算法。

函数近似中常将自举目标视为固定量，只对当前预测求导，即半梯度。若让梯度穿过目标网络，优化对象发生改变。表格方法的收敛论证还依赖访问覆盖和步长条件，不能从一次曲线趋平直接断言已得到最优值。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 当前 $Q=2$，奖励为 1，下一最大 Q 为 4，$\gamma=0.9$，$\alpha=0.5$，更新后是多少？

**答案：** 目标为 $1+0.9\times4=4.6$，新值为 $2+0.5(4.6-2)=3.3$。若该转移真正终止，目标应只有 1，新值为 1.5。

<a id="sec-7-1"></a>

### 边界追问：MC 无自举是否就总更准

**问题：** 完整回报不依赖尾部值估计，能否据此断言 MC 在所有任务优于 TD？

**推理解析：** 不能，完整回报可能方差高、等待久，TD 在偏差与波动间取舍。数据相关、探索与函数近似也影响表现。比较固定环境交互与目标，不把单次回报更接近真值当普遍优势；真正终止和采样截断仍需区分。
