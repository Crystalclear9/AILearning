## 1. 明确环境和终止

状态为 0 到 4，初始为 0，动作 0 向左、1 向右，边界不再向外移动。进入 4 获得奖励 1 并真正终止，其他步奖励为 -0.01。目标是在折扣回报下尽快到达终点。

以下代码无需环境库；每回合的 100 步上限只是防止教学循环过长，达到上限不被当作环境真正终止。

```python
import numpy as np
rng = np.random.default_rng(42)
Q = np.zeros((5, 2))
alpha, gamma, epsilon = 0.2, 0.95, 0.2
for episode in range(1000):
    s = 0
    for step in range(100):
        if rng.random() < epsilon:
            a = int(rng.integers(2))
        else:
            ties = np.flatnonzero(Q[s] == Q[s].max())
            a = int(rng.choice(ties))
        next_s = max(0, s - 1) if a == 0 else min(4, s + 1)
        terminated = next_s == 4
        reward = 1. if terminated else -0.01
        target = reward if terminated else reward + gamma * Q[next_s].max()
        Q[s, a] += alpha * (target - Q[s, a])
        s = next_s
        if terminated:
            break
print(Q)
print("policy for states 0..3:", Q[:4].argmax(axis=1))
```

初始 Q 全相等时随机打破平局，避免动作编号带来的固定偏好。状态 4 是终点，其动作没有实际决策含义，不应解释它的 argmax。

<a id="deep-dive-1"></a>

### 深入讲解：表格Q学习怎样从一条转移落实到一项更新

从状态s按行为策略选a，执行后得到r、s'和边界；目标y=r+γb maxQ(s',·)，再以Q(s,a)←Q(s,a)+α(y−Q(s,a))更新一项。b表示真正允许自举，而非所有episode结束一律为零。

若当前Q=0、奖励1且真正终止，α=0.5，新Q为0.5；重复观察同一确定转移会逐步靠近1。若误保留终点自环价值，会把终点奖励重复累积，数值和策略都可能异常。

ε-greedy需在合法动作内探索，并明确并列最大时如何选。总体ε不低不代表罕见状态覆盖充分，应统计状态动作访问次数与成功路径。

训练允许探索和更新，评价冻结Q并用预设策略跑完整回合。一次成功只能说明一次路径，随机环境需多回合和独立训练种子；价值表本身不能代替真实行为。

用动态规划参考比较每个可识别Q，再核对轨迹折扣回报。手算局部更新、表级误差和策略效果是逐层证据，不应互相替代。

<a id="sec-2"></a>

## 2. 训练与评估分开

训练时需要探索，评估可使用预先规定的贪心策略并多次独立运行环境。报告回报、成功率和步数，而不仅报告最高一次奖励。这个确定性小环境没有展示复杂随机环境中的全部方差。

<a id="sec-1-1"></a>

### 基础算例：探索行为与贪心目标分别追踪

某状态两个动作 Q 为 2 和 1，ε-greedy 可能采到第二动作以探索；Q-learning 更新下一状态时仍使用 max 对应目标。行为选择与学习目标不是同一个随机操作。记录采样动作、奖励、下一状态和终止，再手算一项更新，可检查索引与边界。评价时按预设协议运行，不能把训练持续探索的回报直接当作最终贪心策略表现。

<a id="sec-2-1"></a>

### 机制展开：评价环境不能继续更新 Q 表

训练采样用于更新，评价应在确定行为协议下独立运行并冻结参数。评价若仍更新，会让不同回合使用不同策略且消耗额外交互，结果不再是固定策略表现。明确相等 Q 值时的动作选择和 ε，记录成功、回报、长度及终止原因。先执行路径再解释数值，Q 表很大可能只是奖励循环或自举错误。

<a id="sec-3"></a>

## 3. 检查学到的路径而非只看Q表

训练后可从状态 0 开始按贪心动作走到终点，记录状态序列、步数与累计奖励。预期路径是不断向右，但应通过真实执行验证，而不是只看某几个 Q 值较大。若出现循环，检查探索覆盖、更新次数、边界和终止处理。

Q 值整体变化不一定意味着策略变化：两个动作的相对次序更直接决定贪心行为。固定学习率还可能让随机环境中的值持续波动，因此复杂任务需要看多回合评估与独立种子。小例子建立的是理解闭环，不是给所有环境提供默认参数。

<a id="sec-4"></a>

## 4. 环境执行与Q值核对

训练后用固定策略实际走完整路径，并报告步数、成功和回报。Q 值大小可能受奖励缩放改变，而贪心策略不一定改变；因此价值表本身不能代替行为评估。

对随机转移，需要多个回合与独立训练种子。一次成功路径只证明存在该次成功，不证明平均可靠。

对表格小环境可独立算最优 Q 或用动态规划求参考，再按状态—动作比较，而非仅看轨迹成功。未访问项、终止动作及并列选择规则要明确；成功率高也可能仍有部分价值项估计不准。

评价时冻结 Q 和探索参数，避免评估又更新模型。记录回合长度与实际累计折扣回报，核对奖励在哪次转移记入；若显示的 Q 与轨迹回报量级不符，先查终止自举、奖励预处理和访问覆盖，不急于改训练轮数。

<a id="sec-5"></a>

## 5. 进阶：行为覆盖与贪心目标的分离

Q-learning 用探索行为采数据，目标却用下一贪心动作，说明 off-policy 是策略关系而非是否存回放。未访问动作没有可靠估计，贪心高值可能只是初始化或噪声，必须有覆盖机制。

随机平局可减少动作编号偏好，但不能解决稀疏奖励的全部探索困难。评估应固定策略和初始分布，多回合报告成功率与步数。Q 值整体尺度随奖励改变，不应单凭表中数值大判定策略更好。

<a id="sec-5-1"></a>

### 小型 Q-learning 例子应核对更新的每个分量

设当前 $Q(s,a)=1$，奖励为 2，下一状态最大 Q 为 3，γ=0.9、学习率 α=0.1，则目标为 4.7，TD 误差为 3.7，新 Q 为 1.37。若转移真正终止，目标改为 2，新值为 1.1；终止语义会直接改变数字。

ε-greedy 负责行为探索，更新中的 max 对应目标策略。训练时随机动作帮助覆盖，评价时通常按预设贪心或固定探索协议运行，不能把训练含探索回报直接当成最终策略质量。相等 Q 值的 tie-breaking 也可能影响早期探索。

验收除最终 Q 表，还应执行策略检查真实路径、成功率与回合长度。Q 数字变大可能来自奖励尺度、错误自举或循环，不自动表示行为更好。人工小环境适合逐转移对照，再扩展到更复杂状态。

<a id="sec-6"></a>

## 6. 练习与参考答案

**练习：** 去掉每步 -0.01 的代价，为什么仍可能更偏好短路径？如果同时令 $\gamma=1$ 呢？

**答案：** $\gamma<1$ 时，越早获得终点奖励，折扣越少。若又令 $\gamma=1$ 且无其他代价，所有最终到达的路径可能具有相同未折扣回报，目标不再明确鼓励更短路径。

<a id="sec-6-1"></a>

### 边界追问：探索覆盖能否只由 ε 大小判断

**问题：** ε=0.2 但关键状态几乎从不到达，是否已满足充分探索直觉？

**推理解析：** 未必，总体随机动作比例不保证罕见状态动作覆盖。记录访问数、行为分布和关键路径，检查环境可达性及奖励。训练与评价协议分别固定，避免通过改变探索率带来的回报变化误归于 Q 估计更准。
