## 1. 训练回报与评估回报

训练策略有探索，回报可能低于部署贪心策略；也可能训练偶然高分。应另用预设评估策略多回合测试，并记录平均回报、成功率、长度和波动。评估不应用结果继续调整测试协议。

另开评价环境，按预设频率固定模型、关闭训练探索或使用约定评价策略，收集多个完整回合；评价数据不写回训练回放，也不在评价过程中更新参数。环境本身若随机，即使策略确定，回报仍会波动。

同一训练运行下的多回合主要估计环境与评价噪声，重新训练多个种子才包含初始化及学习过程的变化。不要将数百个评价回合当成数百次独立训练。报告均值、分布或适当区间，并同时保留成功率和长度，帮助识别高回报是否来自奖励定义中的特殊行为。

<a id="sec-2"></a>

## 2. 常见实现问题

状态索引越界、动作映射颠倒、终止仍 bootstrap、未给未知动作访问机会、平局固定偏向，都会让表格方法失败。先用极小确定环境核对每次目标，再进入随机环境。

<a id="sec-2-1"></a>

### 机制展开：失败诊断先核对可观察行为

回报不升先检查奖励、终止、动作索引、探索覆盖与数据配对，再看学习率和函数近似。训练损失低可能只是拟合了错误目标，Q 值升高也不保证行为成功。固定评价策略记录路径与关键事件，比较环境步与梯度步预算。若只能重现最好种子，结论范围应明确，不能用平滑曲线掩盖多数运行失败。

<a id="deep-dive-2"></a>

### 深入讲解：用真值小环境诊断高Q低损失却差策略的情况

TD损失小只说明当前采样数据上的回归残差小，未访问动作和状态可能仍错。max会偏向乐观误差，策略可利用估计缺口；Q越来越高而真实回报不升时，应同时查覆盖、奖励尺度和终止处理。

若绝对奖励有界R且γ<1，相应无限期回报绝对值不超过R/(1−γ)。超出可作诊断线索，仍需确认奖励预处理、任务时域和定义一致，不能无条件当实现错误。

训练回报包含探索与更新，独立评价冻结模型和行为规则。按环境步数对齐Q量级、loss与评价，避免把回放更新次数当新样本数。

多评价回合估环境噪声，多次重新训练包含学习随机性，两种层级应分开。保留全部预设种子和失败运行，不只选峰值或最好回合。

最小MDP中计算真实Q，逐项核对目标、mask、访问及贪心动作，再扩到复杂任务。局部数值一致、估计准确和策略有用是三个不同验收目标。

<a id="sec-3"></a>

## 3. 分析曲线

Q 值持续变大但回报不变，检查奖励尺度、终止和自循环；策略来回变化，检查学习率、探索与估计方差。训练损失小可能只是重复拟合已访问区域，不能说明未见状态正确。

先把 TD 损失、估计 Q 与独立评估回报按同一环境步数对齐。Q 的量级可用奖励范围与折扣作粗检查：若绝对单步奖励有界于 R 且折扣小于 1，则相应无限期折扣回报绝对值不超过 R/(1−γ)。超出只是诊断线索，仍需核对是否采用不同奖励、有限时域或函数近似误差。

损失低而回报差时，检查数据是否只覆盖少数状态，以及动作选择是否受未见动作的乐观估计影响。用已知转移的小环境先算真实 Q，再对照估计误差与策略；这样能区分 Bellman 更新错误、探索不足与泛化失败，避免仅凭曲线形状猜测。

<a id="sec-4"></a>

## 4. 实验协议

固定环境定义、总交互步数、训练种子、评估频率与回合数。比较不同方法时，更新次数与环境样本量分别记录，避免把重复使用经验当作获得新信息。

调参用预定训练和验证环境或种子，最终结果在独立评价条件下汇总；若用评价回报反复选择检查点，这些评价也参与了选择，不能再当完全独立测试。记录失败运行和全部预设种子，而非只保留最好曲线。

一组训练产生多个评价回合时，回合波动与重新训练的波动属于不同层级。报告跨训练运行分布，并说明每次评价的回合数；达到某目标所需环境步数和固定时间内表现分别衡量样本效率与实际速度，两个结论不可互换。

<a id="sec-5"></a>

## 5. 指标可以揭示奖励投机

平均奖励上升但成功率不变，可能智能体在收集中间奖励；成功率高但步数很长，可能目标未鼓励效率。报告多个任务相关量，可以发现单个回报掩盖的行为差异。

若训练贪心策略陷入循环，查看所经状态两个动作值及更新目标，判断是否缺探索、自循环奖励不当或终止处理错。把问题缩成确定性两三状态，通常能快速隔离公式与环境问题。

独立种子既影响初始化也影响环境随机和探索。比较时预设种子数与汇总方式，保存所有运行，不挑最高。平滑仅用于观察，最终统计仍基于明确原始回合或固定评估窗口。

<a id="sec-1-1"></a>

### 基础算例：成功率与训练回报可能给出不同信号

策略学会循环领取小奖励，平均回报上升，但到达目标的成功率下降。这可能是奖励设计与真实任务不一致，而不是指标噪声。记录终止原因、回合长度、关键事件和路径，再与固定评价策略对应。探索率改变也会影响训练回报，评价应在固定条件下独立进行，并用多个种子观察稳定性，避免只挑最好曲线。

<a id="sec-6"></a>

## 6. 综合算例与实现核对

建立固定评价初始状态集合，每个策略使用相同环境种子条件，减少难度差异；再用独立训练种子观察学习波动。环境种子配对与训练随机性是不同层次，报告需分别说明。

训练期定期评估可用于选择检查点，因此最终结果还需预设报告规则。挑整个训练曲线最高峰会包含选择偏差，不应当作常规稳定性能。

若回报提高但策略只学会利用奖励漏洞，应回到任务定义检查成功、效率与约束。价值学习准确优化错误奖励并不等于完成真实目标，行为审计是评估必要部分。

<a id="sec-7"></a>

## 7. 进阶：回报曲线的选择偏差与行为审计

训练曲线最高峰包含时间选择，最好种子包含随机选择，都可能高估常规使用。预设评估频率、回合数、种子和汇总方式，并记录总环境样本预算，才能比较完整学习流程。

成功率、回报与步数可以揭示奖励投机：回报上升但任务不完成，可能在收集中间奖励。TD 损失下降也只说明拟合当前估计目标，不等于未见状态价值正确。环境与奖励定义应和算法一起审计。

<a id="sec-7-1"></a>

### 回报曲线需要与行为和预算一起解释

训练回报混合了策略改进与探索变化。若 ε 随时间下降，曲线上升可能部分来自少做随机动作，不能全部归于 Q 估计更好。独立评估应在固定预设行为协议下运行，不更新参数，报告多个回合与种子的结果。

横轴可以是环境步、回合、梯度更新或墙钟时间，选择不同单位会改变效率结论。回合长度不同的任务尤其不能只按回合数比较样本效率。平滑曲线需保留原数据，并说明窗口，避免把失败尖峰抹掉。

若奖励增加却成功率下降，应检查是否出现奖励投机或任务定义错位。可记录终止原因、路径、动作频率和关键事件，把分数变化对应到行为。挑选最好的种子或最好的训练时点，也属于选择过程，应在报告中保留其规则和成本。

<a id="sec-8"></a>

## 8. 练习与解析

**题目：** 稀疏奖励任务中始终回报零，是否足以认定价值更新公式错误？

**解析：** 不一定，也可能从未探索到奖励。应先核对环境与公式，再用可达奖励的小环境检查，分离探索困难与学习实现。

<a id="sec-9-2"></a>

### 边界追问：回报上升而成功率下降怎么判断

**问题：** 训练越来越会领取小奖励但更少到目标，是学习正确还是失败？

**推理解析：** 可能优化了规定奖励却偏离真实任务。检查奖励排序、终止、路径与评估探索，不能仅归因模型未收敛。明确代理奖励与目标差别，给成功、约束和预算等行为指标，再决定修环境、奖励或算法。

<a id="sec-9"></a>

## 9. 进阶研究练习与解析

**问题：** 解释 SARSA 和 Q-learning 在危险路径任务中为何可能偏好不同路线。

**解析：** SARSA 目标使用实际下一动作，把继续 epsilon 探索的风险纳入估计；Q-learning 目标使用贪心下一动作，学习不同目标策略。训练行为仍探索，因此某条贪心路线很优不表示训练期间安全。二者差异来自行为与目标，不只是公式有没有 max。

**验收：** 同环境固定交互预算，分别报告训练回报与无探索评价，观察成功率和危险事件。不要用单条最好路径替代平均行为，也不把表格收敛条件推广到任意神经网络。

<a id="sec-9-1"></a>

### 综合练习：Q 值增大与策略改善分开判断

**问题：** 训练 Q 越来越大但成功率下降，怎样排查？

**逐步解析与验收：** 检查奖励尺度、终止自举、循环刷分、索引和覆盖，再以固定策略评价记录路径、回报和终止原因。训练探索率变化也需单列。验收用人工转移核对更新，再用多种子行为验证，不能用估计值自己的上升证明真实收益。
