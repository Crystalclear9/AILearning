## 1. 探索的目标

探索要覆盖可能更优的行为，同时控制风险与样本成本。epsilon-greedy 忽略动作价值差异，softmax 按分数温度随机选择，乐观初值利用未知动作高估鼓励尝试。每种机制都有环境前提，不能保证复杂任务充分探索。

ε-greedy 在概率 1−ε 下选择当前贪心动作，其余从约定合法集合探索。某动作的总体概率还包含随机分支恰好选中它的部分，不能把 ε 直接解释为非贪心动作总概率；并列贪心和非法动作处理也要明确。

探索不足可由状态—动作访问表、首次成功时间和不同轨迹覆盖诊断。即使 ε 不低，难到达状态仍可能几乎未见；奖励稀疏、环境重置与时间上限都会限制覆盖。训练探索策略与独立评价策略应分开记录，避免回报差异只是动作随机性不同。

<a id="sec-2"></a>

## 2. n步更新

目标为 $r_{t+1}+\gamma r_{t+2}+\cdots+\gamma^{n-1}r_{t+n}+\gamma^nV(s_{t+n})$。它把奖励更快传播到较早状态，但需要保存若干步骤并处理回合尾部。off-policy 多步还涉及行为与目标策略差异，不能直接忽略。

<a id="sec-1-1"></a>

### 基础算例：两步回报如何组合奖励和尾部值

奖励为 1、2，γ=0.9，第二步后估计值为 3，则两步目标为 $1+0.9\times2+0.9^2\times3=5.23$。若第二步真正终止，目标为 2.8；若第一步就终止，则仅为 1。实现时不仅要限制数组长度，还要在真实终止处切断后续奖励与自举。n 增大改变未来估计权重和采样波动，比较时应固定环境交互预算。

<a id="sec-2-1"></a>

### 机制展开：多步目标遇到终止要提前截断

n 步目标累加奖励到 n 或真实终止较早者，只有仍可继续的尾部才加折扣价值。采样批末尾与任务终止不相同，外部截断还需合法最终观察。λ 回报组合多跨度目标，其前向与资格迹等价性依具体更新约定。先用三步轨迹逐位置算目标，再实现循环，能发现奖励错位、γ 次方与 mask 的组合错误。

<a id="deep-dive-2"></a>

### 深入讲解：多步回报与资格迹如何在时间跨度上折中

n步目标将前n项奖励相加，再加γ^nV(s(t+n))。n大减少尾部估计权重，却加入更多随机奖励；真实终止提前截断，采样批次末尾则按定义保留合法尾部值，不能接reset后另一回合。

λ回报以几何权重混合不同n步目标。λ=0对应一步，更大给长跨度更多权重；有限回合最后一项需合并剩余概率质量，不能把无限求和直接截掉却仍称精确同一目标。

累积迹et=γλe(t−1)+当前状态指示，当前TD误差通过迹更新近期相关状态。两步访问A再B，γλ=0.8时A资格0.8、B为1；重复访问与替换迹规则又不同。

前向回报与后向迹等价依赖更新版本和策略条件。在线参数边走边变、离策略或函数近似时需匹配相应算法，不能只因都含λ就认定完全一样。

探索、访问和时域也影响比较。控制环境交互与更新预算，分别观察价值误差和真实回报，才能判断收益来自更合适信用分配还是额外数据。

<a id="sec-3"></a>

## 3. 资格迹直觉

资格迹保存近期状态或参数的资格权重，使当前 TD 误差能更新过去相关步骤。TD(lambda) 在不同时间跨度之间折中，lambda 越大通常把更远过去纳入。具体累计或替换迹等定义不同，应配合相应公式。

表格状态价值的一种累积迹写为 $e_t(s)=\gamma\lambda e_{t-1}(s)+\mathbf1[s_t=s]$，并以 $V(s)\leftarrow V(s)+\alpha\delta_t e_t(s)$ 更新所有有资格的状态，其中 $\delta_t=r_{t+1}+\gamma V(s_{t+1})-V(s_t)$，真正终止时不自举并清除跨回合迹。

例如 γλ=0.8，先访问 A 再访问 B，第二步迹为 e(A)=0.8、e(B)=1，当前误差将同时更新两者。重复访问时累积迹会相加，替换迹使用另一规则，不能混写。前向 λ 回报与后向迹的精确关系依赖离线、在线和权重更新版本；离策略还需专门修正。

<a id="sec-4"></a>

## 4. 探索概率与动作覆盖

epsilon 不是只为让曲线抖动，而是给当前非最优动作被访问的机会。早期 Q 估计不准时过快降为零，可能把偶然优势固定；一直很高又使训练行为难以收敛。应按环境难度和预算设计，并单独规定评估策略。

多步目标会把更远奖励传播到当前，代价是等待与更高采样噪声。若中间真正终止，不能继续把 reset 后新回合奖励串入同一回报。回放或批量处理中，这个边界尤其需要测试。

资格迹把当前误差信号分配给近期访问，衰减决定影响多远。它与简单保存过去所有状态不同，更新公式和 off-policy 修正需配套。学习时可先手工列三步轨迹，算各时刻资格与更新，再封装代码。

<a id="sec-5"></a>

## 5. 综合算例与实现核对

假设某状态两个动作初值相同，固定 argmax 总选择编号小者，短预算下可能迟迟不探索另一个。随机打破平局加适当探索，可减少编号产生的偶然偏好，但仍不保证复杂任务充分覆盖。

对三步轨迹，先列奖励、折扣与终止，再分别计算一步、两步和完整回报。比较哪些项是真实采样、哪些来自价值估计，才能理解偏差方差折中，不只是记住不同算法名称。

资格迹可理解为对近期访问的衰减记账。当前误差出现时，多处状态按资格更新；但 off-policy 与函数近似还会带来额外条件，不能把表格直觉无限推广。学习实现应配套明确算法和小例子核对。

<a id="sec-6"></a>

## 6. 进阶：n步与lambda回报的联系

在相应回合定义下，lambda 回报是不同 n 步回报的几何加权，TD(lambda) 的资格迹提供在线形式。lambda 为零退化为一步，更大减少部分 bootstrap 依赖却增加采样跨度和方差。

这个等价需要匹配算法版本、状态更新时机和 on-policy 条件，off-policy 多步通常需相应修正。终止前截断回报，批次边界保留合法尾部估计；将 reset 后奖励跨回合串入会破坏目标。

<a id="sec-6-1"></a>

### n 步回报把时间跨度与估计误差连接起来

n 步目标为 $\sum_{k=0}^{n-1}\gamma^kr_{t+k+1}+\gamma^nV(s_{t+n})$，若中间真正终止则提前截断并移除后续价值。n=1 是一步自举，接近完整回合时更接近 MC；跨度增大减少尾部估计权重，也增加更多随机奖励的波动。

无限或适当截断情形的 λ 回报以几何权重组合不同 n 步目标，与资格迹存在相应前向—后向联系。该等价依赖具体更新约定；离策略、截断和函数近似时需检查修正，不能只把两个公式名称对上就断言实现完全等价。

探索设计还要保证重要状态动作有机会被访问。总体 ε 不低并不保证罕见状态覆盖充分；访问次数、行为分布与成功路径可提供更具体诊断。评价多步方法时控制样本预算，避免把更多环境交互误计为算法效率提升。

<a id="sec-7"></a>

## 7. 练习与解析

**题目：** 两步奖励为 1、2，下一状态价值为 4，gamma=0.5，两步目标是多少？

**解析：** $1+0.5\times2+0.25\times4=3$。若第二步真正终止，去掉最后 bootstrap 项，目标为 2。

<a id="sec-7-1"></a>

### 边界追问：更大 n 是否总减少学习误差

**问题：** 把一步目标改为很长多步目标，尾部估计权重减少，是否必然更好？

**推理解析：** 不必，奖励随机性与离策略偏移可能增加，终止和批边界也更易处理错误。n 控制信用跨度与误差来源，需在固定预算比较。先手算短轨迹和不同边界，再核对经验目标；更多环境样本不能偷偷算作同成本算法收益。
