## 1. 采样与更新分阶段

用旧策略收集固定预算数据，保存旧 log_prob 和价值；计算回报与优势；在有限轮次的小批上更新；然后重新采样。旧数据不是可以无限重复训练的静态监督集，策略变化后分布关系会恶化。

<a id="sec-1-1"></a>

### 基础算例：一次采样与多轮更新中的旧量哪些固定

采样时记录旧观察、动作、log 概率和价值，再计算优势与目标。重复优化同一批时，旧 log 概率和作为 Actor 权重的优势保持固定；当前策略概率随参数更新而变化。若用新网络覆盖旧概率，比率可能总接近 1，却失去新旧比较含义。更新轮数增加还会扩大分布偏移，需预设预算与监控，再重新采样，而不是无限复用旧轨迹。

<a id="sec-2"></a>

## 2. 完整目标的组成

策略裁剪项、价值回归与熵项共同决定更新。价值裁剪、优势标准化等属于具体实现选择，不应在不同代码之间默认相同。连续策略的动作变换和 log probability 修正必须一致。

<a id="sec-2-1"></a>

### 机制展开：总损失的符号与共享参数要明确

常见最小化目标包含负 PPO 代理、价值回归和负熵奖励，系数决定共享骨干收到的合成梯度。Actor 优势停止梯度不意味着 Critic 不训练，而是由独立价值项训练。价值裁剪、标准化与熵估计有实现差异，复现时应逐项写出。策略 loss 下降只是旧批代理改善，仍需固定环境评价确认真实回报。

<a id="deep-dive-2"></a>

### 深入讲解：采样更新评价三阶段怎样避免策略版本混淆

采样阶段固定当前策略记录观察、动作、奖励、旧log概率和价值，再用合法尾值计算回报与优势。更新阶段在这批数据上做预定轮数，评价阶段冻结模型并使用约定行为，三者职责不能混合。

总目标常含策略代理、价值回归和熵项。优化器最小化时各项符号及权重必须明确，奖励缩放也改变价值loss量级。只看总loss难以判断是哪一项在主导。

更新前同批动作新旧概率比应接近1，这是版本与分布接口检查。其后看KL、clip比例、熵、价值误差及参数梯度，同时与独立回报对齐。

失败先核对动作范围、概率变换、mask、优势方向及归一，再调学习率和epoch数。增加网络或继续训练不能修复使用错误旧策略或串错回合的目标。

结果保留环境步数、梯度更新、种子、评估回合和选择规则。PPO代码能跑与算法在当前任务稳定有效，需要不同层次证据共同支持。

<a id="sec-3"></a>

## 3. 监控

记录平均回报、成功率、KL 变化、裁剪比例、熵、价值误差与梯度。熵迅速归零可能过早确定化，KL 过大可能更新过猛，Critic 表现差可能污染优势。但任何单信号都需结合任务解释。

每次策略更新应记录新旧策略在同一批动作上的概率变化，KL 的估计方向和聚合口径需固定。裁剪比例只说明多少样本的比率越界，不等于策略距离的严格上界；价值误差也应结合回报尺度解释。若奖励尺度改变，原有阈值与损失系数未必仍合适。

画图按环境交互步数对齐，并保留训练与独立评价回报。熵下降有时表示学到确定行为，有时表示过早塌缩，需结合成功率、状态覆盖与失败轨迹判断。告警用于定位问题，不能机械地看到单个数偏大就认定算法错误。

<a id="sec-4"></a>

## 4. 失败排查

先用小环境验证回报和 mask，再检查动作采样与环境尺度、旧概率、优势方向、归一化与优化次数。不要直接增加网络或延长训练掩盖基础错误。

可先固定一批采样轨迹，重新计算新旧策略在相同动作上的 log 概率；更新前概率比应接近 1。核对优势在正负情形下的梯度方向，再检查裁剪分支是否符合目标。采样时保存的旧概率应保持冻结，不能在多轮更新中被新策略覆盖。

接着用包含真正终止与时间截断的小例子核对回报、bootstrap 和 GAE。若局部计算都正确，再逐项改变学习率、每批更新轮数和价值损失系数，观察 KL、裁剪比例及回报。单纯调大网络不能修复动作密度、mask 或旧策略定义错误；排查结果应能在同一固定输入上重现。

<a id="sec-5"></a>

## 5. 采样批更新多久才合适

PPO 允许对同一批进行若干优化，但旧策略分布与新策略会逐渐分离。轮次太多可能过度适应有限样本，所以监控 KL、裁剪比例与回报，并按预设规则停止。裁剪不是允许无限重用旧数据的许可证。

熵系数影响探索，价值系数影响共享表示，学习率影响更新幅度。调参应先核对实现与数据再调整少量高影响参数。若旧 log probability 重算时使用了新网络，概率比率可能接近一却失去意义。

对连续控制，还需检查环境动作范围与模型输出尺度。动作被环境悄悄裁剪，实际执行动作与计算概率的动作不同，会影响估计。明确变换、保存和 log probability 计算，才能建立正确闭环。

<a id="sec-6"></a>

## 6. 进阶：重要性比率与旧数据重用边界

新旧动作概率比修正固定状态下的动作分布差异，不自动修正状态访问分布在多轮更新后的全部变化。PPO 因而限制同批更新并重新采样，不能把裁剪当无限使用旧轨迹的保证。

连续策略经 tanh 变换要含雅可比修正，环境直接裁剪则使实际动作和计算分布不一致。研究复现应记录动作缩放、熵系数、优势归一化、价值目标与更新轮次，这些细节往往与算法名称同样重要。

<a id="sec-6-1"></a>

### 一批轨迹的复用受状态分布与动作密度共同限制

新旧概率比修正固定状态下所采动作的相对密度，不会自动修正策略变化后全部状态访问分布。PPO 多轮复用同一批时仍是在旧数据覆盖上优化局部代理，不能把裁剪解释为允许无限离策略重放。

连续动作若由 u 经 $a=\tanh u$ 得到，log 密度需要减去变换雅可比的对数项，多维时按动作事件维求和。若额外做动作缩放，还应核对相应常数与环境协议。直接裁剪动作并继续使用原高斯密度，不是同一可逆变换模型。

完整最小化损失常由负代理收益、价值误差和负熵奖励组成，符号与系数均需明确。共享网络使各项相互影响，策略 loss 变小不保证环境回报上升。固定采样预算、更新轮次、优势处理和评价规则后再比较设置，才能解释稳定性。

<a id="sec-7"></a>

## 7. 练习与解析

**题目：** PPO 裁剪范围固定为 0.2，是否保证真实 KL 永不超过某固定小值？

**解析：** 不保证，裁剪的是样本上的代理收益，共享参数更新仍会改变其他概率。需实际监控 KL，必要时使用预设停止或调整机制。

<a id="sec-8-2"></a>

### 边界追问：策略 loss 更小是否代表真实回报更好

**问题：** 同一旧批反复优化，代理目标不断改善，可否不再采新轨迹？

**推理解析：** 不能，动作比率不自动修正全部状态访问分布偏移，旧批可被过度适应。限制复用并按预设监控与重新采样，独立评价真实回报。熵、价值和共享参数还影响更新，单个 loss 无法替代完整行为验证。

<a id="sec-8"></a>

## 8. 进阶研究练习与解析

**问题：** 为什么动作无关状态基线不改策略梯度期望，而任意动作相关基线可能改？

**解析：** 固定状态，$\sum_a\pi(a\mid s)\nabla\log\pi(a\mid s)b(s)=b(s)\nabla\sum_a\pi(a\mid s)=0$。若 b 依赖动作，就不能移出求和，一般不再抵消。合法控制变量也可能更复杂，但需额外推导修正。

**实现：** 在两动作分布手算与自动微分核对，改变优势正负检查更新方向。连续动作经变换的 log probability、事件维求和和 detach 都要明确，避免数值运行正常却优化错误目标。

<a id="sec-8-1"></a>

### 综合练习：PPO 的旧量与梯度边界

**问题：** 每轮更新都用当前网络重新覆盖旧 log 概率，为什么可能比率近一却无效？

**逐步解析与验收：** 分母不再对应采样策略，失去新旧密度比较。旧 log 概率及 Actor 使用的优势应按算法约定固定，当前概率保持可导；Critic 另优化价值目标。验收用一次受控参数改动确认比率确实变化，再核对 KL、裁剪和真实回报，不能只看策略 loss。
