## 1. 为什么直接学习策略

连续动作空间中，枚举每个动作的 Q 值不现实；随机策略也可能更适合需要探索或存在不完全信息的任务。参数化策略 $\pi_\theta(a\mid s)$ 直接给出动作概率或连续分布参数，目标是最大化期望回报 $J(\theta)$。

策略梯度的核心形式是对 $\nabla_\theta\log\pi_\theta(a_t\mid s_t)$ 乘以相应回报或动作价值后取期望。轨迹中获得较好回报的动作，其对数概率沿相应方向增加；这不是把高奖励动作当作永远正确的监督标签。

<a id="sec-2"></a>

## 2. REINFORCE 的估计

对采样轨迹，可用 $\sum_t\nabla\log\pi_\theta(a_t\mid s_t)G_t$ 构造估计。具体是否出现额外的 $\gamma^t$ 与目标、状态采样分布的约定有关，推导与实现必须一致。完整回报噪声大，因此估计可能方差很高。

减去不依赖当前动作的状态基线 $b(s_t)$，在相应条件下不改变梯度期望，却可减少方差。常用价值函数 $V(s)$ 作为基线，得到优势 $A(s,a)=Q(s,a)-V(s)$，表示该动作相对当前状态平均水平有多好。

<a id="sec-1-1"></a>

### 基础算例：两动作策略的更新方向手算

两个动作初始 logits 为 (0,0)，选中第二动作且优势为 2。负 log 概率乘优势的梯度为 (1,-1)，梯度下降会降低第一 logit、提高第二 logit，使被选动作概率上升。若优势改为 -2，方向反转。正奖励并不必然对应正优势，关键是相对基线。这个例子可先核对 loss 负号、事件维和 detach，再接长轨迹训练。

<a id="sec-2-1"></a>

### 机制展开：回报权重必须与动作和时刻对应

轨迹中每个 log 概率乘其合法未来回报或优势，而不是整条轨迹任意标签。最大化 J 在最小化优化器里通常需负号。连续多维动作 log 密度按事件维求和，批量再平均；把事件维平均会改变动作维数对应的尺度。状态基线不依赖当前动作时可保持相应无偏性，实现中优势通常固定，避免额外 Critic 梯度混入 Actor。

<a id="deep-dive-2"></a>

### 深入讲解：策略梯度的log导数技巧怎样连接动作概率与回报

轨迹密度依策略包含动作概率乘积。对期望回报求导，在相应可交换条件下用∇p=p∇logp，得到回报加权的score期望。环境动力学未知时，其不直接依策略参数的项可在求导中消去，这不是说环境后果无关。

log轨迹概率的梯度为各时刻logπ(a|s)梯度之和。用reward-to-go可去掉与当前动作无因果联系的过去奖励，减少噪声而保持相应期望；时刻索引必须一致。

减去只依状态的基线不改期望，因为Σaπ(a|s)∇logπ(a|s)=∇Σaπ(a|s)=0。若基线依当前动作，不能直接沿用同一证明，需额外修正。

代码最小化负号损失−logπ×优势，优势常作固定权重。正优势提高所选动作相对概率，负优势反向；不是“奖励正就所有动作都增加”，关键是相对于基线的好坏。

离散log_prob对应实际采样动作，连续多维动作还要对事件维求和。核对局部方向后再加入真实轨迹和边界，才能把公式正确连接到环境学习。

<a id="sec-3"></a>

## 3. 一个局部方向例子

若某动作优势为正，应增加其概率；优势为负则降低。所有动作都得到正奖励不代表都应等比例增加，关键是相对于基线的表现。熵奖励鼓励保留一定随机性，但过大可能阻碍策略集中到优良动作。

以两动作 softmax 为例，选择动作 1 的概率为 p，单样本损失为 $-A\log p$。对两 logits 的梯度为 $A(p-1)$ 与 $A(1-p)$；A 为正时梯度下降提高动作 1 的相对 logit，A 为负时方向相反。优势看的是相对预期的好坏，绝对奖励为正并不足以确定方向。

基线若只依赖状态，在相应条件下不改变策略梯度期望，因为对动作求和后的 score 期望为零；若随当前动作变化，则不能直接沿用该证明。实际估计仍可能有方差、近似偏差和策略分布变化，方向算例只是局部公式核对。

<a id="sec-4"></a>

## 4. 为什么基线不能随意依赖动作

对固定状态，有 $E_{a\sim\pi}[\nabla\log\pi(a\mid s)b(s)]=b(s)\nabla\sum_a\pi(a\mid s)=0$，因此减去状态基线不改变期望梯度。若基线依赖当前动作，一般不能提到求和外，结果不再自动为零，可能引入偏差。

实现中通常把优势作为 Actor 更新的固定权重，避免 Actor 损失沿 Critic 的计算图产生非预期梯度。Critic 使用自己的价值损失训练。共享骨干时更要明确梯度来自哪些目标，以及不同损失系数如何影响共同参数。

<a id="sec-5"></a>

## 5. 最大化回报与最小化损失

推导常写梯度上升最大化 J，代码优化器通常最小化 loss，因此 Actor 损失常带负号。漏掉符号会降低高优势动作概率，程序仍能运行却学反方向。

离散动作分布的 log_prob 与实际采样动作必须对应，不能把全类别 log 概率平均后乘一个回报。连续多维动作则需明确事件维求和与批维平均。

<a id="sec-6"></a>

## 6. 进阶：策略梯度的对数导数推导

从轨迹分布 $p_\theta(\tau)$ 出发，$\nabla J=E[R(\tau)\nabla\log p_\theta(\tau)]$。环境转移不依赖策略参数时，log 导数只保留动作策略项。因果性允许去掉动作之前奖励，得到 reward-to-go 估计。

状态基线不依赖当前动作时，期望贡献为 $b(s)\nabla\sum_a\pi(a\mid s)=0$，故可减方差。任意动作相关基线不自动无偏；折扣、占用分布与采样权重的约定也需在推导和实现中一致。

<a id="sec-6-1"></a>

### 折扣策略梯度中的时间权重从哪里来

对目标 $J=E[\sum_t\gamma^tr_{t+1}]$，对轨迹概率取对数导数，再利用过去奖励不受当前动作影响的因果性，可写成 $E[\sum_t\gamma^t\nabla\log\pi(a_t\mid s_t)G_t]$，其中 $G_t=\sum_{k\geq0}\gamma^kr_{t+k+1}$。若改用折扣占用分布抽状态，外部权重可被吸收到期望定义，推导约定必须一致。

动作无关基线的零期望来自 $\sum_a\nabla\pi(a\mid s)b(s)=0$。这允许减去状态价值以降低方差，但价值函数并非所有情况下精确的最小方差基线；最优权重还可能涉及 score 范数。

实现 Actor loss 时把回报或优势作为固定权重，避免通过基线引入额外梯度路径。若共享骨干，Critic 的价值损失仍可更新共同表示，两种梯度来源应明确。先在两动作分布核对符号与归一化，再扩到连续动作和长轨迹。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 状态价值估计为 8，某次动作回报为 6，这次优势估计是多少？为什么正回报也可能降低该动作概率？

**答案：** 优势约为 -2。相对于当前状态的预期表现，它更差，因此策略更新可以降低其概率；优化目标关注相对选择，而非奖励符号本身。

<a id="sec-7-1"></a>

### 边界追问：动作相关基线能否直接减掉

**问题：** 把基线从 b(s) 换成任意 b(s,a)，仍可援引 score 期望为零吗？

**推理解析：** 一般不能，动作相关项无法从动作求和提出，可能改变梯度期望。合法控制变量可有更复杂修正，但需重新推导。状态基线的零期望也不等于它在所有设置下精确最小方差，Actor 固定权重和 Critic 自身训练应分别管理。
