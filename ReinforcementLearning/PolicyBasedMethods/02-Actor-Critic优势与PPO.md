## 1. 两个角色分别学习什么

Actor 更新策略，Critic 估计价值或动作价值。Critic 可用 TD 目标学习，Actor 使用优势估计。若 Critic 偏差大，策略也可能被误导；二者同时变化会使训练成为相互耦合的过程。

GAE 用多个 TD 残差的指数加权和构造优势，参数 $\lambda$ 在偏差与方差之间折中。使用终止掩码时要区分真正终止、截断与采样批次结束，否则优势与回报目标可能错误。

<a id="sec-2"></a>

## 2. PPO 的概率比率

令 $r_t(\theta)=\pi_\theta(a_t\mid s_t)/\pi_{old}(a_t\mid s_t)$。PPO-Clip 最大化

$$E[\min(r_tA_t,\operatorname{clip}(r_t,1-\epsilon,1+\epsilon)A_t)].$$

它对过大的有利概率变化截断收益，减少一次更新走得过远的倾向。裁剪目标不是严格约束所有状态下的策略差异，也不保证策略性能必然提升。

<a id="sec-1-1"></a>

### 基础算例：正负优势分别代入裁剪式

ε=0.2、r=1.4。若 A=2，两个乘积为 2.8、2.4，取 min 得 2.4；若 A=-2，乘积为 -2.8、-2.4，取 min 得 -2.8。负优势下不能把比率统一裁到 1.2 后就当作等价目标。裁剪限制的是样本代理中的有利增益，不保证真实 KL 总被固定上界约束；仍需监控策略变化、价值误差和实际回报。

<a id="sec-2-1"></a>

### 机制展开：概率比应从采样动作的密度构造

r=exp(logπnew-logπold)，两者需对应同一观察、动作和变换。连续动作经 tanh 时密度含雅可比修正，旧值来自采样策略并保持固定。只比较均值或对所有动作概率取平均不是同一比率。裁剪作用于乘优势后的两个收益，不是简单将所有概率限制区间；共享参数仍可改变已裁剪样本，需要实际监控分布变化。

<a id="deep-dive-2"></a>

### 深入讲解：PPO裁剪为什么只是代理目标而非策略距离硬约束

Actor改变动作分布，Critic估状态或动作价值，优势描述当前动作相对基线。共享骨干会收到两种目标梯度，系数和停止梯度需要明确；Critic拟合好也不保证Actor决策正确。

PPO用新旧同动作概率比r乘优势，并与裁剪版本取较小。正优势时过大r被限制，负优势时过小r的下降方向受限制，分段符号决定实际梯度；简单把r无条件clip再乘优势并不等价。

旧log概率来自采样时策略且冻结，多轮更新仍相对同一旧策略。若每轮重算旧值，比率失去原意；同样动作的事件维与变换密度也要一致。

裁剪不保证所有状态上的KL或概率变化都有硬上界。可监控近似KL、clip比例、熵和真实回报，必要按明确规则停止更新；单一指标不能替代完整诊断。

先固定小批正负优势算例核对分段，再检查GAE、终止和时间截断，最后多种子评价。代理目标改善与长期策略收益之间仍需要独立环境证据。

<a id="sec-3"></a>

## 3. 数据使用和实现检查

先用旧策略收集一批轨迹，保存旧 log probability、价值和奖励；计算优势后，在有限轮次的小批量上优化，再重新采样。旧概率应视为固定数据，不应随着当前网络一同变化。

连续动作常用高斯策略。若通过 `tanh` 限制动作范围，计算对数概率时需要对应变量变换修正，不能只裁剪动作后继续使用未修正的概率公式。

<a id="sec-4"></a>

## 4. PPO裁剪不是硬性的距离约束

当某些样本进入裁剪区间后，其他样本与共享参数的更新仍可能让它们的概率继续变化。因此还会监控近似 KL、裁剪比例、熵和价值误差；某些实现达到目标 KL 后提前停止。单看裁剪阈值，不能知道实际策略改变了多少。

优势标准化可以改善数值尺度，但会改变有限批量中的权重关系，尤其批次很小时需谨慎。旧 log probability、动作和观察必须一一对应；重算时还要保持动作变换与掩码规则一致，否则概率比率会失去正确意义。

<a id="sec-5"></a>

## 5. 价值目标与优势的停止梯度

Actor 更新时通常把优势作为固定权重，Critic 用自己的回归目标更新。若共享骨干，多个损失会共同影响表示，系数要明确。旧策略概率必须固定，否则比率不再表示新旧变化。

优势估计错误可能导致 Actor 稳定地优化错误方向，因此同时监控价值误差、熵和实际回报，不只看策略损失。

<a id="sec-6"></a>

## 6. 专题推导：PPO裁剪究竟截断哪一边

令 r 为新旧概率比、A 为固定优势。A 为正时，代理收益是 $A\min(r,1+\epsilon)$：下侧错误减少概率仍受惩罚，上侧过多增加不再获益。A 为负时，收益是 $A\max(r,1-\epsilon)$：过多降低概率的收益被截断，而增加坏动作仍受罚。不能先对 r 统一裁剪后当作完全等价目标。

```python
import torch
r = torch.tensor([0.5, 1., 1.5, 0.5, 1., 1.5], requires_grad=True)
advantage = torch.tensor([2., 2., 2., -2., -2., -2.])
clipped = r.clamp(0.8, 1.2)
surrogate = torch.minimum(r * advantage, clipped * advantage)
expected = torch.tensor([1., 2., 2.4, -1.6, -2., -3.])
assert torch.allclose(surrogate, expected)
(-surrogate.sum()).backward()
assert r.grad[2] == 0 and r.grad[3] == 0
assert r.grad[0] < 0 and r.grad[5] > 0
print(surrogate.detach(), r.grad)
```

示例分别核对目标值与分段梯度，避开恰好位于边界的不可微点。实际网络共享参数，某样本自身被裁剪不代表其概率不再受其他样本更新影响，所以仍需监控 KL。old log probability 必须来自采样时策略且固定，优势也通常作为 Actor 更新的常量权重。

<a id="sec-7"></a>

## 7. 进阶：PPO裁剪目标的分段分析

优势为正时，概率比超过上界不再增加该项收益；优势为负时，低于下界的改善被限制。min 作用于乘积，负优势不能只机械截断比率。共享参数仍会改变已裁剪样本，所以它不是硬 KL 约束。

Critic 偏差会污染优势，GAE 通过跨度权衡偏差方差。旧概率必须固定，采样动作、变换和 log probability 一一对应。策略损失、熵、KL 与真实回报需共同检查，任何单指标都不保证策略提升。

<a id="sec-7-1"></a>

### PPO 的局部代理与真实策略改善之间的距离

比率 $r=\exp(\log\pi_\theta-\log\pi_{old})$ 针对采样动作，旧 log 概率必须固定。裁剪目标截断的是过度有利的样本收益，不直接把每个状态的完整分布限制在某个 KL 球内。共享参数可使已裁剪样本继续变化，多个更新轮次会进一步放大分布偏移。

正优势下目标为 $A\min(r,1+\epsilon)$，负优势下为 $A\max(r,1-\epsilon)$。例如 A=-2、r=1.5、ε=0.2，应使用 -3 而不是 -2.4，因为增加坏动作仍受惩罚。先乘优势再取 min 是必要语义。

可监控近似 KL、裁剪比例、熵、价值误差与真实回报，但这些量也有有限样本噪声。提前停止规则应预先设定，不是看到结果后挑选最有利轮次。PPO 易于实现的外观不代表数据边界、优势和动作变换可以省略。

<a id="sec-8"></a>

## 8. 练习与参考答案

**练习：** 优势为正，$r=1.5$，$\epsilon=0.2$，裁剪目标使用的收益因子是多少？若优势为负，能否只机械选择 1.2？

**答案：** 正优势时使用 1.2，进一步增加比率不再增加这部分目标。负优势时要先算两个乘积再取最小，因为乘负数会改变大小关系，不能只记一个截断方向。

<a id="sec-8-1"></a>

### 边界追问：PPO 裁剪是否把所有比率锁在范围

**问题：** ε=0.2，更新后某样本比率仍到一点五，是否直接证明实现一定错？

**推理解析：** 不一定，裁剪限制样本代理收益的一侧，不是硬约束全部比率；共享参数和其他样本可继续改变它。核对正负优势分段、旧概率固定和真实 KL，再判断。裁剪不保证任意多轮复用都安全或环境性能必升。
