## 1. 轨迹需要保存什么

保存观察、动作、奖励、终止与动作 log probability，明确回报对应时刻。回合结束后从后向前计算 reward-to-go，避免把动作之后的奖励错配到前后位置。真正终止的尾部价值为零，采样截断则另处理。

对每条转移同时保存当前状态、实际采样动作、对应旧 log 概率、奖励、下一实际状态及边界标记，必要时保存当时价值。自动 reset 的环境返回的新初态不能代替截断处最终状态，否则尾部价值会接到另一回合。

批量多环境应让时间轴与环境轴独立，按每条轨迹反向处理回报或 GAE，不能将展平后的邻接行自动当成相邻时刻。先构造两条短轨迹，手算每个目标及 mask，再核对向量化版本；保存形状和索引约定可避免后续 PPO 重算概率错配。

<a id="sec-2"></a>

## 2. 一个策略梯度方向实验

```python
import torch
from torch.distributions import Categorical
logits = torch.tensor([0., 0.], requires_grad=True)
dist = Categorical(logits=logits)
action = torch.tensor(1)
advantage = torch.tensor(2.)
loss = -dist.log_prob(action) * advantage
loss.backward()
print(logits.grad)
assert logits.grad[1] < 0
```

梯度下降会增加第二个 logit，使正优势动作概率上升。负优势会反向；这个实验检查符号，不构成完整 RL 训练。

<a id="sec-2-1"></a>

### 机制展开：局部梯度实验只验证明确的一项

两动作 logits 实验可验证正优势提高所选概率、负优势反向，却不验证环境奖励、轨迹边界或长期策略改善。扩展时逐项加入真实采样、回报、基线和 GAE，保留手算短轨迹。若一接入环境就失败，先核对数据时刻与 mask，不要把局部实验通过误称为整个算法正确。Critic 目标与 Actor 固定权重还需独立检查。

<a id="sec-3"></a>

## 3. GAE的递推

没有边界时，定义 TD 残差 $\delta_t=r_{t+1}+\gamma V(s_{t+1})-V(s_t)$，优势用 $\hat A_t=\delta_t+\gamma\lambda\hat A_{t+1}$ 反向递推。有 reset 或采样边界时，需要区分两个掩码：

$$
\delta_t=r_{t+1}+\gamma b_tV(s_{t+1}^{\mathrm{final}})-V(s_t),\qquad
\hat A_t=\delta_t+\gamma\lambda c_t\hat A_{t+1}.
$$

其中 $b_t$ 决定是否保留下一状态的价值，$c_t$ 决定是否继续累加下一条已采样转移的优势。`final` 指该次转移真正到达的状态，不能误取自动 reset 后新回合的初始观察。

| 当前转移的边界 | $b_t$ | $c_t$ | 处理原因 |
| --- | ---: | ---: | --- |
| 普通连续转移，下一条样本仍属于同一轨迹 | 1 | 1 | 价值和优势都能向后衔接 |
| MDP 定义的真正终止 | 0 | 0 | 不再有后续回报 |
| 外部时间限制截断并 reset | 1 | 0 | 保留终点价值，但不拼接新回合优势 |
| 采样批次末尾，后续转移未收集 | 1 | 0 | 用尾部价值自举，停止本批有限和 |

有限时域任务本身规定的到期属于真正终止，和人为设置的外部采样时限不同。判定依据是任务定义，不能只看是否发生 reset；相关环境语义见 [Gymnasium 时间限制说明](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)。

例如 $r=1$、$\gamma=0.9$、$V(s_t)=2$、$V(s_{t+1}^{\mathrm{final}})=3$。真正终止的残差是 $-1$，外部截断的残差是 $1.7$；两者都不能把 reset 后另一回合的优势加进来。有限批次中通常令批外 $\hat A_{T}=0$，但最后一条残差仍应包含适用的尾部价值。这里估计的是有限 rollout 的 GAE，不能把省略批外残差说成获得了完整无限轨迹的精确优势。

<a id="sec-1-1"></a>

### 基础算例：两步 GAE 从后向前算

两步 TD 残差为 1、2，γ=0.9、λ=0.5，批外优势取零且中间无边界。末步优势为 2，前步为 1+0.45×2=1.9。若第一步后已经 reset，就不能把另一回合的第二步优势接过来。外部截断仍可在该步残差中保留合法最终状态值，自举 mask 与跨回合递推 mask 因而需要区分。先用短轨迹核对，再实现多环境批量循环。

<a id="deep-dive-3"></a>

### 深入讲解：GAE的两个掩码分别管理价值与轨迹连接

TD残差δt=rt+γbtV(s't)−V(st)，GAE逆推At=δt+γλctA(t+1)。bt决定下一状态价值是否存在，ct决定下一条已采样优势是否属于同一可连接片段；把二者都写done的反面，会混淆截断与终止。

真正终止时b=c=0；外部时间上限reset时可b=1、c=0，下一值取截断前真实final observation；批末未采后续同样停止有限和，但可保留尾值。任务本身到期则按真实终止，不由框架字符串决定。

例如r=1、γ=.9、V=2、Vnext=3，终止残差−1，合法截断残差1.7。两者都不能再叠reset后新回合优势。这个差异会直接改变Actor方向，不是小数值实现细节。

多环境数据保留时间与环境轴，展平后不能把相邻行当同一轨迹。先手算两条短轨迹，再与向量化比较，能检验边界与索引。

优势归一、Critic目标与Actor固定权重还各有约定。局部logit实验通过只验证符号，不证明轨迹目标和环境回报都正确，需逐层接入验证。

<a id="sec-4"></a>

## 4. 两动作例子的梯度方向

初始两个 logit 相等，各动作概率一半。选择动作一且优势为二时，负 log probability 损失对该 logit 梯度为负一、对另一个为正一；梯度下降提高被选动作并降低另一个。概率总和约束通过分母同时影响两者。

连续动作多维 log probability 要对动作事件维合并，再按批平均；如果直接平均所有维，目标尺度会随动作维数改变。采样和概率计算还要使用同一动作变换，尤其经过 tanh 限幅时。

GAE 反向计算需要尾部值和终止标记。真正终止后优势不跨回合；批次截断但任务继续时保留相应 bootstrap。把所有 reset 都看作相同边界，会系统性改变优势和策略方向。

<a id="sec-5"></a>

## 5. 综合算例与实现核对

设两步 TD 残差为一和二，gamma 为零点九、lambda 为零点八，末步优势二，前步优势为一加零点七二乘二，即二点四四。lambda 为零时只保留一步残差；更大时让后续信号传回更远。

若第二步真正终止，其未来价值和跨回合优势必须切断；若只是采样批末尾，则需相应尾部估计。这个例子可以手工核对反向循环顺序和 mask。

Actor 使用这些优势作固定权重，Critic 另有价值目标。不要让优势归一化或 detach 的位置变成未说明细节；它们影响梯度路径和有限批量尺度。先把两步轨迹算清，再扩到多环境批次。

<a id="sec-6"></a>

## 6. 进阶：GAE与bootstrap误差传播

GAE 写为 $\hat A_t=\sum_{l\ge0}(\gamma\lambda)^l\delta_{t+l}$，其中残差含估计价值。lambda 控制较远残差的权重，不能消除 Critic 系统偏差；优势标准化还改变有限批量权重尺度。

Actor 通常将优势作为固定权重，Critic 另算价值损失。共享骨干时总梯度来自多个目标，系数与 detach 位置需明确。连续多维动作的 log probability 要按事件维合并，不能误把动作维当批维平均。

<a id="sec-6-1"></a>

### GAE 中价值误差如何传到优势

令真实值与估计值之差为 $e_t=\hat V(s_t)-V(s_t)$，则估计 TD 残差相对真实值残差多出 $\gamma e_{t+1}-e_t$。GAE 把这些项按 $(\gamma\lambda)^l$ 累加，因此 λ 改变误差传播方式，而不是把 Critic 偏差自动变成零。

当 λ=0，只保留一步残差；当 λ 接近 1，在适当回合边界下更接近多步回报减当前值。有限 rollout 末尾仍依赖尾部价值，不能把 λ=1 简化为任意截断下都完全没有自举误差。

实现时分别核对价值自举掩码与跨轨迹优势递推掩码。外部截断可以使用最终状态值，却不能继续接入 reset 后新回合的优势；真正终止则连尾部值也切断。手算两三步轨迹并故意改变边界，是验证反向循环比只运行长训练更直接的方法。

## 7. 练习与解析

**题目：** 对正优势漏掉 loss 前负号会怎样？

**解析：** 优化器最小化正 log probability 项，会倾向降低该动作概率，方向与预期相反。先用两动作例子验证，再接入复杂采样代码。

<a id="sec-7-1"></a>

### 边界追问：λ 等于一时是否完全没有尾部估计

**问题：** 有限 rollout 的 GAE 取 λ=1，就能不管批末 V 值吗？

**推理解析：** 不能，真实未终止的批末仍可能依赖 bootstrap。完整回合与有限截断条件不同。区分价值自举与跨轨迹递推 mask，使用最终状态而非 reset 新观察。λ 改变远处残差权重，不能自动消除 Critic 的系统偏差。
