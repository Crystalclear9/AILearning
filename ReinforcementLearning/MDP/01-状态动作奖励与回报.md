## 1. 智能体与环境的交互

时刻 $t$，智能体观察状态 $s_t$，按策略 $\pi(a\mid s_t)$ 选择动作 $a_t$，环境产生奖励 $r_{t+1}$ 和下一状态 $s_{t+1}$。策略可以是确定性映射，也可以输出动作分布。奖励是每一步的反馈，价值是对未来回报的估计，二者不同。

MDP 由状态空间、动作空间、转移规律、奖励规律与折扣因子等定义。马尔可夫性表示给定当前状态和动作后，未来转移不再需要更早历史；它是关于状态表示的假设，不是声称真实世界没有记忆。

<a id="sec-2"></a>

## 2. 状态可能没有被完整观察

摄像头的一张图像可能无法判断物体速度，因此单帧观察不是充分状态。可以叠加历史帧、使用循环网络或维护信念状态。部分可观察问题应明确承认这一限制，而不是把任何观测都直接称为满足马尔可夫性的状态。

<a id="sec-2-1"></a>

### 机制展开：状态定义影响是否能用 Markov 递推

只看当前画面可能无法辨别物体速度，同一观察对应不同动作后果。增加历史或内部记忆有助估计，却不保证对任意隐藏过程充分；信念状态把历史变成隐藏状态的后验分布。有限时域的剩余时间也可能必需。先写观察与真实状态的差别，再决定算法输入，避免把环境不可识别问题简单归为网络太小。

<a id="sec-3"></a>

## 3. 回报连接即时与长期

折扣回报为 $G_t=\sum_{k=0}^{\infty}\gamma^kr_{t+k+1}$，通常 $0\le\gamma<1$ 便于控制长期和式；有限回合也可采用 $\gamma=1$，前提是问题与回报定义良好。折扣较大更重视远期，但也增加估计难度。

例如先付成本 -1，下一步获得 10，$\gamma=0.9$ 时回报为 $-1+0.9\times10=8$。只比较当前奖励可能拒绝这条长期有益路径。

<a id="sec-1-1"></a>

### 基础算例：奖励序列与折扣回报逐项相加

未来奖励为 1、2、4，γ=0.5，则当前回报为 $1+0.5\times2+0.25\times4=3$。下一时刻回报为 2+0.5×4=4，因此满足 $G_t=r_{t+1}+\gamma G_{t+1}$。这个递推是 Bellman 思想的样本级起点。若任务在第二步真正终止，不能继续加入第三个奖励；外部采样截断则需根据目标决定尾部估计。先固定奖励与终止，再讨论算法。

<a id="deep-dive-3"></a>

### 深入讲解：即时奖励与长期回报怎样通过状态连接

交互为观察状态、选择动作、收到奖励和下一状态。奖励通常属于一次转移，记号可用rt或r(t+1)，但代码与推导必须一致；把终点奖励重复加在进入和停留两处，会改变任务。

折扣回报G=Σγ^k r让当前动作受到后续影响。小γ更偏近处，γ不是单纯数值稳定开关，它改变优化偏好；无限期有界奖励且γ<1时，回报有相应上界。

状态应足以概括影响未来的历史。若只给当前位置却隐藏速度，相同观察可能有不同下一状态分布；需要更多历史、内部状态或信念，而不是假设任何输入向量都天然Markov。

策略给动作条件分布，环境给下一状态及奖励机制。已知模型可规划，未知模型靠交互估计，二者都受覆盖与机制假设影响，模拟器表现不自动转移现实。

先画小环境的全部转移和奖励，手算两条轨迹折扣回报，再谈学习算法。这样能区分策略真的更好，还是奖励、终止和采样定义变了。

<a id="sec-4"></a>

## 4. 奖励函数表达偏好

同一环境中，“到终点得 1”和“每步得 1、结束后不再得分”可能诱导相反行为。前者鼓励成功，后者可能鼓励拖延。设计环境时先写出希望比较的两条轨迹，再计算各自回报，检查奖励是否给了正确排序。

初始状态分布也是任务的一部分。只从容易位置评估，可能高估策略在全部环境中的能力。对有限回合问题，时间上限如果影响决策，应纳入状态或时间索引，否则相同观测在剩余时间不同的情况下可能对应不同最优动作。

<a id="sec-5"></a>

## 5. 模型已知与未知

已知转移模型时可以对未来期望直接规划，未知时需要从交互样本估计价值或模型。模型式方法学习环境规律后用于规划，无模型方法不显式依赖完整模型，但两者都受数据覆盖限制。

模拟器准确不等于真实环境完全一致。策略可能利用模拟器误差，迁移时需检查动力学、观测和奖励差异，不能只报告模拟回报。

<a id="sec-6"></a>

## 6. 进阶：马尔可夫性与状态充分统计

状态应使 $P(s_{t+1},r_{t+1}\mid h_t,a_t)=P(s_{t+1},r_{t+1}\mid s_t,a_t)$。这是对历史压缩充分性的要求，不是给观察命名为 state 就成立。有限时间任务若省略剩余时间，可能把不同决策情形混在同一状态。

折扣可表达偏好，也使有界奖励的无限和易于控制；gamma 为一的持续任务需另设适定性。奖励设计改变优化对象，规划正确与真实目标一致是两件事，需先比较候选轨迹的回报排序。

<a id="sec-6-1"></a>

### 状态充分性是对未来条件分布的要求

Markov 性要求给定当前状态和动作后，未来转移与奖励分布不再依赖更早历史。它不是“系统没有记忆”，而是所选状态已经包含预测未来所需的信息。位置相同但速度不同的机器人，若只把位置作为状态，就可能不满足这一条件。

有限历史堆叠可以补充信息，却不保证对任意部分可观测过程都充分。信念状态用对隐藏状态的条件分布概括历史，在模型已知等条件下能形成相应决策过程；实际估计通常仍有近似。

回报定义也改变任务。无限时域折扣回报为 $\sum_{k\geq0}\gamma^kr_{t+k+1}$；有限时域任务可能需要把剩余时间加入状态，否则相同观察在不同剩余步数下的最优行动会不同。奖励、终止和状态定义应一起固定，再讨论算法是否正确。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 奖励依次为 2、0、4，折扣为 0.5，初始回报是多少？为何不能把奖励简单相加？

**答案：** $2+0.5\times0+0.5^2\times4=3$。简单相加对应未折扣回报，是另一个目标。折扣选择会影响最优行为，需要与任务意图一致。

<a id="sec-7-1"></a>

### 边界追问：立即奖励更高是否代表长期选择更好

**问题：** 动作 A 先得一分、下一步得负十分并终止，动作 B 先得零分、下一步得二分并终止，γ=0.9。哪个折扣回报更高？

**推理解析：** A 的回报为 1-0.9×10=-8，B 为 0+0.9×2=1.8，所以 B 更好。正的立即奖励不保证长期最优；评价依赖奖励序列、折扣与终止定义。先把各转移的奖励和结束位置写清，再比较策略，不能只用当前一步得分代替完整目标。
