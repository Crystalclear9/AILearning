## 1. 构造确定性导航

状态 0、1、2，状态 2 为终点；向右前进，向左后退且不能越界。非终止奖励 -0.1，进入终点奖励 1，折扣 0.9。最优应尽快向右，但先通过 Bellman 更新求解，而非凭直觉直接写策略。

可先写出可核对的转移：状态 0 向左仍在 0，向右到 1；状态 1 向左到 0，向右进入终点 2；终点价值固定为零，进入终点的奖励已经记在最后一次转移上，不要再额外奖励一次。

最优价值为 V(1)=1、V(0)=−0.1+0.9×1=0.8。若在状态 0 原地一步再前进，回报为 −0.1+0.9×0.8=0.62，低于直接前进。这个手算同时给出转移、奖励时刻及终止处理的测试基准；改变终点奖励或步耗后，应重新求解而不是保留原表。

<a id="sec-2"></a>

## 2. 价值迭代

```python
import numpy as np
V = np.zeros(3)
for _ in range(100):
    new = V.copy()
    for s in (0, 1):
        candidates = []
        for move in (-1, 1):
            ns = min(2, max(0, s + move))
            terminal = ns == 2
            candidates.append(1. if terminal else -0.1 + 0.9*V[ns])
        new[s] = max(candidates)
    if np.max(np.abs(new - V)) < 1e-10:
        V = new
        break
    V = new
print(V)
assert np.allclose(V, [0.8, 1., 0.])
```

同步更新使用上一轮 V，避免把循环顺序混入解释；异步更新也可设计，但要明确算法。终点价值固定为零，因为进入终点奖励已在转移中计算。

<a id="sec-1-1"></a>

### 基础算例：一次同步价值更新能传播几步

三状态 A→B→终点，最后转移奖励 1，其余为 0，γ=0.9，初始值全零。同步第一轮 B 变 1，A 仍为 0；第二轮 A 变 0.9。若按 B 再 A 的顺序原地更新，同一轮就可把信号传回 A。两者中间轨迹不同却可求同一固定点，不能只按相同轮数逐项相等判断实现。检查应包括更新语义、Bellman 残差和最终策略。

<a id="sec-2-1"></a>

### 机制展开：同步轮次对应有限范围的奖励传播

从同一旧表计算新表时，一轮只把旧价值再向前传播一步；原地更新则依遍历顺序可在一轮传播更远。比较实现应核对目标固定点与残差，不要求每轮表相同。停止阈值还受 γ 影响，残差 ε 对应值误差界 ε/(1-γ)。γ 接近一时同样残差不代表同等值精度，预算与精度需分别报告。

<a id="deep-dive-2"></a>

### 深入讲解：三状态导航怎样逐轮算出价值与策略

状态0、1、2，2终止，右移进1或2，左移后退且不越界；进入终点奖励1，其他转移−0.1，γ=0.9。初始V全零，第一轮同步更新使V1=1、V0=−0.1，终点仍0。

第二轮V0=max(−0.1+0.9×旧V0,−0.1+0.9×旧V1)=0.8，V1仍选右得1。此后保持，得到从0立即右移最优。同步更新读取上一轮表，与顺序原地更新的中间轨迹不同，虽在相应条件下可能同收敛。

提取策略时重新比较各动作r+γV(s')，而不是直接取最大状态价值。状态0左停一回的值为−0.1+0.9×0.8=0.62，右为0.8，所以选右；状态1右为1，左为−0.1+0.9×0.8=0.62。

这个例子可同时检查奖励记入、终点不自举、边界自环与动作合法。若实现表不同，先逐转移核对，不要仅增加迭代数。

再改变步耗或折扣，观察策略何时变化，可理解任务定义如何塑造长期偏好。动态规划学习的是对指定环境模型的最优，而非脱离奖励语义的“聪明”。

<a id="sec-3"></a>

## 3. 从价值提取策略

在每个非终止状态比较一步奖励加下一状态折扣价值，选择最大动作。并列时可规定稳定或随机规则，终点无需动作。价值与策略的关系由这个一步展开建立。

若当前价值估计为 V，可构造 $Q_V(s,a)=\sum_{s'}P(s'\mid s,a)[r(s,a,s')+\gamma V(s')]$，再取贪心动作。精确最优 V 对应最优策略；尚未收敛的近似 V 则可能在动作价值接近时选错，不能只因数值残差很小就忽略动作间隙。

提取后可固定该策略重新做策略评价，核对实际价值与原估计是否一致。终止状态、非法动作与并列选择需明确处理；非法动作不应因默认填零而优于合法的负回报动作。这样同时检验价值计算和策略输出接口。

<a id="sec-4"></a>

## 4. 价值迭代的轮次含义

初始 V 为零，第一轮只有能直接到终点的状态一获得价值一；第二轮状态零通过状态一得到负零点一加零点九，即零点八。奖励信息沿转移关系向前传播，而非一次神奇地知道所有未来。

状态零向左会停在原地，候选是负零点一加折扣后的自身价值；向右更好。终点不再更新，所以没有通过自循环反复领取一次性奖励。这个边界是许多初学实现的关键。

同步更新与异步更新可有不同迭代路径，但应在各自条件下研究收敛。教学中复制上一轮值便于解释每轮信息传播，实际大问题可能采用其他顺序。算法细节应与报告一致。

<a id="sec-5"></a>

## 5. 综合算例与实现核对

将折扣改为零时，状态零只看本步负奖励，不再重视终点未来收益；此时动作可能按即时回报并列。改为接近一，延迟终点收益损失更少，但每步负代价仍鼓励短路径。

若在每个非终点增加正奖励，循环可能变得更有吸引力。先手算无限或有限累计，检查是否仍偏好完成。算法得到与直觉不同策略时，先检查目标排序，不急于认定更新错误。

动态规划使用已知确定转移，不能据此推导未知随机环境也只需两轮。采样学习还有访问和估计噪声，理论条件与信息来源不同，应在从规划转向强化学习时明确区分。

<a id="sec-6"></a>

## 6. 进阶：同步异步更新与模型已知前提

同步价值迭代每轮用旧表，便于跟踪奖励传播；异步可就地更新，在适当覆盖与折扣条件下也能收敛，但每轮含义不同。迭代次数比较必须说明更新单位和顺序。

小确定环境的两轮传播依赖模型已知，不代表采样学习只需同样次数。未知转移还需探索与估计，随机回报引入方差。终点价值与进入奖励应采用一致约定，重复计入会改变任务而不是仅产生计算误差。

<a id="sec-6-1"></a>

### 同步更新与原地更新为何轨迹不同

同步价值迭代从同一份旧 V 计算所有新状态值，便于把第 k 轮解释为统一层数的传播。原地异步更新会立即使用本轮已更新的邻居值，传播速度依赖状态遍历顺序；在适当条件下可收敛到相同固定点，但中间数值不必相同。

以确定性链为例，奖励在末端，从靠近终点向前遍历的原地更新可在一轮把信号传得更远；相反顺序则较慢。只比较相同轮数的结果，可能把更新顺序差异误认为算法错误。应检查最终残差及策略，而不是要求所有中间表逐项一致。

规划需要已知转移与奖励模型；从采样轨迹估计更新属于另外的信息条件。验收时列出每个动作的后继状态、奖励与终止，再手算一轮 Bellman 更新。模型本身若写错，再精确的价值迭代也只会求出错误环境的最优策略。

<a id="sec-7"></a>

## 7. 练习与解析

**题目：** 把进入终点奖励既加在转移上，又令终点 V=1，会怎样？

**解析：** 把同一收益重复计入，改变任务目标。必须统一本步奖励和终点价值约定，不能在两处各加一次。

<a id="sec-7-1"></a>

### 边界追问：同步与原地迭代需逐轮一致吗

**问题：** 两实现最终策略一致，但中间表因遍历顺序不同，是否必须修成逐项相同？

**推理解析：** 不必，先确认一种使用旧表同步、另一种即时复用本轮值。它们可在相应条件下有同一固定点而传播速度不同。验收更新规则、最终残差、策略与预算，不把轮数当相同计算量，也不能由最后碰巧一致忽略模型写错。
