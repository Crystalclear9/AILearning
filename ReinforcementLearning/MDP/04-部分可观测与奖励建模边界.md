## 1. 观察不是完整状态

单张画面无法确定速度，单次交易无法确定用户历史。可使用历史堆叠、循环状态或信念分布，但有限摘要未必完全恢复马尔可夫性。模型应承认信息限制，不把不可观察结果当作可确定预测。

<a id="sec-1-1"></a>

### 基础算例：观察相同不代表决策状态相同

两辆车当前位置相同，一辆高速前进，另一辆静止。若观察只有位置，相同输入对应的下一位置分布不同；速度或相关历史可能是所需状态信息。有限时域任务还可能需要剩余时间。补历史并非任意问题的充分解，信念状态则用隐藏状态分布概括信息。建模前先问当前输入是否足以预测动作后果，避免把状态缺失误当算法训练不够。

<a id="deep-dive-1"></a>

### 深入讲解：部分可观测与有限时域为何需要扩展状态

若同一观察对应不同隐藏状态，单看观察的策略可能无法区分后果。历史摘要、递归状态或信念分布可补信息；信念是给定过去观察动作后的隐藏状态后验，并非简单把所有历史拼长就自动充分。

有限时域任务剩余时间会影响最优动作，必要时将时间纳入状态。任务到期真正结束与外部运行上限截断不同，前者无未来价值，后者可能仍需自举；判定依据任务而非是否reset。

任意奖励塑形可能改变最优策略，例如每步小正奖鼓励拖延。势函数形式F=γΦ(s')−Φ(s)的折扣和可望远镜相消，在有界、终点等相应条件下只差与选择无关项，才有保策略解释。

如果终点势不处理，有限轨迹尾项可能依终点变化，不能省略边界后继续引用结论。用带循环与捷径的小MDP手算候选轨迹，最易暴露刷奖励问题。

模型与奖励都只是现实任务的表达。先确认观察足够、时域一致和成功定义正确，随后算法优化结果才可能对应真正需求。

<a id="sec-2"></a>

## 2. 时间限制

若任务规定必须在 100 步内完成，剩余时间影响最优动作，应进入状态或时间相关价值。若训练仅为计算方便在 100 步截断，而底层任务继续，则截断通常保留 bootstrap。两种语义不能混用。

<a id="sec-2-1"></a>

### 机制展开：外部时间限制与任务终止由定义区分

有限任务到期是真正终止，持续任务被采样器打断则可能保留最终状态价值。自动 reset 返回的新初始观察不能当作截断转移的后继值。若到期改变最优动作，剩余时间应纳入状态。mask 应依据转移语义生成，而不是把所有结束标记统一处理；手算一个正尾部和一个负尾部可看出错误清零的偏差方向不同。

<a id="sec-3"></a>

## 3. 奖励塑形

给中间进展奖励可以改善探索，也可能改变最优策略。基于势函数的特定塑形形式在相应条件下有保策略性质，任意加奖励则没有同样保证。先算几条候选轨迹，检查奖励是否符合真正目标。

常见势函数塑形为 $F(s,a,s')=\gamma\Phi(s')-\Phi(s)$。沿长度 T 的轨迹，其折扣和为 $-\Phi(s_0)+\gamma^T\Phi(s_T)$。在无限折扣情形且势有界时，尾项消失；在有限 episode 中，应恰当处理终点势，例如令其为零，使相同初态下的回报只差与动作无关的常数。

若任务时域有限，可使用与时间相符的势并设置终点边界；任意给“靠近目标”正奖励却不给返回时相应负项，不具有上述抵消结构，可能鼓励循环刷分。先在一个有捷径和循环的小 MDP 中手算原奖励与塑形奖励下的候选轨迹，再讨论是否保持策略排序。

<a id="sec-4"></a>

## 4. 用候选轨迹验证奖励偏好

列出快速完成、慢速完成、永远徘徊三条轨迹，计算各自折扣回报。如果奖励让徘徊最高，训练学到拖延正是优化正确、目标错误。先在简单路径上审查奖励，能避免长时间训练后误把目标设计问题归咎算法。

部分可观测还意味着相同画面可能需要不同动作。历史堆叠和循环状态提供线索，但若关键变量从未被观测，模型无法凭空恢复。评价应允许合理不确定性，并明确观察限制。

模型式规划的误差会随多步展开累积。学习的模拟模型在常见区域准确，不代表极端策略访问区域也准确；策略可能利用其漏洞。实际迁移需要独立验证动力学与行为，而非只看模型预测训练损失。

<a id="sec-5"></a>

## 5. 综合算例与实现核对

同一位置但剩余一步与剩余十步，可能需要不同动作。如果状态只存位置，模型无法区分两个情形，转移和回报分布会显得依赖隐藏历史。加入剩余时间可把有限时任务描述得更完整。

对外部截断，环境可能需要 reset 才继续采样，但价值目标仍代表底层任务未来。实现应保留截断前最终观察，而不是把 reset 后初始状态混作下一状态。

练习时分别写一个固定期限任务和一个持续任务加采样上限，列出终止与截断处理。这能明确同一接口返回值在不同任务语义下为何有不同 bootstrap 规则。

<a id="sec-6"></a>

## 6. 进阶：势函数塑形与部分可观察性

塑形奖励 $F(s,a,s')=\gamma\Phi(s')-\Phi(s)$ 在适当边界与折扣条件下沿轨迹望远镜相消，回报相差由初始势和终端项控制，因此可保留相应最优策略。任意进度奖励没有同样保证。

POMDP 可用历史条件下的状态信念作为充分统计，但精确维护常昂贵。循环表示是近似记忆，不保证恢复全部信息。外部截断与任务终止需分别处理，reset 后新观察不能冒充截断前的下一状态。

<a id="sec-6-1"></a>

### 势函数塑形的策略保持来自望远镜求和

将奖励改为 $r'_t=r_t+\gamma\Phi(s_{t+1})-\Phi(s_t)$，折扣求和后的附加项大多抵消，留下起点项和尾项。在无限折扣且势函数有界等条件下，尾项消失，对同一起点所有策略增加相同常数，因此保持相应最优策略排序。

有限回合需正确处理终止势函数，否则剩余尾项可能依赖到达何处或何时，改变策略偏好。随意奖励“靠近目标”不是自动满足上述形式；如果奖励可被反复领取，智能体可能循环刷分而不完成任务。

奖励设计可先构造几条候选行为，手算原奖励与新奖励，检查完成、拖延、循环和危险捷径的排序。部分可观测时，奖励还可能依赖智能体看不到的信息；此时应区分训练信号可用性与策略观察输入，不能把隐藏答案直接作为可部署状态。

<a id="sec-7"></a>

## 7. 练习与解析

**题目：** 机器人每走一步都获正奖励，完成任务后停止获奖，可能学到什么？

**解析：** 可能拖延结束以持续积累奖励。应使奖励对成功、时间与安全的排序符合原任务，而非只增加“鼓励行动”的正数。

<a id="sec-8-2"></a>

### 边界追问：任意接近目标奖励都保持最优策略吗

**问题：** 给每步靠近目标加分，智能体来回移动刷分，这与势函数塑形结论矛盾吗？

**推理解析：** 不矛盾，任意奖励未必写成 γΦ(s′)-Φ(s)，终止尾项也可能未正确处理。策略保持有明确条件。列候选行为手算折扣总和，确认完成、拖延与循环排序，再评价真实成功率，不用改过的高奖励自证任务完成。

<a id="sec-8"></a>

## 8. 进阶研究练习与解析

**问题：** 证明 Bellman 最优算子的 sup 范数收缩，并说明 gamma=1 时缺少哪一步。

**解析：** 每个动作的期望差不超过 gamma 乘价值最大差，两个最大值的差不超过对应动作差的最大值，因此得到收缩系数 gamma。小于一时可用固定点结论；等于一只得到不扩张，不能直接保证唯一固定点和同样收敛，需要任务适定性等额外条件。

**实验：** 对有限回合和含零奖励自循环的持续任务分别迭代，比较边界和解唯一性。终点约定、时间状态和奖励定义应与理论一致。

<a id="sec-8-1"></a>

### 综合练习：有限时域的到期与外部截断

**问题：** 两个环境都在第十步结束，是否都应将尾部值设为零？

**逐步解析与验收：** 若第十步是任务定义的真正终止，尾部为零；若只因外部采样时限而中断持续任务，可保留合法最终状态自举。有限时域若最优行动依赖剩余时间，应把它纳入状态。验收先写任务定义，再确定 mask，不能只根据 reset 发生与否决定。
