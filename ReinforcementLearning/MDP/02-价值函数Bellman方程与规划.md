## 1. 状态价值与动作价值

$V^\pi(s)=E_\pi[G_t\mid s_t=s]$ 表示按策略行动时状态的长期价值；$Q^\pi(s,a)=E_\pi[G_t\mid s_t=s,a_t=a]$ 先固定当前动作，之后再遵循策略。状态价值可通过动作价值按策略求平均得到。

Bellman 期望方程为

$$V^\pi(s)=\sum_a\pi(a\mid s)E[r+\gamma V^\pi(s')\mid s,a].$$

它把整个未来拆成一步奖励加下一状态价值。递归不是忽略未来，而是用一个函数概括之后的长期结果。

<a id="sec-1-1"></a>

### 基础算例：两状态价值方程求解一次

状态 A 每次奖励 1 并确定转到 B，B 每次奖励 2 且保持 B，γ=0.5。则 VB=2+0.5VB，得 VB=4；VA=1+0.5×4=3。价值不是当前奖励，而是未来折扣总和。若 B 被定义为到达后真正终止，方程应重新写，不能沿用持续自环价值。模型已知时可解方程或迭代，未知时才从采样估计相应期望。

<a id="sec-2"></a>

## 2. 最优性与动态规划

最优动作价值满足 $Q^*(s,a)=E[r+\gamma\max_{a'}Q^*(s',a')\mid s,a]$。已知模型时，价值迭代反复应用最优 Bellman 更新；策略迭代交替评估当前策略并贪心改进。

对有限状态动作、奖励有界且 $0\le\gamma<1$ 的标准折扣 MDP，Bellman 最优算子具有收缩性质，支持相应收敛结论。大规模或未知环境则无法直接枚举所有转移，需要采样与函数近似。

<a id="sec-2-1"></a>

### 机制展开：策略评估与策略改进分别改变什么

固定策略 π 的 Bellman 期望算子对动作按 π 加权，用于求 Vπ；最优算子把动作期望换为 max，对应寻找最佳选择。策略迭代先评估当前策略再贪心改进，价值迭代则交替进行更局部的最优更新。精确有限折扣条件下的保证不能直接推广到任意近似网络与采样更新。明确算子与信息条件，才能解释算法差异。

<a id="deep-dive-2"></a>

### 深入讲解：Bellman递推为何能从一步关系恢复长期价值

固定策略价值Vπ是从状态出发的期望回报。把首步奖励与其余回报分开，得到Vπ(s)=E[r+γVπ(s')|s,π]；Qπ先固定首动作。方程来自期望分解，不是凭经验构造的训练目标。

有限MDP可写V=rπ+γPπV，γ<1时满足相应可逆与收缩性质。Bellman算子在最大范数下差至多γ倍，因此反复精确应用趋向唯一不动点；这一证明不能无修改推广到带函数近似和采样的神经网络更新。

最优算子在动作上取max，价值迭代逐步逼近，策略改善依据当前一步动作价值。并列动作、非法动作和终点需明确定义，默认零值可能错误优于合法负回报动作。

真正终止后无未来回报，目标不自举；人为截断若任务还可继续，应保留合法下一状态价值。自动reset的新初态不能当截断前下一状态，否则会串错价值。

用已知小系统解线性方程与迭代对照，再转到采样TD，才能理解规划误差、估计噪声和近似偏差分别从哪来。

<a id="sec-3"></a>

## 3. 真正终止与外部截断

任务进入终止状态后，不应再加入未来任务价值；外部时间限制导致的截断，若底层任务仍会继续，通常仍需 bootstrap。若有限时间本来就是任务定义的一部分，剩余时间应纳入状态或另用时间相关价值。混淆两种边界会使价值目标有偏：把本应继续的正未来价值置零会低估，若未来价值为负则可能高估，不能一概断言偏差方向。

<a id="sec-4"></a>

## 4. Bellman方程是自洽条件

价值不是一个独立于策略的状态评分。换策略后，未来行动改变，$V^\pi$ 也改变。一个危险状态若策略能立即逃离，价值可能尚可；同一状态在错误策略下则可能很差。比较价值时必须明确所对应的策略。

动态规划需要转移模型的期望，采样学习只看到部分转移。把一次奖励当成其期望可能噪声很大，因此价值估计通常要逐步平均。有限状态中的精确收敛性质也不能自动推广到神经网络近似，近似误差会在 bootstrap 中继续传播。

<a id="sec-5"></a>

## 5. Bellman更新与采样误差

精确动态规划对所有可能下一状态求期望，TD 只使用采样转移估计。一次目标可能噪声很大，反复更新后才能稳定。对确定性小环境有效的学习率不能直接视为随机大环境默认最佳值。

策略改善还需要探索有效动作；未见动作的高估值可能诱导错误选择。规划与估计的数学关系清楚后，才便于理解深度方法的不稳定性。

<a id="sec-6"></a>

## 6. 进阶：Bellman收缩证明与误差界

对有界价值函数，$\|TV-TW\|_\infty\le\gamma\|V-W\|_\infty$，因为期望与 max 都不会放大 sup 差异。gamma 小于一时，收缩保证唯一固定点与反复更新收敛。

还可由三角不等式得到 $\|V-V^*\|_\infty\le\|TV-V\|_\infty/(1-\gamma)$。这把 Bellman 残差联系到价值误差，但要求使用真实算子和全状态 sup，采样近似神经网络残差不能无条件套同一保证。

<a id="sec-6-1"></a>

### Bellman 收缩证明中最大值不等式的作用

对最优算子 T，利用 $|\max_a u_a-\max_a v_a|\leq\max_a|u_a-v_a|$ 以及转移概率归一，可得 $\|TV-TW\|_\infty\leq\gamma\|V-W\|_\infty$。当 $0\leq\gamma<1$ 且值函数空间满足相应条件时，固定点唯一，重复精确更新收敛。

若当前近似残差 $\|TV-V\|_\infty\leq\epsilon$，可由三角不等式得 $\|V-V^*\|_\infty\leq\epsilon/(1-\gamma)$。γ 接近 1 时，同样 Bellman 残差对应更松的值误差界，因此不能给所有折扣率使用相同停止阈值解释精度。

这些结论针对精确算子与指定范数，不自动保证神经网络、采样、离策略和投影组合后的更新仍收缩。终止处理错误更会改变算子本身。理论保证、数值近似和环境语义应分开检查，避免把表格规划结论直接套到深度训练曲线。

<a id="sec-7"></a>

## 7. 练习与参考答案

**练习：** 一个动作确定获得 3 并真正终止，另一个获得 0 后进入价值为 5 的状态，$\gamma=0.9$ 时应选哪个？

**答案：** 两者价值分别为 3 和 4.5，若估计正确应选后者。真正终止的动作不能再加一个虚构的下一状态价值。

<a id="sec-7-1"></a>

### 边界追问：Bellman 收缩能否直接保证深网训练

**问题：** 表格折扣最优算子收缩，加入采样、离策略和神经网络投影后是否仍必然收敛？

**推理解析：** 不能直接推广，近似更新已是另一算子或随机过程，可能失去相同范数下收缩。理论条件、函数逼近和环境语义各需检查。先验证小模型精确更新，再研究近似残差与行为，不能仅用损失下降宣称最优固定点已得到。
