# 马尔可夫决策过程

建立状态、动作、奖励和长期回报的统一描述，理解 Bellman 方程。

**先修知识：** 概率、条件期望；基础优化。

## 学习顺序与覆盖范围

基础正文解释概念与计算，各章的进阶小节讨论证明、方法联系、实现等价条件与失效反例。已有基础可直接使用章内目录进入进阶；本主题最后一章另有研究练习和解析。阅读策略见[进阶学习路线](../../学习路线.md#advanced)。

| 章节 | 主要内容 | 深入讲解入口 |
| --- | --- | --- |
| [状态动作奖励与回报](01-状态动作奖励与回报.md) | 智能体与环境的交互；状态可能没有被完整观察；进阶：马尔可夫性与状态充分统计 | [进入讲解](01-状态动作奖励与回报.md#deep-dive-3) |
| [价值函数Bellman方程与规划](02-价值函数Bellman方程与规划.md) | 状态价值与动作价值；最优性与动态规划；进阶：Bellman收缩证明与误差界 | [进入讲解](02-价值函数Bellman方程与规划.md#deep-dive-2) |
| [有限状态动态规划完整算例](03-有限状态动态规划完整算例.md) | 构造确定性导航；价值迭代；进阶：同步异步更新与模型已知前提 | [进入讲解](03-有限状态动态规划完整算例.md#deep-dive-2) |

## 如何完成本主题

完成各章后，先独立作答[综合练习：有限时域的到期与外部截断](04-部分可观测与奖励建模边界.md#sec-8-1)，再对照逐步解析与验收要求。

读完一章后，先不看答案复述定义、假设与计算过程，再完成正文实验和练习。代码章节要能解释每个轴、变量和关键步骤；理论章节要能手算一个例子，并指出结论在哪些条件下成立。遇到不熟悉的先修概念，返回相关主题补学。
